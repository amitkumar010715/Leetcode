Let's break down the problem step by step:

---

## 1. **Short Summary**

Given an array of integers, for each number, if it **has exactly four divisors**, add the **sum of those divisors** to the answer. Return the total sum for the whole array.

---

## 2. **Constraints & Edge Cases**

- Constraints:
  - `1 <= nums.length <= 10^4` (reasonable, up to 10,000 elements)
  - `1 <= nums[i] <= 10^5` (the highest possible value in nums is 100,000)
- Edge cases:
  - Numbers with fewer or more than 4 divisors are ignored.
  - Numbers with repeats (e.g., `[21,21]`) are counted each time.
  - There may be no numbers with exactly four divisors (output `0`).
  - Small numbers (e.g., 1, 2, 3, 5, 7) will usually NOT have 4 divisors.

---

## 3. **Optimal Algorithm**

<div style="font-size: 1.05em">

### **Observation:**
A number has **exactly 4 positive divisors** if and only if:
1. **It's the product of two distinct primes:** `num = p * q` (divisors: `1, p, q, pq`)
2. **It's a cube of a prime:** `num = p^3` (divisors: `1, p, p^2, p^3`)

All other numbers do **not** have exactly 4 divisors.

### **Algorithm Steps:**

1. **Precompute primes up to sqrt(1e5) using Sieve of Eratosthenes.**
   - (Since cubes up to 1e5 only need primes up to 100)

2. For each number `n` in `nums`:
   - **Case 1: Check if n == p^3 for prime p.**
     - Compute the integer cube root and check exact match and primeness.
   - **Case 2: Check if n == p * q for two distinct primes p, q (p < q).**
     - For each prime `p <= sqrt(n)`, check if `q = n / p` is an integer, not equal to `p`, and is prime.

3. If n matches either case,
   - For `p^3`, divisors are `1, p, p^2, n`; sum: `1 + p + p^2 + n`.
   - For `p*q`, divisors are `1, p, q, n`; sum: `1 + p + q + n`.

4. Add the sum to the answer.

### **Complexity:**
- Sieve: O(N log log N)
- For each num: O(sqrt(num)) for searching divisors or primes (acceptable since num ≤ 1e5 and nums.size ≤ 1e4)

</div>

## 4. **C++ Solution**

```cpp
#include <vector>
#include <cmath>
#include <numeric>
using namespace std;

// Sieve to get all primes up to limit
vector<int> getPrimes(int limit) {
    vector<bool> isPrime(limit+1, true);
    vector<int> primes;
    isPrime[0]=isPrime[1]=false;
    for(int i=2;i<=limit;++i) {
        if(isPrime[i]) {
            primes.push_back(i);
            for(int j=i*i;j<=limit;j+=i)
                isPrime[j]=false;
        }
    }
    return primes;
}

class Solution {
public:
    int sumFourDivisors(vector<int>& nums) {
        const int MAXN = 1e5;
        // Primes up to sqrt(1e5) is enough
        auto primes = getPrimes((int)sqrt(MAXN)+10);
        vector<bool> isPrime(MAXN+1, true);
        isPrime[0]=isPrime[1]=false;
        for(int p:primes) isPrime[p] = true;
        for(int i=2;i<=MAXN;++i)
            if(i>=primes.back() && isPrime[i])
                for(int j=i*2;j<=MAXN;j+=i)
                    isPrime[j]=false;
        
        int ans = 0;
        for(int n : nums) {
            int sum = 0;
            // Case 1: Cube of a prime
            int root = round(pow(n, 1.0/3)); // Cube root
            if(root*root*root==n && root > 1 && isPrime[root]) {
                sum = 1 + root + root*root + n;
            } else {
                // Case 2: Product of two distinct primes
                for(int p : primes) {
                    if(p * p > n) break;
                    if(n % p == 0) {
                        int q = n / p;
                        if(q != p && q > 1 && isPrime[q]) {
                            sum = 1 + p + q + n;
                        }
                        break; // Only one such pair possible
                    }
                }
            }
            ans += sum;
        }
        return ans;
    }
};
```

## 5. **Example Explanation**

### Example Input:
```cpp
nums = [21, 4, 7]
```

Let's process each:

- **21:**
  - Divisors: 1, 3, 7, 21 (**exactly 4**; 3 and 7 are primes and 21 = 3*7).
  - Sum: 1 + 3 + 7 + 21 = **32**
- **4:**
  - Divisors: 1, 2, 4 (only 3 divisors).
- **7:**
  - Divisors: 1, 7 (only 2 divisors).

**Only 21 qualifies,**
so total is **32**, which matches the output.
