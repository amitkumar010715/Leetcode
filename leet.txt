## 1. **Short Summary**

Given a non-negative integer `n`, the problem asks for its *bitwise complement* with respect to its binary representation (i.e., flip every bit from 0 to 1 and vice versa), and to return the corresponding integer value.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**  
  - `0 <= n < 10^9`
- **Edge Cases:**  
  - `n = 0`: Binary is "0"; flipping gives "1" (`1` in decimal).
  - Input always fits within a 32-bit signed integer.
  - The complement should only flip the bits in the original number's binary digits (i.e., leading zeros are ignored).

---

## 3. **Optimal Algorithm**

1. **Find a bitmask** that has 1s in all places where `n` has bits (i.e., the smallest number of the form 2^k - 1 that is >= n). For instance, if `n = 5` (`101`₂), the mask is `111`₂.
2. **Flip the bits** by taking the bitwise NOT of `n`, but restrict to relevant bits by using the mask:
    ```
    complement = (~n) & mask
    ```
3. **Return complement**.

- **Time Complexity:** O(1) or O(log n), due to bit counting.

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int bitwiseComplement(int n) {
        if (n == 0) return 1;
        int mask = 0;
        int temp = n;
        while (temp > 0) {
            mask = (mask << 1) | 1;
            temp >>= 1;
        }
        return (~n) & mask;
    }
};
```

---

## 5. **Example Explanation**

**Example:**  
n = 10

- Binary: `1010`
- Mask: Since `1010` has 4 bits, mask is `1111` (binary), i.e., 15 (decimal).
- `~n` in bits: `...11111111111111111111111111110101` (bitwise NOT in 32 bits for 10 is all-ones except the original bits)
- `(~10) & 15` is `0101` in binary, which is `5` in decimal.

**Thus, `bitwiseComplement(10)` returns `5`.**
