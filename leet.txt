## 1. **Summary**

We have an `m x n` grid of integers, and in one operation, we can add or subtract a given number `x` from any grid cell. The goal is to make all grid cells have the same value (uni-value grid) with as few operations as possible. If it's not possible, return `-1`.

---

## 2. **Constraints & Edge Cases**

- **Grid size**: `1 ≤ m, n ≤ 1e5` (but total cells `m * n ≤ 1e5`, so grid is a 1D array conceptually).
- **Cell value and x:** `1 ≤ x, grid[i][j] ≤ 1e4`
- **Not possible**: If the difference between any pair of values isn't divisible by `x`, we can't make the grid uni-value.
- **Edge Cases**:
    - All elements are already equal ⇒ 0 operations.
    - Impossible cases: Return -1.
    - Large grid but total elements capped to `1e5`.

---

## 3. **Optimal Algorithm**

**Step 1:**  
Flatten the grid into a 1D array for easier processing.

**Step 2:**  
Check that for all elements, `(cell value - first cell value) % x == 0`. If not, return `-1`.

**Step 3:**  
Let’s define `b[i] = (cell value - base) / x` for all cells, where `base` is the value of the first cell.  
Now, making all values equal is equivalent to making all `b[i]`s equal via increment/decrement by 1.

- The minimum number of operations needed (for standard integer grid median minimization) is minimized by making all `b[i]` equal to their median value.

**Step 4:**  
Find the median of the `b[]` values.  
Sum up `abs(b[i] - median)` for all i.  
Total operations = this sum.

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int minOperations(vector<vector<int>>& grid, int x) {
        vector<int> vals;
        int m = grid.size(), n = grid[0].size();
        int base = grid[0][0];
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                int diff = grid[i][j] - base;
                if (diff % x != 0) return -1;
                vals.push_back(diff / x);
            }
        }
        sort(vals.begin(), vals.end());
        int median = vals[vals.size() / 2];
        int result = 0;
        for (int b : vals) {
            result += abs(b - median);
        }
        return result;
    }
};
```

## 5. **Example Explanation**

### Example 1
```
grid = [[2,4],[6,8]], x = 2
Step 1: Flatten → [2, 4, 6, 8]
base = 2
Check: each (val - 2) % 2 == 0 ⇒ Yes

b[] = [(2-2)/2, (4-2)/2, (6-2)/2, (8-2)/2] = [0, 1, 2, 3]
Median of [0,1,2,3] = 1.5 → But since indexes, use index 2 → median = 2

Sum abs(b[i] - 1): 
|0-1| + |1-1| + |2-1| + |3-1| = 1 + 0 + 1 + 2 = 4

Total operations = 4
```
So, the answer is **4**.
