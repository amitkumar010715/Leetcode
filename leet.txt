---

## 1. **Short Summary**

Given integers `n` and `t`, find **the smallest integer** `x` such that `x ≥ n` and the **product of its digits** is divisible by `t`.

---

## 2. **Constraints & Edge Cases**

- `1 ≤ n ≤ 100`
- `1 ≤ t ≤ 10`

**Edge Cases:**
- **Product is 0:** Any number containing digit `0` has a product of digits equal to 0, so it is always divisible by `t` unless `t == 0` (not possible here).
- **t = 1:** All numbers have a product divisible by 1.
- **Single-digit `n`:** Handle cases where `n` is a single digit (`1 ≤ n ≤ 9`).
- The range is very small (`n` up to 100), so brute-force solution is feasible and efficient.

---

## 3. **Optimal Algorithm**

Since `n` is up to 100, we can **simply iterate from `n` upwards**, for each number:
- Compute the product of its digits.
- If that product is divisible by `t`, return the number.

Product calculation:
- For a number `x`, extract digits and multiply (careful: if a digit is `0`, product immediately becomes `0`).

**Why is this optimal?**
- Max 2-digit numbers only, so even checking up to a few numbers per query is fast.

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    int smallestDivisibleDigitProduct(int n, int t) {
        for (int x = n; ; ++x) {
            int product = 1;
            int y = x;
            if (y == 0) product = 0;
            else {
                while (y > 0) {
                    int d = y % 10;
                    product *= d;
                    y /= 10;
                }
            }
            // If product == 0, it is divisible by any t > 0
            if (product % t == 0)
                return x;
        }
        // Should never reach here because solution always exists for given constraints
        return -1;
    }
};
```

## 5. **Example Explanation**

### Example 2

> **Input:** `n = 15, t = 3`

**Start checking from 15:**

- **15:** Digits: 1 and 5; Product: 1 * 5 = 5. 5 % 3 != 0.
- **16:** Digits: 1 and 6; Product: 1 * 6 = 6. 6 % 3 == 0.

**So 16 is the answer.**
