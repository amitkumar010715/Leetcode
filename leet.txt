## 1. **Short Summary**

Given an array `nums` and an integer `target`, you start at index `0`. From index `i`, you can jump to any `j > i` (i.e., to the right), only if `nums[j] - nums[i]` is in the range `[-target, target]`. The goal is to **maximize** the number of jumps needed to reach the last index (`n-1`). If you can't reach it, return `-1`.

---

## 2. **Constraints & Edge Cases**

### **Constraints**
- `2 <= n <= 1000` (small enough for O(n²) solutions)
- `nums[i]` can be large (`-1e9` to `1e9`), but only their differences are used.
- `0 <= target <= 2e9` (including `0`, which can block all jumps)

### **Edge Cases**
- If `target == 0`, can only jump to a `j` such that `nums[j] == nums[i]`.
- If there are no valid jumps at all, output is `-1`.
- It's possible that you can reach `n-1` by multiple paths; we need **the one with the maximum number of jumps**.
- If only direct jump from `0` to `n-1` is possible, answer is `1`.

---

## 3. **Optimal Algorithm**

Since `n` is at most 1000, an **O(n²) DP** is feasible.

- **State:** Let `dp[i]` be the maximum number of jumps needed to reach index `i`; initialize all values to `-1`.
- **Transition:** For every `j > i`, if `abs(nums[j] - nums[i]) <= target`, we can jump from `i` to `j`, and do:  
  `dp[j] = max(dp[j], dp[i] + 1)`.
- Start with `dp[0]=0` (0 jumps to reach index 0).
- Iterate forwards; for each `i`, update possible `j`s.
- Finally, if `dp[n-1] == -1`, output `-1` (cannot reach); else output `dp[n-1]`.

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maximumJumps(vector<int>& nums, int target) {
        int n = nums.size();
        vector<int> dp(n, -1);
        dp[0] = 0;
        for (int i = 0; i < n-1; ++i) {
            if (dp[i] == -1) continue; // Unreachable
            for (int j = i+1; j < n; ++j) {
                int diff = nums[j] - nums[i];
                if (diff >= -target && diff <= target) {
                    dp[j] = max(dp[j], dp[i] + 1);
                }
            }
        }
        return dp[n-1];
    }
};
```

## 5. **Example Walkthrough**

**Example 1:**

```
nums = [1,3,6,4,1,2], target = 2
```

### Step-by-Step:

- Start at idx 0 (`dp[0]=0`).
- From 0, check jumps:
  - idx 1: diff = 3-1 = 2 ∈ [-2,2] → dp[1]=1
  - idx 2: diff = 5 (not within bounds)
  - idx 3: diff = 3 (not within bounds)
  - idx 4: diff = 0 ∈ [-2,2] → dp[4]=1
  - idx 5: diff = 1 ∈ [-2,2] → dp[5]=1
- Now, from idx 1 (`dp[1]=1`):
  - idx 2: 6-3=3 (not valid)
  - idx 3: 4-3=1 ∈ [-2,2], so dp[3]=2
  - idx 4: 1-3=-2 ∈ [-2,2], so dp[4]=max(1,2)=2
  - idx 5: 2-3=-1 ∈ [-2,2], so dp[5]=max(1,2)=2
- Continue to idx 3 (`dp[3]=2`):
  - idx 4: 1-4=-3 (not valid)
  - idx 5: 2-4=-2 ∈ [-2,2], so dp[5]=max(2,3)=3

At the end, `dp[5]=3` is the answer.
