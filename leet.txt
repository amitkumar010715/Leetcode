Let's tackle the **Apply Operations on Array to Maximize Sum of Squares** problem step by step.

---

## 1. Summary

Given an array and an operation (for any two distinct indices, set one to `(nums[i] & nums[j])` and the other to `(nums[i] | nums[j])`), apply any sequence of these operations, then select `k` elements from the final array to maximize the **sum of their squares**.

---

## 2. Constraints & Edge Cases

- `1 <= k <= nums.length <= 1e5`
- `1 <= nums[i] <= 1e9`
- Need an **O(n log n)** or **O(n)** solution due to large `n`.

**Edge Cases:**
- `k == n`: Must use all elements.
- All elements already have similar or disjoint bits.
- Maximum value can be very large; use modulo `1e9+7`.

---

## 3. Optimal Algorithm & Insight

### **Key Observations**

- Every operation only **redistributes bits between two numbers**; their bitwise combined count (sum) is unchanged.
- **The sum of all bits' counts in the array is invariant**.
- The operation (AND/OR) only 'moves' bits; it can't create or destroy them.
- **Squaring favours numbers with more set bits combined**; to maximize sum of squares, **concentrate as many set bits as possible into as few numbers as possible**.

### **How to Maximize the Sum of Squares?**

- Distribute the total set bits in all numbers such that the top `k` numbers have as **many set bits as possible**, the rest are minimized (ideally 0).
    - *Equivalently*, form `k` new numbers whose bitwise representation collects all the set bits in nums (preserving the per-bit total counts).

#### **Concrete Steps**

1. For each bit position `b` (up to 30 for 1e9), **count** how many times the bit is set in the entire array (`cnt[b]`).
2. To maximize the sum of squares, **assign the bits to the top k numbers as evenly as possible**:
    - For each bit, distribute `cnt[b]` times among the k, i.e., if `cnt[b]>=k` then each gets one, remaining get extra as appropriate.

#### **Implementation:**
- For k numbers, build an array `[0, 0, ..., 0]` of size k.
- For each bit from 0 to 30:
    - Distribute the set bits for that bit among the k numbers round-robin.
- When done, sum up the squares of these k numbers.

**This approach is O(n + k*maxbit) = O(n)**, since generally, k <= n and 32 bits at most.

#### **Why this works**
- You can "gather" bits using the allowed operation.
- The key to maximize the sum of squares is to concentrate bits into as few numbers as possible.

---

## 4. C++ Solution

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maximumSumOfSquares(vector<int>& nums, int k) {
        const int MOD = 1e9+7;
        const int MAXB = 30;
        int n = nums.size();
        vector<int> bitCount(MAXB+1, 0);

        // Count bits
        for (int num : nums) {
            for (int b = 0; b <= MAXB; ++b) {
                if ((num >> b) & 1) bitCount[b]++;
            }
        }

        // The k numbers we're building
        vector<long long> vals(k, 0);

        // Distribute bits (from high to low for large numbers, but order doesn't matter)
        for (int b = 0; b <= MAXB; ++b) {
            int cnt = bitCount[b];
            for (int i = 0; i < cnt; ++i) {
                vals[i % k] |= (1LL << b);
            }
        }

        // Sum squares
        long long ans = 0;
        for (long long v : vals) {
            ans = (ans + v * v % MOD) % MOD;
        }
        return (int)ans;
    }
};
```

## 5. Example Explanation

**Example Input:**  
`nums = [2, 6, 5, 8], k = 2`

1. **Bit counts:**
    - 2: 0010
    - 6: 0110
    - 5: 0101
    - 8: 1000

    Bit 0: count = 1 (5)  
    Bit 1: count = 3 (2,6,5)  
    Bit 2: count = 2 (6,5)  
    Bit 3: count = 1 (8)  

2. **Distribute bits to two numbers:**
    - Bits for vals[0]: b1(1), b3(1)
    - Bits for vals[1]: b0(1), b2(1)
    - Next, as you distribute counts round robin, you'll get:
      - vals[0]: get first of each bit count, vals[1]: next set, etc.

    You end up with:
    - vals[0] = 15 (1111)
    - vals[1] = 6 (0110)

3. Squares:
    - 15^2 = 225
    - 6^2 = 36
    - Total = 261

**Which matches the problem example.**
