Let's solve **Smallest Palindromic Rearrangement II** (LeetCode, Hard).

---

## 1. **Short Summary**

Given a palindromic string `s` and an integer `k`, find the *k-th* lexicographically smallest **distinct** palindromic permutation of `s`. If fewer than `k` exist, return `""`.

---

## 2. **Constraints & Edge Cases**

**Constraints**
- `1 <= s.length <= 10^4`
- All chars lowercase English
- `s` is a palindrome
- `1 <= k <= 10^6`

**Edge Cases**
- Only one palindromic rearrangement? Return empty if `k > 1`.
- Multiple repeated characters? 
- String length odd/even.
- `k` is large.
- Must count **distinct** palindromic rearrangements, ignore duplicates.

---

## 3. **Optimal Algorithm**

### **Key Observations**

1. **Palindrome Structure**:  
   Any palindromic permutation can be built using a **first half** and its reverse as the second half, with an optional **center character** if the length is odd.

2. **Counting Distinct Palindromic Permutations**:  
   - For even-length: All chars must have even counts.
   - For odd-length: Exactly one char with odd count (for the center).
   - The first half can use half of each char's count.

   **Number of distinct permutations of first half**:  
   If the multiset for the half is `n` total chars, with counts `c1, c2, ...` per char:
   \[
   \text{\#perms} = \frac{n!}{c1! \cdot c2! \cdot ...}
   \]

3. **Lexicographical k-th Palindromic Permutation**:  
   - Build the first half lexicographically, one letter at a time.
   - At each step, for each available char, compute how many total palindromic permutations can be built using that char next.
   - If `k` is within that, pick that char.
   - Subtract possibilities if not.

### **Implementation Steps**
1. **Count character frequencies**.  
2. **Check palindromic rearrangement possible** (should always be true since `s` is palindromic).
3. **Build first half's multiset**: Use `cnt[c] // 2` for each char `c`.
4. **Middle character**: Char with odd count (if needed).
5. **k-th permutation by stepwise selection**:  
   - At each position, try every possible remaining character in lex order.
   - For each, count how many permutations if that char is picked next.
   - If `k` <= that count, pick; else, decrement `k` and try next char.
6. **Assemble full palindrome**: first half + mid (if any) + reversed first half.

### **Efficient Multinomial Coefficient Computation**
- Since n can be up to 5000, precompute factorials up to n.
- Use `log(fac)` anti-overflow, but since 1e4 is fine, regular int/LL factorials and divisions work in C++ up to that.

---

## 4. **C++ Solution**

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    string kthPalindrome(string s, int k) {
        vector<int> cnt(26, 0);
        for (char c : s) cnt[c - 'a']++;
        // Check mid char
        int n = s.size();
        int odd_count = 0, mid_c = -1;
        for (int i = 0; i < 26; ++i)
            if (cnt[i] % 2) { odd_count++; mid_c = i; }
        if (odd_count > 1) return ""; // Shouldn't happen, s is palindromic

        // Build first half multiset
        vector<int> half_cnt(26, 0);
        int half_len = 0;
        for (int i = 0; i < 26; ++i) {
            half_cnt[i] = cnt[i] / 2;
            half_len += half_cnt[i];
        }

        // Precompute factorials up to 10^4/2
        static const int MAX = 5000 + 10;
        static vector<long long> fac(MAX, 0), ifac(MAX, 0);
        static bool fac_init = false;
        if (!fac_init) {
            fac[0] = 1;
            for (int i = 1; i < MAX; ++i) fac[i] = fac[i-1] * i;
            ifac[MAX-1] = 1.0 / fac[MAX-1]; // Actually, we'll only use fac and mult/div here, so can avoid ifac.
            fac_init = true;
        }

        // Helper: multinomial for half_cnt
        auto perm_count = [&](vector<int> &cnt) -> long long {
            long long res = fac[accumulate(cnt.begin(), cnt.end(), 0)];
            for (int x : cnt) if (x > 1) res /= fac[x];
            return res;
        };

        // If not enough possibilities
        long long total = perm_count(half_cnt);
        if (k > total) return "";

        // Build answer
        string half = "";
        for (int i = 0; i < half_len; ++i) {
            for (int c = 0; c < 26; ++c) {
                if (half_cnt[c] == 0) continue;
                half_cnt[c]--;
                long long cnt_here = perm_count(half_cnt);
                if (k <= cnt_here) {
                    half += (char)('a' + c);
                    break;
                } else {
                    k -= cnt_here;
                    half_cnt[c]++;
                }
            }
        }
        string rev_half = half;
        reverse(rev_half.begin(), rev_half.end());
        string res = half;
        if (s.size() % 2 == 1) res += (char)('a' + mid_c);
        res += rev_half;
        return res;
    }
};
```

---

## 5. **Example Explanation**

**Example 1:**  
`s = "abba"`, `k = 2`

- Char counts: `a:2,b:2`
- Half counts: `a:1,b:1` ("ab" or "ba" as first half)
- Permutations of half: `2` (`ab` or `ba`)

- First permutation (k=1):  
  - Try 'a': use 'a', half_cnt->`a:0,b:1`. Then only 'b' left, so `ab`.  
  - Final: `ab | ba` (mirror) = `"abba"`

- Second permutation (k=2):  
  - Try 'a': if use 'a', have 1 permutation, which is abba. Since k > 1, skip.  
  - Try 'b': use 'b', then 'a' left, so "ba" as first half.  
  - Final: `ba | ab` = `"baab"`

So output is `"baab"`.
