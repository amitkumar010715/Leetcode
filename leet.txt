## 1. **Summary**

- Alice and Bob take turns removing stones from a pile of `n` stones.
- Alice removes **exactly 10** stones on her first turn.
- On each subsequent turn, **each player removes 1 less stone** than the previous opponent took.
- If a player cannot make a legal move, they lose.
- **Goal:** Given `n`, return `true` if Alice can win, otherwise `false`.

---

## 2. **Constraints & Edge Cases**

- **Constraints:** `1 <= n <= 50`
- **Edge Cases:**
  - If `n < 10`, Alice cannot take her first move — **she instantly loses**.
  - If `n = 10`, Alice removes all stones in her first move — **she wins**.
  - If there are not enough stones for the current required move, the player loses (the game ends).

---

## 3. **Optimal Algorithm**

Let’s formalize how the game plays:
- Alice starts with `remove = 10`
- Bob must then remove `remove = 9`
- Alice then must remove `remove = 8`, etc., until a player cannot remove enough stones.

For any `n`, simulate the game alternately:
- On Alice's turn: if `n >= remove`, subtract `remove` from `n`, decrement `remove`, pass to Bob.
- On Bob's turn: same thing, alternate.
- If a player cannot remove enough stones (i.e., `n < remove`), they lose.

Because `n <= 50`, simulating both players with a simple loop is optimal.

**Implementation steps:**
- Keep track of whose turn it is (`Alice` or `Bob`).
- Reduce `n` by the required `remove` amount each time.
- If `n < remove`, the current player loses — return the winner accordingly.

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    bool stoneGame(int n) {
        int remove = 10;
        bool aliceTurn = true;
        while (true) {
            if (n >= remove) {
                n -= remove;
                remove--;
                aliceTurn = !aliceTurn;
            } else {
                // Current player cannot move, so the OTHER player wins
                return !aliceTurn; // If it's Alice's turn and can't move, Bob wins, so return false
            }
        }
    }
};
```

---

## 5. **Example Explanation**

**Example:** `n = 12`

- **Turn 1 (Alice):** Must remove 10. Remaining stones: `12 - 10 = 2`.
- **Turn 2 (Bob):** Must remove 9. **But only 2 stones left!** Bob cannot move.
- **Alice wins** (`true`).

---

**Summary Table for reference (`n = 12`):**

| Turn   | Player | Stones to Remove | Stones Left | Can Move? |
|--------|--------|------------------|-------------|-----------|
| 1      | Alice  | 10               | 2           | Yes       |
| 2      | Bob    | 9                | 2           | **No**    |

**Result:** Alice wins.

#### This method is both simple and efficient, given the small limit on `n`.
