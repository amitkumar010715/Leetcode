## 1. **Short Summary**

You are given a string representing cars moving left (`L`), right (`R`), or staying (`S`). Cars may collide:
- **R** meets **L**: both stop, +2 collisions.
- **R** meets **S** or **S** meets **L**: +1 collision per move.
Cars at the *very left* moving left and at the *very right* moving right never collide. The task is to count all *collisions*.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- Up to 100,000 cars (`1 <= n <= 1e5`).
- Each car is at a *unique* point.
- Cars only interact with specific local cars based on movement.

**Edge Cases:**
- All left-moving (`LLLL...`) or all right-moving cars (`RRRR...`) → No collisions.
- Any surrounded stationary car (`RS`, `SR`, etc.).
- Car at one end moving away → Can't collide with any car.

---

## 3. **Optimal Algorithm**

### **Key Observations:**
- **Cars at the start moving left** and **cars at the end moving right** will **never collide**, as nothing impedes their path.
- The *collisions* can only happen for the *block* of cars between the first non-left car and the last non-right car.
- In this segment, **any car moving (L or R) contributes a collision**: any moving car here will ultimately stop due to a collision.

### **Steps**:
1. Find the leftmost index (`left`) where the car is not moving left.
2. Find the rightmost index (`right`) where the car is not moving right.
3. For all cars in the range `[left, right]`, count the number of **moving** cars (`L` or `R`).
   - Those are the only cars that will eventually collide.

#### **Time Complexity:**  
- O(N), single pass to find bounds + one pass segment.

---

## 4. **Clean C++ Solution**

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int countCollisions(string directions) {
        int n = directions.size();
        // Find leftmost index where not 'L'
        int left = 0;
        while (left < n && directions[left] == 'L') ++left;
        // Find rightmost index where not 'R'
        int right = n - 1;
        while (right >= 0 && directions[right] == 'R') --right;
        
        int collisions = 0;
        // Count moving cars (L or R) in [left, right]
        for (int i = left; i <= right; ++i)
            if (directions[i] != 'S')
                ++collisions;
        return collisions;
    }
};
```

## 5. **Example Explanation**

**Input:** `"RLRSLL"`

**Step-by-step:**
```
Positions: 0 1 2 3 4 5
Cars:      R L R S L L
```
- The first car (0) is **R** (not 'L'), so `left = 0`.
- The last car (5) is **L** (not 'R'), so `right = 5`.
- So, look at the range [0, 5].
- In this range, count all **L** or **R** cars: positions 0,1,2,4,5.
  - Pos 0: 'R'
  - Pos 1: 'L'
  - Pos 2: 'R'
  - Pos 4: 'L'
  - Pos 5: 'L'
- There are 5 such cars, so **5 collisions** will eventually happen.
