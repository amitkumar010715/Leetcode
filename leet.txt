Let's break down the solution as required:

---

## 1. **Short Summary**

Given a grid of integers, you can move only **right** or **down** from the top-left to the bottom-right. At each step, you accumulate the product of the values you traverse. Return the **maximum non-negative product** modulo `10^9+7` of any such path, or `-1` if all products along all possible paths are negative.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- Grid size: **1 &le; m, n &le; 15**
- Each cell: **-4 &le; grid[i][j] &le; 4**

**Implications:**
- Brute force all paths is impractical (as paths can be exponential in m+n).
- DP approaches are OK, since O(mn) state fits.
- Negative numbers can flip the sign of the product.

**Edge Cases:**
- **Zeros** in the path: 0 product can be optimal (since it's non-negative).
- **All negatives**: maximum product always negative; return -1.
- **Single cell**: Just that value.

---

## 3. **Optimal Algorithm (DP on State with min/max Tracking)**

**Key Insight:**  
Because multiplying negatives can flip product's sign, **at each cell, we must remember BOTH the maximal and minimal product achievable up to that cell**.

Define two DP tables:
- `max_dp[i][j]`: The largest product (could be negative) achievable up to (i,j)
- `min_dp[i][j]`: The smallest product achievable up to (i,j)

At each cell (i,j):
- Get products from top (i-1,j) and left (i,j-1)
- For current grid value `v`:
    - Possible products: `v * max`, `v * min` from both directions
    - max_dp = max of those; min_dp = min of those

Initialization:
- At (0,0), both max_dp and min_dp are grid[0][0]

Answer:
- At (m-1, n-1), if `max_dp` is >= 0, return it modulo 1e9+7, otherwise return -1.

**Time Complexity:**  
O(m*n)

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int maxProductPath(vector<vector<int>>& grid) {
        const int MOD = 1e9 + 7;
        int m = grid.size(), n = grid[0].size();
        vector<vector<long long>> max_dp(m, vector<long long>(n));
        vector<vector<long long>> min_dp(m, vector<long long>(n));
        
        max_dp[0][0] = min_dp[0][0] = grid[0][0];
        
        // Fill first row
        for (int j = 1; j < n; ++j) {
            max_dp[0][j] = min_dp[0][j] = max_dp[0][j-1] * grid[0][j];
        }
        // Fill first column
        for (int i = 1; i < m; ++i) {
            max_dp[i][0] = min_dp[i][0] = max_dp[i-1][0] * grid[i][0];
        }
        
        for (int i = 1; i < m; ++i) {
            for (int j = 1; j < n; ++j) {
                long long a = max_dp[i-1][j] * grid[i][j];
                long long b = min_dp[i-1][j] * grid[i][j];
                long long c = max_dp[i][j-1] * grid[i][j];
                long long d = min_dp[i][j-1] * grid[i][j];
                max_dp[i][j] = max({a, b, c, d});
                min_dp[i][j] = min({a, b, c, d});
            }
        }
        
        long long ans = max_dp[m-1][n-1];
        if (ans < 0)
            return -1;
        else
            return ans % MOD;
    }
};
```

## 5. **Example Explanation**

Let's run through **Example 2** step-by-step:

Grid:
```
[1, -2, 1]
[1, -2, 1]
[3, -4, 1]
```

Paths that maximize non-negative product:

- Path: **(0,0) → (1,0) → (2,0) → (2,1) → (2,2)**
- Actual values: **1 → 1 → 3 → -4 → 1**
- Product: 1 * 1 * 3 * (-4) * 1 = **-12** (negative, not usable)

- Path: **(0,0) → (0,1) → (1,1) → (2,1) → (2,2)**
- Actual values: **1 → -2 → -2 → -4 → 1**
- Product: 1 * -2 * -2 * -4 * 1 = **8**

So **8** is maximum non-negative product.  
Final answer: **8**
