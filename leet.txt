Let's break down the solution step-by-step:

---

## 1. **Short Summary**

Given an "encodedText" generated by a slanted transposition cipher with a fixed number of rows, **decode** it to retrieve the original string.  
The original string was written diagonally (top-left to bottom-right), and then the encoded text was obtained by reading the matrix row-wise.

---

## 2. **Constraints & Edge Cases**

- `0 <= encodedText.length <= 1e6` (up to 1,000,000 characters)
- `1 <= rows <= 1000`
- "encodedText" consists of lowercase letters and spaces.
- Always only one possible originalText; originalText has **no trailing spaces**.
- **Edge Cases**:
  - `rows == 1`: encodedText == originalText (just a straight line).
  - `encodedText.empty()`: output should be empty.
  - Rows > len(encodedText): possible only if input is empty.
  - Input may have trailing spaces in encodedText due to matrix shape, but originalText should not.

---

## 3. **Optimal Algorithm**

**Let:**  
- `encodedText` length = *n*  
- rows = *rows*
- Let the number of columns be `cols = n / rows` (ceiling division)

**Steps:**

1. **Calculate cols:**  
   - `cols = n / rows` but since the last column can't be empty, if `n % rows != 0`, we take `cols = (n + rows - 1) / rows`

2. **Simulate the diagonal decoding:**  
   - The matrix was filled by putting originalText in diagonals from `[0,0] -> [rows-1,cols-1]`  
   - To reconstruct: For each diagonal starting at column `c` from 0 to `cols-1`:
     - For each `i = 0 to rows-1`:
       - Row: `i`
       - Col: `c + i`
       - Check if `col` is in range (i.e., `< cols`), and `encodedText[i * cols + c + i]` is a valid position.

3. **Collect the characters in correct order:**  
   - For k in 0 to (cols-1)
     - For i in 0 to (rows-1)
       - If col = k + i < cols and row = i, then fetch the character at matrix[i][k+i] == encodedText[i * cols + k + i]
   - But actually, since originalText was filled diagonally, each originalText character is at position `(i, j)` in the matrix where the diagonal index is `d = i + j`. So, processing by diagonal order, for d in 0...(cols+rows-2), collect all matrix[i][j] where i+j==d and i < rows, j < cols.

   **But originalText was written in diagonals: for k from 0..cols-1:**  
   - for i from 0 to rows-1:
     - row = i
     - col = k + i
     - if col < cols, take character at matrix[row][col] = encodedText[row * cols + col]
   - Proceed until you exhaust positions in matrix.

4. **Build the result and trim trailing spaces.**

<br>

**Efficient Approach:**  
We can simulate the "diagonal" read without actually building the matrix.

Here's the efficient pseudo-code:

```
for k = 0 to cols - 1:
  i = 0
  while k + i < cols and i < rows:
    pos = i * cols + k + i
    if pos < n:
      append encodedText[pos] to result
    i += 1
```
But simpler is:
- For i in 0..rows-1
- For j in 0..cols-1
- Read matrix[i][j] from encodedText[i * cols + j]
But to decode diagonal, we need to go in increasing diagonal k:
  - For k = 0..cols-1:
    - For i = 0 .. rows-1:
      - j = k + i
      - If j < cols, and i * cols + j < n, collect encodedText[i*cols + j]

But that's what the Leetcode editorial does.

## 4. **C++ Solution**

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string decodeCiphertext(string encodedText, int rows) {
        int n = encodedText.size();
        if(n == 0 || rows == 0) return "";
        int cols = (n + rows - 1) / rows; // ceil division

        string res;
        // Loop over diagonals
        for(int k = 0; k < cols; ++k) {
            for(int i = 0; i < rows; ++i) {
                int j = k + i;
                if(j >= cols) break;
                int pos = i * cols + j;
                if(pos < n) {
                    res += encodedText[pos];
                }
            }
        }

        // Remove trailing spaces (originalText never has trailing spaces)
        while(!res.empty() && res.back() == ' ') res.pop_back();
        return res;
    }
};
```

## 5. **Example Explanation**

**Example:**
```
encodedText = "ch   ie   pr", rows = 3
```

- n = 9 + 3 spaces = 11, plus another 2 (for total length = 12, as the input has 12 characters).
- Let's check the length: `"ch   ie   pr"`. Counting, there are 12 characters in "ch   ie   pr".
- Number of rows = 3
- cols = (12 + 3 - 1) / 3 = 14/3 = 4.666... -> 4 (since 12 / 3 = 4), so cols = 4

Build matrix (3x4):
```
c h  
  i e
    p r
```
Which when filled row-wise matches the encodedText.

To recover originalText:
- For k = 0 to 3:
  - k=0:
    - i=0, j=0 → 0*4+0=0 → 'c'
    - i=1, j=1 → 1*4+1=5 → 'h'
    - i=2, j=2 → 2*4+2=10 → 'p'
  - k=1:
    - i=0, j=1 → 0*4+1=1 → 'h'
    - i=1, j=2 → 1*4+2=6 → 'i'
    - i=2, j=3 → 2*4+3=11 → 'r'
  - k=2:
    - i=0, j=2 → 0*4+2=2 → ' ' (space)
    - i=1, j=3 → 1*4+3=7 → 'e'
  - k=3:
    - i=0, j=3 → 0*4+3=3 → ' ' (space)
[Append all in order]: c h p h i r   e (with some repeated letters - actually only one per character!)

But following the inner loop, we take:
1) k=0: i=0,j=0 => 0; i=1,j=1=>5; i=2,j=2=>10
Add encodedText[0]='c', [5]='i', [10]='p'  → cip
2) k=1: i=0,j=1=>1; i=1,j=2=>6; i=2,j=3=>11
[1]='h', [6]='e',  [11]='r' → her
3) k=2: i=0,j=2=2; i=1,j=3=7
[2]=' ', [7]=' '
4) k=3: i=0,j=3=3
[3]=' '

Final string is: "cipher", as required.

## **Conclusion**

- We efficiently simulate the diagonal fill to reconstruct the originalText.
- The solution works in O(n) time with O(1) extra space (beyond answer).
- Handles all edge cases, and trims trailing spaces as per the problem requirement.
