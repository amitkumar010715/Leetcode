## 1. Short Summary

Given two non-increasing arrays, **nums1** and **nums2**, find the maximum distance \( j - i \) such that \( i \leq j \), and \( nums1[i] \leq nums2[j] \). If no such pair exists, return 0.

---

## 2. Constraints & Edge Cases

**Constraints:**
- Both arrays can be up to \( 10^5 \) in length (large inputs demand O(n) or O(n log n) solutions).
- All elements are positive integers.
- Both arrays are non-increasing.

**Edge Cases:**
- Arrays of length 1.
- No valid pairs exist at all (in which case, return 0).
- Multiple pairs with same maximum distance.
- All elements equal.

---

## 3. Optimal Algorithm

### Approach: Two Pointers

Because both arrays are non-increasing, we can use the two-pointer technique:

- Use pointer **i** for nums1 and pointer **j** for nums2.
- For each **i** (starting from 0), move **j** forward (never back!), as long as \( j < \text{len(nums2)} \) and \( nums2[j] \geq nums1[i] \).
- For each **i**, the **largest j** you can reach (where \( j \geq i \)) gives the max possible distance for this **i**.
- For efficiency, we do NOT need to reset **j** to **i** for each **i**; since both arrays are non-increasing, if **nums2[j-1]** failed for \( i-1 \), it will also fail for \( i \).
- Time Complexity: \( O(n + m) \), as **j** only moves forward and never resets.

#### Steps:
1. Initialize **maxDist = 0**, **j = 0**.
2. For every **i**:
   1. Set **j** to at least **i**.
   2. While \( j < n \) and \( nums2[j] \geq nums1[i] \), move **j** forward.
   3. Update **maxDist** as \( j-1-i \) if \( j > i \).
3. Return **maxDist**.

## 4. Clean C++ Solution

```cpp
class Solution {
public:
    int maxDistance(vector<int>& nums1, vector<int>& nums2) {
        int n1 = nums1.size(), n2 = nums2.size();
        int maxDist = 0;
        int j = 0;
        for (int i = 0; i < n1; ++i) {
            // Move j at least to i, since i <= j is required
            j = max(j, i);
            // While nums2[j] >= nums1[i], move j forward
            while (j < n2 && nums2[j] >= nums1[i]) {
                ++j;
            }
            // j-1 is the largest index where nums2[j-1] >= nums1[i]
            if (j-1 >= i) {
                maxDist = max(maxDist, j-1 - i);
            }
        }
        return maxDist;
    }
};
```
