Let's break down the solution as requested:

---

## 1. **Short Summary**

To partition a number `n` (as a string) into the minimum number of **deci-binary** numbers (numbers with digits only 0 or 1), you need as many deci-binary numbers as the largest digit in `n`.

---

## 2. **Constraints & Edge Cases**

- `1 <= n.length <= 10^5` — `n` can be very large, so we can't convert it to an integer.
- `n` consists only of digits, and **no leading zeros**.
- Edge cases:
    - Single digit (`n = "1"` or `"9"`) — answer is the digit.
    - Very large numbers — must process as strings only.

---

## 3. **Optimal Algorithm**

**Key Insight:**
Each deci-binary number can contribute at most **1** toward each digit. To construct a digit `d` in position `i`, we need at least `d` deci-binary numbers so that their sum at position `i` is `d`.

**Therefore:**
The minimum number is the **maximum digit** in `n`.

**Algorithm:**
- Scan `n`.
- Find the maximum digit.
- Return that digit (as an integer).

**Time Complexity:** O(n), where n is the number of digits.

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int minPartitions(string n) {
        char max_digit = '0';
        for (char c : n) {
            if (c > max_digit) max_digit = c;
        }
        return max_digit - '0';
    }
};
```

---

## 5. **Example Explained**

**Example:**  
n = "82734"

**Step-by-Step:**
- The digits are: `8, 2, 7, 3, 4`
- The maximum digit is `8`
- So, we need at least 8 deci-binary numbers whose sum is "82734".

**Why?**  
Because, for the highest digit `8`, you need to stack up at least 8 deci-binary numbers with `1` in that position to reach 8. You cannot do it with 7 or fewer.

---

**In short:**  
**Answer is the maximum digit in `n`.**
