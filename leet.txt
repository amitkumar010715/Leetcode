## 1. **Short summary**

You are given a string of **distinct lowercase letters**. On a phone keypad (keys 2 to 9), each letter is assigned to one key, and letters on the same key require more pushes. You can **remap the letters to keys as you wish**. The goal is to map letters such that **typing the whole word requires the smallest possible total key pushes**.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= word.length <= 26`
  - All letters in `word` are unique.
  - 8 keys: 2-9 (i.e., you have 8 "buckets" to distribute letters among in any way).
  - Each letter must be assigned to *exactly one* key.
- **Edge Cases:**
  - If length <= 8, best is to put one letter per key: each letter costs 1 push.
  - For numbers not divisible by 8, can fill the "earliest" positions to minimize the total.
  - Longer inputs fill keys in a round-robin or greedy "leveled" fashion to minimize pushing required.

---

## 3. **Optimal Algorithm**

- We can distribute letters among 8 keys.
- The minimum number of pushes is achieved by distributing letters as **evenly as possible**: assign the first 8 letters one in each key (all cost 1), next 8 letters fill the "second slot" of each key (all cost 2), etc.
- For a `len(word) = n`, sort letters into "levels":
  - Level 1: first up to 8 letters (cost 1)
  - Level 2: next up to 8 letters (cost 2)
  - etc.
- So, for i from 0 to n-1:
  - **Cost for letter at index i:** 1 + (i/8)
- **Sum this up for all i in [0, n):**

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int minimumPushes(string word) {
        int n = word.size();
        int total = 0;
        for (int i = 0; i < n; ++i) {
            // For i in 0..7 -> cost 1, i in 8..15 -> cost 2, etc.
            total += 1 + (i / 8);
        }
        return total;
    }
};
```

## 5. **Explanation with Example**

**Example:**  
`word = "xycdefghij"` (length = 10)

- We have 8 keys, so the first 8 letters get cost 1 each: positions 0..7 ("x" to "h")
- Next 2 letters get cost 2: positions 8,9 ("i","j")
- Total = 8 * 1 + 2 * 2 = 8 + 4 = **12**.

**Step-by-step:**

| Letter | Index | Cost |
|--------|-------|------|
| x      |  0    | 1    |
| y      |  1    | 1    |
| c      |  2    | 1    |
| d      |  3    | 1    |
| e      |  4    | 1    |
| f      |  5    | 1    |
| g      |  6    | 1    |
| h      |  7    | 1    |
| i      |  8    | 2    |
| j      |  9    | 2    |

Sum: **8 × 1 + 2 × 2 = 12**

---

### **Summary**

- Distribute letters as evenly as possible among 8 keys.
- Cost for each letter is 1 + (index/8), all indices from 0.
- Sum all costs for the final answer.
