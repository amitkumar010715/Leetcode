## 1. **Short Summary**

Given a positive integer `n`, determine if its binary representation has alternating bits (no two adjacent bits are the same). For example, `5` in binary is `101`, which alternates (`1-0-1`).

---

## 2. **Constraints & Edge Cases**

### Constraints
- `1 <= n <= 2^31 - 1` (n is a positive 32-bit signed integer)

### Edge Cases
- **Single bit:** `n = 1` (`1`): Should return `true`.
- **Alternating starting with 0**: By definition, numbers do not start with leading zeros, so we only care about the actual bits.
- **Long Alternating Sequence:** Test with numbers like `10` (`1010`), `42` (`101010`).
- **All bits same:** e.g., `7` (`111`), `3` (`11`) should return `false`.
---

## 3. **Optimal Algorithm**

**Observation:**  
If `n` has alternating bits (e.g., `10101010...`), shifting it right by 1 (`n >> 1`) will "line up" the 1s and 0s. If you sum `n` and its right shifted value, their bits will all be 1:

For example, for `n = 5 (101)`:  
- `n      = 101`
- `n>>1   = 010`
- `n ^ (n>>1) = 111` (all bits set to 1).

If `n` has alternating bits, then `n ^ (n>>1)` will be a string of 1s in binary. Also, if we add 1 to this, it becomes a power of 2, for which `x & (x+1) == 0`.

So, the check can be:
```cpp
int x = n ^ (n >> 1);
return (x & (x + 1)) == 0;
```
- **Time:** O(1)
- **Space:** O(1)

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    bool hasAlternatingBits(int n) {
        int x = n ^ (n >> 1);
        return (x & (x + 1)) == 0;
    }
};
```

---

## 5. **Example Explanation**

Let's walk through `n = 5`:

1. **Binary Representation:**  
   `n  = 5` → `101`
   
2. **Shift Right by 1:**  
   `n >> 1` → `10` (in binary `010`)
   
3. **XOR:**  
   `101 ^ 010 = 111` (binary) = `7` (decimal)
   
4. **Check:**  
   `x = 7`, `x + 1 = 8` (binary `1000`)
   
   `7 & 8 = 0` (i.e. `0111 & 1000 = 0000`)
   
5. **Result:**  
   Returns `true`.
