Let's break down the problem step by step:

---

## 1. **Summary**

Given a positive integer `n`, return the **maximum product** obtainable by multiplying any two digits of `n`.  
The same digit can be used twice only if it appears more than once in `n`.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `10 <= n <= 10^9` (so `n` has at least 2 digits, and at most 9 digits)
- **Edge Cases:**
  - All digits are the same (like `11`, `9999`): only one unique product.
  - Digits include `0` (like `102`, `904`): zero will result in products of zero.
  - Only two digits (e.g., `10`).
  - Multiple occurrences of digits: using same digit twice is allowed if it actually appears at least twice.
  - n will never have only one digit by constraints.

---

## 3. **Optimal Algorithm**

- **Observation:** With up to 9 digits, a brute force check of all pairs is efficient (since \( C(n,2) + C(f,2) \) is at most 36 for 9 digits).
- **Algorithm:**
  1. Extract all digits of `n` into a vector.
  2. For each pair of indices `(i, j)` (`i <= j`), if `i == j` then only count it if that digit appears more than once.
  3. Compute `digit[i] * digit[j]`, and keep track of the maximum.
- Thus, O(number of digits^2), always less than 100 iterations.

---

## 4. **C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int maxProduct(int n) {
        vector<int> digits;
        vector<int> count(10, 0);
        int temp = n;
        // Extract digits & count them
        while (temp > 0) {
            int d = temp % 10;
            digits.push_back(d);
            count[d]++;
            temp /= 10;
        }
        int ans = 0;
        int len = digits.size();
        for (int i = 0; i < len; ++i) {
            for (int j = i; j < len; ++j) {
                if (i == j && count[digits[i]] < 2) continue; // can't reuse if only one occurrence
                ans = max(ans, digits[i] * digits[j]);
            }
        }
        return ans;
    }
};
```

---

## 5. **Example Explanation**

### Example: `n = 124`

- **Digits:** `[1, 2, 4]`
- **All pairs:**
  - (1,1): only one `1`, cannot use twice.
  - (1,2): `1*2 = 2`
  - (1,4): `1*4 = 4`
  - (2,2): only one `2`.
  - (2,4): `2*4 = 8`
  - (4,4): only one `4`.
- **Maximum:** `8` (from `2*4`)
- **Output:** `8`

---

**In summary:**  
We extract digits, count occurrences, and check all valid pairs for their product, tracking the maximum. Constraints allow this brute-force approach, and the C++ solution is both optimal and clear!
