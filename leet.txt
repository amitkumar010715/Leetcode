Let's break down the challenge step by step:

---

## 1. **Short Summary**

Given a string `s`, you need to find the length of its **longest substring** where **each distinct character occurs the same number of times**.

---

## 2. **Constraints & Edge Cases**

- Constraints:
    - `1 <= s.length <= 1000`
    - `s` only has lowercase English letters.
- Edge Cases:
    - All characters are unique (`"abc..."`). Whole string is balanced.
    - All characters are the same (`"aaaa"`). Whole string is balanced.
    - Multiple possible balanced substrings, possibly overlapping.
    - Minimum-length substrings (one character) are always balanced (length = 1).
    - The string contains only two kinds of characters but in imbalanced amounts.

---

## 3. **Optimal Algorithm**

### Brute Force (works due to small `n`)
- We can check all substrings (there are O(n^2)) and for each, count the frequency of each character (O(26)).
- For each substring, **it's balanced if ALL non-zero counts in the frequency array are equal.**
- Return the length of the longest balanced substring.

#### Steps:
1. For every pair `(i, j)` where `i <= j`, process substring `s[i..j]`:
    - Count frequencies of each character in this substring.
    - If all non-zero frequencies are the same, possibly update answer.

Total complexity: O(n^2 * 26) => 26,000,000 operations (acceptable for n <= 1000).

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <string>
#include <algorithm>

class Solution {
public:
    int longestBalancedSubstring(std::string s) {
        int n = s.size();
        int maxlen = 0;
        for (int i = 0; i < n; ++i) {
            std::vector<int> freq(26, 0);
            for (int j = i; j < n; ++j) {
                freq[s[j]-'a']++;
                // collect all non-zero frequencies
                int cnt = 0, value = 0;
                bool balanced = true;
                for (int k = 0; k < 26; ++k) {
                    if (freq[k]) {
                        if (value == 0) value = freq[k];
                        if (freq[k] != value) {
                            balanced = false;
                            break;
                        }
                        cnt++;
                    }
                }
                if (balanced && cnt > 0) {
                    maxlen = std::max(maxlen, j - i + 1);
                }
            }
        }
        return maxlen;
    }
};
```

---

## 5. **Example Explained**

**Example:**  
Input: `s = "abbac"`

- Let's check all substrings:
    - `"abba"`:  
        - `freq['a'] = 2`
        - `freq['b'] = 2`
        - Both non-zero counts are 2.
        - This substring (length 4) is balanced.

    - `"abbac"`:  
        - `freq['a'] = 2`, `freq['b'] = 2`, `freq['c']=1`  
        - Counts: {2,2,1} are not all equal.

So the longest balanced substring is `"abba"` with length 4.

**Output: 4**

---

### Summary Table

| Substring   | Frequencies          | Balanced?      |
|-------------|---------------------|----------------|
| "a"         | {a:1}               | Yes            |
| "ab"        | {a:1, b:1}          | Yes            |
| ...         | ...                 | ...            |
| "abba"      | {a:2, b:2}          | Yes (**max**)  |
| ...         | ...                 | ...            |
| "abbac"     | {a:2, b:2, c:1}     | No             |

---

This solution leverages the problem's manageable size for a straightforward, brute-force (but efficient in this context) scan for balanced substrings.
