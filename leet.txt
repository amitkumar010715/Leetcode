Let's break down the problem as requested:

---

## 1. **Short Summary**

Given an m x n grid with obstacles, reset zones, and “litter” to collect, a student must collect all the litter. Moving costs 1 energy point (starting with `energy`), which can be refilled to max at 'R' zones. Find the minimal number of moves to collect all 'L', or return -1 if impossible.

---

## 2. **Constraints & Edge Cases**

**Constraints**
- `1 <= m, n <= 20` (grid is small)
- `1 <= energy <= 50` (student’s max movement per energy refill)
- ≤ 10 'L' cells (litter items to collect)
- Exactly 1 'S'
- Multiple 'R' allowed, can revisit for energy
- 'X' is blocked

**Edge Cases**
- Litter may be unreachable (output -1)
- Multiple ways to reach 'L'; need minimal moves (not minimal segments between litters, but total steps)
- Must handle all combinations of litter pickup order (TSP style), but under manageable size due to K ≤ 10.

---

## 3. **Optimal Algorithm**

This is a **stateful shortest path/TSP variant** with energy constraints and refilling.

**Key Observations:**
- With at most 10 litters, collecting them in any order is feasible to track (K! ~ 3 million for K=10, but we can prune).
- Each state can be represented by: (x, y, remaining_energy, litter_mask)
- BFS is suitable to find minimum moves, as all steps cost 1 move.

**Approach:**
1. **Preprocessing:**
   - Record locations of S, L, R.
   - Assign indexes to L (for bitmask).

2. **BFS (or Dijkstra, but all moves are same cost):**
   - State = (row, col, remaining_energy, litter_mask)
   - Use a 4D visited array (row, col, litter_mask, energy).
   - For each move:
     - If at R, can refill energy.
     - If entering an L cell, mark corresponding bit in litter_mask.
     - Enqueue neighboring cells if not X, and energy>0.

3. **Stop when:**
   - All Litters are collected (litter_mask == all 1's).
   - If not possible, return -1.

**Complexity:**
- #States: m * n * (2^K) * (energy+1) <= 20^2 * 2^10 * 51 ~ 20,000,000 at maximum, often less due to obstacles, and real BFS explores much less in practice.

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <string>
#include <queue>
#include <tuple>
#include <cstring>
using namespace std;

class Solution {
public:
    int minMovesToClean(vector<string>& classroom, int energy) {
        int m = classroom.size(), n = classroom[0].size();
        vector<pair<int, int>> litter;
        int sx, sy; // start position
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (classroom[i][j] == 'S') {
                    sx = i; sy = j;
                } else if (classroom[i][j] == 'L') {
                    litter.emplace_back(i, j);
                }
            }
        }

        int k = litter.size();
        vector<vector<int>> litterPos(m, vector<int>(n, -1));
        for (int i = 0; i < k; ++i)
            litterPos[litter[i].first][litter[i].second] = i;

        // visited[x][y][litterMask][energyLeft]
        bool visited[20][20][1<<10][51];
        memset(visited, 0, sizeof(visited));
        
        queue<tuple<int,int,int,int,int>> q;
        // (x, y, litterMask, energyLeft, moves)
        q.emplace(sx, sy, 0, energy, 0);
        visited[sx][sy][0][energy] = true;

        int dirs[4][2] = {{1,0}, {-1,0}, {0,1}, {0,-1}};

        while (!q.empty()) {
            auto [x, y, mask, e, moves] = q.front(); q.pop();
            // If collected all litters
            if (mask == (1 << k) - 1) return moves;

            // If this is a reset, consider resetting energy (if not already at max)
            if (classroom[x][y] == 'R' && e != energy) {
                if (!visited[x][y][mask][energy]) {
                    visited[x][y][mask][energy] = true;
                    q.emplace(x, y, mask, energy, moves);
                }
            }

            // Try moving in 4 directions
            if (e == 0) continue;
            for (auto& dir : dirs) {
                int nx = x + dir[0], ny = y + dir[1];
                if (nx < 0 || ny < 0 || nx >= m || ny >= n) continue;
                char cell = classroom[nx][ny];
                if (cell == 'X') continue; // Obstacle

                int nmask = mask;
                if (cell == 'L') {
                    int lidx = litterPos[nx][ny];
                    nmask |= (1 << lidx);
                }
                int ne = e - 1;
                if (!visited[nx][ny][nmask][ne]) {
                    visited[nx][ny][nmask][ne] = true;
                    q.emplace(nx, ny, nmask, ne, moves + 1);
                }
            }
        }
        return -1;
    }
};
```

## 5. **Example Walkthrough**

**Example 2**

```text
classroom = ["LS", "RL"], energy = 4
```

The grid:
```
L S
R L
```
- Start: (0,1), energy=4
- Litters at (0,0) and (1,1)
- Reset at (1,0)

**Possible steps:**
1. Move left (0,1) → (0,0): Use 1 energy (now 3), collect first L (moves: 1)
2. Move down (0,0) → (1,0): Use 1 energy (now 2), step on R and restore to 4 (optional), (moves: 2)
3. Move right (1,0) → (1,1): Use 1 energy (now 3), collect second L (moves: 3)

Thus, minimal number of moves is **3**.
