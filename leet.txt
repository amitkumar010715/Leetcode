## 1. **Short Summary**

You are given an array and a target sum. You must find **two non-overlapping subarrays** (contiguous) whose **sum is exactly the target**. Among all such possible pairs, **minimize the sum of their lengths**. If it's not possible, return -1.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- Array length up to 1e5 (100,000).  
- All elements and target are positive (1 to 1000 for elements, up to 1e8 for target).  
- O(N²) solutions will not pass; need O(N) or O(N log N).

**Edge cases:**
- Multiple possible pairs (must choose pair with minimal total length).
- No possible subarrays with sum = target (return -1).
- Subarrays can't overlap, but can be adjacent.
- Input like `[target, target]` → output `2`
- Cases where the shortest possible is to use single elements `[3,2,2,4,3] target=3` → [3], [3]

---

## 3. **Optimal Algorithm**

### **Approach**
We need to be able to, for every possible subarray with sum = target, efficiently find a non-overlapping second subarray with sum = target whose length is minimized.

#### **Sliding Window + Dynamic Tracking**

**Step 1:**
- Use sliding window to find all subarrays with sum = target.
- For each, track its starting and ending indices and length.

**Step 2:**
- As we slide, we want to know: "At index i, what is the shortest *previous* subarray [0..i] ending at or before i with sum=target?"

**Step 3:**
- While finding subarrays, for each ending at `j`, check if there is a previous disjoint interval ending before i.
- Use a `minLenLeft[i]` array:  
  At each position, what's the minimal length *ending at or before* `i` with sum = target.

**Step 4:**
- For every subarray `[i, j]` with sum = target:
  - Look at `minLenLeft[i-1]`.
  - If it's not inf, then we have two non-overlapping subarrays - sum their lengths.
  - Update result if minimal.

**Step 5:**
- After checking, update `minLenLeft[j]` to keep track of the minimal so far.

**Why O(N)?**
- Each index is processed sequentially; at most O(N).

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int minSumOfLengths(vector<int>& arr, int target) {
        int n = arr.size();
        vector<int> minLenLeft(n, INT_MAX);
        int left = 0, sum = 0;
        int minLen = INT_MAX;
        int res = INT_MAX;

        // First pass: sliding window, for each end pos, track minimal length up to this point
        for (int right = 0; right < n; ++right) {
            sum += arr[right];
            // Shrink window if sum too big
            while (sum > target && left <= right) {
                sum -= arr[left++];
            }
            // Found a subarray with target sum
            if (sum == target) {
                int len = right - left + 1;
                // If possible, combine with earlier interval's minimal length
                if (left > 0 && minLenLeft[left-1] != INT_MAX) {
                    res = min(res, minLenLeft[left-1] + len);
                }
                minLen = min(minLen, len); // update min length up to now
            }
            // Propagate the minimal length up to index right
            minLenLeft[right] = minLen;
        }
        return res == INT_MAX ? -1 : res;
    }
};
```

## 5. **Explain One Example**

Let's use **Example 1**:

**Input:**  
`arr = [3,2,2,4,3], target = 3`  

**Step by step:**  
- **Subarrays with sum=3:**  
  - `[3]` at 0  
  - `[3]` at 4

- As sliding window progresses:
  - At index 0: `[3]` (length=1)
    - minLenLeft[0]=1
  - At indices 1,2,3: sum != 3, so minLenLeft propagates
  - At index 4: `[3]` (from 4 to 4, length=1)
    - The last valid (non-overlapping) left for a pair is at index 3.
    - minLenLeft[3]=1, so current result = 1 (for previous) + 1 (now) = 2

**So answer is `2`.**

---

**In summary:**
- We use a sliding window to find all subarrays with sum=target.
- At each step, we track min lengths up to point to efficiently pair any later subarray with the best previous, non-overlapping one.
- The solution is efficient O(N) and can handle the input size constraints.
