Let's break down the solution as requested:

---

## 1. **Summary**

Given a string `s` containing substrings in round brackets (e.g., `(name)`) and a list of key-value mappings called `knowledge`, we need to replace every bracketed key in `s` with its mapped value (or with `?` if no mapping exists). There is **no bracket nesting**, and all keys in bracket pairs are non-empty.

---

## 2. **Constraints & Edge Cases**

- **Input Lengths:** Up to 1e5 for both `s` and `knowledge` (so efficiency is critical).
- **Key-Value:** All keys/values are lowercase and of length <= 10.
- **No Nesting:** Bracket pairs do not nest (e.g., `"(a(b))"` will not appear).
- **Edge Cases:**
  - A bracketed key not in `knowledge` (should output '?').
  - Consecutive or overlapping bracket pairs.
  - Brackets at the start or end of string.
  - No brackets at all.

---

## 3. **Optimal Algorithm Approach**

1. **Preprocess `knowledge` into a Hash Map** (unordered_map) for fast O(1) key lookups.
2. **Iterate through `s` once**, building the output string as you go:
     - If a `'('` is found, record the content until the next `')'`, look it up in the map, and output the value or '?'.
     - Otherwise, just append the current character to the result.
3. **Time Complexity:** O(|s| + |knowledge|)—linear in the input sizes.

---

## 4. **C++ Solution**

```cpp
#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    string evaluate(string s, vector<vector<string>>& knowledge) {
        unordered_map<string, string> dict;
        for (const auto& pair : knowledge) {
            dict[pair[0]] = pair[1];
        }
        string res;
        int n = s.size();
        for (int i = 0; i < n; ) {
            if (s[i] == '(') {
                int j = i + 1;
                // find closing ')'
                while (j < n && s[j] != ')') ++j;
                string key = s.substr(i + 1, j - i - 1);
                if (dict.count(key)) {
                    res += dict[key];
                } else {
                    res += '?';
                }
                i = j + 1; // move after ')'
            } else {
                res += s[i];
                ++i;
            }
        }
        return res;
    }
};
```

---

## 5. **Example Explained**

**Example 1:**

- `s = "(name)is(age)yearsold"`
- `knowledge = [["name","bob"],["age","two"]]`
  
**Step by Step:**
- Start parsing: see '(', extract "name", lookup: found "bob".
- Output so far: "bob"
- Next part: "is" (not in brackets), append as is.
- Next: '(', extract "age", lookup: found "two".
- Output so far: "bobis" + "two"
- Remaining: "yearsold", append as is.

**Final output:** `"bobistwoyearsold"`
