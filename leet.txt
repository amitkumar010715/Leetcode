Let's break down the solution step by step:

---

## 1. **Summary**

Given a binary tree, for each level, calculate the sum of all node values on that level. Return the smallest level number with the maximum sum. Root starts at level 1.

---

## 2. **Constraints & Edge Cases**

- **Nodes**: Between 1 and 10,000.
- **Node Values**: Each node's value is between -100,000 and 100,000 (can be negative or positive).
- **Edge Cases**:
    - All values may be negative.
    - Maximal sum may occur at more than one level; choose the smallest level.
    - Tree may have only one node.

---

## 3. **Optimal Algorithm**

### **Approach: Breadth-First Search (BFS) / Level Order Traversal**

- Do a level order traversal (BFS) to visit nodes level by level.
- For each level, sum the node values.
- Keep track of the maximum sum and its associated (smallest) level.

### **Steps:**

1. Start BFS from the root.
2. Use a queue to process nodes by level.
3. For each level:
   - Compute the sum of values for all nodes at that level.
   - If this sum is larger than the previous max, update the max and level.
   - If equal, retain the smallest level.
4. Continue to next level until the queue is empty.

**Time Complexity:** O(N) where N is the number of nodes.

**Space Complexity:** O(W) where W is the maximum width of the tree (at most N/2).

---

## 4. **C++ Solution**

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxLevelSum(TreeNode* root) {
        if (!root) return 0;

        std::queue<TreeNode*> q;
        q.push(root);
        int level = 1;
        int maxLevel = 1;
        int maxSum = root->val;

        while (!q.empty()) {
            int size = q.size();
            int currLevelSum = 0;
            for (int i = 0; i < size; ++i) {
                TreeNode* node = q.front(); q.pop();
                currLevelSum += node->val;

                if (node->left)
                    q.push(node->left);
                if (node->right)
                    q.push(node->right);
            }
            if (currLevelSum > maxSum) {
                maxSum = currLevelSum;
                maxLevel = level;
            }
            level += 1;
        }
        return maxLevel;
    }
};
```

---

## 5. **Example Explained**

Let's take **Example 1**:  
`root = [1,7,0,7,-8,null,null]`

**Tree:**
```
        1
       / \
      7   0
     / \
    7  -8
```

**Level Sums:**
- Level 1: 1
- Level 2: 7 + 0 = 7
- Level 3: 7 + (-8) = -1

**Maximum sum is 7** at **level 2**.  
**Return:** `2`
