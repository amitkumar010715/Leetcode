Let's break down and solve the **"Construct the Minimum Bitwise Array I"** LeetCode problem as requested:

---

## 1. **Short Summary**

Given an array of prime numbers `nums`, for each element we must find the **minimal non-negative integer `x`** such that:
- `(x) | (x + 1) == nums[i]`  
  (where `|` is the bitwise OR)

If impossible, output `-1` for that index in the result.

---

## 2. **Constraints & Edge Cases**

- **`1 <= nums.length <= 100`** – Small, simple for per-element processing.
- **`2 <= nums[i] <= 1000`** – Each value is a reasonably small prime. All elements are >1.
- **Only primes** – No composite or 1 allowed.
- **Result for each index should be minimized.**
- If multiple answers exist, take the smallest; if none, return `-1` for that index.

**Edge Cases:**
- No solution: e.g., in sample, for 2, output is -1.
- For small numbers: Particularly, for small primes (2, 3, 5), check all 0 ≤ x < nums[i].
- Primes near a power of two (ex: 3,7,31) have patterns.

---

## 3. **Optimal Algorithm**

### **Observations**

Given: `x | (x + 1) == num`  
Want minimal x.

We can loop `x` from `0` to `num`, and check if `x | (x+1) == num`;  
But that's O(num) per number, which is fine here (num up to 1000, 100 items).

But let's analyze bitwise:

- Two consecutive numbers (`x`, `x+1`) will have different least significant bits (the LSB will always be 0 for `x`, 1 for `x+1`), but all higher bits almost the same, except for carry.
- Their OR is `x | (x+1)`. Whenever there is a 0 in `x` which becomes 1 in `x+1`, the OR will reflect that.

#### **Brute Force is Acceptable**

For each `num`, try all `x` in `[0, num]` (because for x > num, x|x+1 > num as all values are positive).

For each, check if `(x | (x + 1)) == num` and keep the minimal such x.

---

## 4. **C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> constructArray(vector<int>& nums) {
        vector<int> ans;
        for(int num : nums) {
            int best = -1;
            for(int x = 0; x <= num; ++x) {
                if ((x | (x + 1)) == num) {
                    best = x;
                    break;  // minimal, so break immediately
                }
            }
            ans.push_back(best);
        }
        return ans;
    }
};
```

---

## 5. **Example Explanation**

**Example 1:**  
`nums = [2,3,5,7]`

Let's process one: `nums[2] = 5`

Find minimal x ≥ 0, `x | (x+1) == 5`

Try x from 0 up:

- **x = 0:**  0 | 1 = 1
- **x = 1:**  1 | 2 = 3
- **x = 2:**  2 | 3 = 3
- **x = 3:**  3 | 4 = 7
- **x = 4:**  4 | 5 = 5  ✔️ **(minimum!)**

So, ans[2] = 4.

---

# **Summary Table for Example 1**

| nums[i] | Minimum x | Reason                         |
|---------|-----------|--------------------------------|
| 2       |   -1      | No x such that x|x+1 == 2      |
| 3       |   1       | 1|2 = 3                        |

---

# **Key Takeaway**

We brute-force check all x from 0 to num for each prime:  
The first x such that x | (x+1) == num is the answer, otherwise -1.
