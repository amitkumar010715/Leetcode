Let's dive in step by step!

---

## 1. **Short Summary**

Given two strings `source` and `target`, and a list of allowed letter conversions with associated costs, find the minimum total cost to convert `source` into `target`. Each change must follow the conversion rules, and you can chain conversions (e.g., 'a' → 'c' → 'b'). Return `-1` if impossible.

---

## 2. **Constraints & Edge Cases**

- **Sizes:**  
  `source` and `target` may be up to $10^5$ in length (so per-character O(1) operations are a must).
- **Transformation rules:**  
  At most 2000 conversion rules, affecting letters 'a' to 'z' (26).
- **Multiple rules:**  
  There may be multiple ways to change the same letter-pair (choose the cheapest).
- **Chaining:**  
  You may use as many conversion steps as needed, in any sequence.
- **Direct or multi-step:**  
  If a direct transformation isn’t possible, check if a multi-step way exists.
- **Impossible transformations:**  
  If there is no way to convert a letter at any position, return `-1`.
  
---

## 3. **Optimal Algorithm**

This is a classic "all-pairs shortest paths" on a small node set (the 26 letters), but applied many times (for each differing character in the input string).

**Step-by-step:**
1. **Build Graph:**  
   - Nodes: 'a' to 'z'.
   - Edges: conversion allowed by rules, with given cost. Keep *minimum* cost if multiple rules exist for the same conversion.
2. **Floyd-Warshall:**  
   Compute the minimum cost to convert any letter `x` to any letter `y` (all-pair shortest path for 26x26).
   - Each node (letter) is a vertex.
   - Each conversion is a directed edge.
3. **Answer Calculation:**  
   For each character position in the string:
   - If `source[i] == target[i]`, cost is 0.
   - Else, get the cheapest cost from `source[i]` to `target[i]` from the distance matrix.
   - If unreachable (`INF`), return `-1`. Otherwise, sum up the cost.
   
- **Efficiency:**  
  - Floyd-Warshall on 26 nodes: $O(26^3)$, which is very fast.
  - One pass over input string: $O(n)$.
  - Total O(26^3 + n), easily fits constraints.

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <string>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int minimumCost(string source, string target, vector<char>& original, vector<char>& changed, vector<int>& cost) {
        const int ALPHA = 26;
        // 1. Build min cost graph (initialize with INF, 0 for self-loop)
        vector<vector<int>> dist(ALPHA, vector<int>(ALPHA, INT_MAX/2));
        for (int i = 0; i < ALPHA; ++i)
            dist[i][i] = 0;

        for (int i = 0; i < original.size(); ++i) {
            int from = original[i] - 'a';
            int to = changed[i] - 'a';
            dist[from][to] = min(dist[from][to], cost[i]);
        }

        // 2. Floyd-Warshall: All-pairs shortest path
        for (int k = 0; k < ALPHA; ++k) {
            for (int i = 0; i < ALPHA; ++i) {
                for (int j = 0; j < ALPHA; ++j) {
                    if (dist[i][j] > dist[i][k] + dist[k][j])
                        dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }

        // 3. For each character, sum the minimal conversion cost
        int n = source.size();
        long long total = 0;
        for (int i = 0; i < n; ++i) {
            if (source[i] == target[i]) continue; // No cost needed
            int s = source[i] - 'a', t = target[i] - 'a';
            int c = dist[s][t];
            if (c >= INT_MAX/2) // No path found
                return -1;
            total += c;
        }
        return (int)total;
    }
};
```

## 5. **Walk-through Example**

### Sample 1

> **Input:**  
> source = "abcd"  
> target = "acbe"  
> original = ["a","b","c","c","e","d"]  
> changed =  ["b","c","b","e","b","e"]  
> cost =     [2,   5,   5,   1,   2,  20]

Let's process the conversions:
- a→b : 2
- b→c : 5
- c→b : 5
- c→e : 1
- e→b : 2
- d→e : 20

Run Floyd-Warshall on these rules…

**Now, for each char position:**

| i | source[i] | target[i] | Steps                                              | Cost |
|---|-----------|-----------|----------------------------------------------------|------|
| 0 | a         | a         | = → (no cost)                                      | 0    |
| 1 | b         | c         | b→c (direct)                                       | 5    |
| 2 | c         | b         | c→e (1), e→b (2): c→e→b   OR c→b (direct, 5)      | min(3,5) = 3 |
| 3 | d         | e         | d→e                                                | 20   |

Sum: 5 + 3 + 20 = **28**
