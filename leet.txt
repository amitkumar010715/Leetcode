Let's break down the problem and provide a complete solution:

---

## 1. **Short Summary**

Given an integer array, sort its elements based on the number of `1`s in their binary representation (bit count). For numbers with the same bit count, sort by their numeric value in ascending order.

---

## 2. **Constraints & Edge Cases**

- **Constraints**
  - `1 <= arr.length <= 500`
  - `0 <= arr[i] <= 10^4`
- **Edge Cases**
  - All elements are the same (`[5,5,5]`).
  - All elements have the same bit count (`[2, 4, 8, 16]`).
  - The array includes `0`, which has a bit count of 0.
  - The array is already sorted either by value or bit count.

---

## 3. **Optimal Algorithm**

- Calculate the number of set bits (`1`s) for each element (can use built-in functions or implement it manually).
- Sort using a custom comparator:
    - **First** by set bit count (ascending).
    - **Second** by actual value (ascending).
- This can be done in `O(N log N)` time.

**Bit Counting:**  
For each integer `x`, you can use `__builtin_popcount(x)` in C++ (or manually count by shifting and masking).

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>

class Solution {
public:
    int bitCount(int x) {
        int count = 0;
        while (x) {
            x &= (x - 1); // Remove the lowest set bit
            ++count;
        }
        return count;
    }
    
    std::vector<int> sortByBits(std::vector<int>& arr) {
        std::sort(arr.begin(), arr.end(), [this](int a, int b) {
            int ca = bitCount(a), cb = bitCount(b);
            if (ca == cb)
                return a < b;
            return ca < cb;
        });
        return arr;
    }
};
```

- If your compiler supports it, replace `bitCount(x)` with `__builtin_popcount(x)` (GNU/Clang) or `std::popcount(x)` (C++20):

```cpp
#include <vector>
#include <algorithm>

class Solution {
public:
    std::vector<int> sortByBits(std::vector<int>& arr) {
        std::sort(arr.begin(), arr.end(), [](int a, int b) {
            int ca = __builtin_popcount(a), cb = __builtin_popcount(b);
            if (ca == cb)
                return a < b;
            return ca < cb;
        });
        return arr;
    }
};
```

---

## 5. **Example Explanation**

**Input:** `arr = [0,1,2,3,4,5,6,7,8]`

- **Bit counts:**
    - `0  = 0b0000` → **0** ones
    - `1  = 0b0001` → **1** one
    - `2  = 0b0010` → **1** one
    - `3  = 0b0011` → **2** ones
    - `4  = 0b0100` → **1** one
    - `5  = 0b0101` → **2** ones
    - `6  = 0b0110` → **2** ones
    - `7  = 0b0111` → **3** ones
    - `8  = 0b1000` → **1** one

- **Group by number of 1's:**
    - `0` → [0] (0 ones)
    - `1` → [1,2,4,8] (1 one)
    - `2` → [3,5,6] (2 ones)
    - `3` → [7] (3 ones)

- **Result (merge all groups, each sorted numerically):**
    - `[0, 1, 2, 4, 8, 3, 5, 6, 7]`
