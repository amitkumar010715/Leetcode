Let's break down the **LeetCode Daily Challenge: Minimum Add to Make Parentheses Valid** step by step.

---

## 1. **Short Summary**

Given a string containing only `'('` and `')'`, the task is to calculate the **minimum number of parentheses insertions required** to make the string valid (all open have close, and proper order).  
You can insert either `'('` or `')'` at any position any number of times.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= s.length <= 1000`
- Only `'('` and `')'` characters.

**Edge Cases:**
- All `'('` (e.g., `"(((("`): Need one `')'` for each `'('`.
- All `')'` (e.g., `"))))"`): Need one `'('` for each `')'`.
- Alternating but invalid (e.g., `"(()))(()"`).
- Already valid string: should return `0`.
- Empty string is not allowed by constraints (`length >= 1`).

---

## 3. **Optimal Algorithm (with Explanation)**

### Approach

We don't need to use a stack!  
We can use two counters:
- `opened`: Number of `'('` that are waiting for a `')'`.
- `insertions`: Number of insertions required.

**Process:**
- Scan the string left to right.
- For each `'('`, increment `opened`.
- For each `')'`:
    - If `opened > 0`, it matches: decrement `opened`.
    - Else, it's an unmatched `')'`, so we must insert a `'('`: increment `insertions`.
- After processing, if there are unclosed `'('` left (`opened > 0`), each needs a `')'` inserted.

**Total answer:**  
`insertions + opened`

#### Time Complexity
- O(n), single pass.

#### Space Complexity
- O(1), just counters.

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    int minAddToMakeValid(string s) {
        int opened = 0;    // Opened '(' waiting for a ')'
        int insertions = 0; // Insertions required

        for (char c : s) {
            if (c == '(') {
                opened++;
            } else { // c == ')'
                if (opened > 0) {
                    opened--;
                } else {
                    // Need an extra '(' before this ')'
                    insertions++;
                }
            }
        }
        // Need to insert ')' for every unmatched '('
        return insertions + opened;
    }
};
```

---

## 5. **Example Walk-through**

**Example:**  
`s = "())"`

- **Step 1:** `'('` → `opened = 1`, `insertions = 0`
- **Step 2:** `')'`
    - `opened > 0`, matches, so `opened = 0`
- **Step 3:** `')'`
    - `opened == 0`, so need an insertion: `insertions = 1`

**After processing:**  
- `opened = 0` (no unmatched `'('`)
- `insertions = 1` (one unmatched `')'` needed a `'('` before it)

**Total answer:** `1`  
**Output:** `1`  

---

### **Summary Table for the Approach**

| Char | opened | insertions | Explanation                |
|------|--------|------------|----------------------------|
| '('  |   1    |     0      | Add one unmatched '('      |
| ')'  |   0    |     0      | Matches previous '('       |
| ')'  |   0    |     1      | Need '(' before this ')'   |

---

## **In summary:**
- Count unmatched `'('` and unmatched `')'` in one pass.
- Final answer = unmatched closing + unmatched opening counts.
- The C++ code above implements this efficiently.
