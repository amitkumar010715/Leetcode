---

## 1. **Short Summary**

Given a string `s` of only `a` and `b`, you need to delete as few characters as possible to ensure no `b` appears **before** an `a`. The resulting string must look like all `a`s on the left and all `b`s on the right (possibly some of one type missing). Return the **minimum number of deletions** needed.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
    - `1 <= s.length <= 100,000`
    - Each character is `'a'` or `'b'`
- **Edge Cases:**
    - String is already balanced (e.g. all `a`s then all `b`s).
    - All `a`s or all `b`s (already balanced, answer is 0).
    - Alternating characters (`"ababab"`, etc.).
    - All `b`s first, then all `a`s at the end (`"bbbaaa"`).

---

## 3. **Optimal Algorithm**

### Key insight:

For the string to be balanced, **all `a`s must appear before all `b`s**.

Let’s try to partition the string at some point:  
- Delete all `b`s to the **left** of the partition (so only `a`s remain on the left)  
- Delete all `a`s to the **right** of the partition (so only `b`s remain on the right)

We try every "split point" between characters, compute how many deletions needed, and pick the minimum.

#### Steps:

1. **Precompute right suffix counts of `a`s**  
   For each index `i`, the number of `a`s in `s[i:]`.

2. **Traverse from left to right, tracking left prefix count of `b`s**  
   For each split position, deletions = left `b`s + right `a`s.

3. The answer is the minimum over all splits (including the edge case where you delete all `a`s or all `b`s).

#### Time & Space Complexity

- O(n) time for a single pass each direction
- O(n) space for the suffix array; can optimize to O(1) if we scan twice

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int minimumDeletions(string s) {
        int n = s.size();

        // Compute suffix count of 'a's
        vector<int> sufA(n + 1, 0);
        // sufA[i]: number of 'a' in s[i:]
        for (int i = n - 1; i >= 0; --i) {
            sufA[i] = sufA[i+1] + (s[i] == 'a' ? 1 : 0);
        }

        int minDel = INT_MAX;
        int preB = 0;
        for (int i = 0; i <= n; ++i) {
            // Partition before index i: delete all b's in [0, i-1] and all a's in [i, n-1]
            minDel = min(minDel, preB + sufA[i]);
            if (i < n && s[i] == 'b') {
                preB++;
            }
        }
        return minDel;
    }
};
```

---

## 5. **Example Explained**

**Example 1:**  
`s = "aababbab"`

Let's analyze:

- Try all splits. For example:
  - **Split at i=0:** Left is empty, right is `"aababbab"`  
    - Delete all `a`s on the right: 4 deletions
  - **Split at i=2 (right after both 'a's):** Left is `"aa"`, right is `"babbab"`  
    - Left: zero `b` to delete; right: 2 `a`s in `"babbab"`, so 2 deletions
  - **Split at i=4:** Left: `"aaba"`, right: `"bbab"`  
    - Left: 1 `b` to delete, right: 1 `a` to delete; total 2 deletions

The code checks all these in O(n) using prefix and suffix counts and finds **minimum = 2**.

---

## **Wrap-up**

- The core idea is to precompute suffix `a` counts, traverse with prefix `b` counts, and keep track of the minimum deletions needed for every possible partition.
- The algorithm is O(n) and fits the constraints comfortably.
