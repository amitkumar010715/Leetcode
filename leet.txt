Let's address each requirement step by step:

---

### 1. **Short Summary**

Given an array of **distinct** integers, you need to remove both the minimum and maximum element. You can only remove elements from **the front or the back** of the array (not from the middle directly). You must find the **minimum total deletions** required to remove both.

---

### 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= nums.length <= 10^5`
- `-10^5 <= nums[i] <= 10^5`
- All numbers are distinct.

**Edge Cases:**
- Array length \( n = 1 \): Only one element, it's both min and max.
- Min and max are at the same position (only possible if array has length 1).
- Min at front and max at back (or vice versa): Can take both in one deletion each (2 total).
- Min and max are close together, e.g., both in the first 3 elements or last 3 elements.
- Large arrays: Only linear solutions are feasible.

---

### 3. **Optimal Algorithm (O(n) Time, O(1) Space)**

#### **Steps**

1. **Find indices** of the minimum and maximum elements:
   - Let's call them `minIdx` and `maxIdx`.

2. **Compute all possible ways to remove both**:
    - **Option 1:** Remove from the front only (cover both indices): `max(minIdx, maxIdx) + 1`
    - **Option 2:** Remove from the back only: `n - min(minIdx, maxIdx)`
    - **Option 3:** Remove from the front up to one, and from the back up to the other:
      - Remove up to leftmost one from the front, and up to rightmost one from the back: `minIdx + 1 + n - maxIdx` (if `minIdx < maxIdx`)
      - Or: `maxIdx + 1 + n - minIdx` (if `maxIdx < minIdx`)
      - But the general formula: `min(minIdx, maxIdx) + 1 + n - max(minIdx, maxIdx)`

3. Take the **minimum** of these options.

---

### 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minimumDeletions(vector<int>& nums) {
        int n = nums.size();
        int minIdx = 0, maxIdx = 0;
        for (int i = 1; i < n; ++i) {
            if (nums[i] < nums[minIdx]) minIdx = i;
            if (nums[i] > nums[maxIdx]) maxIdx = i;
        }
        // Ensure minIdx <= maxIdx for easier calculation
        int left = min(minIdx, maxIdx);
        int right = max(minIdx, maxIdx);
        // Three options:
        int opt1 = right + 1;            // remove from front both
        int opt2 = n - left;             // remove from back both
        int opt3 = (left + 1) + (n - right); // remove one from front, one from back
        return min({opt1, opt2, opt3});
    }
};
```

---

### 5. **Example Explanation ([2, 10, 7, 5, 4, 1, 8, 6])**

- `nums = [2, 10, 7, 5, 4, 1, 8, 6]`
- min = 1 at index 5
- max = 10 at index 1
    - left = min(1, 5) = 1
    - right = max(1, 5) = 5

Options:
- Option 1 (from front): remove first 6 elements: 5 + 1 = 6 removals (covers index 5, the later one)
- Option 2 (from back): remove last 7 elements: 8 - 1 = 7 removals (covers index 1, the earlier one)
- Option 3: remove 2 from front (indices 0, 1), and 3 from back (indices 7,6,5): (1+1)+(8 - 5) = 2+3=5

**Minimum deletions is 5.**

---

**Summary Table**:

| Option    | Calculation | Value |
|-----------|-------------|-------|
| From front | right + 1 | 6 |
| From back  | n - left   | 7 |
| Both ends  | (left+1)+(n-right) | 5 (best) |
