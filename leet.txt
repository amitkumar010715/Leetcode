Let's go through your requirements step by step:

---

### 1. **Short Summary**

Given values `n` and `k`, you want the `k`-th bit (1-indexed) of a recursively constructed binary string:
- **Base:** S₁ = "0"
- **Recurrence:** Sᵢ = Sᵢ₋₁ + "1" + reverse(invert(Sᵢ₋₁))

You **RETURN** the k-th bit in Sₙ without building the full string (which explodes exponentially).

---

### 2. **Constraints & Edge Cases**

- **Constraints:**
  - 1 ≤ n ≤ 20
  - 1 ≤ k ≤ 2ⁿ - 1 (length of Sₙ is always odd and exponential)
- **Edge Cases:**
  - k = 1 (first character)
  - k = 2ⁿ - 1 (last character)
  - n = 1 (S₁ = "0")
- You CANNOT build the entire string for large n due to exponential size (even for n=20, Sₙ has nearly a million bits!).

---

### 3. **Optimal Algorithm**

#### **Key Insight:**

- **Structure of Sₙ:**
  - Sₙ = [Sₙ₋₁] + '1' + reverse(invert([Sₙ₋₁]))

- **Observation:**
  - The string is symmetrical, with a center '1'. The right half is reverse(invert) of the left.

#### **Recursive Solution:**

Let lenₙ = 2ⁿ - 1 (length of Sₙ)

- **If k == mid** (mid = (lenₙ / 2) + 1, the center):  
    → Return '1'

- **If k < mid** (in the left part, which is Sₙ₋₁):  
    → The k-th bit is the same as in Sₙ₋₁.

- **If k > mid** (in the right part):  
    → Corresponds to reverse(invert(Sₙ₋₁)).
    → Let mirrored = lenₙ - k + 1 (the symmetric counterpart in Sₙ₋₁).
    → The answer is INVERT( result(n-1, mirrored) )

#### **Pseudocode:**

```text
FindKthBit(n, k):
    if n == 1: return '0'
    mid = (1 << (n-1))
    if k == mid:
        return '1'
    elif k < mid:
        return FindKthBit(n-1, k)
    else:
        mirrored = (1 << n) - k
        return invert(FindKthBit(n-1, mirrored))
```

- **invert('0') = '1', invert('1') = '0'**

#### **Time Complexity:** O(n)
- Max recursion depth is n.

---

### 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    char findKthBit(int n, int k) {
        if (n == 1) return '0';
        int mid = 1 << (n - 1);
        if (k == mid) return '1';
        if (k < mid) {
            return findKthBit(n - 1, k);
        } else {
            char bit = findKthBit(n - 1, (1 << n) - k);
            return bit == '0' ? '1' : '0';
        }
    }
};
```

---

### 5. **Example Explanation**

#### **Example: n = 4, k = 11**

Let's walk through the recursion.

- **Compute:** S₄, k = 11
- Length of S₄ = 2⁴ - 1 = 15
- Center (mid) = 8

1. **k = 11 > 8**, so we are in the right part.
    - mirrored = 16 - 11 = 5
    - Find S₃, k=5, and invert the bit.

2. **S₃**, mid = 4
    - k = 5 > 4, right part
    - mirrored = 8 - 5 = 3
    - Find S₂, k=3, invert.

3. **S₂**, mid = 2
    - k = 3 > 2, right part
    - mirrored = 4 - 3 = 1
    - Find S₁, k=1, invert.

4. **S₁, k=1:** return '0'.

Now, go back up inverts:
- invert '0' = '1' (S₂)
- invert '1' = '0' (S₃)
- invert '0' = '1' (S₄)

**The answer:** `"1"`
