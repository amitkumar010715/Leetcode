---

## 1. **Short Summary**

Given a binary string `s`, we want to make it "alternating" (no two adjacent characters are the same) with the **minimum number of character flips** (change `'0'` to `'1'` or vice versa). Find and return this minimum number.

---

## 2. **Constraints & Edge Cases**

- Length: `1 <= s.length <= 10^4` (so O(n) is optimal).
- `s` consists only of `'0'` and `'1'`.
- **Edge cases:**
    - Length 1: Already alternating, so answer is 0.
    - All same: May require many flips.
    - Already alternating: Answer is 0.

---

## 3. **Optimal Algorithm**

There are only **two possible valid alternating strings** for a string of length `n`:
1. Starting with `'0'`: Pattern is `"0101...."`.
2. Starting with `'1'`: Pattern is `"1010...."`.

For each character in `s`, compare with both the `'0'`-start and `'1'`-start patterns, and count mismatches (which represent needed flips). The minimum of these two counts is the answer.

**Steps:**
1. For each position `i` in `s`:
    - If `i%2 == 0`, 
        - Pattern 1 expects `'0'`, Pattern 2 expects `'1'`.
    - If `i%2 == 1`, 
        - Pattern 1 expects `'1'`, Pattern 2 expects `'0'`.
2. Count mismatches for both patterns.
3. Return the minimum.

**Time Complexity:**\
O(n) (single pass)

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int minOperations(string s) {
        int n = s.size();
        int count1 = 0; // flips to match pattern starting with '0'
        int count2 = 0; // flips to match pattern starting with '1'
        for (int i = 0; i < n; ++i) {
            char expected1 = (i % 2 == 0) ? '0' : '1';
            char expected2 = (i % 2 == 0) ? '1' : '0';
            if (s[i] != expected1) count1++;
            if (s[i] != expected2) count2++;
        }
        return min(count1, count2);
    }
};
```

---

## 5. **Example Explanation**

**Example:** `s = "0100"`

**Pattern 1 (start with '0'):** Should be `"0101"`
- Index 0: '0' (ok)
- Index 1: '1' (ok)
- Index 2: '0' (ok)
- Index 3: **should be '1'**, but is '0' (needs flip)

-> **1 flip** (at index 3)

**Pattern 2 (start with '1'):** Should be `"1010"`
- Index 0: should be '1' (is '0') → flip
- Index 1: should be '0' (is '1') → flip
- Index 2: should be '1' (is '0') → flip
- Index 3: should be '0' (is '0') → ok

-> **3 flips**

**Minimum = 1 flip**

---

**Summary Table:**

| Pattern    | Target   | Flips Needed |
|------------|----------|--------------|
| Start '0'  | "0101"   |      1       |
| Start '1'  | "1010"   |      3       |

**Final Answer:** `1`
