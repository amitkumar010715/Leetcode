## 1. **Short Summary**

Given two **sorted** arrays, return the smallest integer present in both. If there is no common integer, return -1.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= nums1.length, nums2.length <= 1e5`
- `1 <= nums1[i], nums2[j] <= 1e9`
- Both arrays are **sorted non-decreasingly.**

**Edge Cases:**
- Arrays with no common values (should return -1)
- Arrays with all values the same (should return the repeated value)
- Arrays with only one value in common (should return it)
- First value (minimum) is the common one (should return directly)
- Duplicates in one or both arrays
- Arrays of different lengths

---

## 3. **Optimal Algorithm**

**Observation:**
Since both arrays are sorted, we can use a **two-pointer approach**:
- Let `i` point to the start of `nums1`, `j` to the start of `nums2`.
- At each step:
    - If `nums1[i] == nums2[j]`, return `nums1[i]`.
    - Else, increment the pointer that points to the smaller value.
- If we reach the end of either array without finding a match, return -1.

**Time Complexity**:  
O(N+M) where N and M are lengths of the two arrays.  
**Space Complexity**:  
O(1) extra space.

---

## 4. **C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int getCommon(vector<int>& nums1, vector<int>& nums2) {
        int i = 0, j = 0;
        int n = nums1.size(), m = nums2.size();
        while(i < n && j < m) {
            if(nums1[i] == nums2[j]) return nums1[i];
            else if(nums1[i] < nums2[j]) ++i;
            else ++j;
        }
        return -1;
    }
};
```

---

## 5. **Example Explained**

**Example:**  
`nums1 = [1,2,3,6], nums2 = [2,3,4,5]`

**Walkthrough:**
- `i=0, j=0`: nums1[0]=1, nums2[0]=2  → 1<2 so increment `i`.
- `i=1, j=0`: nums1[1]=2, nums2[0]=2  → Equal! Return 2.

**Output:**  
`2` (the smallest common element)

---

**Summary:**  
Use two pointers to scan both arrays from the start. Only advance a pointer if its array has the smaller value. As soon as matching elements are found, return the value—guaranteed minimal due to sorted order. If no such value is found, return -1.
