Certainly! Here’s a thorough answer for “Minimum Moves to Equal Array Elements”:

---

## 1. **Summary**

Given an array, in one move you can increment **n - 1** elements by 1. Your goal is to find the *minimum* number of such moves to make all elements equal.

---

## 2. **Constraints & Edge Cases**

- **Array Size:** `1 ≤ nums.length ≤ 10^5`
- **Element Range:** `-10^9 ≤ nums[i] ≤ 10^9`
- Array may contain negative numbers, zeros, duplicates
- Output is guaranteed to fit in **32 bits**
- For an array where all elements are already equal, answer is **0**
- For a single element, answer is **0** (trivially equal)
---

## 3. **Optimal Algorithm**

### **Key Insight**

Incrementing `n-1` elements by 1 **is equivalent** to decrementing **1** element by 1 (the one you *don't* increment).

Thus, making all elements equal is the same as reducing all elements to the minimum element in the array by decrementing *one at a time*.

### **Solution**

- Let **min_elem** = minimum element in `nums`
- **Total moves = sum(nums) - n * min_elem**

Why? Because for each move, you're effectively making one number closer to the minimum until all are at min.

### **Algorithm Steps**
1. Find minimum (`min_elem`)
2. Calculate sum of array (`sum`)
3. Return `sum - n * min_elem`

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)` (if you don’t count input array)

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    int minMoves(vector<int>& nums) {
        long long sum = 0;
        int mn = INT_MAX;
        for (int v : nums) {
            sum += v;
            mn = min(mn, v);
        }
        return static_cast<int>(sum - (long long)nums.size() * mn);
    }
};
```
*Note: Use long long sum to prevent overflow in sum calculation!*

---

## 5. **Example Explained**

**Input:** `nums = [1, 2, 3]`

- **min_elem = 1**
- **sum = 1 + 2 + 3 = 6**
- **n = 3**
- **Moves = 6 - 3*1 = 3**

**How?**
- Move 1: [1,2,3] → [2,3,3] (increment all but last)
- Move 2: [2,3,3] → [3,4,3] (increment all but one)
- Move 3: [3,4,3] → [4,4,4]
- **Total moves = 3**

---

**In summary:**  
Calculate `sum(nums) - n * min_element` for the answer — all in linear time. This transforms the incrementing operation into a simple subtraction problem!
