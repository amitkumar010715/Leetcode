## 1. **Short Summary**

Given robots on the X-axis, and factories with limited capacities at certain positions, assign all robots to factories so that each factory takes at most its limit, and the **total distance all robots move to reach their assigned factories is minimized**. Output this minimum total distance.

---

## 2. **Constraints & Edge Cases**

- `1 <= robot.length, factory.length <= 100` (So DP solutions are feasible.)
- `-1e9 <= robot[i], position_j <= 1e9` (High value, but as only differences matter, after sorting, safe.)
- `0 <= limit_j <= robot.length` (A factory can have 0 capacity.)
- All positions (for robots and factories) are *unique*.
- It is always possible to repair all robots (limits add up sufficiently).
- Edge Cases:
  - All robots on the same side of all factories.
  - A factory with zero capacity.
  - Robots at the exact position of a factory.
  - Only one robot or one factory.
  - Some factories may not be used (if out of the way or have zero limit).

---

## 3. **Optimal Algorithm (with Explanation)**

### **Approach: DP Assignment**

- **Sort robots and factories by positions**: This makes matching left-to-right logical.
- Define `dp[r][f]` = minimal cost to repair robots `r..end` with factories `f..end`.
  - **For each (r, f):**
    - **Option 1:** Skip factory `f` (use `f+1` for robot `r`): `dp[r][f+1]`
    - **Option 2:** Use factory `f` to fix `k` robots (from `r` up to `r+k-1`, for `k=1..limit_f`), and add the cost of sending these robots to `factory_pos_f`.
      - For each possible `k`:
         - Cost = `sum_{i=r}^{r+k-1} |robot[i] - factory[f][0]|`
         - Next state: `dp[r+k][f+1]`
         - Keep the minimum over all possible `k`
    - Memoize to avoid recomputation.

#### **Time complexity:**
- O(R * F * L), for R robots, F factories, L up to 100 robots per factory, so it's O(100*100*100) = 1,000,000, which is fast enough.

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    long long dp[105][105]; // Memoization array

    long long solve(int ri, int fi, const vector<int>& robots, const vector<pair<int, int>>& factories) {
        int R = robots.size(), F = factories.size();
        if (ri == R) return 0;       // All robots assigned
        if (fi == F) return LLONG_MAX / 2; // Out of factories (not possible, but for safety)
        if (dp[ri][fi] != -1) return dp[ri][fi];

        long long ans = solve(ri, fi+1, robots, factories);  // Option 1: skip factory fi

        // Option 2: Assign k robots (k in [1, limit]) to factory fi
        long long cost = 0;
        int limit = factories[fi].second;
        for (int k = 1; k <= limit && ri + k - 1 < R; k++) {
            cost += abs(robots[ri + k - 1] - factories[fi].first);
            long long next = solve(ri + k, fi + 1, robots, factories);
            ans = min(ans, cost + next);
        }
        return dp[ri][fi] = ans;
    }

    long long minimumTotalDistance(vector<int>& robot, vector<vector<int>>& factory) {
        sort(robot.begin(), robot.end());
        vector<pair<int, int>> fact;
        for (auto& f : factory)
            fact.emplace_back(f[0], f[1]);
        sort(fact.begin(), fact.end());

        // Initialize DP table
        memset(dp, -1, sizeof(dp));
        return solve(0, 0, robot, fact);
    }
};
```

## 5. **Example Explanation**

> **Example 1**  
> `robot = [0,4,6], factory = [[2,2],[6,2]]`

- After sorting:  
  robots: `[0,4,6]`  
  factories: `[[2,2], [6,2]]`

- DP explores:
  - Robot 0 and robot 4 both go to factory at 2: costs = `|2-0| + |2-4| = 2 + 2 = 4`. Factory 2's limit is 2, so it can take 2 robots.
  - Robot 6 goes to factory 6: `|6-6| = 0`.
  - Total = `4 + 0 = 4`
- This is optimal, as sending robot 4 to factory 6 would be higher cost: `|6-4| = 2`, but now robot 2 only takes one robot and factory 6 two.
- Algorithm checks all such splits.

---

### **Summary of Optimal Algorithm Steps**

1. **Sort** robots and factories by position.
2. **DP:**  
   For each robot and factory, consider all possible numbers of robots to assign (up to factory limit), compute cost, recurse.
3. **Base case:** All robots assigned.
4. **Return minimal total distance.**
