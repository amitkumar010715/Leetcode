Let's break down the **LeetCode daily challenge: "Check if Array is Good"** step by step.

---

## 1. **Short Summary**

Given an array `nums`, check if it is a permutation of a "base array" defined for some `n` as  
`base[n] = [1, 2, ..., n-1, n, n]`, i.e., it consists of `1` to `n-1` each once and `n` twice.  
You need to check if `nums` is such a permutation.

---

## 2. **Constraints & Edge Cases**

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 200`
- For `nums` to be "good":
    - Let `n = max(nums)` (since base[n] always contains two `n` and no element greater than `n`).
    - `nums.size() == n + 1`
    - For each `k` in `[1, n-1]`, `k` appears **exactly once**; `n` appears **exactly twice**.
- Edge Cases:
    - All elements are `1`. Only possible valid size: `[1, 1]`.
    - Any missing numbers in `[1, n-1]` make it invalid.
    - More or fewer than 2 occurrences of `n` make it invalid.

---

## 3. **Optimal Algorithm**

1. Find `n = max(nums)`.
2. Check if `nums.size() == n + 1`. If not, return false.
3. Count occurrences of each number in `nums`:
    - For each `k` in `[1, n-1]`, check count is 1.
    - Check count of `n` is exactly 2.
    - If all checks pass, return true. Otherwise, return false.

Time: O(N), as counting/validation is linear and input size is small.

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>

class Solution {
public:
    bool isGood(std::vector<int>& nums) {
        int n = *max_element(nums.begin(), nums.end());
        if (nums.size() != n + 1) return false;

        std::vector<int> count(n + 1);
        for (int x : nums) {
            if (x < 1 || x > n) return false;
            count[x]++;
        }
        // Check counts
        for (int i = 1; i <= n - 1; ++i)
            if (count[i] != 1) return false;
        if (count[n] != 2) return false;

        return true;
    }
};
```

---

## 5. **Example Explanation**

**Example: `nums = [1, 3, 3, 2]`**

- `n = max(nums) = 3`
- Expected base[3]: `[1, 2, 3, 3]`
- Size: `nums.size() == 4 == n + 1` ✔
- Counting elements:
    - Count for `1`: 1 ✔
    - Count for `2`: 1 ✔
    - Count for `3`: 2 ✔
- All other values (`[4, 5, ...]`): Not present (which is fine).
- So, `nums` is **a permutation of `[1, 2, 3, 3]`** ⇒ output is `true`.
