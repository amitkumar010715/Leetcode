---

## 1. **Short Summary**

Given an integer `k`, find the length of the smallest positive integer `n` made **only of digit '1'** (e.g. 1, 11, 111, ...) such that `n` is divisible by `k`. Return its length, or `-1` if such a number doesn't exist.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= k <= 10^5`
- **Edge Cases:**
  - If `k` is even or divisible by 5, such `n` does **not exist** (because numbers with only digit '1' are not divisible by 2 or 5).
  - k=1: The answer is 1.
  - For some values of k, the repeating remainder cycle guarantees an answer ≤ k, or we know it's impossible.

---

## 3. **Optimal Algorithm**

### Key Insights

- The numbers considered (`n`) are: 1, 11, 111, 1111, ...
- We can't construct `n` directly (it's too big), but we can work with their **remainders modulo k**.
- At each step:
  - Let `rem` be the remainder of the number so far.
  - New remainder: `rem = (rem * 10 + 1) % k`
  - If at any point `rem == 0`, we've found our answer.
- **Cycle detection**: There are at most `k` unique possible remainders (`0..k-1`). If we repeat a remainder (excluding 0), there is an infinite loop (impossible case).

### Steps

1. If `k` is divisible by 2 or 5, return `-1`.
2. Initialize `rem = 0`.
3. For up to `k` steps (length from 1 to k):
   - `rem = (rem * 10 + 1) % k`
   - If `rem == 0`, return current length.
4. If no such remainder found, return `-1`.

#### Time Complexity:

- **O(k)**

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    int smallestRepunitDivByK(int k) {
        // If k is even or divisible by 5, impossible
        if (k % 2 == 0 || k % 5 == 0) return -1;
        
        int rem = 0;
        for (int length = 1; length <= k; ++length) {
            rem = (rem * 10 + 1) % k;
            if (rem == 0) return length;
        }
        return -1;
    }
};
```

---

## 5. **Example Explained**

**Input:** `k = 3`

- Let's simulate:
  - Length 1: rem = (0 * 10 + 1) % 3 = 1
  - Length 2: rem = (1 * 10 + 1) % 3 = 11 % 3 = 2
  - Length 3: rem = (2 * 10 + 1) % 3 = 21 % 3 = 0

When length is 3, remainder is 0.  
So, the smallest such number is "111" (which is 111 / 3 = 37), and its length is **3**.

---

### **Summary Table for k = 3**

| Step | Build Number | Remainder Calculation | Remainder |
|------|--------------|-----------------------|-----------|
| 1    | 1           | 1 % 3                 | 1         |
| 2    | 11          | (1*10+1)%3 = 11 % 3   | 2         |
| 3    | 111         | (2*10+1)%3 = 21 % 3   | 0         |

At length 3, remainder is 0 → **return 3**.
