## 1. **Short Summary**

Given an array `nums`, we are to count indices (partitions) such that the difference between the sum of the left part `[0, i]` and the right part `[i+1, n-1]` is **even**. That is, `sum_left - sum_right` should be even.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `2 <= n == nums.length <= 100`
  - `1 <= nums[i] <= 100`
- **Edge Cases:**
  - All values are even → all partitions are valid.
  - All values are odd → depends on the count of odds accumulated in sum_left and sum_right.
  - Minimal length (`n=2`): Only 1 possible partition.
  - No partition is valid (e.g., [1,2,2]).
  - All partitions are valid (e.g., [2,4,6,8]).

---

## 3. **Optimal Algorithm**

### **Key Insight**

Let `S` be the total sum. For an index `i`:
- `left_sum = prefix_sum[i]`
- `right_sum = S - prefix_sum[i]`
- The difference: `D = left_sum - right_sum = 2 * left_sum - S`

We require `D` to be **even**.

- `2 * left_sum - S` even ⇨ since `2 * left_sum` is always even, `S` must be **even** for the sum to be even.
- Therefore, the difference is **even iff the total sum S is even**.

But let's formalize this:
- `D = 2 * prefix_sum[i] - S`
- `D even` ⇔ `2 * prefix_sum[i] - S` is even
- `2 * prefix_sum[i]` is always even, so difference is even iff `S` is even

#### **Conclusion**
- If `S` is **odd**, it's **impossible** to get an even difference for any partition (since subtracting an odd number from an even gives odd).
- If `S` is **even**, then for all `i` where `prefix_sum[i]` is integer:
    - `D is even` always, so **all partitions are valid**.

**Wait, is this correct? Let's test with the given example [1,2,2]:**

Total sum = 5 (odd). So, **no valid partitions** — confirmed by example.

For [2,4,6,8]: sum = 20 (even), so **all partitions are valid** — confirmed.

## 4. **C++ Solution**

Given the approach, the steps are:
1. Compute the total sum `S`.
2. If `S` is odd, return 0.
3. Otherwise, count all possible partitions (`n-1`).

**C++ Implementation:**

```cpp
class Solution {
public:
    int countPartitions(vector<int>& nums) {
        int n = nums.size();
        int S = 0;
        for (int x : nums) S += x;
        // If total sum is odd, no valid partitions
        if (S % 2 != 0) return 0;
        // Otherwise, all n-1 partitions are valid
        return n - 1;
    }
};
```

## 5. **Example Explained**

**Example 1:**

`nums = [10,10,3,7,6]`  
Total sum: 10+10+3+7+6 = **36** (even)

Possible partitions (indices 0...n-2):

- Partition at i = 0: left = [10], right = [10,3,7,6], difference = 10 - 26 = -16 (even)
- Partition at i = 1: left = [10,10], right = [3,7,6], difference = 20 - 16 = 4 (even)
- Partition at i = 2: left = [10,10,3], right = [7,6], difference = 23 - 13 = 10 (even)
- Partition at i = 3: left = [10,10,3,7], right = [6], difference = 30 - 6 = 24 (even)

All 4 possible partitions are valid, **answer: 4**.
