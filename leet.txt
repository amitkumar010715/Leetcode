## 1. **Short Summary**

Given a string consisting only of 'a' and 'b', check if **all** `'a'` characters appear **before** any `'b'`. If any `'a'` appears **after** a `'b'`, return `false`. Otherwise, return `true`.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - 1 ≤ s.length ≤ 100
  - s consists of only 'a' and 'b'

- **Edge Cases:**
  - The string contains all `'a'` or all `'b'`: Always valid, return `true`.
  - The string is a single character: Always valid, return `true`.
  - 'a' appears after a 'b' (e.g., "ba", "aabbbaa"): Invalid, return `false`.

---

## 3. **Optimal Algorithm**

### **Key Insight**
Once a `'b'` is found, there **must not** be any more `'a'` after it. If that happens, the order is violated.

### **Algorithm Steps**
1. Iterate through the string.
2. After you find a `'b'`, if you encounter any more `'a'`, **return false**.
3. If no such violation is found, **return true**.

### **Time Complexity:** O(n), where n is the length of the string.

#### **Alternative**
You can check if the string contains the substring `"ba"`. If yes, return `false`; otherwise, `true`.  
But to match the competitive programming requirement and be explicit, we go with the loop.

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    bool checkString(string s) {
        bool found_b = false;
        for (char c : s) {
            if (c == 'b') {
                found_b = true;
            } else if (found_b && c == 'a') {
                // Found an 'a' after 'b'
                return false;
            }
        }
        return true;
    }
};
```

---

## 5. **Example Explained**

**Example:**  
Input: `s = "aaabbb"`

- Traverse from left:
  - Index 0: 'a' (OK)
  - Index 1: 'a' (OK)
  - Index 2: 'a' (OK)
  - Index 3: 'b' (first 'b' found, set flag)
  - Index 4: 'b' (no issue, as 'a' not found after 'b')
  - Index 5: 'b' (no issue)

At **no point** is there an `'a'` after the `'b'`, so **return `true`**.

---

**Summary Table:**

| String         | Output | Reason                                    |
|----------------|--------|-------------------------------------------|
| "aaabbb"       | true   | All a's before all b's                    |
| "abab"         | false  | Found 'a' after first 'b'                 |
| "bbb"          | true   | No 'a's, trivially valid                  |
| "a"            | true   | Only one char, valid                      |
| "ba"           | false  | 'a' appears after 'b'                     |
