Let's address the problem step by step:

---

## 1. **Short Summary**

Given two axis-aligned rectangles represented by `[x1, y1, x2, y2]`, determine whether their **interior areas overlap** (overlapping area is positive). Rectangles touching only at a side or corner do **not** count as overlapping.

---

## 2. **Constraints & Edge Cases**

- Each rectangle's array has exactly 4 integers.
- Coordinates can be very large or very small: \([-10^9, 10^9]\).
- Rectangles always have **non-zero area** (x1 < x2 and y1 < y2 for both rectangles).
- Edge cases:
  - Rectangles only **touch** at the edge or a corner (should return `false`).
  - One rectangle is completely inside the other (should return `true`).
  - The rectangles are far apart (should return `false`).

---

## 3. **Optimal Algorithm**

**Key observation:**  
Two rectangles DO NOT overlap if:
- One is completely to the left of the other, or
- One is completely to the right of the other, or
- One is completely above the other, or
- One is completely below the other.

So, **their projections on both X and Y axes must intersect with positive length**.

**Mathematical Condition:**
Suppose:
- Rectangle 1: `[x1, y1, x2, y2]`
- Rectangle 2: `[a1, b1, a2, b2]`

They **overlap iff** BOTH:
- `min(x2, a2) > max(x1, a1)` (**X-axis** overlap is positive)
- `min(y2, b2) > max(y1, b1)` (**Y-axis** overlap is positive)

If either is ≤ (i.e., just touch), then they don't overlap.

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    bool isRectangleOverlap(vector<int>& rec1, vector<int>& rec2) {
        // rec1: [x1, y1, x2, y2], rec2: [a1, b1, a2, b2]
        return min(rec1[2], rec2[2]) > max(rec1[0], rec2[0]) &&
               min(rec1[3], rec2[3]) > max(rec1[1], rec2[1]);
    }
};
```

---

## 5. **Example Explanation**

**Example 1:**
``` 
rec1 = [0,0,2,2]
rec2 = [1,1,3,3]
```
- X projections: `[0,2]` and `[1,3]`  
  - Overlap is `[1,2]` (length 1)
- Y projections: `[0,2]` and `[1,3]`  
  - Overlap is `[1,2]` (length 1)
- Both overlaps have positive length, thus **rectangles overlap** → output: `true`.

If the rectangles were `[0,0,1,1]` and `[1,0,2,1]`:
- Overlap in X: `[1,1]` (length 0, just touching at the side), so they **do not overlap** → output: `false`.

---

## **Summary Table**

| Condition                          | Overlap? |
|-------------------------------------|----------|
| X and Y overlap > 0                | true     |
| X overlap = 0 OR Y overlap = 0     | false    |
| Only corners/edges touch           | false    |

---

**This method is optimal (\(O(1)\)) and handles all cases!**
