## 1. **Short Summary**

Given an even-length array `nums` and an integer `limit`, we want to make the array **complementary**: for every index `i`, `nums[i] + nums[n - 1 - i]` equals the same constant for all `i`. In one move, we can set any number to any value from `1` to `limit`. The task is to **find the minimum number of moves needed**.

---

## 2. **Constraints & Edge Cases**

- **n** can be up to 10^5, so **O(n log n)** or **O(n)** is required.
- Every number in `nums` is already in the range [1, limit].
- `n` is always **even**.
- Trivial case: If `nums` is already complementary, answer is 0.
- Edge: Minimum (`2`) and maximum (`10^5`) `n` and `limit`.

---

## 3. **Optimal Algorithm**

### Key Insights

- We only need to consider **(n/2) pairs**: `(nums[i], nums[n-1-i])`.
- For each pair `(a, b)` (with `i` from `0` to `n/2-1`), the sum is `a + b`.
- To make all pairs sum to some target `T`, we can change `a`, `b` or both in each pair.

Let’s analyze **for a single pair** how many moves are needed to reach a sum `T`:

- **0 moves needed:** If `a + b == T`
- **1 move needed:** If `T` is between `min(a, b) + 1` to `max(a, b) + limit` (i.e., you can change one of the two to make the pair sum to `T`)
- **2 moves needed:** Otherwise

### Efficient Calculation

We can use a **sweep line with prefix sums** and difference arrays to process all candidate targets (`T`) in linear time.

#### For Each Pair:

For the pair `(a, b)`:
- If we do **nothing**, cost is 0 when sum is exactly `a + b`.
- If we change **one element**, cost is 1 if `T` is in `[min(a, b) + 1, max(a, b) + limit]`.
- Otherwise, **two moves** needed.

We can formulate **for each pair** – how many moves are required for each possible `T`, as follows:

- Initially, **cost is 2** for all sums.
- For sums in `[min(a, b)+1, max(a, b)+limit]`, cost reduces to 1 (change one element).
- For sum at `a + b`, cost further reduces to 0 (no change needed).

Thus, it's a **range operation problem** – for each pair, we update:
- Add 1 to the range `[min(a, b)+1, max(a, b)+limit]` (cost from 2→1)
- Add -1 at `a + b` to make cost from 1→0.

#### Implementation

We’ll use a difference array `diff` (size `2*limit + 2`), initially all pairs have 2 moves/cost. For each pair, we update:
- `diff[lo] -= 1`   and   `diff[hi+1] += 1` where `lo = min(a, b)+1, hi = max(a, b)+limit`
- At `diff[s] -= 1` and `diff[s+1] += 1`, where `s = a+b` (cost reduces from 1 to 0 at `s`)
  
Finally, do a prefix sum, and for all possible `T` in `[2, 2*limit]`, pick the minimal total cost.

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minMoves(vector<int>& nums, int limit) {
        int n = nums.size();
        vector<int> diff(2 * limit + 2, 0); // difference array

        for (int i = 0; i < n / 2; ++i) {
            int a = nums[i], b = nums[n - 1 - i];
            int lo = min(a, b) + 1;
            int hi = max(a, b) + limit;
            int s = a + b;

            // For sums in [lo, hi], reduce cost from 2 to 1
            diff[lo]   -= 1;
            diff[hi + 1] += 1;

            // For sum == s, reduce cost from 1 to 0
            diff[s]    -= 1;
            diff[s + 1] += 1;
        }

        int res = n; // the maximal cost is n (if every pair requires 2 moves)
        int curr = n; // initially, each pair needs 2 moves
        for (int T = 2; T <= 2 * limit; ++T) {
            curr += diff[T];
            res = min(res, curr);
        }
        return res;
    }
};
```

## 5. **Example Explained**

**Example:** `nums = [1,2,4,3]`, `limit = 4`

- Pair indices: `(0,3)` → (1,3); `(1,2)` → (2,4)
- For pair (1,3):
  - min=1, max=3, sum=4
  - Range for 1 move: [2, 7]
  - So cost 1 in [2,7], cost 0 at 4.
- For pair (2,4):
  - min=2, max=4, sum=6
  - Range for 1 move: [3,8]
  - So cost 1 in [3,8], cost 0 at 6.

Sweep through T=2..8:
- T=4: Both pairs can be changed to sum 4 in 1 move (for one pair 0 moves, other 1 move)
- T=6: Similar

Minimum total moves is **1** (change only one element).

---

### **Summary**

- For each pair, by using a difference array, we efficiently mark for each possible target sum `T` the cost reduction points.
- Overall, sweep from T=2 to 2*limit, and pick the minimum total moves.
- **Time:** O(n + limit)
- **Space:** O(limit)
