---

## 1. **Short Summary**

Given a circular integer array, build a new array where each element is replaced by the value found after moving either `nums[i]` steps to the right (if positive), left (if negative), or staying put (if zero). Movement is modulo the array's length because the array is circular.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= nums.length <= 100` (very small constraint, so O(n) is trivial)
- `-100 <= nums[i] <= 100` (moves cover full wrap-around)
- Array can contain negative, zero, or positive values.

**Edge Cases:**
- **Single element**: Moving any number of steps should always wrap to itself.
- **Move magnitude >= length**: Movement should always be `mod n` (e.g., move 101 steps in size 5 array is 1 step).
- **Zero value**: Stay put, i.e., `result[i] = nums[i]`.
- **Negative index after move**: Should be wrapped into [0,n-1] range (C++ handles negative modulo differently, so manual adjustment is needed).
- **All zeros** or all positive/negative values.

---

## 3. **Optimal Algorithm**

For each index `i`:
- If `nums[i] == 0`, set `result[i] = nums[i]`.
- Otherwise, calculate new index as `i + nums[i]` (for positives) or `i + nums[i]` (for negatives).
- Wrap index using `((i + nums[i]) % n + n) % n` due to negative modulo in C++.
- Set `result[i] = nums[wrapped_index]`.

Time Complexity: **O(n)**, Space: **O(n)**.

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> transformedArray(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n);
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 0) {
                result[i] = 0;
            } else {
                // Wrap the index for circular movement
                int newIdx = ((i + nums[i]) % n + n) % n;
                result[i] = nums[newIdx];
            }
        }
        return result;
    }
};
```

---

## 5. **Example Explanation**

Let's take **Example 1:**

**Input:** `nums = [3, -2, 1, 1]`

Let's process each element:

- `i = 0`, `nums[0] = 3`
    - Move 3 steps right: `(0 + 3) % 4 = 3` ⇒ `nums[3] = 1`
    - result[0] = `1`

- `i = 1`, `nums[1] = -2`
    - Move 2 steps left: `(1 + (-2)) = -1`
    - Wrap: `(-1 % 4 + 4) % 4 = (3 + 4) % 4 = 3 % 4 = 3` ⇒ `nums[3] = 1`
    - result[1] = `1`

- `i = 2`, `nums[2] = 1`
    - Move 1 step right: `(2 + 1) % 4 = 3`
    - result[2] = `nums[3] = 1`

- `i = 3`, `nums[3] = 1`
    - Move 1 step right: `(3 + 1) % 4 = 0`
    - result[3] = `nums[0] = 3`

**Final output:** `[1, 1, 1, 3]`

---

**In summary:**  
- Move right for positive, left for negative, with circular wrap using modulo, and `((index % n) + n) % n` for correct handling of negative results in C++.  
- Each result is the value you land on after such a move.
