Let's address each requirement step by step:

---

## 1. **Short Summary**

Given a binary matrix, you can **rearrange the columns** in any order, any number of times.  
Find the maximum possible area of a submatrix (**contiguous block**) consisting entirely of 1s, over all possible column orders.

---

## 2. **Constraints & Edge Cases**

- **Matrix Size:** `1 <= m * n <= 10^5` (the product, so matrices can be very large and non-square)
- **Values:** Only 0 or 1.
- **Edge Cases:**
  - All zeros: max area is `0`.
  - All ones: max area is size of matrix.
  - Very wide (n >> m) or very tall (m >> n): watch out for row-major and column-major logic.
  - A single row or column.

---

## 3. **Optimal Algorithm**

### *High-level Idea*

- **Column rearrangement** allows us to place the "tallest columns" (longest consecutive 1s up to each row) together, maximizing rectangle area inside any row.
- For each row, we can treat the current state as a "histogram" of heights. By **sorting the histogram for the row in descending order**, we can compute the largest rectangle using first `k` columns with height ≥ the `k`-th tallest.

### *Details*

1. **Compute heights:** For each cell, compute the current height of consecutive 1s **above and including** row `i` (if `matrix[i][j]` is 1, it is `heights[i-1][j] + 1`, else 0).
2. For each row, sort the array of column heights in descending order.
3. For position `k` (starting at 0), maximal rectangle area using first `k+1` columns is:  
   `area = heights[k] * (k+1)`  
   This works because, after sorting, for first `k+1` columns, each column is **at least** `heights[k]` tall.
4. Keep the maximal area across all rows.

### *Time Complexity*

- Preprocessing all heights: O(m \* n)
- Sorting each row: O(m \* n log n) worst-case (but with constraints, we need O(m \* n log n) to work; that's ~ 2 million ops at most for moderate n, so acceptable).

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int largestSubmatrix(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        // Calculate heights
        for (int i = 1; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (matrix[i][j])
                    matrix[i][j] += matrix[i-1][j];
            }
        }
        int maxArea = 0;
        // For each row
        for (int i = 0; i < m; ++i) {
            // Copy and sort the heights for this row
            vector<int> heights = matrix[i];
            sort(heights.begin(), heights.end(), greater<int>());
            for (int k = 0; k < n; ++k) {
                int area = heights[k] * (k+1);
                if (area > maxArea) maxArea = area;
            }
        }
        return maxArea;
    }
};
```

## 5. **Example Explanation**

Take:
```
matrix = [
  [0,0,1],
  [1,1,1],
  [1,0,1]
]
```

**Heights Calculation:**

At each cell, show how many consecutive 1s from top to current row:

```
Row 0:  0 0 1
Row 1:  1 1 2
Row 2:  2 0 3
```

**Row 1:** (heights = [1,1,2])  
Sort descending: [2,1,1]  
Possible areas:
- 2*1 = 2 (using tallest col alone)
- 1*2 = 2 (using 2 highest cols)
- 1*3 = 3 (using all three)

**Row 2:** (heights = [2,0,3])  
Sort: [3,2,0]
- 3*1=3
- 2*2=4 ← maximum area here!
- 0*3=0

**So max area is 4.**

---

### **Summary Table**

| Row | Heights    | Sorted      | Areas (by prefix)   |
|-----|------------|-------------|---------------------|
|  0  | 0 0 1      | 1 0 0       | 1, 0, 0             |
|  1  | 1 1 2      | 2 1 1       | 2, 2, 3             |
|  2  | 2 0 3      | 3 2 0       | 3, 4, 0             |

Largest = 4.

---

## **Summary**

- Calculate "heights" for each cell.
- For each row, sort heights descending.
- For each prefix, area = height * number columns.
- Return max area over all rows.
