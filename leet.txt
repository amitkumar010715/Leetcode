## 1. Short Summary

**Problem:**  
Given an ascending sorted array that may have been rotated at an unknown pivot (with all elements unique), and a `target` value, efficiently determine the index of the target value, or return -1 if it does not exist.

**Goal:**  
Algorithm must run in **O(log n)** time.

---

## 2. Constraints & Edge Cases

- **Array Length:** `1 <= nums.length <= 5000`.
- **Element Value Range:** All elements and the target are in `[-10000, 10000]`.
- **Unique Values:** No duplicates in `nums`.
- **Always a Rotation:** Could be a zero rotation (not rotated at all).
- **Possible Edges:**
  - Array is not rotated (normal binary search).
  - Array has length 1.
  - Target is not present.
  - Target is at the pivot or the boundaries.
  - Minimal or maximal values may be the target.
  
---

## 3. Optimal Algorithm

Since the array is essentially two sorted ascending subarrays split by the rotation, we can **modify binary search** as follows:

- At each step, you examine `nums[mid]`. 
- One "half" (left or right) must be **sorted** (since a single rotation splits at only one point).
- Decide if the target is in the sorted half, and **narrow search** accordingly.

**Steps:**
1. Set `low = 0`, `high = n-1`.
2. While `low <= high`:
    - Get `mid = (low + high) / 2`.
    - If `nums[mid] == target`: **Return `mid`.**
    - Identify the **sorted half**:
      - If `nums[low] <= nums[mid]`: **Left half is sorted**.
          - If `nums[low] <= target < nums[mid]`: search **left half** (`high = mid - 1`).
          - Else: search **right half** (`low = mid + 1`).
      - Else: **Right half is sorted**.
          - If `nums[mid] < target <= nums[high]`: search **right half** (`low = mid + 1`).
          - Else: search **left half** (`high = mid - 1`).
3. If target not found, return **-1**.

This approach always discards half of the range, guaranteeing O(log n) time.

---

## 4. Clean C++ Solution

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int low = 0, high = nums.size() - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (nums[mid] == target)
                return mid;
            
            // Left half is sorted
            if (nums[low] <= nums[mid]) {
                if (nums[low] <= target && target < nums[mid])
                    high = mid - 1;      // Target in left half
                else
                    low = mid + 1;       // Target in right half
            }
            // Right half is sorted
            else {
                if (nums[mid] < target && target <= nums[high])
                    low = mid + 1;       // Target in right half
                else
                    high = mid - 1;      // Target in left half
            }
        }
        return -1;
    }
};
```

## 5. Example Explanation

**Example:**  
`nums = [4,5,6,7,0,1,2], target = 0`

- Initial: `low=0`, `high=6`
- 1st Iteration:  
    - `mid=3`, `nums[3]=7`
    - Left half `[4,5,6,7]` is sorted
    - Is `target` (`0`) in `[4,5,6,7]`? No (`0 < 4`)
    - So, search right: `low = 4`
- 2nd Iteration:  
    - `low=4`, `high=6`
    - `mid=5`, `nums[5]=1`
    - Right half `[1,2]` is sorted
    - Is `target` (`0`) in `[0,1,2]`? Yes (`0 >= 0 && 0 < 1`)
    - So, search left: `high = 4`
- 3rd Iteration:
    - `low=4`, `high=4`
    - `mid=4`, `nums[4]=0` (Found target!)
- **Return index 4.**
