### 1. **Short Summary**

Given a string `text`, we need to determine the **maximum number of times** we can use its characters to form the word `"balloon"`. Each character in `text` can be used **at most once**. Return the greatest number of non-overlapping `"balloon"`s that can be formed.

---

### 2. **Constraints & Edge Cases**

- **Constraints**:
    - `1 <= text.length <= 10^4`
    - Input contains only lowercase English letters.
- **Edge Cases**:
    - If `text` doesn't have all the letters needed for `"balloon"`, output is `0`.
    - Letters `'l'` and `'o'` are needed **twice** for each `"balloon"`; others only once.
    - Very short `text` may not contain enough letters.

---

### 3. **Optimal Algorithm**

**Main Idea**:  
Count how many times each character in `"balloon"` appears in `text`. For `'l'` and `'o'`, since each appears **twice** in `"balloon"`, their count must be halved (integer division) before comparing. The final answer is the **minimum** such count across all required characters.

**Steps**:
1. Create a frequency map (array or hash map) of letters in `text`.
2. For each character in `"balloon"`, calculate how many times it can be taken from `text`, accounting for multiplicity (`l`, `o` need 2 each).
3. The answer is the *minimum* number of `"balloon"`s we can construct by available letters.

**Time Complexity**: **O(n)**  
Where `n` is the length of `text`. Just one pass to count, and one pass over `"balloon"`'s unique letters.

---

### 4. **C++ Solution**

```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxNumberOfBalloons(string text) {
        vector<int> freq(26, 0);
        for(char c : text)
            freq[c - 'a']++;
        
        // 'b','a','l','o','n' are needed. 'l' and 'o' are needed twice.
        int count_b = freq['b' - 'a'];
        int count_a = freq['a' - 'a'];
        int count_l = freq['l' - 'a'] / 2;
        int count_o = freq['o' - 'a'] / 2;
        int count_n = freq['n' - 'a'];
        
        return min({count_b, count_a, count_l, count_o, count_n});
    }
};
```

---

### 5. **Example Explanation**

#### Input: `"loonbalxballpoon"`

- Letter frequency breakdown:
    - b: 2, a: 2, l: 4, o: 4, n: 2
- For `"balloon"` we need:
    - b: 1, a: 1, l: 2, o: 2, n: 1
- Calculating per word:
    - b: 2 // 1 = 2
    - a: 2 // 1 = 2
    - l: 4 // 2 = 2
    - o: 4 // 2 = 2
    - n: 2 // 1 = 2
- **Answer**: `min(2,2,2,2,2) = 2`

So, we can make `"balloon"` **2 times** with the letters in this input.
