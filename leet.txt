Let's walk through the solution step by step:

---

## 1. **Short Summary**

Given a binary array, build the prefix number for each index as a binary number and check if that number is divisible by 5. Return a boolean array where each element is `true` if corresponding prefix is divisible by 5.

---

## 2. **Constraints & Edge Cases**

### **Constraints**
- `1 <= nums.length <= 10^5`: The array can be quite large, so O(n) solutions are needed.
- `nums[i]` is `0` or `1`.

### **Edge Cases**
- All zeros: e.g., `[0, 0, 0]` - should all be `true` (since 0 is divisible by 5).
- First bits zero: e.g., `[0, 1, 0, 1]`.
- All ones: e.g., `[1, 1, 1, 1]`.
- Mixed pattern.
- Very long arrays.

---

## 3. **Optimal Algorithm**

### Key Insight:

#### Avoid Huge Numbers:
- Instead of actually forming the complete number (which may be too large for 64-bits), we keep the prefix modulo 5 (`num % 5`).
- With each additional bit, the prefix number forms as:  
    `num_next = num_prev*2 + nums[i]`
- So,
    `num_next % 5 = ((num_prev % 5) * 2 + nums[i]) % 5`
- Just keep the current value modulo 5.

### Steps
1. Initialize `prefix_mod` to 0.
2. For each bit in `nums`:
    - `prefix_mod = (prefix_mod * 2 + nums[i]) % 5`
    - If `prefix_mod == 0`, append `true`, else `false`.

**Time Complexity:** O(n), single scan.

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<bool> prefixesDivBy5(vector<int>& nums) {
        vector<bool> result;
        int prefix_mod = 0;
        for (int bit : nums) {
            prefix_mod = ((prefix_mod << 1) | bit) % 5;
            result.push_back(prefix_mod == 0);
        }
        return result;
    }
};
```

---

## 5. **Example Explanation**

### Input:
`nums = [0, 1, 1]`

**Step-by-step:**

- `i=0`:  
  - prefix: 0 (binary "0")  
  - 0 % 5 = 0 → `true`
- `i=1`:  
  - previous prefix = 0  
  - New: (0 * 2) + 1 = 1 (binary "01")  
  - 1 % 5 = 1 → `false`
- `i=2`:  
  - previous prefix = 1  
  - New: (1 * 2) + 1 = 3 (binary "011")  
  - 3 % 5 = 3 → `false`

**Output:** `[true, false, false]`

## **Final Notes**

- Only the current remainder (mod 5) needs to be stored and updated for each bit.
- The solution is efficient and handles all edge and size constraints.
