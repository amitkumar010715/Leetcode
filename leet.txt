Let's go step by step:

---

## 1. **Summary**

Given a pyramid of glasses, where each glass holds only 1 cup, champagne is poured into the top glass. Any overflow splits equally between the glasses below to the left and right. **Given how much champagne is poured and a target glass at (row, glass), return how full (0 to 1) that glass is after all the champagne has settled.**

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
    - `0 <= poured <= 1e9`
    - `0 <= query_glass <= query_row < 100`

- **Edge Cases:**
    - Not enough champagne to reach the queried glass → answer is 0.
    - If there's more than 1 cup in a glass, only 1 cup stays, excess flows down.
    - Even with an enormous `poured`, no glass can be more than full: max answer is 1.

---

## 3. **Optimal Algorithm**

### Dynamic Programming (DP):

Let `dp[r][c]` be the amount of champagne in the glass at row `r`, glass `c`.

**Core idea:**
- Start with `dp[0][0] = poured`.
- For each glass, if it has more than 1 cup, the excess splits equally to the two glasses below (`(r+1, c)` and `(r+1, c+1)`).
- Iterate row by row, updating the next row based on the current row's overflow.

**Space Optimization:**
- Only need two rows at a time: current and next (but actually you can do with a single row, updating from back to front).

**Time & Space:**
- Time: O(query_row^2) (since query_row < 100, this is fast).
- Space: O(query_row) (with 1D array).

---

## 4. **C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    double champagneTower(int poured, int query_row, int query_glass) {
        vector<double> dp(query_row + 2, 0.0);
        dp[0] = poured;

        for (int row = 0; row <= query_row; ++row) {
            // Update from right to left to avoid overwriting values we need!
            for (int glass = row; glass >= 0; --glass) {
                double excess = max(0.0, (dp[glass] - 1.0) / 2.0);
                dp[glass + 1] += excess;
                dp[glass] = excess;
            }
        }
        return min(1.0, dp[query_glass]);
    }
};
```

---

## 5. **Example Explanation**

### Example 2

```
Input: poured = 2, query_row = 1, query_glass = 1
```

- Start: `dp[0] = 2.0`
- Row 0:
    - Glass 0: 2.0 → full (1.0), excess = 1.0
    - Excess splits: 
        - `dp[0] (row 1, glass 0)` += 0.5
        - `dp[1] (row 1, glass 1)` += 0.5
    - After: `dp = [0.5, 0.5]`
- Row 1:
    - Glasses 0 and 1: both at 0.5 (not full)
- Therefore, glass (1, 1): **0.5**

**Output: 0.5**

---

| Row | dp[] after row |
|-----|---------------|
| 0   | [2.0, 0.0]    |
|     | [0.5, 0.5]    | (after processing) |
| 1   | [0.5, 0.5, 0.0]|
