---

## 1. Short Summary

Given an unbalanced Binary Search Tree (BST), rebuild it into a **balanced BST** (the depth of the subtrees of any node never differs by more than 1), maintaining the same set of node values. If there are multiple correct answers, any of them is accepted.

---

## 2. Constraints & Edge Cases

### Constraints:
- **Number of nodes**: 1 to 10,000 (so efficiency matters!)
- **Node values**: 1 to 100,000 (unique because it's a BST)

### Edge Cases:
- **Single node**: Already balanced.
- **Already balanced**: Should return a tree with same structure.
- **Completely skewed**: Eg. a straight line `1->2->3...`, needs full rebalancing.
- **Duplicates?**: Not possible for BST per problem constraints.
- **Very large trees**: Algorithm needs to be O(N) or O(N log N).

---

## 3. Optimal Algorithm

### **Approach:**

**Step 1. Inorder Traversal**  
- Traverse the BST in-order to **collect all nodes (or values) in sorted order** (since BST in-order gives a sorted array).

**Step 2. Build Balanced BST from Sorted List**  
- Recursively build a balanced BST:
  - Take the middle element as root.
  - Recursively construct left and right subtrees from the left/remainder halves.

**Time Complexity:**  
- Inorder traversal: O(N)  
- Tree building: O(N)

**Space Complexity:**  
- O(N) for storing nodes/values.

---

## 4. Clean C++ Solution

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    // Collect nodes' values in sorted order (in-order traversal)
    void inorder(TreeNode* node, vector<int>& vals) {
        if (!node) return;
        inorder(node->left, vals);
        vals.push_back(node->val);
        inorder(node->right, vals);
    }
    
    // Rebuild balanced tree from sorted values
    TreeNode* build(const vector<int>& vals, int left, int right) {
        if (left > right) return nullptr;
        int mid = left + (right - left)/2;
        TreeNode* root = new TreeNode(vals[mid]);
        root->left = build(vals, left, mid-1);
        root->right = build(vals, mid+1, right);
        return root;
    }
    
    TreeNode* balanceBST(TreeNode* root) {
        vector<int> vals;
        inorder(root, vals);
        return build(vals, 0, vals.size() - 1);
    }
};
```

## 5. Example Walkthrough

### Input

```
root = [1,null,2,null,3,null,4,null,null]
```
(Tree: 1 -> 2 -> 3 -> 4, all to the right, a degenerate/skewed tree)

### Step 1: In-order Traversal

Outputs the sorted values:  
`[1, 2, 3, 4]`

### Step 2: Build Balanced BST

- **First call (0,3).** Mid=1, root=2
  - Left: (0,0): mid=0, root=1 (no left, no right).
  - Right: (2,3): mid=2, root=3
    - Left: (2,1): null
    - Right: (3,3): mid=3, root=4 (no left, no right)

```
                      2
                   /      \
                 1         3
                             \
                              4
```

Which is balanced: depth of left and right subtrees of every node never differs by more than 1.

## **Conclusion**

- Use in-order traversal to get sorted values (O(N))
- Build balanced BST from sorted values (O(N))
- Works for all cases, optimal and simple.
