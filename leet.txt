Let's go step by step.

---

## 1. **Short Summary**

Given an array `nums` and integer `k`, pick exactly `k` non-empty (possibly overlapping, even repeated) subarrays. For each subarray, its "value" is `max(subarray) - min(subarray)`. Maximize the total sum of these `k` chosen subarray values.

---

## 2. **Constraints & Edge Cases**

- `1 <= n <= 5*10^4` (Array is large, so O(n^2) is likely not feasible.)
- `0 <= nums[i] <= 10^9` (Large values, but easy min/max calculation.)
- `1 <= k <= 10^5` (Up to 10^5 subarrays — but can pick the same subarray multiple times.)
- Subarrays may overlap, and the *same* subarray can be chosen multiple times.
- Edge Cases:
    - All elements are equal ⇒ max(subarray) - min(subarray) = 0 for any subarray.
    - k > n — legal, because you can repeat subarrays.
    - n = 1 — only one subarray: [nums[0]] ⇒ value 0.

---

## 3. **Optimal Algorithm**

### **Key Observation**

You can pick the *same* subarray multiple times. To maximize the total, just pick the highest-value subarray *k* times.

The value for subarray `[l, r]` is `max(nums[l..r]) - min(nums[l..r])`.  
Thus, the maximum possible subarray value is for the subarray where `max(nums[l..r]) - min(nums[l..r])` is maximized.

- The highest possible difference is `max(nums) - min(nums)` for the full array, which exists as `nums[0..n-1]`.
- Subarrays [l, r] with this value may exist for smaller l, r.

But since we can *repeat* subarrays, it's always optimal to pick the subarray with the highest value `k` times.

Therefore:

**Algorithm:**
1. Find `mx = max(nums)`
2. Find `mn = min(nums)`
3. Their difference `d = mx - mn` is the max possible subarray value.
4. Total is `d * k`.

---

### **Time Complexity**

O(n) — just 2 passes through the array (to find max and min).

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    long long maxTotalValue(vector<int>& nums, int k) {
        int mx = *max_element(nums.begin(), nums.end());
        int mn = *min_element(nums.begin(), nums.end());
        long long val = (long long)(mx - mn) * k;
        return val;
    }
};
```

---

## 5. **Example Explanation**

**Example:**  
nums = [4,2,5,1], k = 3

1. Maximum: 5 (at index 2)
2. Minimum: 1 (at index 3)
3. Value: 5 - 1 = 4
4. Total value: 4 * 3 = 12

Choose the subarray [4,2,5,1] three times (or any other subarray that features 5 & 1 as its max and min), sum their values, answer is **12**.

---

### **Final Summary**

- Find `max(nums)` and `min(nums)`
- Answer is `(max - min) * k`
- O(n) time, O(1) space
