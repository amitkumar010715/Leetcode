## 1. **Short Summary**

Given a binary tree, **find the smallest subtree** that contains **all the deepest nodes**. The answer should return the root **TreeNode** of that subtree.

This is the same as finding the **lowest common ancestor of all the deepest leaves** in the tree.

---

## 2. **Constraints & Edge Cases**

- **Tree Size:** 1 ≤ nodes ≤ 500 (so O(N) is fine).
- **Node Value:** 0 ≤ Node.val ≤ 500 and unique.
- **Edge Cases:**
    - Only the root node (tree with 1 node).
    - Deepest nodes are not all in the same subtree.
    - All deepest nodes are on one side (skewed).
    - Tree with several nodes at the same maximum depth.

---

## 3. **Optimal Algorithm**

We'll use a **post-order DFS** traversal:

- For each node, **compute:**
    - Its **depth** (max depth from it).
    - The node which is the LCA of all deepest nodes in its subtree.

**Detailed Steps:**

1. **Recursively** process left and right subtrees.
2. For each node:
    - Compare the **maximum depth** in left & right subtree.
    - If **equal depths**, it means deepest nodes are on both sides: this node is their LCA.
    - If **one side is deeper**, propagate up the LCA from that side.
3. Return the LCA for the root subtree.

**Time Complexity:** O(N), visits each node once.

---

## 4. **C++ Solution**

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    // Pair: (subtree root, subtree depth)
    pair<TreeNode*, int> dfs(TreeNode* root) {
        if (!root)
            return {nullptr, 0};

        auto left = dfs(root->left);
        auto right = dfs(root->right);

        if (left.second > right.second) {
            return {left.first, left.second + 1};
        } else if (right.second > left.second) {
            return {right.first, right.second + 1};
        } else {
            // Equal depth: current node is the LCA
            return {root, left.second + 1};
        }
    }

    TreeNode* subtreeWithAllDeepest(TreeNode* root) {
        return dfs(root).first;
    }
};
```

## 5. **Example Explanation**

**Input:**  
`root = [3,5,1,6,2,0,8,null,null,7,4]`

- The deepest nodes are 7 & 4, both at depth 4.
- Their lowest common ancestor is node 2.
- Node 2 is the **minimal subtree** covering both deepest nodes.
- So, return the `TreeNode*` for node 2 (subtree: `[2,7,4]`).

|   2  |     1      |     1       |      2       |

**In essence:**  
This algorithm finds the LCA of all deepest leaves, returning the smallest subtree covering all of them.
