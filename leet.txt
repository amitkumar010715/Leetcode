---

### 1. **Short Summary**

This problem requires simulating a task processing system using a set of servers, where each task is assigned to the earliest-available server with the smallest weight (and smallest index if tied). We must return which server handled each task.

---

### 2. **Constraints & Edge Cases**

- **Constraints:**
  - Up to 200,000 servers and 200,000 tasks: O(N log N) solutions are necessary.
  - Server weights and task processing times can be up to 200,000.
- **Edge Cases:**
  - All servers the same weight.
  - Tasks that take 1 second and/or max time.
  - All servers busy at task arrivals → need to queue tasks and possibly fast-forward time.
  - Tasks entering faster/slower than servers can complete tasks.

---

### 3. **Optimal Algorithm**

#### **Key Ideas**
- Use two priority queues (heaps):
  - One min-heap for **available servers**: by `(weight, index)`.
  - Another min-heap for **busy servers**: by `(available_time, weight, index)`.
- At every second (task arrival), do the following:
  1. **Free-up servers**: Move busy servers whose finish time ≤ current time to the free-servers heap.
  2. **Assign task**:
     - If free servers exist, assign current task to the top one (min weight/index).
     - If not, fast-forward time to next server's available_time, process all servers that become free, then assign.
- Each task is assigned one at a time; always try to assign ASAP, in input order.

#### **Time Complexity**
- Each task is pushed/popped once from both heaps → O(M log N), where M is number of tasks and N is number of servers.

---

### 4. **C++ Solution**

```cpp
#include <vector>
#include <queue>
using namespace std;

vector<int> assignTasks(vector<int>& servers, vector<int>& tasks) {
    using pii = pair<int, int>; // (weight, index)
    using busy_t = tuple<long long, int, int>; // (free_time, weight, index)
    int n = servers.size(), m = tasks.size();

    // Min-heap by (weight, index)
    priority_queue<pii, vector<pii>, greater<pii>> free;
    // Min-heap by (free_time, weight, index)
    priority_queue<busy_t, vector<busy_t>, greater<busy_t>> busy;

    for (int i = 0; i < n; ++i)
        free.emplace(servers[i], i);

    vector<int> ans(m);
    long long curr_time = 0;

    for (int i = 0; i < m; ++i) {
        curr_time = max<(long long)>(curr_time, i);
        // Free servers whose task completed by curr_time
        while (!busy.empty() && get<0>(busy.top()) <= curr_time) {
            auto [t, w, idx] = busy.top(); busy.pop();
            free.emplace(w, idx);
        }
        // If none free, fast forward to the earliest finish time
        if (free.empty()) {
            curr_time = get<0>(busy.top());
            while (!busy.empty() && get<0>(busy.top()) <= curr_time) {
                auto [t, w, idx] = busy.top(); busy.pop();
                free.emplace(w, idx);
            }
        }
        auto [w, idx] = free.top(); free.pop();
        ans[i] = idx;
        busy.emplace(curr_time + tasks[i], w, idx);
    }
    return ans;
}
```

### 5. **Example Explained ([3, 3, 2], tasks = [1, 2, 3, 2, 1, 2])**

Let's step through the first few tasks:

- **Second 0:** Task 0 arrives (time needed: 1).
  - Servers: [(2,2), (3,0), (3,1)] → pick 2 (index 2).
  - Server 2 will be free at 1.

- **Second 1:** Task 1 arrives (2s).
  - Server 2 is now free.
  - Pick server 2 (index 2).
  - Will be free at 3.

- **Second 2:** Task 2 arrives (3s).
  - All servers busy except (3,0), (3,1) (from initial). Server 2 is busy until 3.
  - Pick server 0 (weight 3, idx 0). Free at 5.

- **Second 3:** Task 3 arrives (2s).
  - Server 2 is now free again.
  - Pick server 2 (index 2), will be free at 5.

- **Second 4:** Task 4 arrives (1s).
  - No server free till 5, fast forward.
  - At 5: All servers become free. Among [(3,0), (3,1), (2,2)], pick 1st available: 1 (index 1, weight 3).
  - Will be free at 5.

- **Continue similarly for remaining tasks.**

**Output:** `[2,2,0,2,1,2]` matches each assignment.
