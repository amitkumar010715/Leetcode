Let's break down the problem step-by-step.

---

## 1. **Short Summary**

Given an integer `n`, form a new integer `x` by concatenating all non-zero digits of `n` (preserving order). Compute the sum of the digits in `x`. Return `x * sum`.

---

## 2. **Constraints & Edge Cases**

### Constraints:
- `0 <= n <= 10^9`  
  (So `n` has up to 10 digits)

### Edge Cases:
- **`n = 0`**: There are no non-zero digits, so `x = 0`, also, sum = 0, so return 0.
- **`n` with only zeros**: Like `n = 0`, or `n = 000`, behave as above.
- **`n` with only one non-zero digit**: E.g., `n = 1000` → `x = 1`, sum = 1 → output 1.
- **All digits are non-zero**: E.g., `n = 123` → `x = 123`, sum = 6 → output 738.
- **Non-zeroes separated by zeros**: E.g., `n = 102030` → `x = 123`, sum = 6 → output 738.

---

## 3. **Optimal Algorithm**

0. Special case: If `n == 0`, return 0.
1. Convert `n` to a string for easy digit-wise processing.
2. Go through each character:
   - If it's not `'0'`, append to string `x_str`.
3. If `x_str` is empty (should only happen if `n == 0`), set `x = 0` and sum = 0.
4. Otherwise:
   - Convert `x_str` to integer `x`.
   - Compute the digit sum of `x`.
5. Return `x * sum`.

**Complexity:**  
- O(d), where d is the number of digits in `n` (at most 10).

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    int getSum(int x) {
        int sum = 0;
        while (x) {
            sum += x % 10;
            x /= 10;
        }
        return sum;
    }
    
    int concatenatedNonZeroDigits(int n) {
        if (n == 0) return 0;
        string s = to_string(n);
        string xStr;
        for (char c : s) {
            if (c != '0') xStr += c;
        }
        if (xStr.empty()) return 0;
        int x = stoi(xStr);
        int sum = getSum(x);
        return x * sum;
    }
};
```

---

## 5. **Explain One Example**

**Example:** `n = 10203004`

- Digits: 1, 0, 2, 0, 3, 0, 0, 4
- Non-zero digits: 1, 2, 3, 4 (in order)
- Concatenate: `"1" + "2" + "3" + "4" = "1234"`
- x = 1234
- sum = 1 + 2 + 3 + 4 = 10
- Answer: 1234 * 10 = **12340**
