## 1. **Short Summary**

Given `n` computers and a set of batteries (each with a certain charge), we want to find the **maximum number of minutes** we can run all `n` computers **simultaneously** (using at most one battery at a time per computer, but we can swap batteries between computers at any time). **Batteries cannot be recharged.**

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= n <= batteries.length <= 1e5`
  - `1 <= batteries[i] <= 1e9`
- **Edge Cases:**
  - **More batteries than computers:** But some batteries might be small, so total energy is the key.
  - **Large single battery:** One giant battery plus many tiny batteries.
  - **All small batteries:** Uniform small batteries, i.e. `[1,1,1,...]`.
  - **A computer runs out first:** If the energy can't be distributed equally, the weakest link limits the total time.
  - **Not enough total energy:** Total battery sum < n, then the answer is obviously 0.

---

## 3. **Optimal Algorithm**

### **Observation**

- We want to maximize `T` (minutes) such that **sum of all battery energy** ≥ `n * T`.
- But no computer can ever be powered for longer than the total battery supply divided evenly.
- The trickiest part: **No battery can be used by multiple computers at the same time**.

### **Approach**

- **Key Insight:**  
  At any time, a computer is powered by some battery (swap is allowed at 0 cost).  
  The best we can do is to **distribute all available energy as evenly as possible** among the `n` computers, i.e. `T <= totalEnergy / n`.

  However, **no single computer can use more total energy than all the batteries combined**—but we must watch out for *the largest batteries*.

- **Binary Search Solution:**

  1. Compute the total sum of all batteries.
  2. Set search range for maximum possible running time from `1` up to `sum / n`.
  3. For a candidate time `T`, **can we keep all `n` computers on for `T` minutes?**
     - For each battery, compute how much it can contribute (max `T` per battery because a battery can't be used by multiple computers at the same time).
     - Sum up all contributions and check if it's at least `n * T`.

### **Pseudocode for Check:**
```cpp
bool canRun(vector<int>& batteries, long long T, int n) {
    long long total = 0;
    for (int b : batteries)
        total += min((long long)b, T);
    return total >= T * n;
}
```

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    long long maxRunTime(int n, vector<int>& batteries) {
        long long left = 1, right = 0;
        for (int b : batteries) right += b;
        
        right /= n; // No need to try longer than sum(batteries) / n
        
        long long ans = 0;
        while (left <= right) {
            long long mid = left + (right - left) / 2;
            
            long long total = 0;
            for (int b : batteries)
                total += min((long long)b, mid);
            if (total >= mid * n) {
                ans = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ans;
    }
};
```

## 5. **Walkthrough of Example**

### **Example 1**

**Input:**  
`n = 2`, `batteries = [3,3,3]`

**Total energy:** 3 + 3 + 3 = 9  
**Max possible time:** 9 / 2 = 4 (because 9/2 = 4.5, but cannot power for 5 full minutes)

- Try T=4:  
  - Each battery can contribute at most 4 minutes, so total = 3 + 3 + 3 = 9 (since all are less than 4, nothing is capped).
  - Leftover is enough: 9 >= 2*4 = 8.
- T=5:  
  - Each battery can contribute at most 5, but each has 3, so sum = 3 + 3 + 3 = 9.
  - 9 < 2*5 = 10, so can't do 5.
- **Maximum T we can achieve is 4.**

**How:**  
Run two computers for 4 minutes by swapping batteries as needed, as shown in the problem's image.

## **Conclusion**

- We use **binary search on time**, distributing as much battery as possible to each computer.
- For each time candidate, check if the **sum of min(battery, time) for all batteries** is at least `n * time`.
- Key insight: can't use more energy per battery than it has, and total energy must be split across all computers.
