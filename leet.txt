## 1. **Short Summary**

Given an array `nums` and integer `k`, **find the maximum sum of any non-empty subarray of length divisible by `k`**.

---

## 2. **Constraints & Edge Cases**

- `1 <= k <= nums.length <= 2 * 10^5`
- Each `nums[i]` can be in `[-10^9, 10^9]`
- Subarrays must be contiguous, and their **length is a multiple of `k`**
- Must handle **negative numbers** (max sum might be negative)
- **k == 1**: Any subarray length allowed
- **nums** could be all negative, all positive, or mixed.

**Edge Cases:**
- All numbers negative: should pick the least negative sum with a length divisible by `k`.
- k == nums.length: Only the whole array is valid.
- k == 1: Like classical Maximum Subarray Sum problem (Kadane's).

---

## 3. **Optimal Algorithm**

This problem is a variation of the **maximum subarray sum**, with an added length constraint.

**Key Observations:**

- For a subarray `nums[i..j]`, the length is `(j - i + 1)`. 
- We want to maximize sum of `nums[i..j]` with `(j - i + 1) % k == 0`.

**Reformulation:**
- Use prefix sums: `pref[0] = 0`, `pref[i] = nums[0] + ... + nums[i-1]`
- Subarray `nums[l..r]`: Sum is `pref[r+1] - pref[l]`
- Length is `(r - l + 1)`. So `(r - l + 1) % k == 0` ⟹ `(r + 1) % k == l % k`

**So, for any end index `r`, and any prefix starting at `l`, the subarray `nums[l..r]` is valid iff**
> `(r + 1) % k == l % k`

Thus:
- For each possible prefix index `i`, keep **minimum prefix sum** for each `i % k`.
- For each end index `j`, try `pref[j+1] - min_pref[j % k]`.

**Algorithm:**

1. Compute prefix sums.
2. For each modulo class `m = 0..k-1`, maintain the **minimum prefix sum** seen so far for that modulo.
3. For each index, compute candidate subarray sum ending here with matching `(j + 1) % k`, and update the answer.

**Time Complexity:**  
- O(n), only a constant extra work per element.

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <climits>
using namespace std;

class Solution {
public:
    long long maximumSubarraySum(vector<int>& nums, int k) {
        int n = nums.size();
        vector<long long> pref(n+1, 0);
        for (int i = 0; i < n; ++i)
            pref[i+1] = pref[i] + nums[i];
        
        // For each modulo, track the minimal prefix
        vector<long long> min_pref(k, LLONG_MAX);
        min_pref[0] = 0; // empty prefix

        long long res = LLONG_MIN;
        for (int j = 1; j <= n; ++j) {
            int mod = j % k;
            if (min_pref[mod] != LLONG_MAX)  // valid minimum to compare
                res = max(res, pref[j] - min_pref[mod]);
            // Update minimal prefix for current mod class
            min_pref[mod] = min(min_pref[mod], pref[j]);
        }
        return res;
    }
};
```

## 5. **Example Explanation**

Let's use Example 3:

**Input:** `nums = [-5, 1, 2, -3, 4]`, `k = 2`

Walkthrough:

### Step 1: Prefix sums

| Index | Prefix Sum | j    | j%k = j%2 |
|-------|------------|------|-----------|
|   0   |     0      |  0   |     0     |
|   1   |    -5      |  1   |     1     |
|   2   |    -4      |  2   |     0     |
|   3   |    -2      |  3   |     1     |
|   4   |    -5      |  4   |     0     |
|   5   |    -1      |  5   |     1     |

### Step 2: min_pref[0] = 0, min_pref[1] = LLONG_MAX, res = LLONG_MIN

Iterate j = 1 to 5:

- j=1, mod=1: min_pref[1]=LLONG_MAX ⇒ no update  
  Update min_pref[1]=-5

- j=2, mod=0: min_pref[0]=0 ⇒  
  sum = pref[2]-min_pref[0] = -4-0 = -4, res = max(-4, LLONG_MIN) = -4  
  Update min_pref[0]=min(0, -4) = -4

- j=3, mod=1: min_pref[1]=-5 ⇒  
  sum = -2-(-5) = 3, res=max(3, -4)=3  
  Update min_pref[1]=min(-5, -2)=-5

- j=4, mod=0: min_pref[0]=-4 ⇒  
  sum = -5-(-4)= -1, res=max(3, -1)=3  
  Update min_pref[0]=min(-4, -5)=-5

- j=5, mod=1: min_pref[1]=-5  
  sum = -1-(-5)=4, res=max(3,4)=**4**  
  Update min_pref[1]=min(-5, -1)=-5

Final answer: **4**

This corresponds to subarray `[1,2,-3,4]` (length 4, divisible by 2, sum=4).

## **Summary**

- Use prefix sums and track minimum prefix value for each modulo class.
- At each step, maximum valid sum is `prefix[j] - min_prefix[j % k]`.
- Time complexity is O(n).
