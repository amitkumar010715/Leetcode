## 1. **Short Summary**

Given an array of distinct integers, find all pairs `[a, b]` (with `a < b`) such that `b - a` is equal to the smallest absolute difference between any two values in the array. Return these pairs sorted in ascending order.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `2 <= arr.length <= 10^5`: The array can be quite large, so efficient `O(N log N)` solutions are required.
  - Each element is a **distinct integer** within `[-10^6, 10^6]`.
- **Edge Cases:**
  - The smallest array size is 2.
  - All elements are positive, negative, or a mix.
  - Multiple pairs might have the same minimum difference.
  - The array might not be in any sorted order.

---

## 3. **Optimal Algorithm**

### **Observation**
- The minimal absolute difference will *always* occur between two consecutive elements *when the array is sorted*. This is because, for any non-consecutive pair, there is another number between them due to distinctness.

### **Algorithm Steps**
1. **Sort the array**.
2. Compute the minimum absolute difference between adjacent elements.
3. Traverse the sorted array again, collecting all pairs whose difference equals this minimum.

- **Time Complexity:** 
  - Sorting: `O(N log N)`
  - Scanning for minimum difference: `O(N)`
  - Collecting pairs: `O(N)`
  - **Total:** `O(N log N)`

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> minimumAbsDifference(vector<int>& arr) {
        sort(arr.begin(), arr.end());
        int minDiff = INT_MAX;
        int n = arr.size();
        // First pass: Find the minimum difference
        for (int i = 1; i < n; ++i) {
            minDiff = min(minDiff, arr[i] - arr[i-1]);
        }
        // Second pass: Collect all pairs with that minimum difference
        vector<vector<int>> res;
        for (int i = 1; i < n; ++i) {
            if (arr[i] - arr[i-1] == minDiff) {
                res.push_back({arr[i-1], arr[i]});
            }
        }
        return res;
    }
};
```

---

## 5. **Example Walkthrough**

Let's use **Example 1**:  
`arr = [4, 2, 1, 3]`

**Step 1:** Sort the array: `[1, 2, 3, 4]`  
**Step 2:** Find min difference:
  - `2 - 1 = 1`
  - `3 - 2 = 1`
  - `4 - 3 = 1`
  - The **min difference** is `1`.

**Step 3:** Collect all consecutive pairs with difference `1`:
  - `[1, 2]` (since `2 - 1 = 1`)
  - `[2, 3]` (since `3 - 2 = 1`)
  - `[3, 4]` (since `4 - 3 = 1`)

**Final Output:**  
`[[1,2],[2,3],[3,4]]`

---

> **Summary:**  
Sort, find min difference, collect all consecutive pairs with it.

**Time complexity:** `O(N log N)` (due to sorting).  
**Space complexity:** `O(N)` for the result.
