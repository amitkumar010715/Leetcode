## 1. **Short Summary**

Given a binary string `s`, starting at index 0, and two integers `minJump` and `maxJump`, you can move from index `i` to any index `j` where:
- `i + minJump <= j <= min(i + maxJump, n - 1)`
- `s[j] == '0'`

Return `true` if you can reach the last index using such jumps, otherwise return `false`.

---

## 2. **Constraints & Edge Cases**

- `2 <= s.length <= 1e5` — large, so O(n) solutions are needed.
- Movement can only be to positions marked with `'0'`.
- `s[0] == '0'`, thus always a valid start.
- `1 <= minJump <= maxJump < s.length`
- Edge cases:
    - All zeros: should return `true`.
    - All ones after `s[0]`: should return `false`.
    - No `'0'` in last minJump-maxJump window: unreachable.

---

## 3. **Optimal Algorithm**

A naïve BFS/DP checking every possible jump is O(n * maxJump) — too slow for n=1e5.  
Instead, **Sliding Window + DP**:

- Use `dp[i]` to represent if position `i` is reachable (from 0).
- Maintain a running `prefix sum` or count of reachable indices in the last `[i - maxJump, i - minJump]` window.
- At each position `i`, if `s[i] == '0'`, 
    - If there is any `dp[j]==true` such that `j` in `[i-maxJump, i-minJump]`, then you can reach `i`.

### High-Level Steps
1. Initialize `dp[0] = true`, rest are false.
2. Use a **running window count** to check if the jump window leading to `i` has any reachable index.
3. Iterate from `1 to n-1`, for each position:
    - If `i >= minJump`, add `dp[i-minJump]` to `count`.
    - If `i > maxJump`, subtract `dp[i-maxJump-1]` from `count`.
    - If `s[i]=='0'` and `count>0`, set `dp[i]=true`.

This approach is O(n).

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    bool canReach(string s, int minJump, int maxJump) {
        int n = s.size();
        vector<bool> dp(n, false);
        dp[0] = true;
        int windowReachable = 0;
        
        for (int i = 1; i < n; ++i) {
            // Expand the window: add new left end.
            if (i >= minJump && dp[i - minJump]) windowReachable++;
            // Shrink the window: remove old out-of-range left end.
            if (i > maxJump && dp[i - maxJump - 1]) windowReachable--;
            
            // If current is '0' and window has at least one reachable.
            if (s[i] == '0' && windowReachable > 0) {
                dp[i] = true;
            }
        }
        return dp[n - 1];
    }
};
```

## 5. **Example Explained**

**Example 1:**
Input: `s = "011010"`, `minJump = 2`, `maxJump = 3`

- Indices: 0 1 2 3 4 5
- s:      0 1 1 0 1 0

Let's step:
- Start at index 0 (must).
- Can jump from 0 to indices: 2 (s[2]=='1'), 3 (s[3]=='0')
    - 3 is possible, so mark `dp[3] = true`.
- From 3, can jump to indices: 5 (`3+2` to `3+3`)
    - s[5]=='0', so mark `dp[5] = true`.

We can reach the last index!

---

**Summary:**  
We use a DP table where `dp[i]` tracks if position `i` can be reached, and a sliding window to efficiently check the range of valid previous indices. This efficiently solves the problem within constraints.
