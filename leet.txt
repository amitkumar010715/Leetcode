Let's break down your request step by step:

---

## 1. **Short Summary**

Given a binary array `nums`, for each prefix (from index 0 to `i`), form the binary number, and check if it's divisible by 5. Return a boolean array where each element indicates whether the respective prefix is divisible by 5.

---

## 2. **Constraints & Edge Cases**

- `1 <= nums.length <= 10^5`  
  Large size — must process in linear time.
- `nums[i]` is `0` or `1` — so valid binary digits only.
- **Edge Cases:**
    - Prefixes with leading zeros (e.g., `[0,0,0,1,...]`)
    - Very long `nums` (must not generate large integers directly, use modular arithmetic)
    - All zeroes (every prefix is 0)
    - All 1's

---

## 3. **Optimal Algorithm**

**Observation:**  
Instead of constructing the actual binary number (which gets huge), we can keep track of it modulo 5, because only "divisible by 5" is needed.

At each step, the prefix number in decimal is:

- For index `i` (`nums[0..i]` as binary):  
  `x_i = ((x_{i-1} * 2) + nums[i])`

So we can maintain a running `current_mod = 0`, and update as:

- `current_mod = (current_mod * 2 + nums[i]) % 5`

If `current_mod == 0`, then the current prefix is divisible by 5.

This runs in **O(N)** time and uses O(N) space for the answer array.

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<bool> prefixesDivBy5(vector<int>& nums) {
        vector<bool> answer(nums.size());
        int current_mod = 0;
        for (int i = 0; i < nums.size(); ++i) {
            current_mod = (current_mod * 2 + nums[i]) % 5;
            answer[i] = (current_mod == 0);
        }
        return answer;
    }
};
```

---

## 5. **Example Explanation**

**Example:**  
`nums = [0, 1, 1]`

Let's walk through it:

| i | current_mod calculation         | current_mod | x[i] decimal | Divisible by 5? | answer[i] |
|---|---------------------------------|-------------|--------------|-----------------|-----------|
| 0 | (0 * 2 + 0) % 5 = 0             | 0           | 0            | YES             | true      |
| 1 | (0 * 2 + 1) % 5 = 1             | 1           | 1            | NO              | false     |
| 2 | (1 * 2 + 1) % 5 = 3             | 3           | 3            | NO              | false     |

**Return Value:**  
`[true, false, false]`
