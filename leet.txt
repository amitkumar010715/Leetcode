## 1. **Short Summary**

Given a list of intervals, we must remove all intervals that are *covered* by another interval, where an interval `[a, b)` is covered by `[c, d)` if `c <= a` and `b <= d`. The task is to return how many intervals are left after all covered ones are removed.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= intervals.length <= 1000`
  - `intervals[i].length == 2`
  - `0 <= l_i < r_i <= 10^5`
  - Intervals are all unique.
- **Edge Cases:**
  - Only one interval: can't be covered.
  - All intervals identical: all unique, still only one stays.
  - Interval completely inside another: should be covered.
  - Intervals that *touch* but do not overlap: not covered unless contain completely inside.

---

## 3. **Optimal Algorithm**

**Idea:**

- **Sort** the intervals:
    - First by starting point (`l_i`) in ascending order.
    - If two intervals have same starting point, put the longer (rightmost) first (`r_i` descending).
- **Iterate** through sorted intervals, keeping track of the farthest right boundary (`max_right`) seen so far.
    - If current interval's end (`r_i`) is less than or equal to `max_right`, it's covered.
    - Otherwise, it is not covered, so increment a counter, and update `max_right`.

**Why this works?**
- By sorting this way, all possible covering intervals come before possible covered ones.
- We only need to check current right endpoint to know if it's covered.

**Time Complexity:**
- Sorting: `O(N log N)`
- One pass: `O(N)`
- Total: `O(N log N)`

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int removeCoveredIntervals(vector<vector<int>>& intervals) {
        // Sort by start asc. If same start, by end desc.
        sort(intervals.begin(), intervals.end(), [](const vector<int>& a, const vector<int>& b) {
            if (a[0] == b[0]) return a[1] > b[1];
            return a[0] < b[0];
        });

        int res = 0;
        int max_right = 0;  // the furthest right endpoint we've seen

        for (const auto& interval : intervals) {
            if (interval[1] > max_right) {
                // Not covered, count it
                res++;
                max_right = interval[1];
            }
            // else: covered by previous interval(s), do not count
        }

        return res;
    }
};
```

## 5. **Explain One Example**

Let's use **Example 1**:

**Input:** `intervals = [[1,4], [3,6], [2,8]]`

1. **Sort:**
    - By start ascending, tie by end descending:
    - Sorted: `[[1,4], [2,8], [3,6]]`

2. **Iterate:**
    - `max_right = 0`; `res = 0`
    - Interval `[1,4]`: `4 > 0` --> **not covered**, so `res=1`, `max_right=4`
    - Interval `[2,8]`: `8 > 4` --> **not covered**, so `res=2`, `max_right=8`
    - Interval `[3,6]`: `6 <= 8` --> **is covered** by `[2,8]`, **do not count**

**Output:** `2`

---

**Summary Table:**

| Interval | Is Covered? | Count So Far | max_right |
|----------|-------------|-------------|-----------|
| [1,4]    | No          | 1           | 4         |
| [2,8]    | No          | 2           | 8         |
| [3,6]    | Yes         | 2           | 8         |

## **In summary:**
- **Sort** intervals as described.
- **One pass** with a max right tracker.
- **Count** intervals not covered.

**This is optimal for the given constraints.**
