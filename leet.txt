Let's solve the **"Distinct Subsequences II"** problem as requested:

---

### 1. **Short Summary**

Given a string `s`, count the number of distinct **non-empty subsequences** that can be formed by deleting any (possibly none) characters without reordering the rest. **Return the count modulo 10^9 + 7.**

---

### 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= s.length <= 2000`
  - `s` contains **lowercase English letters** only.

- **Edge Cases:**
  - All characters same, e.g., `"aaaa"`.
  - All characters unique, e.g., `"abcd"`.
  - Duplicates in between, e.g., `"abacb"`.
  - Minimum/maximum length strings.

---

### 3. **Optimal Algorithm**

This is a classic **DP with recomputation avoidance using last occurrence tracking**:

#### **Intuition:**

- For every character in `s`, the new set of subsequences it creates is by adding this character to all previous subsequences, **plus itself as a single-character subsequence**.
- **But if a character repeats,** previous subsequences containing the last occurrence of this character would be recomputed, leading to duplicates. So, we need to **subtract** the number of subsequences that existed before the last occurrence of the character.

#### **Steps:**

1. Let `dp[i]` represent the **number of distinct subsequences** in `s[0..i-1]`.
2. `dp[0] = 1` corresponds to the empty subsequence (though at the end, we subtract this).
3. For each char at pos `i`:
   - `dp[i+1] = dp[i] * 2`, because for each old subsequence, we can either add s[i] or not.
   - If we saw s[i] before at position `j`, subtract `dp[j]` as these subsequences have already been counted.
4. Maintain an array `last[c]` (for all 26 lowercase characters) to store the last occurrence index of each character.

#### **Pseudocode:**
```
dp[0] = 1
for i in 0 to n-1:
    dp[i+1] = dp[i]*2
    if last[s[i]] != -1:
        dp[i+1] -= dp[last[s[i]]]
    last[s[i]] = i
result = dp[n] - 1    // exclude the empty subsequence
```
Remember to do modulo operations to avoid overflow.

---

### 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int distinctSubseqII(string s) {
        const int MOD = 1e9 + 7;
        int n = s.length();
        vector<int> dp(n + 1, 0); // dp[i]: number of distinct subsequences of s[0..i-1]
        dp[0] = 1; // base case: empty string
        vector<int> last(26, -1); // last occurrence of each character

        for (int i = 0; i < n; ++i) {
            int c = s[i] - 'a';
            dp[i + 1] = (2LL * dp[i]) % MOD;
            if (last[c] != -1) {
                // subtract the number before previous occurrence of s[i]
                dp[i + 1] = (dp[i + 1] - dp[last[c]] + MOD) % MOD;
            }
            last[c] = i;
        }
        // subtract 1 to exclude the empty subsequence
        return (dp[n] - 1 + MOD) % MOD;
    }
};
```

### 5. **Example Explanation**

#### Input: `"aba"`

Let's walk through step by step:

Positions: `0 1 2`
Letters:   `a b a`

- `dp[0] = 1` ("")   // base, empty string only

Iterate:

- `i=0`: 'a'
  - dp[1] = 2*1 = 2 (`""` and `"a"`)
  - last['a'] = -1 → skip subtract
  - last['a'] = 0

- `i=1`: 'b'
  - dp[2] = 2*2 = 4 (`"", "a", "b", "ab"`)
  - last['b'] = -1 → skip subtract
  - last['b'] = 1

- `i=2`: 'a'
  - dp[3] = 2*4 = 8
  - last['a'] = 0
    - subtract dp[0]=1 ⇒ dp[3] = 8 - 1 = 7
  - last['a'] = 2

- Exclude empty subseq: result = dp[3] - 1 = 6

Distinct subsequences: `"a", "b", "ab", "aa", "ba", "aba"`

## **Summary**

- **DP with duplicate avoidance via last seen tracking.**
- **Optimal O(n) time, O(26) space.**
- **Handles large `n` due to O(1) per char.**
- C++ clean and clear code above.
