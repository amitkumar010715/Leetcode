Let's break down the problem and provide a thorough solution:

---

## 1. **Summary**

Given an array `nums`, for each possible subarray, count the number of distinct (unique) elements. For all subarrays, **sum up the squares** of each distinct count. Return the total.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - Array length \( 1 \leq n \leq 100 \) (small!)
  - Elements in \( [1, 100] \)

- **Edge Cases:**
  - All elements the same ⇒ every subarray has distinct count 1.
  - All distinct ⇒ maximum distinct count per subarray.
  - Minimum/smallest input: nums = [x] (single-element array).

---

## 3. **Optimal Algorithm**

Since \( n \leq 100 \), an **O(n^3)** solution is feasible.

**Approach:**
- For every possible subarray [i..j]:
    - Use a set or frequency array to count how many unique numbers in [i..j].
    - Add (distinct_count)^2 to the total sum.

**Implementation Details:**
- Two nested loops for start (`i`) and end (`j`) of subarray.
- Use array `cnt[101]` or a `set` to track elements in current subarray.
- For single elements: count = 1
- For longer subarrays, build up as you extend `j`.

**Time complexity:** \( O(n^2 \times k) \), where \( k \) is cost to add/check a number (worst case 100).

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int sumCounts(vector<int>& nums) {
        int n = nums.size();
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            unordered_set<int> seen;
            for (int j = i; j < n; ++j) {
                seen.insert(nums[j]);
                int cnt = seen.size();
                ans += cnt * cnt;
            }
        }
        return ans;
    }
};
```

**Extras:**
- Instead of `unordered_set<int>`, you could use `int freq[101]` to further optimize, but here, clarity is preferred.

---

## 5. **Example Explanation**

Let's use **Example 1**:  
`nums = [1, 2, 1]`

List all subarrays and distinct counts:

| Subarray  | Distinct Values | Square |
|-----------|----------------|--------|
| [1]       | {1}    | 1^2 = 1 |
| [1,2]     | {1,2}  | 2^2 = 4 |
| [1,2,1]   | {1,2}  | 2^2 = 4 |
| [2]       | {2}    | 1^2 = 1 |
| [2,1]     | {2,1}  | 2^2 = 4 |
| [1]       | {1}    | 1^2 = 1 |

Sum: 1 + 4 + 4 + 1 + 4 + 1 = **15**

Which matches the output.

**If you want a pure array solution (for even faster code):**

```cpp
class Solution {
public:
    int sumCounts(vector<int>& nums) {
        int n = nums.size();
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            int freq[101] = {0};
            int distinct = 0;
            for (int j = i; j < n; ++j) {
                if (++freq[nums[j]] == 1) distinct++;
                ans += distinct * distinct;
            }
        }
        return ans;
    }
};
```

---

## **Summary**

- Brute-force all subarrays; for each, count unique elements and sum up squares.
- Reasonable due to small bounds.
- Supports all edge cases.
