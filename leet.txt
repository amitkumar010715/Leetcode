Let's break down the problem into all the requirements.

---

## 1. **Short Summary**

We are given an array `nums`. Find the **minimum possible distance** of a "good" tuple `(i, j, k)` where **all three indices are distinct and `nums[i] == nums[j] == nums[k]`**. The distance of such a tuple is `abs(i-j) + abs(j-k) + abs(k-i)`. Return `-1` if no such tuple exists.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= n == nums.length <= 10^5`
  - `1 <= nums[i] <= n`
- **Edge Cases:**
  - No value appears at least three times → **answer is `-1`**.
  - There may be multiple triplets for the same value; choose the *minimal* distance.
  - Large inputs: **solution must be optimal** (avoid brute-force triple loops).
  - The positions must be **distinct**.

---

## 3. **Optimal Algorithm**

### **Key Observations**

- For any value, collect all its indices into a list.
- For each list size `m >= 3`, consider *each consecutive window of 3 indices*; this gives the *minimal* possible distance for that value.
- For three indices `(a, b, c)` (sorted), the distance is:
  
  ```
  abs(a-b) + abs(b-c) + abs(c-a) =
    (b-a) + (c-b) + (c-a) = 2*(c-a)
  ```
  Because the indices are sorted: `a < b < c`.

- So, for each window of 3 positions, the minimal distance is `2*(pos[window_end] - pos[window_start])` where `window_end = i+2`, `window_start = i`.

### **Algorithm Steps**

1. Use a hash map: `unordered_map<int, vector<int>>` to collect indices.
2. For each value with `m >= 3`:
    - Sort the positions (they are already sorted if you collect during a forward scan).
    - Loop over `i` for all windows of 3 (`i, i+1, i+2`):
        - Compute `2 * (pos[i+2] - pos[i])`.
        - Keep track of the minimal value.
3. Return `-1` if no such triplet exists.

**Time Complexity:**  
O(n) to collect indices + O(n) to process all positions (as total number of positions across all values is n).  
**Space Complexity:** O(n)

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int minimumDistance(vector<int>& nums) {
        unordered_map<int, vector<int>> posMap;
        int n = nums.size();

        // Collect indices for each value
        for (int i = 0; i < n; ++i) {
            posMap[nums[i]].push_back(i);
        }

        int res = INT_MAX;
        // For each group with >=3 occurrences
        for (auto& [num, pos] : posMap) {
            int m = pos.size();
            if (m < 3) continue;
            // Slide window of 3 positions
            for (int i = 0; i + 2 < m; ++i) {
                int dist = 2 * (pos[i+2] - pos[i]);
                res = min(res, dist);
            }
        }

        return res == INT_MAX ? -1 : res;
    }
};
```

---

## 5. **Explain with Example**

**Let's use `nums = [1,2,1,1,3]`.**

- Build `posMap`:
    - 1: [0, 2, 3]
    - 2: [1]
    - 3: [4]

Only `1` has >=3 positions: [0, 2, 3].  
There is only *one* triplet of consecutive indices: (0, 2, 3).

Compute distance for (0,2,3):

`distance = abs(0-2) + abs(2-3) + abs(3-0) = 2 + 1 + 3 = 6`

So we return `6`.
