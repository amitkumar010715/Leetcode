## 1. **Short Summary**

Given two binary strings, add them as if you were adding binary numbers (bit by bit, right to left, considering carries), and return their sum as a binary string.

---

## 2. **Constraints & Edge Cases**

- **String Length:** Both strings can have length up to 10,000. This means you **cannot** convert them to integers since they may not fit in built-in types.
- **Input Nature:** Both strings contain only `'0'` or `'1'`. No leading zeros except possibly a single zero.
- **Edge Cases:**
    - One or both input strings are `"0"`.
    - Strings of different lengths.
    - The sum produces an extra bit due to carry (e.g., adding `"1"` + `"1"` gives `"10"`).
    - Long inputs — be sure the algorithm is linear in time and space.

---

## 3. **Optimal Algorithm**

This is a simulation of binary addition (just like how you add decimal digits by hand):

1. Set up pointers `i` and `j` at the end of each string (`a` and `b`).
2. Initialize `carry` to 0.
3. Loop while `i >= 0` or `j >= 0` or `carry` is non-zero:
    - Get the digit from `a` if `i >= 0` else 0.
    - Get the digit from `b` if `j >= 0` else 0.
    - Compute the sum: `digit_a + digit_b + carry`.
    - The resulting digit for this position is `sum % 2`.
    - The new carry is `sum / 2`.
    - Prepend (or push to a vector/stack and then reverse) the result.
4. When done, reverse the computed result (if you constructed it backwards).
5. Return the final string.

**Time complexity:** O(max(n, m)), where n and m are the lengths of input strings.  
**Space complexity:** O(max(n, m)) for the result.

---

## 4. **Clean C++ Solution**

```cpp
#include <string>
using namespace std;

class Solution {
public:
    string addBinary(string a, string b) {
        string result;
        int i = (int)a.length() - 1, j = (int)b.length() - 1;
        int carry = 0;
        while (i >= 0 || j >= 0 || carry) {
            int sum = carry;
            if (i >= 0) sum += a[i--] - '0';
            if (j >= 0) sum += b[j--] - '0';
            result += (sum % 2) + '0';
            carry = sum / 2;
        }
        reverse(result.begin(), result.end());
        return result;
    }
};
```

## 5. **Example Explanation**

**Input:**  
`a = "1010"`, `b = "1011"`

Let's add right to left:

```
Carry:      1 1 0 0
           -------
         1 0 1 0    (a)
       + 1 0 1 1    (b)
--------------------
Index:     3 2 1 0
```
- **At index 3:** `0 + 1 + 0 (carry)` = 1  → result: `1`, carry: 0
- **At index 2:** `1 + 1 + 0 (carry)` = 2  → result: `0`, carry: 1
- **At index 1:** `0 + 0 + 1 (carry)` = 1  → result: `1`, carry: 0
- **At index 0:** `1 + 1 + 0 (carry)` = 2  → result: `0`, carry: 1
- **After finishing both strings, but carry = 1:** → result: `1`

So from backwards, the result string is `10101`.

**Output:**  
`"10101"`
