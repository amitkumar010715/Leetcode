Let's break down the problem step by step:

---

## 1. **Short Summary**

Given an array of `2n` integers containing `n+1` unique elements, with **one element repeated exactly `n` times**, find and return this repeated element.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `2 <= n <= 5000` (so array length: `4` to `10000`)
- Each number is `0 <= nums[i] <= 10^4`
- `nums.length == 2 * n`
- Exactly one element appears `n` times.
- Rest of the `n` elements are **unique** (appear once).

**Edge Cases:**
- The repeated element could be anywhere (front, back, or scattered).
- The repeated element could be `0` or `10^4` (test range boundaries).
- Array is always of **even length** (at least 4).

---

## 3. **Optimal Algorithm**

Since only one element is repeated many times (n times!), and the rest are unique, several methods work:

### **Approach 1: Using HashSet** (Clean, O(n) time/space)
- Traverse the array and use a set to record seen numbers.
- The first number seen twice is the repeated one (since it's the only one with `n` duplicates).

### **Approach 2: Sort and Find Streak** (O(n log n), no extra space)
- Sort the array. The repeated element will occupy `n` contiguous positions; so, find the element that exists in position `i` and `i+1`.

### **Approach 3: Smart Pairwise Check (O(1) Space, O(n) time)**
- Since the repeated element is present `n` times, it's guaranteed that **at least two of them will appear with less than three elements in-between**. So, comparing every pair within three apart:
    - For each `i` from 0 to `len-2`, compare `nums[i] == nums[i+1] || nums[i] == nums[i+2] || nums[i] == nums[i+3]` (for within array range).
    - If found, return that number.

### HashSet is clean and simple, and optimal given the constraints.

---

## 4. **Clean C++ Solution**

(Most readable is with HashSet.)

```cpp
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int repeatedNTimes(vector<int>& nums) {
        unordered_set<int> seen;
        for (int num : nums) {
            if (seen.count(num)) {
                return num;
            }
            seen.insert(num);
        }
        // Problem guarantees a solution exists, so shouldn't reach here.
        return -1;
    }
};
```

---

## 5. **Example Explanation**

**Example:**  
`nums = [2,1,2,5,3,2]`  
- n = 3 (since len = 6)
- The unique numbers: 1, 2, 3, 5 (i.e., 4 numbers, and n+1 = 4)
- Only **one** number appears 3 times: `2`.
- As we iterate:
    - Seen: {}
    - 2 not seen → insert (Seen: {2})
    - 1 not seen → insert (Seen: {1,2})
    - 2 **already seen** → **return 2**

**Output:** `2`
