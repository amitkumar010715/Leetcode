## 1. **Short Summary**

Given an array `nums` and an integer `target`, return the number of subarrays where `target` is the **majority element** (appears **more than half** the time in the subarray).

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= nums.length <= 1000` (array is small/medium sized; O(n²) is acceptable)
- `1 <= nums[i], target <= 10⁹` (Value ranges are large, so we cannot use value-indexed arrays)

**Edge Cases:**
- `target` does **not appear** in `nums` ⇒ answer is 0.
- Every element is `target` ⇒ all subarrays work (answer = n * (n+1) / 2).
- Each element occurs once but `target` only occurs in a few spots.

---

## 3. **Optimal Algorithm**

Because n ≤ 1000, an O(n²) solution is feasible.

### **Plan**
- For every starting index `l`, move rightwards to every ending index `r` (`l <= r < n`)
- For each subarray, count how many times `target` occurs.
- For subarray `nums[l..r]` (length = r-l+1): target is majority ⇔ count_target > (r-l+1)//2

#### **Optimizations**
Instead of recounting target every time for a subarray, we can:
- For each `l`, maintain a running count as we expand `r`. This is very efficient for 1000 elements.

#### **Time Complexity**:  
O(n²) — as we check all subarrays, but are careful not to recount for each new subarray.

---

## 4. **C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int countSubarrays(vector<int>& nums, int target) {
        int n = nums.size();
        int ans = 0;
        for (int l = 0; l < n; ++l) {
            int count = 0;
            for (int r = l; r < n; ++r) {
                if (nums[r] == target)
                    ++count;
                int length = r - l + 1;
                if (count > length / 2)
                    ++ans;
            }
        }
        return ans;
    }
};
```

## 5. **Example Explained**

Let's take **Example 1:**
- **Input**: `nums = [1,2,2,3], target = 2`

**All subarrays & majorities:**

| Subarray      | Elements   | count of 2 | Length | Majority?   |
|---------------|------------|:----------:|:------:|-------------|
| [1]           | 1          | 0          | 1      | No          |
| [1,2]         | 1 2        | 1          | 2      | No (not >1) |
| [1,2,2]       | 1 2 2      | 2          | 3      | Yes (2 > 1.5)|
| [1,2,2,3]     | 1 2 2 3    | 2          | 4      | No (2 = 2)  |
| [2]           | 2          | 1          | 1      | Yes         |
| [2,2]         | 2 2        | 2          | 2      | Yes (2>1)   |
| [2,2,3]       | 2 2 3      | 2          | 3      | Yes (2>1.5) |
| [2]           | 2          | 1          | 1      | Yes         |
| [2,3]         | 2 3        | 1          | 2      | No          |
| [3]           | 3          | 0          | 1      | No          |

Counting the "Yes", we have **5** subarrays:
- [1,2,2]
- [2]
- [2,2]
- [2,2,3]
- [2] (the second single-2 at position 2)

**Answer is `5`.**

---

### **In summary:**
- Iterate all subarrays using two loops, and for each, keep a running count of `target`.
- Check if it is a majority, update answer.
- C++ solution provided above.
