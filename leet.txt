## 1. **Short Summary**

You are given an n x n 2D matrix. **Rotate the matrix by 90 degrees clockwise in-place** — that is, modify `matrix` directly without using any extra matrix for storage.

---

## 2. **Constraints & Edge Cases**

- `matrix` is always square (`n x n`), where `1 <= n <= 20`.
- Each element is in range `[-1000, 1000]`.
- **Edge Cases:**
  - `n = 1`: Only one element; matrix stays the same.
  - All elements are the same: After rotation, matrix visually remains unchanged.
  - Even and odd `n`: Make sure your code handles both.

---

## 3. **Optimal Algorithm**

### Rotation by 90° Clockwise (In-Place)

You can achieve this in two clear steps:

#### **Step 1: Transpose the Matrix**
Swap element at `(i, j)` with `(j, i)` for all `i < j`.

#### **Step 2: Reverse Each Row**
For each row, reverse the elements (swap the first with the last, and so on).

**Why does this work?**
- Transposing swaps rows and columns.
- Reversing each row "twists" the rows into the correct order for a 90° clockwise rotation.

**Time Complexity**: O(n²), since every element has to be moved.
**Space Complexity**: O(1), since we are operating in-place.

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        // Step 1: Transpose
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }
        // Step 2: Reverse each row
        for (int i = 0; i < n; ++i) {
            reverse(matrix[i].begin(), matrix[i].end());
        }
    }
};
```

## 5. **Example Walkthrough**

Let's use example 1:

**Input:**  
```
[ [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9] ]
```

**Step 1: Transpose**
Swap `(i, j)` with `(j, i)` for `i < j`:

```
After transpose:
[ [1, 4, 7],
  [2, 5, 8],
  [3, 6, 9] ]
```

**Step 2: Reverse each row**
- Row 1: `[1, 4, 7]` -> `[7, 4, 1]`
- Row 2: `[2, 5, 8]` -> `[8, 5, 2]`
- Row 3: `[3, 6, 9]` -> `[9, 6, 3]`

**Result:**
```
[ [7, 4, 1],
  [8, 5, 2],
  [9, 6, 3] ]
```
Which matches the expected output.
