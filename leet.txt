Let's solve the LeetCode daily challenge:

---

## 1. **Short Summary**

Given `zero`, `one`, and `limit`, **count the number of binary arrays of length zero + one,** with exactly that many 0's and 1's, so that **no subarray of length > limit is all 0's (or all 1's)**.

**Key:** You can't have more than `limit` consecutive 0's or 1's anywhere in the array.

---

## 2. **Constraints & Edge Cases**

- `1 <= zero, one, limit <= 200`
- Arrays must use all 0s and all 1s.
- If `zero` or `one` is 0, there is only 1 possible arrangement if the total count is within the limit; else, it's 0.
- When `limit` is large, essentially just select all permutations.
- When `limit` is 1, strictly alternated pattern.

---

## 3. **Optimal Algorithm**

This is a **Dynamic Programming** (DP) problem:

**DP State:**
- Let `dp(z, o, last, len)` be the number of ways to arrange `z` zeros and `o` ones, where last added was digit `last` (0 or 1), and the current contiguous streak of `last` is `len`.

**Recurrence:**
- If last added was 0, and have `z>0`, and streak `len < limit`, can add another 0: `dp(z-1, o, 0, len+1)`
- Else, can switch to 1: `dp(z, o-1, 1, 1)`
- Similarly for 1.

**Initialization:**
- Start with both:
    - If `zero>0`: `dp(zero-1, one, 0, 1)` (start with one 0)
    - If `one>0` : `dp(zero, one-1, 1, 1)` (start with one 1)

**Memoization:**
- Cache result for (z, o, last, len), since z and o up to 200, last 0/1, len up to limit (<200). Acceptable.

**Modulus:** $10^9+7$

---

### DP Transition (Pseudocode)

```
int dp(z, o, last, len):
    if z==0 and o==0: return 1
    if memo contains (z,o,last,len): return memo
    ans = 0
    if last == 0:
        if z > 0 and len < limit:
            ans += dp(z-1, o, 0, len+1)
        if o > 0:
            ans += dp(z, o-1, 1, 1)
    else:
        if o > 0 and len < limit:
            ans += dp(z, o-1, 1, len+1)
        if z > 0:
            ans += dp(z-1, o, 0, 1)
    memo[...] = ans % MOD
    return memo[...]
```

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <cstring>
using namespace std;

class Solution {
public:
    static constexpr int MOD = 1e9+7;
    int dp[201][201][2][201];

    int solve(int z, int o, int last, int len, int limit) {
        if (z == 0 && o == 0) return 1;
        int& res = dp[z][o][last][len];
        if (res != -1) return res;
        res = 0;
        if (last == 0) {
            if (z > 0 && len < limit) {
                res = (res + solve(z - 1, o, 0, len + 1, limit)) % MOD;
            }
            if (o > 0) {
                res = (res + solve(z, o - 1, 1, 1, limit)) % MOD;
            }
        } else {
            if (o > 0 && len < limit) {
                res = (res + solve(z, o - 1, 1, len + 1, limit)) % MOD;
            }
            if (z > 0) {
                res = (res + solve(z - 1, o, 0, 1, limit)) % MOD;
            }
        }
        return res;
    }

    int stableArrays(int zero, int one, int limit) {
        memset(dp, -1, sizeof(dp));
        int ans = 0;
        if (zero > 0) ans = (ans + solve(zero - 1, one, 0, 1, limit)) % MOD;
        if (one > 0) ans = (ans + solve(zero, one - 1, 1, 1, limit)) % MOD;
        return ans;
    }
};
```

## 5. **Explain One Example**

Let's take Example 2:  
`zero = 1`, `one = 2`, `limit = 1`

So: arrays use exactly one `0` and two `1`s.  
**Constraint:** No more than 1 consecutive 0s or 1s.

Try out possible arrays:
- Start with 0: [0,?,?]
  - Next must be 1. Use a one: [0,1,?]
    - Next must be 0? but zeros are used up, so must be 1: [0,1,1]
      - But now, the last two are both 1s, so that's two in a row (violates limit=1).
    - Actually, adding 1 at the end triggers limit violation. So this arrangement not valid.

- Start with 1: [1,?,?]
  - Next must be 0: [1,0,?]
    - Use the only zero, so last must be 1: [1,0,1]
      - Now, all 0/1 used, and no consecutive 1s or 0s.
      - This array ([1,0,1]) is valid.

Thus, **only one valid way**: [1,0,1].

---

## **Conclusion**

- This problem is a classic **DP with states**: (remaining zeros, ones, last used, consecutive count), memoized for performance.
- Handles all the constraints efficiently with $\mathcal{O}(zero \cdot one \cdot limit)$ states.
