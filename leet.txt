Let's break down the solution step by step:

---

## 1. **Short Summary**

You are given an array of integers. The task is to count the number of subarrays whose sum is **odd**. Return the answer modulo \( 10^9 + 7 \).  
The brute-force way is too slow; we'll use prefixes and clever counting to achieve a linear solution.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- \( 1 \leq \text{arr.length} \leq 10^5 \)
- \( 1 \leq \text{arr}[i] \leq 100 \)

**Edge Cases:**
- All elements are even → answer is always 0 (since sums stay even).
- All elements are odd → answer increases but needs careful calculation.
- Single element → result is 1 if that element is odd, otherwise 0.

---

## 3. **Optimal Algorithm**

### **Key Idea:**
- We use prefix sums and count modulo 2 (parity) to track "how many prefix sums so far are even" and "how many are odd."
- The sum of any subarray \([i..j]\) is `prefix[j+1] - prefix[i]`.
    - For this sum to be **odd**, the parities of `prefix[j+1]` and `prefix[i]` must be **different**.
- So, we keep a running count:
    - For each position, we count how many prefixes with opposite parity exist up to that point.

### **Algorithm Steps:**
1. Initialize `countEven = 1` (the empty prefix, sum=0 is even), `countOdd = 0`, and `curr = 0` (current prefix sum parity).
2. For each number in the array:
    - Add the number to the prefix sum and take parity: `curr = (curr + x) % 2`
    - If `curr` is odd, it can be paired with an **even** prefix (so add `countEven` to the answer).
    - If `curr` is even, it can be paired with an **odd** prefix (so add `countOdd` to the answer).
    - Increment either `countEven` or `countOdd` accordingly.
3. Return answer modulo \( 10^9 + 7 \).

**Time Complexity:** O(N)

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    int numOfSubarrays(vector<int>& arr) {
        const int MOD = 1e9 + 7;
        long long ans = 0;
        int countEven = 1, countOdd = 0;
        int curr = 0;
        for (int x : arr) {
            curr = (curr + x) % 2;
            if (curr == 1) {
                ans = (ans + countEven) % MOD;
                countOdd++;
            } else {
                ans = (ans + countOdd) % MOD;
                countEven++;
            }
        }
        return (int)ans;
    }
};
```

---

## 5. **Example Explained**

Let's use the **first example:** `arr = [1, 3, 5]`

### Prefix parity progression:

| Index | x | prefix sum | parity (curr) | countEven | countOdd | ans  | What happened?         |
|-------|---|------------|---------------|-----------|----------|------|-----------------------|
|   -   |   |     0      |      0        |     1     |     0    |   0  | Start                 |
|  0    | 1 |     1      |      1        |     1     |     0    |   1  | curr=1, ans += 1 (even)     |
|  1    | 3 |     4      |      0        |     1     |     1    |   1  | curr=0, ans += 1 (odd)      |
|  2    | 5 |     9      |      1        |     2     |     1    |   4  | curr=1, ans += 2 (even)     |

**Final answer: 4 -- as expected.**
