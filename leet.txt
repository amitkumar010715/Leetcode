Let's break down the solution step by step:

---

## 1. **Short Summary**

Given a string `s` of digits and an integer `k`, repeatedly split `s` into groups of size `k`, replace each group by the sum of its digits (as a string), then concatenate the results. Repeat while the length of `s` is greater than `k`. Return the final string.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= s.length <= 100`
  - `2 <= k <= 100`
  - `s` only contains digits (`'0'` to `'9'`)

- **Edge Cases:**
  - All digits are `0` (e.g., `"0000"`)
  - When `s.length == k` (no operations performed, just return `s`)
  - When the last group's size is `< k`
  - The sum of a group can be more than one digit (e.g., sum is 13)

---

## 3. **Optimal Algorithm**

- **While** the length of `s` is greater than `k`:
  - Initialize an empty string for the next result.
  - For each group of size up to `k` (could be smaller at the end):
    - Sum all digits in the group (convert each char to int).
    - Convert the sum to a string and append to the result string.
  - Set `s` to the new string.
- Return `s`.

**Complexity:**  
- Each round reduces the string size, and since the initial length is at most 100, max O(100*100) operations, so it's efficient.

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    string digitSum(string s, int k) {
        while (s.size() > k) {
            string next;
            for (size_t i = 0; i < s.size(); i += k) {
                int sum = 0;
                for (size_t j = i; j < min(i + k, s.size()); ++j)
                    sum += s[j] - '0';
                next += to_string(sum);
            }
            s = next;
        }
        return s;
    }
};
```

## 5. **Example Walkthrough**

**Input:**  
`s = "11111222223", k = 3`

**Process:**  
- **First round** (groups: `"111"`, `"112"`, `"222"`, `"23"`):
    - `"111"`: 1+1+1 = 3 → `"3"`
    - `"112"`: 1+1+2 = 4 → `"4"`
    - `"222"`: 2+2+2 = 6 → `"6"`
    - `"23"`: 2+3 = 5 → `"5"`
- Concatenate: `"3465"`

- Since length > k, next round:
  - **Second round** (`"346"`, `"5"`):
    - `"346"`: 3+4+6 = 13 → `"13"`
    - `"5"`: 5 → `"5"`
- Concatenate: `"135"`

- Length equals `k`, so return `"135"`.
