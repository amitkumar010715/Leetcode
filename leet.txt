Sure! Let's tackle the "Destroying Asteroids" LeetCode problem in a structured way:

---

## 1. **Short Summary**

You control a planet with an initial mass (`mass`) and are given a list of asteroids (`asteroids[]`), each with their own mass. You can collide with the asteroids in any order. If your planet's mass is **at least as large** as an asteroid, the asteroid is destroyed, and your planet's mass increases by the asteroid's mass. If you ever reach an asteroid that's too big, the planet is destroyed. Your goal: **Can you destroy all asteroids?**

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
    - `1 <= mass <= 1e5`
    - `1 <= asteroids.length <= 1e5`
    - `1 <= asteroids[i] <= 1e5`
- **Edge Cases:**
    - The asteroid list may be empty (but per constraints, at least 1 asteroid).
    - The initial mass may be less than, equal to, or greater than any asteroid.
    - There may be multiple asteroids larger than the initial mass—but if you can grow big enough before hitting them, that's OK.
    - Watch for integer overflow when summing masses (but in C++ with long long, this is fine due to up to 1e10 sum).

---

## 3. **Optimal Algorithm**

**Greedy Approach:**
- **Principle:** Always destroy the smallest available asteroid first. This grows your mass as fast as possible, maximizing the chance of defeating larger asteroids later.
- **Steps:**
    1. **Sort** `asteroids[]` in non-decreasing order.
    2. Iterate through each asteroid:
        - If `mass >= asteroid`, add its mass to `mass`.
        - Else, you cannot destroy it, so return `false`.
    3. If you finish the loop, return `true`.

**Time Complexity:**
- Sorting: `O(N log N)`  
- One pass: `O(N)`  
- **Total:** `O(N log N)`

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    bool asteroidsDestroyed(int mass, vector<int>& asteroids) {
        // To avoid integer overflow, use long long!
        long long curMass = mass;
        sort(asteroids.begin(), asteroids.end());
        for (int a : asteroids) {
            if (curMass < a)
                return false;
            curMass += a;
        }
        return true;
    }
};
```

---

## 5. **Example Explained**

**Input:**  
`mass = 10, asteroids = [3,9,19,5,21]`

**Stepwise:**

1. **Sort asteroids**: `[3, 5, 9, 19, 21]`
2. **Start with mass = 10**

- Asteroid 3: 10 ≥ 3 → destroy → new mass = 10+3 = 13
- Asteroid 5: 13 ≥ 5 → destroy → new mass = 13+5 = 18
- Asteroid 9: 18 ≥ 9 → destroy → new mass = 18+9 = 27
- Asteroid 19: 27 ≥ 19 → destroy → new mass = 27+19 = 46
- Asteroid 21: 46 ≥ 21 → destroy → new mass = 46+21 = 67

**All asteroids destroyed! Return `true`.**

---

**In summary:**  
- Always destroy the smallest asteroid first,
- Grow your mass step by step,
- Return `false` the moment an asteroid is too big for you!
