## 1. Short Summary

Given two arrays of positive integers, find the **length of the longest common prefix** (as digit strings) that exists between any pair of integers, with one integer from each array. Prefix: integer formed by a leading sequence of digits from the left.

---

## 2. Constraints & Edge Cases

- **Array sizes:** up to 50000 each, implying O(N²) solutions are too slow.
- **Element values:** up to 100,000,000 (at most 8 digits per number).
- **Edge cases:**
    - No common prefix at all (output 0).
    - All numbers are single digit.
    - Arrays with duplicate numbers.
    - One array with a single element.
    - Very large numbers.

---

## 3. Optimal Algorithm

### Key Observations

- Brute-force comparing all pairs is too slow.
- Since we care about digit prefixes, treating numbers as strings is effective.
- The **longest common prefix** for two numbers is determined by comparing their string representations from the left.

### Efficient Approach

We want to **quickly check for the longest common prefix between any x in arr1 and y in arr2**.

#### Steps:

1. **Convert all numbers to string representations.**
2. **For each possible prefix length `l` (from max possible down to 1):**
    - Build **all prefixes of length `l`** from arr1 and arr2 (by extracting substrings of length `l`).
    - Use sets or maps to store prefixes for **fast checking**.
    - If there is any prefix that is present in both sets, that's the answer.

Since number lengths are at most 8, we can check from 8 down to 1 quickly.

#### Complexity

- For each length 8..1 (~8 steps)
    - O(N) for extracting prefixes from each array (O(8*N) worst-case).
- Set intersection can be optimized with hash sets.
- Total: **O(8*N + 8*M)**, where N = arr1.size(), M = arr2.size().

### Pseudocode

```
For len = max_length down to 1:
    Build set of all prefixes of len in arr1
    Build set of all prefixes of len in arr2
    If there is intersection:
        return len
return 0
```

## 4. Clean C++ Solution

```cpp
#include <vector>
#include <string>
#include <unordered_set>

using namespace std;

class Solution {
public:
    int longestCommonPrefix(vector<int>& arr1, vector<int>& arr2) {
        vector<string> s1, s2;
        int maxlen = 0;
        // Convert to strings & track max length
        for (int x : arr1) {
            string sx = to_string(x);
            s1.push_back(sx);
            if (sx.size() > maxlen) maxlen = sx.size();
        }
        for (int x : arr2) {
            string sx = to_string(x);
            s2.push_back(sx);
            if (sx.size() > maxlen) maxlen = sx.size();
        }

        // Try from maxlen down to 1
        for (int len = maxlen; len >= 1; --len) {
            unordered_set<string> prefix1, prefix2;

            for (const string& sx : s1) {
                if (sx.size() >= len)
                    prefix1.insert(sx.substr(0, len));
            }
            for (const string& sy : s2) {
                if (sy.size() >= len)
                    prefix2.insert(sy.substr(0, len));
            }

            // Check if any common prefix exists
            for (const string& p : prefix1) {
                if (prefix2.count(p)) {
                    return len;
                }
            }
        }
        return 0;
    }
};
```

## 5. Example Explained

**Example 1:**

Input:  
`arr1 = [1,10,100], arr2 = [1000]`

Let's convert each to strings:

- arr1: ["1", "10", "100"]
- arr2: ["1000"]

Check for longest common prefix:

- Length 3:
    - arr1: "100"
    - arr2: "100"
    - Common prefix "100" (length 3) (since "1000".substr(0,3) = "100")
- There is a match at length 3; so the answer is **3**.
