Let's go through the problem step by step:

---

## 1. **Short Summary**

Given a string `word` consisting of uppercase and lowercase English letters, **count how many distinct letters appear in both lowercase and uppercase forms** within the string. These letters are called "special".

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= word.length <= 50` (small size, so O(N) is fine)
  - Only 'a'-'z' and 'A'-'Z' in the string.

- **Edge Cases:**
  - All letters are lowercase or all are uppercase ⇒ Output should be 0.
  - The same letter appears multiple times, but only in one case ⇒ Not counted.
  - String contains a letter in both cases ⇒ Count once per letter.
  - Overlapping special letters, i.e., more than one letter is special.

---

## 3. **Optimal Algorithm**

- **Idea**: For each letter from 'a' to 'z', check if *both* the lowercase and uppercase forms appear in the string.
- **How to Check?**
  - Use sets to store **all lowercase letters** and **all uppercase letters** present in the string.
  - For each letter 'a' to 'z':
      - If its lowercase is in the lowercase set **and**
      - Its uppercase is in the uppercase set,
      - Then it's "special".
- **Time Complexity:** O(N) + O(26) where N = word length.

---

## 4. **Clean C++ Solution**

```cpp
#include <unordered_set>
#include <string>
using namespace std;

class Solution {
public:
    int numberOfSpecialChars(string word) {
        unordered_set<char> lower, upper;
        for (char c : word) {
            if (islower(c)) lower.insert(c);
            else if (isupper(c)) upper.insert(c);
        }
        int cnt = 0;
        for (char ch = 'a'; ch <= 'z'; ++ch) {
            if (lower.count(ch) && upper.count(toupper(ch))) {
                cnt++;
            }
        }
        return cnt;
    }
};
```

---

## 5. **Explain One Example**

Let's do this for: `word = "aaAbcBC"`

- Lowercase in string: `{a, b, c}`
- Uppercase in string: `{A, B, C}`

**Check for each 'a' to 'z':**
- For 'a': 'a' in lower and 'A' in upper ⇒ special
- For 'b': 'b' in lower and 'B' in upper ⇒ special
- For 'c': 'c' in lower and 'C' in upper ⇒ special

So, answer = **3**.

---

**Summary**:  
Keep track of all lowercase and all uppercase letters present. For each possible letter, if it exists in both, count it as special. The algorithm is efficient and straightforward.
