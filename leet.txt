Let's break down the solution for **"Count Covered Buildings"**:

---

## 1. Summary

Given a list of building coordinates in an n x n grid, a building is **"covered"** if there are at least **other buildings** immediately in all four cardinal directions (left/right/up/down). Your task is to count how many buildings are covered.

---

## 2. Constraints & Edge Cases

- **Constraints:**
    - n can be up to 1e5 (100,000)
    - Up to 1e5 buildings, all with unique coordinates

- **Implications:**
    - Brute-force checking each direction for every building is too slow (O(k²) where k = #buildings).
    - Need O(k log k) or better.

- **Edge Cases:**
    - Some buildings may be on edges/corners (so could never be covered).
    - Some rows or columns may have only one building.
    - All buildings could be in one row or column.

---

## 3. Optimal Algorithm

### **Idea**

- For each building, to be "covered", it must have:
    - Another building in the **same row**, with x position **less than** it (left), and **greater than** it (right).
    - Another building in the **same column**, with y position **less than** it (up), and **greater than** it (down).

- Thus, for each building, we must quickly determine if such buildings exist.

### **Efficient Method**

1. **Store buildings for quick lookup row-wise and column-wise:**
    - For each row, keep a sorted list of columns with buildings.
    - For each column, keep a sorted list of rows with buildings.

2. **For each building:**
    - Using binary search, check for both:
        - In same row: Is there a building to **left** (col < this_col), and to **right** (col > this_col)?
        - In same column: Is there a building **above** (row < this_row), and **below** (row > this_row)?
    - Both must exist for a building to be covered.

This works efficiently even for the largest constraints.

### **Algorithm Steps**

1. For all buildings, group:
    - For each row **x**: a sorted vector of columns (y's) present.
    - For each column **y**: a sorted vector of rows (x's) present.
2. For each building (x, y):
    - Row x: is there any y' < y? any y' > y?
    - Column y: is there any x' < x? any x' > x?
    - Each can be answered with `lower_bound`/`upper_bound` (binary search) in the sorted vectors.

**Time complexity:** O(k log k), with k = #buildings.

---

## 4. C++ Solution

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>

using namespace std;

class Solution {
public:
    int countCoveredBuildings(int n, vector<vector<int>>& buildings) {
        unordered_map<int, vector<int>> row_to_cols;
        unordered_map<int, vector<int>> col_to_rows;

        // Build mappings for quick row/col lookups
        for (auto& b : buildings) {
            int x = b[0];
            int y = b[1];
            row_to_cols[x].push_back(y);
            col_to_rows[y].push_back(x);
        }

        // Sort row/col lists for binary search
        for (auto& [row, cols] : row_to_cols) sort(cols.begin(), cols.end());
        for (auto& [col, rows] : col_to_rows) sort(rows.begin(), rows.end());

        int covered = 0;
        for (auto& b : buildings) {
            int x = b[0], y = b[1];
            // Row x: y's
            auto& row = row_to_cols[x];
            auto it = lower_bound(row.begin(), row.end(), y);
            bool has_left = (it != row.begin());
            bool has_right = (it != row.end() && next(it) != row.end());

            // For right, also check if it's not the last element
            if (it != row.end() && it != row.end() - 1) has_right = true;
            else has_right = false;
            
            // Fix: neater version
            has_right = (it != row.end() && next(it) != row.end());

            // Column y: x's
            auto& col = col_to_rows[y];
            auto it2 = lower_bound(col.begin(), col.end(), x);
            bool has_up = (it2 != col.begin());
            bool has_down = (it2 != col.end() && next(it2) != col.end());

            // Clean up: actually, similar to above, but let's check if there's an element before/after
            // To avoid corner cases, let's check position
            // If 'it' points to the element, need to check if there is anything before and after

            // Actually, to simplify:
            has_left = (distance(row.begin(), it) > 0);
            has_right = (distance(it, row.end()) > 1);
            has_up = (distance(col.begin(), it2) > 0);
            has_down = (distance(it2, col.end()) > 1);

            if (has_left && has_right && has_up && has_down)
                covered++;
        }
        return covered;
    }
};
```

## 5. Example Explanation

Take **Example 1**:

```
n = 3
buildings = [[1,2],[2,2],[3,2],[2,1],[2,3]]

City:
  (row,column)
  [1,2]       <- building
  [2,1] [2,2] [2,3]
  [3,2]

For building [2,2]:
- In row 2: buildings at [2,1], [2,2], [2,3]
  - Left? [2,1] (yes)
  - Right? [2,3] (yes)
- In column 2: buildings at [1,2], [2,2], [3,2]
  - Above? [1,2] (yes)
  - Below? [3,2] (yes)

[2,2] is the only building fully covered, hence answer is **1**.
```
