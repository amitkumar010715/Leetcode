Let's break down the problem and requirements step by step:

---

## 1. **Short Summary**

Given an array `nums`, you must split it into 3 **disjoint contiguous subarrays**. The "cost" of each subarray is the value of its **first element**. Find the split (partition) that minimizes the sum of these costs.


---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `3 <= n <= 50` (small: allows O(n^2) approaches)
  - `1 <= nums[i] <= 50` (all positive)
- **Edge Cases:**
  - Arrays of length 3: only possible split is each element as a subarray
  - Arrays where optimal split creates a longer last subarray
  - Arrays where optimal split is each subarray of length 1

---

## 3. **Optimal Algorithm**

Since we need to split the array into 3 contiguous subarrays, consider the **positions of split points**.  
Let the subarrays be:  
- `nums[0..i-1]`  (first subarray, length at least 1)
- `nums[i..j-1]` (second subarray, length at least 1)
- `nums[j..n-1]` (third subarray, length at least 1)

We need `1 <= i < j <= n-1` so that all subarrays are non-empty.

So, for all possible `i` and `j`:
- sum = nums[0] + nums[i] + nums[j]
- answer = minimal such sum

The complexity is O(n^2), which is efficient for `n <= 50`.

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minimumCost(vector<int>& nums) {
        int n = nums.size();
        int ans = INT_MAX;
        // i: start of second subarray
        // j: start of third subarray
        for (int i = 1; i <= n - 2; ++i) {
            for (int j = i + 1; j <= n - 1; ++j) {
                int sum = nums[0] + nums[i] + nums[j];
                ans = min(ans, sum);
            }
        }
        return ans;
    }
};
```

---

## 5. **Example Explained**

Let's explain Example 1:

**Input:** `nums = [1,2,3,12]`

Possible splits:
- i = 1 (second starts at 1), j = 2 (third starts at 2):
    - [1], [2], [3,12]; cost = 1 + 2 + 3 = 6 (**minimum**)
- i = 1, j = 3:
    - [1], [2,3], [12]; cost = 1 + 2 + 12 = 15
- i = 2, j = 3:
    - [1,2], [3], [12]; cost = 1 + 3 + 12 = 16

**Answer:** 6

---

### **Summary Table**

| i   | j   | Subarrays          | Cost      |
|-----|-----|--------------------|-----------|
|  1  |  2  | [1], [2], [3,12]   | 1+2+3=6   |
|  1  |  3  | [1], [2,3], [12]   | 1+2+12=15 |
|  2  |  3  | [1,2], [3], [12]   | 1+3+12=16 |

---

## **Conclusion**

- Use two loops to try all splits.
- Calculate costs as `nums[0] + nums[i] + nums[j]` for `1 <= i < j <= n-1`.
- Take the minimum. This is efficient and correct given the problem constraints.
