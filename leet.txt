Let's break down the problem as per your requirements:

---

## 1. **Short Summary**

You are given a list of strings of equal length, forming an \( n \times m \) character grid. You must count how many columns **are not sorted lexicographically from top to bottom**, and return that count.

---

## 2. **Constraints & Edge Cases**

- **Constraints**
    - \( 1 \leq n \leq 100 \) (number of strings/rows)
    - \( 1 \leq m \leq 1000 \) (length of each string/columns)
    - Each `strs[i]` consists of lowercase English letters.

- **Edge Cases**
    - Only one string (`n = 1`): All columns are trivially sorted (output 0).
    - Strings of length 1 (`m = 1`): Only one column, so check whether it is sorted.
    - All columns sorted: Output 0.
    - All columns unsorted: Output \( m \).
    - Case with equal letters in a column: It's valid, since equality is allowed for sorted order.

---

## 3. **Optimal Algorithm**

- For each column `j` from 0 to \( m-1 \):
    - For each row `i` from 1 to \( n-1 \):
        - Compare `strs[i][j]` and `strs[i-1][j]`.
        - If `strs[i][j] < strs[i-1][j]`, this column is **not sorted**, so increment the count and move to the next column.
- Time Complexity: \( O(n \cdot m) \) — since we check each character in the grid at most once.

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int minDeletionSize(vector<string>& strs) {
        int n = strs.size(), m = strs[0].size();
        int delCount = 0;
        for (int col = 0; col < m; ++col) {
            for (int row = 1; row < n; ++row) {
                if (strs[row][col] < strs[row-1][col]) {
                    delCount++;
                    break; // Move to next column
                }
            }
        }
        return delCount;
    }
};
```

---

## 5. **Example Explained**

Take example:  
`strs = ["cba", "daf", "ghi"]`

Grid:

```
c b a
d a f
g h i
```

- **Column 0:** `c` → `d` → `g` (c < d < g) -- Sorted
- **Column 1:** `b` → `a` → `h` (`a` < `b`, so not sorted) -- **Needs to be deleted**
- **Column 2:** `a` → `f` → `i` (a < f < i) -- Sorted

**Only column 1 is not sorted, so the function returns 1.**
