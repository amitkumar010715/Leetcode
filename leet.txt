Let's address your requirements step by step.

---

## 1. **Short Summary**

Given an `nums` array and a `target` value, **count the number of subarrays where `target` occurs more than half the time**. That is, in each such subarray, `target` must be the strict majority element.

---

## 2. **Constraints & Edge Cases**

- **Length**: Up to 1e5, so O(N^2) is too slow. We need an O(N log N) or O(N) solution.
- **Elements**: Up to 1e9, so we can't use bucket frequency counting for all values.
- **Target not in array**: Should return 0.
- **Single element array**: Should handle correctly.
- **All same elements, target == element**: All subarrays valid.
- **All different, target once**: Only single-element subarray (if at all).

---

## 3. **Optimal Algorithm**

### Key Observations

- For a subarray `[l, r]` (inclusive), the **majority condition** is:
    - `count(target)` > `(r-l+1)//2`  
- We only want subarrays where `target` occurs **strictly more than half**.

### Approach

#### 1. **Prefix Sums & Balancing**

We process the array and for every prefix, keep track of the **net balance**:
- For each position `i`, let  
    - `bal[i] = 2×#target - (i + 1)`
    - In other words:  
        - +1 for each appearance of `target`
        - -1 for each non-target.

#### 2. **Restating the Majority Condition**

For subarray `[l, r]`:  
Let `s = count(target) in [l, r]`  
Subarray length = `r-l+1`  
The condition: `s > (r-l+1)//2`

Rewriting:
- Let’s consider how the balance `bal` changes over subarrays.
- For prefix sums, the balance at `i` is:
    - `bal[i] = bal[i-1] + (1 if nums[i] == target else -1)`
    - Empirically, for a subarray `[l, r]`, the sum is
        - `sum = bal[r] - bal[l-1]`
    - We seek all `(l, r)` where `sum > (r-l+1)//2`
    - But this is complicated. Let's represent via **balance array**.

#### 3. **Final Reduction to Prefix Sums and Counting**

We can use a **modified balance** array:
- Let `b[i] = (nums[i] == target ? 1 : -1)`
- Let `pref[0] = 0`  
- For all `1 <= i <= n`, `pref[i] = pref[i-1] + b[i-1]`

Now, for any subarray `[l, r]` (prefix interval), `sum = pref[r+1] - pref[l]`

We need, for a subarray `[l, r]`,  
  `count(target in [l, r]) > (r - l + 1) / 2`  
Or equivalently,
  `sum_{i=l}^r b[i] > (r-l+1)/2`  
But since `b[i]` is 1 or -1,  the sum is `s = #target - (#non_target) = 2*#target - (r-l+1)`
So
```
2*#target - (r-l+1) > (r-l+1)/2
2*#target > (3/2)*(r-l+1)
#target > (3/4)*(r-l+1)
```
But that's not ideal for prefix sums.

##### Alternative: Use the original concept:

- For each prefix sum, we process left-to-right, and for each position, count how many prior prefix sums are **less than** a given threshold.

Define `pref[0] = 0`, `pref[1] = b[0]`, ..., `pref[n] = sum(b[i], i=0..n-1)`

For every `right` in `[0, n-1]` (so subarrays ending at `right`):
- For every `left` in `[0, right]`, prefix sum difference is `pref[right+1] - pref[left]`.
- We want: `pref[right+1] - pref[left] > (right - left + 1)/2`

Solve for `pref[left] < pref[right+1] - (right - left + 1)/2`

So for each `right+1`, how many prefix sums to the left are < some value.

This can be counted efficiently using **coordinate compression and a Binary Indexed Tree (Fenwick Tree) or Balanced BST**.

---

### **Efficient Algorithm (Summary)**

1. **Compute `b[i] = (nums[i] == target ? 1 : -1)`**
2. **Build the prefix sum array `pref`**
3. For each position, count how many prior positions have prefix sums less than a threshold.
    - Need to count for each `i` (current end position), the number of `j < i` with:  
      `pref[j] < pref[i] - length/2`
    - But since for all prior indices we need all those who satisfy that.

    By iterating i from 0 to n, and keeping a data structure that lets us query counts of prefix sums efficiently, we can process this in O(N log N).

4. **Implementation:** Map all possible prefix sums (coordinate compression) and maintain cumulative frequency.

---

## 4. **Clean C++ Solution**

```cpp
#include <bits/stdc++.h>
using namespace std;

// Fenwick Tree / BIT
struct Fenwick {
    vector<int> bit;
    int n;
    void init(int _n) { n = _n+2; bit.assign(n, 0); }
    void add(int x, int v) {
        for (++x; x < n; x += x & -x) bit[x] += v;
    }
    int sum(int x) {
        int res = 0;
        for (++x; x > 0; x -= x & -x) res += bit[x];
        return res;
    }
};

class Solution {
public:
    long long countSubarrays(vector<int>& nums, int target) {
        int n = nums.size();
        vector<long long> pref(n+1, 0);
        for (int i = 0; i < n; ++i) pref[i+1] = pref[i] + (nums[i] == target ? 1 : -1);

        // To avoid floating points, work with 2*prefix sums:
        vector<long long> vals;
        for (int i = 0; i <= n; ++i) vals.push_back(2*pref[i]);
        // Also, need all possible 2*prefixSum[i] - (i)
        for (int i = 0; i <= n; ++i) vals.push_back(2*pref[i] - i);

        // Coordinate compression
        sort(vals.begin(), vals.end());
        vals.erase(unique(vals.begin(), vals.end()), vals.end());
        auto idx = [&](long long x) {
            return lower_bound(vals.begin(), vals.end(), x) - vals.begin();
        };

        Fenwick bit; bit.init(vals.size());

        long long ans = 0;
        for (int j = 0; j <= n; ++j) {
            if (j > 0) {
                // For subarrays ending at j-1, number of prior i < j with:
                // 2*pref[i] < 2*pref[j] - (j-i)
                // -> 2*pref[i] < 2*pref[j] - (j-i)
                // For all i < j, we previously inserted 2*pref[i] into the BIT
                // So query sum at 2*pref[j] - j
                int qx = idx(2*pref[j] - j);
                ans += bit.sum(qx - 1);
            }
            // Insert current 2*pref[j] - 0 into BIT (for future queries)
            int ix = idx(2*pref[j]);
            bit.add(ix, 1);
        }
        return ans;
    }
};
```

## 5. **Example Explanation**

**Example 1**: `nums = [1,2,2,3], target = 2`  

Let's list all subarrays:
- [0,0]: [1] -> majority element: 1
- [0,1]: [1,2] -> majority: none  
- [0,2]: [1,2,2] ⇒ target appears 2/3 (>1.5), so majority! ✅
- [0,3]: [1,2,2,3] => target appears 2/4, not strictly more than half.

- [1,1]: [2] ⇒ target is majority! ✅
- [1,2]: [2,2] ⇒ target appears 2/2 (>1), so majority! ✅
- [1,3]: [2,2,3] ⇒ target appears 2/3 (>1.5), so majority! ✅

- [2,2]: [2] ⇒ target! ✅
- [2,3]: [2,3] ⇒ target appears 1/2 (=0.5), not majority.

- [3,3]: [3] ⇒ Not target.

Count of valid subarrays: five, as highlighted.

---

**In summary:**
- This technique essentially converts the problem to counting the number of subarrays where a certain prefix sum difference exceeds half the length, feasible via prefix sums, coordinate compression, and a BIT/segment tree for O(N log N) performance.
