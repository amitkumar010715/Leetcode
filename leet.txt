Let's break down and solve the problem:

---

## 1. **Short Summary**

You are given a binary string `s` (no leading zeros). Return `true` if all `1`s in `s` form **at most one contiguous segment** (block); otherwise, return `false`.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= s.length <= 100` — short length, can check character by character.
- Each character is `'0'` or `'1'`.
- `s[0] == '1'` — no leading zeros.

**Edge Cases:**
- All `1`s: e.g., `"111111"` → `true`
- No `0` at all: same as above.
- All `1`s at start, then all `0`s: `"1110000"` → `true`
- `1`s, then `0`s, then more `1`s: `"110011"` → `false`
- Only one `1`: `"1"` or `"100"` → `true`
- Alternating: `"101"` → `false`
- String like `"10"` or `"1"` → `true`

---

## 3. **Optimal Algorithm**

We need to check **how many segments of `1`s** there are.
Key idea: Once a `0` is found after a block of `1`s, if another `1` is found later, that's a new segment and we should return `false`.

### Approach
- Use a flag (e.g., `found_zero`) to track if we've seen a `0` **after** the first segment of `1`s.
- Loop through the string:
  - If we see a `0`, set `found_zero=true`
  - If we see a `1` **after** we've seen a `0`, return `false`.

### Complexity
- **Time:** O(n)
- **Space:** O(1)

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    bool checkOnesSegment(string s) {
        bool found_zero = false;
        for (char c : s) {
            if (c == '0') {
                found_zero = true;
            } else { // c == '1'
                if (found_zero) {
                    // Found a '1' after a '0'
                    return false;
                }
            }
        }
        return true;
    }
};
```

---

## 5. **Example Explanation**

**Example**:  
Input: `"1001"`
- First character: `'1'` — first segment starts.
- Second character: `'0'` — end of first segment, set found_zero = true.
- Third character: `'0'` — keep found_zero true.
- Fourth character: `'1'` — we've seen a zero before and now a new `1`, so we know there is a **second segment of ones**.

**Output:** `false`
