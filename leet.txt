Let's break it down per your requirements:

---

## 1. Short Summary

Given an array, **find the length of the longest contiguous subarray** that is either **strictly increasing** or **strictly decreasing**. The subarray must use consecutive elements, and the sequence must be *strict*, i.e., all elements **must be** `>` or `<` than their previous element respectively.

---

## 2. Constraints & Edge Cases

- **Constraints**:  
  - Array length: `1 ≤ nums.length ≤ 50`
  - Element value: `1 ≤ nums[i] ≤ 50`
- **Edge Cases**:
  - Single-element arrays (answer is 1).
  - All elements are the same (answer is 1).
  - All elements strictly increasing/decreasing (answer is nums.length).
  - Plateaus (equal consecutive elements): break both increasing/decreasing sequences.
  - Mixed: sequences of length 2 (e.g., `[a, b]` where `a ≠ b`) count as strictly increasing/decreasing.

---

## 3. Optimal Algorithm

Since N is small (≤ 50), a **linear scan** is optimal:

- **Track two values as you scan**:
  - `inc_len`: current length of strictly increasing ending at `i`
  - `dec_len`: current length of strictly decreasing ending at `i`
  - `ans`: max found so far
- For every index from `1` to `n-1`:
  - If `nums[i] > nums[i-1]`: `inc_len += 1`, reset `dec_len` to 1
  - If `nums[i] < nums[i-1]`: `dec_len += 1`, reset `inc_len` to 1
  - If `nums[i] == nums[i-1]`: both reset to 1
  - Update `ans` after each step

This is O(N) time and O(1) extra space.

---

## 4. Clean C++ Solution

```cpp
class Solution {
public:
    int longestMonotonicSubarray(vector<int>& nums) {
        int n = nums.size();
        int inc_len = 1, dec_len = 1, ans = 1;
        for (int i = 1; i < n; ++i) {
            if (nums[i] > nums[i-1]) {
                inc_len += 1;
                dec_len = 1;
            } else if (nums[i] < nums[i-1]) {
                dec_len += 1;
                inc_len = 1;
            } else {
                inc_len = dec_len = 1;
            }
            ans = max(ans, max(inc_len, dec_len));
        }
        return ans;
    }
};
```

---

## 5. Explanation with Example

Take `nums = [1, 4, 3, 3, 2]`.
- Start: inc_len = dec_len = ans = 1
- i=1: 4 > 1 ⇒ inc_len=2, dec_len=1, ans=2
- i=2: 3 < 4 ⇒ dec_len=2, inc_len=1, ans=2
- i=3: 3 == 3 ⇒ reset both to 1, ans=2
- i=4: 2 < 3 ⇒ dec_len=2, inc_len=1, ans=2

**Final answer:** `2`

## **Summary**

- Linear scan: O(N)
- Track strictly increasing & decreasing runs
- Reset on equal nums
- Update max each time.

**This is both fast and clear!**
