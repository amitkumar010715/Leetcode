### 1. **Short summary**

Given an array of digits (`digits`), count the **number of distinct 3-digit even numbers** that can be formed, using each `digits[i]` at most once per number, and avoiding leading zeros.

---

### 2. **Constraints & Edge Cases**

- **Length**: `digits.length` between 3 and 10.
- **Value Range**: Each digit between 0 and 9.
- **Leading Zeros**: Numbers like 012 are not valid (leading zeros not allowed).
- **Even Numbers**: Last digit must be even (0,2,4,6,8).
- **Duplicates Allowed**: Input digits can repeat, but each occurrence used once per number.
- **All Digits Odd**: If only odd digits given, output is 0.
- **For repeated digits**: Need to ensure enough occurrences for numbers with repeated digits.

---

### 3. **Optimal Algorithm**

- **Brute Force is Fine**: Since all possible 3-digit numbers (100-999) is just 900 possibilities and `digits` is max 10 elements, we can check each possibility.
- **Steps**:
    1. Count the frequency of each digit in the input.
    2. For each even 3-digit number from 100 to 998 (step 2):
        - Split number into its digits: hundreds, tens, units.
        - Check that for each digit, enough occurrence exists in `digits`.
        - If yes, add to a result set (to guarantee uniqueness).
    3. Return the size of the result set.

- **Why NOT backtracking permutations?**:
  We want uniqueness, but the number of possible 3-digit even numbers is just 900, manageable for a simple check per candidate.

### 4. **C++ Solution**

```cpp
#include <vector>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int countEven3DigitNumbers(vector<int>& digits) {
        unordered_map<int, int> freq;
        for (int d: digits) freq[d]++;

        unordered_set<int> uniqueNums;

        // Loop over all 3-digit numbers from 100 to 999 (inclusive)
        for (int num = 100; num <= 999; num++) {
            if ((num % 2) != 0) continue; // Must be even

            int a = num / 100, b = (num / 10) % 10, c = num % 10;
            unordered_map<int, int> need;
            need[a]++; need[b]++; need[c]++;

            bool valid = true;
            for (auto& [digit, cnt] : need)
                if (freq[digit] < cnt) { valid = false; break; }

            if (valid)
                uniqueNums.insert(num);
        }
        return uniqueNums.size();
    }
};
```

---

### 5. **Example Explanation**

**Input:** `digits = [0,2,2]`

- Possible 3-digit even numbers:
    - All 3-digit numbers with these digits, must be even, and no leading zero.
    - List all possible non-leading zero permutations:
        - 202 (digits used: 2,0,2)
        - 220 (digits used: 2,2,0)
    - Only these two numbers are possible.

**Output:** `2`
