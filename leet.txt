Sure! Here is a detailed explanation and clean solution for the problem **Robot Return to Origin**:

---

## 1. **Short Summary**

Given a string of moves for a 2D robot (`'U'`, `'D'`, `'L'`, `'R'`), you need to check if the robot returns to the origin `(0, 0)` after executing all moves. Each character in the string represents a unit movement in the direction specified.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= moves.length <= 2 * 10^4`
  - `moves` only contains `'U'`, `'D'`, `'L'`, `'R'`
- **Edge Cases:**
  - The string has only one character: The robot cannot return to origin (`"U"`, `"D"`, `"L"`, `"R"` → returns `false`).
  - The moves cancel each other out: e.g. `"UDLR"` (each move is canceled).
  - All moves in one direction only: e.g. `"LLLL"` or `"UUU"`.
  - The string is balanced but in a "mixed" order: e.g. `"LURD"`.

---

## 3. **Optimal Algorithm**

- **High-level idea:**  
  Keep track of the robot's location using two variables (`x` and `y`) starting from `(0, 0)`.
  - `'U'` increases `y` by 1 (up).
  - `'D'` decreases `y` by 1 (down).
  - `'L'` decreases `x` by 1 (left).
  - `'R'` increases `x` by 1 (right).
- After all moves, if and only if `(x, y) == (0, 0)`, return `true`, else return `false`.
- **Time complexity:** O(n), where n = length of `moves`.

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    bool judgeCircle(string moves) {
        int x = 0, y = 0;
        for (char move : moves) {
            if (move == 'U') y++;
            else if (move == 'D') y--;
            else if (move == 'L') x--;
            else if (move == 'R') x++;
        }
        return x == 0 && y == 0;
    }
};
```

---

## 5. **Example Explanation**

**Example:**  
`moves = "UD"`

- Start at `(0, 0)`.
- `'U'` → move up: `(0, 1)`
- `'D'` → move down: `(0, 0)` (back to origin)

**Result:**  
Since the robot is back at the origin, the answer is `true`.
