## 1. **Short Summary**

Given a string containing lowercase letters and balanced parentheses, **reverse the strings inside each pair of parentheses from the innermost to the outermost**, removing the parentheses in the final output.

---

## 2. **Constraints & Edge Cases**

- **String length:** 1 ≤ s.length ≤ 2000 –– Solution needs to be efficient (preferably O(n)).
- **Characters:** s contains only lowercase letters and '(' / ')'.
- **Balanced Parentheses:** All parentheses are balanced –– no need to handle mismatches or errors.
- **Edge Cases:**
  - No parentheses: `"abc"` → `"abc"`
  - Nested parentheses: `"(a(bc)d)"` → `"dbca"`
  - Multiple separate parentheses: `"(ab)(cd)"` → `"badc"`

---

## 3. **Optimal Algorithm** (with explanation)

### Approach: **Stack Simulation**

- Use a **stack** to simulate parsing and reversing at every parenthesis.
- Iterate `s` character by character:
  - If the character is `'('`: **push a marker** (e.g., current buffer) to stack, start a new buffer.
  - If the character is `')'`: **reverse current buffer**, pop previous buffer from stack, **concatenate** reversed buffer to top of stack.
  - Otherwise, **append character** to current buffer.
- At the end, the current buffer is the answer.

**Reason for stack:**  
The stack helps us handle nested parentheses cleanly, ensuring we always reverse the innermost content first.

#### **Pseudocode**:

```
stack<string> st
current = ""

for c in s:
    if c == '(':
        st.push(current)
        current = ""
    else if c == ')':
        reverse(current)
        prev = st.top(); st.pop()
        current = prev + current
    else:
        current += c

return current
```

- **Time Complexity:** O(n)
- **Space Complexity:** O(n) for the stack and intermediate strings.

---

## 4. **Clean C++ Solution**

```cpp
#include <string>
#include <stack>
#include <algorithm>
using namespace std;

class Solution {
public:
    string reverseParentheses(string s) {
        stack<string> st;
        string cur;
        for (char c : s) {
            if (c == '(') {
                st.push(cur);
                cur = "";
            } else if (c == ')') {
                reverse(cur.begin(), cur.end());
                cur = st.top() + cur;
                st.pop();
            } else {
                cur += c;
            }
        }
        return cur;
    }
};
```

## 5. **Example Explained**

### Example:
```
Input:  s = "(u(love)i)"
Output: "iloveu"
```

**Step by step:**
1. See '(': push `""` onto stack. cur = `""`
2. See 'u': cur = `"u"`
3. See '(': push `"u"` onto stack. cur = `""`
4. See "l", "o", "v", "e": cur = `"love"`
5. See ')': reverse `"love"` -> `"evol"`
   - pop `"u"` from stack, concat: cur = `"u" + "evol"` = `"uevol"`
6. See 'i': cur = `"uevoli"`
7. See ')': reverse `"uevoli"` -> `"iloveu"`
   - pop `""` from stack, concat: cur = `"" + "iloveu"` = `"iloveu"`
8. End of string.

**Return:** `"iloveu"`
