Let's address the LeetCode problem **"Minimize Hamming Distance After Swap Operations"** step by step:

---

## 1. **Summary**

Given two arrays `source` and `target` of equal length and a list of allowed index swaps, you can rearrange `source` by performing any number of these swaps. Your goal is to **minimize the Hamming distance** (number of mismatched entries) between the rearranged `source` and `target`.

Key insight: For any group of indices that are interconnected by swaps, you can permute the elements at those indices however you like. To minimize distance, within each such group, try to match as many elements from `source` to `target` as possible.

---

## 2. **Constraints and Edge Cases**

- **Size**: n up to 100,000; up to 100,000 allowed swaps.
- **Values**: All elements in `source` and `target` are in [1, 100,000].
- **No allowedSwaps**: If empty, only original arrangement possible.
- **Disconnected subgroups**: If swaps don't connect some indices, you can only permute within connected groups.
- **Duplicates**: Both arrays may have duplicate elements.
- **Edge**: allowedSwaps can include cycles and multi-component graphs.

---

## 3. **Optimal Algorithm**

### a) **Observation**
- The indices form groups (connected components) via swaps.
- Within a group, all indices can have their values permuted arbitrarily.

### b) **Steps**
1. **Find all connected components** in the graph defined by allowedSwaps (Union-Find/DSU structure).
2. **For each component:**
    - Collect values from `source` and `target` for indices in this component.
    - Try to maximize matches: for each value in `target`, match if possible with one in `source`, and count mismatches.
3. **Accumulate mismatches** across all groups.

### c) **Implementation Details**
- For efficiency, use a **Union-Find (Disjoint Set Union, DSU)** data structure.
- Use **unordered_map (hash map)**/multiset to count occurrences efficiently within each component.

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    // Union-Find data structure
    struct DSU {
        vector<int> parent;
        DSU(int n): parent(n) {
            for (int i = 0; i < n; ++i) parent[i] = i;
        }
        int find(int x) {
            if (parent[x] != x) 
                parent[x] = find(parent[x]); // Path compression
            return parent[x];
        }
        void unite(int x, int y) {
            parent[find(x)] = find(y);
        }
    };

    int minimumHammingDistance(vector<int>& source, vector<int>& target, vector<vector<int>>& allowedSwaps) {
        int n = source.size();
        DSU dsu(n);

        // Build union-find structure from allowedSwaps
        for (const auto& sw : allowedSwaps) {
            dsu.unite(sw[0], sw[1]);
        }

        // Map: root -> indices in component
        unordered_map<int, vector<int>> groups;
        for (int i = 0; i < n; ++i) {
            int root = dsu.find(i);
            groups[root].push_back(i);
        }

        int res = 0;
        // For each group, match as much as possible
        for (auto& [_, indices]: groups) {
            unordered_map<int, int> countSource, countTarget;
            for (int idx : indices) {
                ++countSource[source[idx]];
                ++countTarget[target[idx]];
            }
            for (auto& [num, cnt]: countTarget) {
                int match = min(countSource[num], cnt);
                cnt -= match; // Reduce unmatched elements only
            }
            // Add up remaining unmatched in target, which failed to be covered by source
            for (auto& [num, cnt]: countTarget) {
                res += cnt;
            }
        }
        return res;
    }
};
```

---

## 5. **Example Explanation**

**Example 1:**
```
source = [1,2,3,4]
target = [2,1,4,5]
allowedSwaps = [[0,1],[2,3]]
```
- Two groups: {0,1} and {2,3}.
  - Group 1 (indices 0,1): source = [1,2], target = [2,1]. By swapping, can match both, 0 distance here.
  - Group 2 (indices 2,3): source = [3,4], target = [4,5]. We can swap, so source = [4,3], still only match 4 in index 2. Leftover: 5 in target but only 3 in source, can't match, so **1 mismatch**.
- **Output: 1**
