Let's address your requirements step by step:

---

## 1. **Short Summary**

You are given an array of candy costs. When buying candies, for every **two candies** you purchase, you can take a **third candy for free**, **but only if its cost is ≤ the cheaper of the two candies you buy**. Your goal is to buy all candies and pay the **least total cost** possible.

---

## 2. **Constraints & Edge Cases**

- **Constraints**:
    - `1 <= cost.length <= 100`  (Small input size – O(N log N) is acceptable)
    - `1 <= cost[i] <= 100`
- **Edge Cases**:
    - If less than 3 candies, none can be taken for free.
    - Free candy cost must be ≤ minimum purchased candy in group of 2
    - There may be duplicates in costs.
    - All costs may be the same.

---

## 3. **Optimal Algorithm**

### **Greedy Strategy**

- **Observation**: To minimize your cost, always pay for the most expensive candies and get the least expensive ones for free (as the constraint ensures the free candy can't be pricier than either purchased one).
- **Step-by-step**:
    1. **Sort the `cost` array in descending order**
    2. **Iterate through the sorted array in chunks of 3**:
        - Pay for the first two candies (`i`, `i+1`) in the chunk.
        - If there is a third (`i+2`), you get it for free (since it's lesser in cost, due to the sorting).
        - Continue until the end.
    3. **Sum up the paid candies**.

- **Why this works**:  
  By always paying for the greatest costs, you maximize the value of what you get for free while minimizing overall expenditure, as you only skip paying for the lowest cost in each triplet.

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minimumCost(vector<int>& cost) {
        sort(cost.rbegin(), cost.rend());       // Sort in descending order
        int total = 0;
        for (int i = 0; i < cost.size(); ++i) {
            if (i % 3 != 2) {                  // Pay for the 1st and 2nd candy in each group of three
                total += cost[i];
            }
            // else: take the 3rd as free, do not add to total
        }
        return total;
    }
};
```

---

## 5. **Example Explained**

### **Example:** `[6,5,7,9,2,2]`

#### **Step 1. Sort descending:**  
`[9, 7, 6, 5, 2, 2]`

#### **Step 2. Pay for 1st & 2nd, skip 3rd in each group:**
1. **First group:**  
   - 9 (paid), 7 (paid), **6 (free)**
2. **Second group:**  
   - 5 (paid), 2 (paid), **2 (free)**

#### **Total paid:**
- 9 + 7 + 5 + 2 = **23**

**Which matches the problem's output.**

### **In conclusion:**

- Sort descending
- For every 3 candies, pay the first two and get the third (cheapest among them) for free.
- This is greedy, optimal, and works due to small input constraints.
