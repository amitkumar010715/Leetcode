Let's walk through the solution step by step:

---

## 1. **Short Summary**

Given an array of integers, find the **minimum possible distance** for any triple of distinct indices `(i, j, k)` such that `nums[i] == nums[j] == nums[k]`. The distance is defined as  
`abs(i-j) + abs(j-k) + abs(k-i)`.  
If no such triple exists, return `-1`.

---

## 2. **Constraints & Edge Cases**

- `1 <= n == nums.length <= 100`.  
  The array size is small (at most 100): Ok to use O(n³) algorithms, but we can optimize further.
- `1 <= nums[i] <= n`.  
  The values are bounded and can be used as indices.
  
**Edge Cases:**
- All elements are unique → return `-1`.
- Any value appears less than 3 times → can't use that value.
- Multiple candidates: Take the minimum possible distance.

---

## 3. **Optimal Algorithm**

### High-level Plan:

- For *every number* appearing at least **three times**:
    - Get all positions where it appears.
    - For all combinations of 3 indices (from its positions), compute distance.
    - Track the minimum across all such triples.

### Implementation Steps:

1. **Index Storage:** Map each value to a vector of its indices.
2. **Triple Search:** For each value with at least 3 positions, try all possible triples, compute the distance.
    - Because distance is symmetric and the indices are distinct, you can iterate `i < j < k`.
3. **Return Answer:** If no triple found, return `-1`.

Optimization is not necessary due to small constraints (n <= 100).

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int minimumDistance(vector<int>& nums) {
        unordered_map<int, vector<int>> mp;

        // 1. Map each value to its indices
        for (int i = 0; i < nums.size(); ++i) {
            mp[nums[i]].push_back(i);
        }

        int res = INT_MAX;

        // 2. For each value with >= 3 indices, try all (i, j, k)
        for (auto& p : mp) {
            vector<int>& idxs = p.second;
            int m = idxs.size();
            if (m < 3) continue;
            for (int a = 0; a < m; ++a) {
                for (int b = a + 1; b < m; ++b) {
                    for (int c = b + 1; c < m; ++c) {
                        int i = idxs[a], j = idxs[b], k = idxs[c];
                        int dist = abs(i - j) + abs(j - k) + abs(k - i);
                        res = min(res, dist);
                    }
                }
            }
        }

        return res == INT_MAX ? -1 : res;
    }
};
```

---

## 5. **Example Explained**

Let's use **Example 1**:  
`nums = [1,2,1,1,3]`

- The value `1` appears at indices `[0, 2, 3]`.
- Check the only triple possible: `(0,2,3)`  
    - Distance:  
      `abs(0-2) + abs(2-3) + abs(3-0) = 2 + 1 + 3 = 6`
- No other value appears 3 times, so no other candidate.

**Final Answer:** `6`
