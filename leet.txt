## 1. **Short Summary**

**Problem:**  
Given a string `s`, find the maximum length of a substring such that every character appears **at most two times** in that substring.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `2 <= s.length <= 100` (string is quite short)
- `s` contains only lowercase letters (`a-z`).

**Edge Cases:**
- All identical characters, e.g., `"aaaa"`.
- All unique characters, e.g., `"abcdef"`.
- Substrings at the start, end, or in the middle are valid.
- The answer is at least `2`, since a substring of two identical characters is always valid.

---

## 3. **Optimal Algorithm Explanation**

Given the small constraint (`n <= 100`), **brute force with optimizations** or a **sliding window** approach are both feasible.

### Approach: **Sliding Window**

- Maintain a window `[left, right]` in the string.
- Use an array (`cnt[26]`) to count occurrences of each character in the current window.
- Expand the window by moving `right` and adding `s[right]` to counts.
- If any character’s count exceeds **2**, shrink the window by moving `left` and reducing counts until all counts ≤ 2.
- At each step, keep track of the window’s maximum size.

**Time Complexity:**  
- Each character is added and removed at most once: O(n)
- Thus, O(n) total.

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maximumLengthSubstring(string s) {
        int n = s.size();
        vector<int> cnt(26, 0);
        int maxLen = 0;
        int left = 0;

        for (int right = 0; right < n; ++right) {
            cnt[s[right] - 'a']++;

            while (cnt[s[right] - 'a'] > 2) {
                cnt[s[left] - 'a']--;
                left++;
            }

            maxLen = max(maxLen, right - left + 1);
        }
        return maxLen;
    }
};
```

```
    - left=4, cnt['b']=2, valid

Throughout, the max valid length observed is **4**.

```
