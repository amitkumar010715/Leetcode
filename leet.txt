## 1. **Short Summary**

Given an integer array `nums`, find the sum of the **longest sequential prefix** (where each element increases by 1 from the previous) and return the **smallest missing integer** from the array that is **greater than or equal to that sum**.

---

## 2. **Constraints & Edge Cases**

- **Array length:** `1 <= nums.length <= 50`
- **Array element values:** `1 <= nums[i] <= 50`
- **Longest sequential prefix:** The prefix must start at index 0.
- The "missing integer" must not be in `nums` and must be **at least** the value of the sum of the sequential prefix.
- **Edge Cases to Consider**:
    - Array of length 1.
    - All elements are sequential starting at any number.
    - The sum itself is missing, or numbers above the sum are missing.
    - `nums` can be in any order after the sequential prefix.

---

## 3. **Optimal Algorithm**

1. **Find the Longest Sequential Prefix:**
    - Start from `nums[0]`, traverse while `nums[i] == nums[i-1] + 1`.
    - Calculate the sum of this prefix.

2. **Find the Smallest Missing Integer:**
    - Create a set (or bool array) of numbers present in `nums`.
    - Check, starting from `seq_sum`, for the smallest integer not in the set.

**Why is this optimal?**
- The operations are linear in `n` (at most 50).

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int missingInteger(vector<int>& nums) {
        // 1. Find the longest sequential prefix and its sum
        int n = nums.size();
        int i = 1;
        while (i < n && nums[i] == nums[i-1] + 1) ++i;
        int seq_sum = 0;
        for (int j = 0; j < i; ++j) seq_sum += nums[j];

        // 2. Store all numbers in a set for O(1) lookups
        unordered_set<int> seen(nums.begin(), nums.end());

        // 3. Find the smallest missing integer >= seq_sum
        int x = seq_sum;
        while (seen.count(x)) ++x;
        return x;
    }
};
```

## 5. **Example Explanation**

Let's use:

**Example 2:**
```plaintext
nums = [3,4,5,1,12,14,13]
```

- **Step 1: Find the longest sequential prefix**
    - `[3, 4, 5]` (since 1 is not 5+1, prefix ends at index 2)
    - Sum: `3 + 4 + 5 = 12`
- **Step 2: Store elements**
    - Set: `{1, 3, 4, 5, 12, 13, 14}`
- **Step 3: Find smallest missing integer ≥ 12**
    - 12 → in set
    - 13 → in set
    - 14 → in set
    - 15 → **not** in set → **Answer: 15**
