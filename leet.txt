Let's break down the problem and answer each of your requirements:

---

## 1. Short Summary

Given an array `nums`, find the **longest subarray** where the number of **distinct even numbers** is equal to the number of **distinct odd numbers**. Return the length of this subarray.

---

## 2. Constraints & Edge Cases

**Constraints:**
- `1 <= nums.length <= 1500`
- `1 <= nums[i] <= 10^5`

**Edge Cases:**
- All numbers are even or all odd ⇒ no balanced subarray except of length `0` or `1` (if 0, 0 is not an answer, if 1, impossible since distinct even ≠ odd).
- All numbers are equal ⇒ largest balanced subarray is at most 0 or 1.
- Repeated numbers should not count towards distinctness more than once.

---

## 3. Optimal Algorithm

### Brute-force (Optimal for n ≤ 1500):

Because `n` is relatively small (≤1500), we can check all subarrays using two nested loops `(O(n^2))` and for each subarray keep track of the set of distinct evens & odds with hash-sets.

#### Steps
- For each starting index `i` in `nums`:
  - Initialize two empty hash-sets: `evens`, `odds`
  - For each ending index `j` (from `i` to `n-1`):
      - If `nums[j]` is even and not in `evens`, insert into `evens`
      - If odd, insert into `odds` if not present
      - If `evens.size() == odds.size()`, update `maxlen = max(maxlen, j-i+1)`
- Return `maxlen`

**Complexity:**  
- Up to 1500 * 1500 = 2.25 million subarrays
- Each insertion/check in set is O(1) average (unordered_set)
- **Acceptable** for constraints.

---

## 4. Clean C++ Solution

```cpp
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int longestBalancedSubarray(vector<int>& nums) {
        int n = nums.size();
        int maxlen = 0;

        for (int i = 0; i < n; ++i) {
            unordered_set<int> evens, odds;
            for (int j = i; j < n; ++j) {
                if ((nums[j] % 2) == 0)
                    evens.insert(nums[j]);
                else
                    odds.insert(nums[j]);
                if (evens.size() == odds.size())
                    maxlen = max(maxlen, j - i + 1);
            }
        }
        return maxlen;
    }
};
```

## 5. Example Explanation

**Example:**  
`nums = [1,2,3,2]`

Check all subarrays:

- `[1]` → evens: {}, odds: {1}
- `[1,2]` → evens: {2}, odds: {1} (evens:1, odds:1 → balanced, length=2)
- `[1,2,3]` → evens:{2}, odds:{1,3} (evens:1, odds:2 → not balanced)
- `[1,2,3,2]` → evens:{2}, odds:{1,3} (same)

Start at index 1:
- `[2]` → evens:{2}, odds:{}
- `[2,3]` → evens:{2}, odds:{3} (evens:1, odds:1 → balanced, length=2)
- `[2,3,2]` → evens:{2}, odds:{3} (evens:1, odds:1 → balanced, length=3) **max so far**

Continue, but no longer balanced ones.

**Final answer: 3** (from `[2,3,2]`)
- Only 1 distinct even (2)
- Only 1 distinct odd (3)
