Let's solve the problem step by step:

---

## 1. **Summary**

Given an array `nums` and an integer `k`, you are to find the **smallest positive multiple** of `k` that **does NOT appear** in `nums`. Each multiple is of the form `k * t` for some positive integer `t`.

---

## 2. **Constraints & Edge Cases**

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= k <= 100`
- There may be numbers in `nums` that are not multiples of `k` — ignore those.
- All values are positive integers.
- If all multiples of `k` up to the max in `nums` are present, we may need to look beyond the array's max value.
- **Edge Cases:**
  - First multiple (`k`) is missing.
  - All multiples in the range are present.

---

## 3. **Optimal Algorithm**

**Observation:**
- Problem just needs us to find the smallest positive integer `t` s.t. `k*t` is **not in** `nums`.
- Only need to care about values in `nums` that are multiples of `k`.
- Since all values are ≤ 100 and `k` ≤ 100, the largest multiple of `k` ≤ 100 is at most 100.

**Steps:**
1. Add all numbers in `nums` to a set for O(1) lookup.
2. For `t = 1, 2, 3, ...` compute `m = k * t`.
   - If `m` is **not** in `nums`, return it.
3. Since `nums` lacks some multiple, and `k * t` can go indefinitely, but since all multiple ≤ 100 can be looked up, the first missing must be small and a loop up to `(max(nums) / k) + 2` suffices (ensures we check just past what's present).

**Time Complexity:**  
- O(n) for the set + O(100) (constant scan) = O(n)

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int findSmallestInteger(vector<int>& nums, int k) {
        unordered_set<int> s(nums.begin(), nums.end());
        int t = 1;
        while (true) {
            int m = k * t;
            if (s.find(m) == s.end()) {
                return m;
            }
            ++t;
        }
    }
};
```

---

## 5. **Example Explanation**

**Example 1:**  
`nums = [8, 2, 3, 4, 6], k = 2`

List the multiples of `2`: 2, 4, 6, 8, 10, ...
Numbers in `nums` that are multiples of 2: 2, 4, 6, 8

- 2 in set? Yes
- 4 in set? Yes
- 6 in set? Yes
- 8 in set? Yes
- 10 in set? **No!**

**So, answer is 10.**
