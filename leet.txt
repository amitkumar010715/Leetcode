## 1. Short Summary

This game asks who will win (or if it's a tie) between Alice and Bob, as they take turns taking 1-3 stones from the front of a row of stones, each with integer values (which can be negative or positive). Both play **optimally** for maximum score. Return "Alice", "Bob", or "Tie".

---

## 2. Constraints & Edge Cases

- **Size**: Up to **50,000** stones: need an **O(n)** or **O(nk)** solution (`k=3`).
- **Values**: Stones can be **negative, zero, or positive**.
- **Edge**: Small arrays (1, 2, or 3 stones).
- **Edge**: All negative - best play may be to force the other to take the worst.
- **Tie**: Ensure equal final scores are handled as 'Tie'.

---

## 3. Optimal Algorithm

### DP Formulation

Let `dp[i]` = **maximum score difference** (`current_player - other_player`) starting at position `i`.

- If `dp[i] > 0`: player to move wins from `i`.
- If `dp[i] == 0`: draw.
- If `dp[i] < 0`: player to move loses.

At each turn (for `i`), the current player can pick 1, 2, or 3 stones (if they exist), summing their values, and the other player then plays from `i+k`. So for each possible `k=1..3`:

```
dp[i] = max(
    sum(stoneValue[i:i+1]) - dp[i+1],  // Takes 1 stone, subtract opponent best from i+1
    sum(stoneValue[i:i+2]) - dp[i+2],  // Takes 2 stones ...
    sum(stoneValue[i:i+3]) - dp[i+3]   // Takes 3 stones ...
)
```

**Base case:** past the last stone, `dp[n] = 0`.

We start from the end and calculate backwards.

## 4. Clean C++ Solution

```cpp
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    string stoneGameIII(vector<int>& stoneValue) {
        int n = stoneValue.size();
        vector<int> dp(4, 0);  // Only keep last 4 since we only look ahead 1-3

        for (int i = n - 1; i >= 0; --i) {
            int currSum = 0;
            int best = INT_MIN;
            for (int k = 1; k <= 3; ++k) {
                if (i + k - 1 >= n) break;
                currSum += stoneValue[i + k - 1];
                best = max(best, currSum - dp[(i + k) % 4]);
            }
            dp[i % 4] = best;
        }

        if (dp[0] > 0)
            return "Alice";
        else if (dp[0] < 0)
            return "Bob";
        else
            return "Tie";
    }
};
```
**Space:** Only `O(1)` extra (rolling array).  
**Time:** `O(n)`

## 5. Example Explanation

Let's work through **Example 1**:  
**Input:** `stoneValue = [1,2,3,7]`

Work backwards (let's use full dp for clarity):

- dp[4] = 0 (past end)  
- i=3: Take `[7]` (only 1 stone left): `7 - dp[4] = 7 - 0 = 7`  
  dp[3] = 7  
- i=2:  
    - Take `[3]`: `3 - dp[3] = 3 - 7 = -4`
    - Take `[3,7]`: sum=10, `10 - dp[4] = 10 - 0 = 10`
    - Only 2 stones remain  
    => best = max(-4, 10) = **10**  
   dp[2]=10
- i=1:  
    - Take `[2]`: `2 - dp[2] = 2 - 10 = -8`
    - Take `[2,3]`: sum=5, `5 - dp[3] = 5 - 7 = -2`
    - Take `[2,3,7]`: sum=12, `12 - dp[4] = 12 - 0 = 12`
    => max(-8, -2, 12) = **12**  
   dp[1]=12
- i=0:
    - Take `[1]`: `1 - dp[1] = 1 - 12 = -11`
    - `[1,2]`: sum=3, `3 - dp[2] = 3 - 10 = -7`
    - `[1,2,3]`: sum=6, `6 - dp[3] = 6 - 7 = -1`
    => max(-11, -7, -1) = **-1**
   dp[0] = -1

Interpretation:  
- dp[0] < 0 => Current player (Alice) will lose, Bob wins!  
**Output:** `"Bob"`
