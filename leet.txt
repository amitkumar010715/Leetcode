## 1. Short Summary

We need to check if an input array `nums` can be obtained by rotating a non-decreasingly sorted array. That is, its elements are sorted (possibly with duplicates), and they're *rotated* some number of times (including zero). Return `true` if possible, otherwise `false`.

---

## 2. Constraints & Edge Cases

- **Constraints:**
  - `1 <= nums.length <= 100` (number of elements is small, so O(N) solutions are fine)
  - `1 <= nums[i] <= 100` (all integers are in [1, 100])

- **Edge Cases:**
  - Arrays of length 1: Always `true`.
  - Already sorted (no rotation): Should return `true`.
  - Arrays with all elements the same: Should return `true`.
  - Two or more "drops" (places where nums[i] > nums[i+1]): Should return `false`.
  - Comparing last to first element, since rotation is circular.
  - Duplicates: Should still work (since non-decreasing).

---

## 3. Optimal Algorithm

**Observation:**
- If an array is a sorted array rotated (possibly zero) times, there should be at most *one place* where `nums[i] > nums[i+1]` (called a "drop").
    - If no such place, it's already sorted.
    - If exactly one such place, rotation happened at that index.
    - More than one such place: not possible.

**Steps:**
1. Count number of pairs `nums[i] > nums[(i+1) % n]` (modulo for circular check).
2. If the count is `0` or `1`, return `true`; else, return `false`.

**Time Complexity:** O(N)  
**Space Complexity:** O(1)

---

## 4. Clean C++ Solution

```cpp
class Solution {
public:
    bool check(vector<int>& nums) {
        int n = nums.size();
        int count = 0;
        for (int i = 0; i < n; ++i) {
            if (nums[i] > nums[(i+1)%n]) {
                count++;
            }
        }
        return count <= 1;
    }
};
```

---

## 5. Example Explanation

**Example:** `[3, 4, 5, 1, 2]`

- Check drops:
  - `3 < 4` (OK)
  - `4 < 5` (OK)
  - `5 > 1` (**Drop 1**)
  - `1 < 2` (OK)
  - `2 < 3` (since circular, last to first) (OK)
- Only *one* drop (`5 > 1`), so this is a sorted array rotated (`[1,2,3,4,5]` rotated by 2 places).
- Return: **`true`**

---

**In summary:**  
Check for at most one "drop" in the circular array. If the count is more than one, the array is not a rotation of a sorted array. Otherwise, it is.
