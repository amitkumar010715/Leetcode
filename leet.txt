Sure! Here’s a full breakdown and solution for **Score of Parentheses**.

---

## 1. **Short Summary**

You're given a balanced parentheses string. Using special rules, you need to compute its **score**:
- `"()"` has score 1.
- Concatenation (like AB) adds their scores.
- Wrapping with parentheses doubles the inner score: `(A)` is `2 * score(A)`.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `2 <= s.length <= 50`
- Only contains `'('` and `')'`
- The string is always **balanced**

**Edge Cases:**
- Minimal case: `"()"` (should return 1)
- Nested: `"(())"` (should return 2)
- Multiple simple pairs: `"()()"` (should return 2)
- Deeply nested: `"(((())))"` (score doubles at each nesting)
- Mixed: `(()())(()())`
- Should not receive invalid strings

---

## 3. **Optimal Algorithm**

**Approach:**  
Use a **stack** to keep track of the score at each nesting level.

**Algorithm Steps:**
1. Initialize a stack, push `0` as the base score.
2. For each character `c` in the string:
   - If `'('`: push `0` onto the stack (start new frame).
   - If `')'`:
     - Pop top element `v` from stack (score inside current pair).
     - If `v` is `0`, this was a `"()"`, so current layer's score = 1.
     - Else, it's a wrapping pair `(A)`, so current layer's score = 2 * v.
     - Pop previous score, add current layer's score to it, push back.
3. At the end, the stack's top element is the answer.

**Time Complexity:** O(N)

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    int scoreOfParentheses(string s) {
        stack<int> stk;
        stk.push(0); // base score
        for (char c : s) {
            if (c == '(') {
                stk.push(0); // new score for new '('
            } else {
                int v = stk.top(); stk.pop();
                int score = (v == 0) ? 1 : 2 * v; // "()" or nested
                stk.top() += score; // add to previous frame
            }
        }
        return stk.top();
    }
};
```

---

## 5. **Example Explanation**

Let's explain **Example 2: `"(())"`**.

Step by step:
- Stack: `[0]`
- See `'('`: push `0` → `[0,0]`
- See `'('`: push `0` → `[0,0,0]`
- See `')'`: pop `0`, since it's `"()"`, so score is `1`, previous score is `0`, add: `[0,1]`
- See `')'`: pop `1`, it's not `0`, so score is `2*1 = 2`, previous score is `0`, add: `[2]`
- Final result is `2`

**Thus, the output is `2`.**
