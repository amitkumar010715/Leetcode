Let's break down the problem and address all your requirements step by step.

---

## 1. **Short Summary**

Given a singly linked list, rotate it to the right by `k` places. Rotating means moving the last elements to the front, preserving the order. For example:  
`head = [1,2,3,4,5], k = 2` → `[4,5,1,2,3]`

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
    - List has 0 to 500 nodes (`0 <= n <= 500`)
    - Node value in range `[-100, 100]`
    - `k` can be very large, up to `2 * 10^9`

- **Edge Cases:**
    1. **Empty List:** If `head == nullptr`, output is also nullptr.
    2. **Single Node:** Rotating a single-node list (`[x], k = anything`) is just itself.
    3. **k = 0:** No rotation, return head as is.
    4. **k >= n:** Rotations are periodic (rotating by the list's length brings it back to the original). Only `k % n` effective rotations are needed.

---

## 3. **Optimal Algorithm**

**Step-by-Step:**

1. **Edge Case Check:** If `head` is `nullptr` or has only one node, or `k` is `0`, return `head`.

2. **Find List Length `n` and Tail:** Traverse the list to count the nodes and keep a pointer to the last node (`tail`).

3. **Make it Circular:** Connect `tail->next` to `head`, making it a circular list for easier rotation.

4. **Effective Rotations:**  
   Since rotating by the list's length (`n`) brings back the original, reduce `k` with `k = k % n`.

5. **Break the Circle at New Tail:**  
   - New tail will be at position `n - k - 1` (0-indexed).
   - New head is `new_tail->next`.
   - Set `new_tail->next = nullptr` to break the ring.

6. **Return the New Head.**

**Time Complexity:** O(n)  
**Space Complexity:** O(1) (in-place operations)

---

## 4. **Clean C++ Solution**

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (!head || !head->next || k == 0) return head;

        // 1. Find length and tail
        int n = 1;
        ListNode* tail = head;
        while (tail->next) {
            tail = tail->next;
            n++;
        }

        // 2. Make circular
        tail->next = head;
        
        // 3. Effective rotations
        k = k % n;
        int stepsToNewTail = n - k;
        
        // 4. Find new tail and new head
        ListNode* newTail = tail;
        while (stepsToNewTail--) {
            newTail = newTail->next;
        }
        ListNode* newHead = newTail->next; // next node is new head
        
        // 5. Break the circular link
        newTail->next = nullptr;

        return newHead;
    }
};
```

---

## 5. **Example Explanation**

Let's use **Example 1**:

**Input:** `head = [1,2,3,4,5], k = 2`

- Count nodes: n = 5
- k = k % n = 2 % 5 = 2
- Make circle: `5 → 1` (tail links to head)
- Steps to new tail: `n - k = 5 - 2 = 3`
    - Start from tail (`5`), move 3 steps:  
      `5 -> 1 (1st), 2 (2nd), 3 (3rd)`  
      So `3` is the new tail.
- New head is `3->next = 4`.
- Break the circle: Set `3->next = nullptr`

So result: `[4,5,1,2,3]`

| 3    |                     | 2   | New tail = node 3 |
