## 1. **Summary**

Given a list of events where each event has a start time, an end time, and a value, pick **at most two non-overlapping events** such that their total value is **maximized**. Times are inclusive, meaning events *cannot touch* at the same time (if one ends at t, the other cannot start at t).

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  * `2 <= events.length <= 1e5`
  * Each event: `[start, end, value]` with `1 <= start <= end <= 1e9` and `1 <= value <= 1e6`
  * Times are large; need efficient (non-brute-force) solution.
- **Edge Cases:**
  * All events overlap (can only pick one).
  * No two events overlap (pick the two with highest values).
  * Some events may completely subsume others.

---

## 3. **Optimal Algorithm**

### **Goal**:
- For each event, find another *non-overlapping* event to combine for max sum (or just pick a single event).

### **Approach**:

#### High Level Steps:
1. **Sort events by start time** for binary search utility.
2. **Sort another copy of events by end time** to query "the best event that ends before a given time".
3. For each event, 
    - Use binary search to find the event with the **largest value** that ends **before** this event's start.
    - Keep a running **maxValueSoFar** as you step through `end-sorted` events.
    - For each event, the answer is max(the event alone, event + bestValueBefore).
4. Track the **global maximum**.

#### Implementation Details:

- As you go through the events in order of start time:
    - For each event, find (via searching the end-sorted array) the maximum value among all events that end **before** this event starts.
    - Use a pointer technique (not brute force) to keep this max up-to-date.
- This method is O(N log N) due to sorting and binary search.

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxTwoEvents(vector<vector<int>>& events) {
        int n = events.size();
        // Sort events by start time
        sort(events.begin(), events.end());

        // Prepare a vector to pair (end time, value)
        vector<pair<int, int>> endEvents;
        for (auto &ev : events) {
            endEvents.emplace_back(ev[1], ev[2]);
        }
        // Sort endEvents by end time (for prefix max query)
        sort(endEvents.begin(), endEvents.end());

        // Prepare prefix max array for endEvents
        vector<int> endTime(n), prefixMax(n);
        for (int i = 0; i < n; ++i) {
            endTime[i] = endEvents[i].first;
            prefixMax[i] = (i == 0 ? endEvents[i].second : max(prefixMax[i-1], endEvents[i].second));
        }

        int ans = 0;
        for (int i = 0; i < n; ++i) {
            int start = events[i][0], value = events[i][2];
            // Find the largest end time < start, i.e., event ends before this one starts
            auto it = lower_bound(endTime.begin(), endTime.end(), start);
            if (it != endTime.begin()) {
                int idx = it - endTime.begin() - 1;
                ans = max(ans, value + prefixMax[idx]);
            }
            ans = max(ans, value); // consider just the current event
        }
        return ans;
    }
};
```

## 5. **Example Explained**

**Example**:  
Input: `events = [[1,5,3],[1,5,1],[6,6,5]]`

- **Sort events by start:** [[1,5,3],[1,5,1],[6,6,5]]
- **endEvents:** [(5,3), (5,1), (6,5)], sorted, and `prefixMax` is [3,3,5] (max value so far)

- Check event [1,5,3]:
    - Find max value with end < 1 → none.
    - Max is `3`.
- Check event [1,5,1]:
    - Same, none. Max is `3` (still).
- Check event [6,6,5]:
    - Find max end < 6. Since ends at [5,5], get index 1 in `endTime`. prefixMax[1] = 3
    - 5 + 3 = **8**
- So output is **8**.

**Output: 8**
