## 1. **Short Summary**

Given an array of integers, you can **increase any element by 1 in a move**.  
Find the **minimum number of moves** needed to make **all elements equal**.

---

## 2. **Constraints & Edge Cases**

- **Constraints**:
  - `1 <= nums.length <= 100`
  - `1 <= nums[i] <= 100`

- **Edge Cases**:
  - All elements are already the same: No moves needed (`0`).
  - Only one element in the array: No moves needed (`0`).
  - Array is sorted or unsorted: Order doesn't affect the solution.

---

## 3. **Optimal Algorithm (Explanation)**

### **Observation**
- Since you can only **increase** elements, the only way to make all equal is to turn every value into the **maximum value** in the array.
- For each `nums[i]`, number of moves needed: `max_element - nums[i]`.
- The total minimum moves is the sum of those differences.

### **Steps**
1. Find the **maximum** number in the array `nums`.
2. For each number, compute `max_element - nums[i]` and add to total.
3. Return the total sum.

- **Time Complexity:** O(N)  
- **Space Complexity:** O(1) (excluding the input)

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>

class Solution {
public:
    int minMoves(std::vector<int>& nums) {
        int max_val = *std::max_element(nums.begin(), nums.end());
        int moves = 0;
        for (int x : nums) {
            moves += (max_val - x);
        }
        return moves;
    }
};
```

---

## 5. **Example Explanation**

**Example:**  
`nums = [2, 1, 3]`

- Maximum value: **3**
- Required moves for each element:
  - For `2`: `3 - 2 = 1`
  - For `1`: `3 - 1 = 2`
  - For `3`: `3 - 3 = 0`
- **Total moves:** `1 + 2 + 0 = 3`

**So, output is `3`.**

---

### **Summary Table**

| Array     | Moves needed           | Total moves |
|-----------|-----------------------|-------------|
| [2, 1, 3] | (3-2) + (3-1) + (3-3) | 3           |
