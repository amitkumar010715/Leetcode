## 1. **Short Summary**

Given an array `nums`, a `target` value, and a starting index `start`, find the minimum distance (in absolute difference) from `start` to any index `i` where `nums[i] == target`. Return this minimum distance. The target value is guaranteed to exist in the array.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
    - `1 <= nums.length <= 1000` (the array is small, so brute-force is fine)
    - `1 <= nums[i] <= 10^4` (`nums` contains positive integers)
    - `0 <= start < nums.length` (`start` is always a valid index)
    - `target` **exists** in `nums` (no need to check for it missing)
- **Edge Cases:**
    - Only one element in `nums`.
    - Multiple occurrences of `target`; need to pick the one closest to `start`.
    - `start` might already point to a `target`.

---

## 3. **Optimal Algorithm**

Since the array size is small, a simple linear scan suffices.

- Initialize `minDist` to a large number (e.g., `nums.size()`).
- Scan each index `i` in `nums`:
    - If `nums[i] == target`, compute `abs(i - start)`.
    - Update `minDist` if this distance is smaller.
- Return `minDist`.

Time complexity: `O(n)`  
Space complexity: `O(1)`

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int getMinDistance(vector<int>& nums, int target, int start) {
        int minDist = nums.size();
        for (int i = 0; i < nums.size(); ++i) {
            if (nums[i] == target) {
                int dist = abs(i - start);
                if (dist < minDist) minDist = dist;
            }
        }
        return minDist;
    }
};
```

## 5. **Explain One Example**

Let's go through **Example 1** step by step:

- **Input:** `nums = [1,2,3,4,5]`, `target = 5`, `start = 3`
- Traverse `nums`:
    - `i=0`: `nums[0]=1` (not `target`)
    - `i=1`: `nums[1]=2` (not `target`)
    - `i=2`: `nums[2]=3` (not `target`)
    - `i=3`: `nums[3]=4` (not `target`)
    - `i=4`: `nums[4]=5` **(is `target`!)**
        - Distance = `abs(4-3)=1`
        - `minDist` becomes `1`
- No closer index exists.
- **Output:** `1`
