Let's answer the requirements step-by-step:

---

## 1. **Short Summary**

Given an array `nums` and an integer `target`, return the indices (in the sorted array) where the value `target` appears. The indices should refer to the sorted version of `nums`.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= nums.length <= 100`
  - `1 <= nums[i], target <= 100`
- **Edge Cases:**
  - `target` does **not** exist in `nums` → return empty list.
  - All nums are the same as `target` → return `[0, 1, ..., n-1]`.
  - `nums` is already sorted/has repeated elements.
  - Only one element.

---

## 3. **Optimal Algorithm**

**Simple O(n) algorithm (without sorting!):**

Let’s count how many elements are *less* than `target` (`countLess`) and how many elements are *equal* to `target` (`countEqual`).

- After sorting, all elements `< target` come first, then all `target` elements, then all `> target`.
- Thus, the target values will lie at indices `countLess`, `countLess + 1`, ..., `countLess + countEqual - 1`.

**Steps:**
1. Initialize `countLess = 0`, `countEqual = 0`
2. For each `num` in `nums`:
   - If `num < target`, increment `countLess`
   - If `num == target`, increment `countEqual`
3. Build the list `[countLess, countLess+1, ..., countLess+countEqual-1]`, or an empty list if `countEqual == 0`.

**Time Complexity:** O(n)

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> targetIndices(vector<int>& nums, int target) {
        int countLess = 0, countEqual = 0;
        for (int num : nums) {
            if (num < target) countLess++;
            else if (num == target) countEqual++;
        }
        vector<int> res;
        for (int i = 0; i < countEqual; ++i) {
            res.push_back(countLess + i);
        }
        return res;
    }
};
```

---

## 5. **Example Explanation**

**Example 1:**

Input: `nums = [1,2,5,2,3], target = 2`

- Elements less than 2: `[1]` → `countLess = 1`
- Elements equal to 2: `[2,2]` → `countEqual = 2`
- In sorted array: `[1,2,2,3,5]`
- Target 2 appears at indices `[1,2]`

**Output:** `[1,2]`
