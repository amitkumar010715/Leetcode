---

## 1. **Short Summary**

Given an integer array `nums`, **find the greatest common divisor (GCD)** of the *minimum* and *maximum* elements of the array. Return that GCD.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `2 <= nums.length <= 1000`
  - `1 <= nums[i] <= 1000`

- **Edge Cases:**
  - All elements are the same (e.g., `[3,3]`): GCD of the same number is itself.
  - The smallest and largest numbers have a GCD of `1` (i.e., are coprime).
  - The array is already sorted or unsorted — doesn't affect the approach since only `min` and `max` matter.

---

## 3. **Optimal Algorithm**

- **Step 1:** Get the minimum and maximum values in the array.
- **Step 2:** Compute the GCD of these two values, using the [Euclidean algorithm](https://en.wikipedia.org/wiki/Euclidean_algorithm).

Both steps are O(N) for scan and O(logM) for GCD computation (`M` is the max value).

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    // Helper function to compute GCD of two numbers
    int gcd(int a, int b) {
        while(b != 0) {
            int tmp = a % b;
            a = b;
            b = tmp;
        }
        return a;
    }
    
    int findGCD(vector<int>& nums) {
        int mn = *min_element(nums.begin(), nums.end());
        int mx = *max_element(nums.begin(), nums.end());
        return gcd(mn, mx);
    }
};
```

---

## 5. **Example Explanation**

**Example Input:**  
`nums = [2,5,6,9,10]`

- **Smallest:** `2`
- **Largest:**  `10`
- **GCD:**  
  - 10 mod 2 = 0 → GCD(10, 2) = 2

**Output:** `2`

---

**Recap:**  
Find `min` and `max` in the array, then return their GCD. This is efficient (O(N)), simple, and leverages the Euclidean algorithm for the GCD.
