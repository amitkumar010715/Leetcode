Let's address each requirement step by step:

---

## 1. **Short Summary**

This problem asks you to add **one** to a big non-negative integer, where the integer is given as an *array* of its digits. You must increment this number and return the new array format—handling carryovers if needed (like 9 + 1 → [1,0]).

---

## 2. **Constraints & Edge Cases**

**Constraints**
- `1 <= digits.length <= 100`
- Each digit: `0 <= digits[i] <= 9`
- The input never has leading zeroes.

**Edge Cases**
- If the last digit is **not** 9, just increment and return.
- If there are trailing 9s, need to "carry over" (e.g., [1,2,9] + 1 → [1,3,0]).
- If *all* digits are 9, a leading 1 is added: [9,9,9] + 1 → [1,0,0,0].
- Single-digit case: [0] → [1], [9] → [1,0].
- Input never contains an empty array.

---

## 3. **Optimal Algorithm**

- Start from the last digit and move backwards:
    - If the current digit is less than 9, increment it and return the array.
    - If the current digit is 9, set it to 0 and continue to carry over.
- If you've finished the loop and didn't return (all were 9s), insert 1 at the beginning.

**Time Complexity:** O(N), as you may need to traverse the whole array (`N = digits.size()`).

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        int n = digits.size();
        // Traverse from least significant to most
        for (int i = n - 1; i >= 0; --i) {
            if (digits[i] < 9) {
                digits[i]++;
                return digits; // Done; no carry needed
            } else {
                digits[i] = 0; // Set to 0 and carry over
            }
        }
        // If we're here, all digits were 9, so we need an extra digit
        digits.insert(digits.begin(), 1);
        return digits;
    }
};
```

---

## 5. **Example Explained**

**Input:** `digits = [9, 9, 9]`

**Step-by-step:**
- Start from the last digit:
    - digits[2] is 9 → set to 0 (carry left)
    - digits[1] is 9 → set to 0 (carry left)
    - digits[0] is 9 → set to 0 (carry left)
- All done, but still have a carry!
- Insert 1 at the beginning: `[1, 0, 0, 0]`

**Output:** `[1, 0, 0, 0]`
