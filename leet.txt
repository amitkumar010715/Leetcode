Let's address the requirements one by one:

---

## 1. **Summary**

Given an array `nums`, count the number of triplets `(i, j, k)` such that `0 <= i < j < k < n`, `nums[i] == nums[j] * 2`, and `nums[k] == nums[j] * 2`. In essence: for each middle element `j`, count the number of elements before `j` equal to `2*nums[j]`, and number of elements after `j` also equal to `2*nums[j]`, then multiply those counts and sum across all `j`.

---

## 2. **Constraints & Edge Cases**

- `3 <= n <= 1e5`: Array length can be large, so O(n^2) is NOT feasible.
- `0 <= nums[i] <= 1e5`: Small possible value range, so frequency/counting arrays/maps are possible.
- Edge Cases:
  - Duplicates may exist.
  - `nums[i]` or `nums[j]` can be zero (handle multiplication correctly).
  - Some elements may not have any valid i or k.

---

## 3. **Optimal Algorithm**

**Observation:**  
We want, for each fixed `j`, to quickly count:
- `count_left`: Number of i (`i < j`) with `nums[i] == 2*nums[j]`
- `count_right`: Number of k (`k > j`) with `nums[k] == 2*nums[j]`

Total for this `j`: `count_left * count_right`, sum over all `j`.

**Steps:**
1. Build a frequency map (`freq_right`) for all numbers in nums.
2. Initialize an empty map (`freq_left`) for left side.
3. For each `j` from left to right:
    - Before processing, decrement `freq_right[nums[j]]` (move current num from right side to left).
    - For current `nums[j]`, let `target = nums[j] * 2`.
    - `count_left` = `freq_left[target]` (before j)
    - `count_right` = `freq_right[target]` (after j)
    - Increment answer by `count_left * count_right`
    - Increment `freq_left[nums[j]]`
4. Return answer modulo 1e9+7.

**Complexity:**  
O(n), since each position and map operation is O(1) (since nums[i] range is limited, unordered_map or vector works).

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int countSpecialTriplets(vector<int>& nums) {
        const int MOD = 1e9 + 7;
        unordered_map<int, int> freq_left;
        unordered_map<int, int> freq_right;

        // Build the freq_right map
        for (int x : nums) freq_right[x]++;

        long long ans = 0;
        int n = nums.size();
        for (int j = 0; j < n; ++j) {
            freq_right[nums[j]]--;  // Move current number out of right side
            int target = nums[j] * 2;

            // Number of i < j with nums[i] == target
            int left = freq_left[target];

            // Number of k > j with nums[k] == target
            int right = freq_right[target];

            ans = (ans + 1LL * left * right) % MOD;

            freq_left[nums[j]]++;
        }
        return (int)ans;
    }
};
```

---

## 5. **Example Explanation**

**Example:**  
`nums = [8,4,2,8,4]`

Let's walk through step by step:

- Build initial freq_right:
  - {8:2, 4:2, 2:1}
- freq_left is {}

Iterate j = 0 to 4:
- j=0, nums[0]=8, target=16
    - freq_left[16]=0, freq_right[16]=0 → add 0
    - Move nums[0]=8 to left: freq_left[8]=1, freq_right[8]=1
- j=1, nums[1]=4, target=8
    - freq_left[8]=1 (pos 0), freq_right[8]=1 (pos 3, left)
    - Add 1*1 = 1 to ans (now ans=1)
    - Move nums[1]=4 to left: freq_left[4]=1, freq_right[4]=1
- j=2, nums[2]=2, target=4
    - freq_left[4]=1 (pos 1), freq_right[4]=1 (pos 4, right)
    - Add 1*1=1 to ans (ans=2)
    - Move nums[2]=2 to left: freq_left[2]=1, freq_right[2]=0
- j=3, nums[3]=8, target=16
    - freq_left[16]=0, freq_right[16]=0 → add 0
    - Move nums[3]=8 to left: freq_left[8]=2, freq_right[8]=0
- j=4, nums[4]=4, target=8
    - freq_left[8]=2, freq_right[8]=0 → add 0

**Total answer: 2**.
