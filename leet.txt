Let's break down and solve the LeetCode challenge: **Total Waviness of Numbers in Range I**.

---

## 1. Short Summary

Given a **range [num1, num2]**, count, for every integer in that range, the total number of *peaks* and *valleys* in its digits (waviness).  
- A *peak* is a digit strictly greater than its neighbors.
- A *valley* is a digit strictly less than its neighbors.
- Edge digits (first/last) can't be peaks/valleys.
- Numbers with fewer than 3 digits have waviness of 0.

Return the **sum of waviness across all numbers in the range**.

---

## 2. Constraints & Edge Cases

- **Range:** 1 ≤ num1 ≤ num2 ≤ 100,000 (so at most 100,000 numbers)
- Numbers < 100: always ∑waviness = 0 (ignore them)
- Single number (num1==num2) is possible
- For each number, only the *internal* digits can be peak/valley: meaning only in numbers with ≥3 digits do we get non-zero waviness
- Each number can have multiple peaks/valleys (all internal digits count independently)

---

## 3. Optimal Algorithm

### Approach

Given the small upper bound (10^5), a direct per-number computation is feasible.

#### Steps

1. For each number `n` from `num1` to `num2`:
    - If `n` has fewer than 3 digits, continue (waviness is 0)
    - Else, for each digit **except first and last**:
        - Is current digit \> both neighbors? If yes, it's a *peak* (add 1)
        - Is current digit \< both neighbors? If yes, it's a *valley* (add 1)
2. Sum up for all numbers and return total.

This is **O(Range × D)** where D is at most 5, so it's efficient.

---

## 4. Clean C++ Solution

```cpp
#include <iostream>
#include <vector>
using namespace std;

class Solution {
public:
    int getWaviness(int n) {
        vector<int> digits;
        // Extract digits in correct order
        int temp = n;
        while (temp > 0) {
            digits.push_back(temp % 10);
            temp /= 10;
        }
        reverse(digits.begin(), digits.end());
        int waviness = 0;
        int sz = digits.size();
        if (sz < 3) return 0;
        for (int i = 1; i < sz-1; ++i) {
            if (digits[i] > digits[i-1] && digits[i] > digits[i+1])
                waviness++;
            else if (digits[i] < digits[i-1] && digits[i] < digits[i+1])
                waviness++;
        }
        return waviness;
    }

    int totalWavinessInRange(int num1, int num2) {
        int total = 0;
        for (int n = num1; n <= num2; ++n) {
            total += getWaviness(n);
        }
        return total;
    }
};

// Example driver code
int main() {
    Solution sol;
    int num1 = 120, num2 = 130;
    cout << sol.totalWavinessInRange(num1, num2) << endl; // Output: 3
    return 0;
}
```

---

## 5. Example Explanation

**Example:** `num1 = 120, num2 = 130`

Check each number:

- 120: digits `[1,2,0]`: '2' is between '1' and '0'. `2 > 1` and `2 > 0` ⇒ '2' is a **peak**, waviness=1.
- 121: digits `[1,2,1]`: '2' is between '1' and '1'. `2 > 1` and `2 > 1` ⇒ '2' is a **peak**, waviness=1.
- 130: digits `[1,3,0]`: '3' is between '1' and '0'. `3 > 1` and `3 > 0` ⇒ '3' is a **peak**, waviness=1.
- All other numbers in the range (122,123...129) have no peaks/valleys in their digits.

**Sum:** 1 + 1 + 1 = **3**

This matches the given output.
