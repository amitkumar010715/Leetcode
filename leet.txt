### 1. **Short Summary**

Given a list of **distinct** positive integers, you must sort it by:
- **Primary:** Sum of digits (ascending)
- **Secondary:** Value itself (ascending)

The task is to return the **minimum number of swaps** required to transform the given list into this sorted order.

---

### 2. **Constraints & Edge cases**

- **Large Input:** `nums.length` can be up to $10^5$, so $O(N \log N)$ is required.  
- **Distinct Elements:** Each number is unique.
- **Range:** Each number can be up to $10^9$.
- **Already Sorted:** If input is already sorted according to the rule, answer is `0`.
- **Reverse Sorted:** If input is the reverse, it may need maximum swaps.

**Edge cases:**
- **Single element:** 0 swaps required.
- **All numbers have different digit sums:** Classic simple sort.
- **Many numbers have same digit sum:** Must respect secondary order.
- **Large numbers:** Just takes more time to compute digit sum.

---

### 3. **Optimal Algorithm**

The problem boils down to:  
Find the **minimum swaps to convert the current permutation into the sorted target permutation**.

Given that:
- All elements are distinct.
- Swap can be done between any two positions.

This is a classic *minimum swaps to sort an array* problem (transforming permutation to another permutations). We can use the **cycle decomposition** method:

**Algorithm Steps:**
1. **Compute digit sum** for each number.
2. **Create sorted target array** based on (digit sum, value).
3. **Map current values to target indices**.
4. For each position, **visit cycles** in the permutation:
    - For a cycle of length $k$, minimum swaps needed: $k-1$.
5. **Sum of all (cycle_size-1) is the answer**.

**Why Cycle Decomposition?**
- Each cycle can be fixed with cycle_length - 1 swaps (proven for array sorting by swapping arbitrary pairs).

**Time Complexity:**  
- $O(N \log N)$ for sorting + $O(N)$ for mapping and cycle finding.

### 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

// Helper function to compute sum of digits
int digitSum(int x) {
    int sum = 0;
    while (x) {
        sum += x % 10;
        x /= 10;
    }
    return sum;
}

class Solution {
public:
    int minimumSwaps(vector<int>& nums) {
        int n = nums.size();
        // Build the sorted array with the required order
        vector<pair<pair<int, int>, int>> arr; // {{digitSum, value}, original_idx}
        for (int i = 0; i < n; ++i) {
            arr.push_back({{digitSum(nums[i]), nums[i]}, i});
        }
        sort(arr.begin(), arr.end());

        // Build position mapping: current_index -> sorted_index
        vector<int> to(n);
        for (int i = 0; i < n; ++i) {
            // arr[i].second: original index in nums
            to[arr[i].second] = i;
        }

        // Classic min swaps needed to sort permutation
        vector<bool> vis(n, false);
        int swaps = 0;
        for (int i = 0; i < n; ++i) {
            if (vis[i] || to[i] == i) continue;
            int cycle = 0, j = i;
            while (!vis[j]) {
                vis[j] = true;
                j = to[j];
                ++cycle;
            }
            swaps += (cycle - 1);
        }
        return swaps;
    }
};
```

### 5. **Example Explanation**

**Example:** nums = [18,43,34,16]

**Step 1:** Calculate digit sums:
- 18: 1+8=**9**
- 43: 4+3=**7**
- 34: 3+4=**7**
- 16: 1+6=**7**

**Step 2:** Sort by (digit sum, value):

| Number | Digit Sum | Value | (digit sum, value)    |
|--------|-----------|-------|----------------------|
| 43     | 7         | 43    | (7, 43)              |
| 34     | 7         | 34    | (7, 34)              |
| 16     | 7         | 16    | (7, 16)              |
| 18     | 9         | 18    | (9, 18)              |

Now, sort these pairs:
- (7,16)  (7,34)  (7,43)  (9,18)

So **target order** is: **16,34,43,18**

Now:
- Original: [18,43,34,16]
- Target:   [16,34,43,18]

Let's build index mapping:
- nums[0]=18 → pos in target: 3
- nums[1]=43 → pos in target: 2
- nums[2]=34 → pos in target: 1
- nums[3]=16 → pos in target: 0

So mapping: [3,2,1,0]. Let's find cycles:
- i=0: 0→3→0 (cycle of size 2)
- i=1: 1→2→1 (cycle of size 2)

Total swaps = (2-1)+(2-1) = **2**

## **Summary Table**

| Step                   | Result                                 |
|------------------------|----------------------------------------|
| Original               | [18,43,34,16]                          |
| Sorted (by rule)       | [16,34,43,18]                          |
| Permutation mapping    | [3,2,1,0]                              |
| Cycle decomposition    | 2 cycles, each needs 1 swap            |
| **Minimum Swaps**      | **2**                                  |

## **Conclusion**

This is a classic minimum swaps to permute an array, solved via cycle decomposition.  
The main twist is to sort with (digit sum, value), and create the mapping accordingly.
