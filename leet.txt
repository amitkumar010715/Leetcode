Let's break down **LeetCode: Count Number of Trapezoids II**.

---

## 1. **Short Summary**

Given up to 500 distinct points in the plane, count the number of unique sets of 4 points that form a **trapezoid**: a convex quadrilateral with **at least one pair** of parallel sides (two segments with equal slopes).

---

## 2. **Constraints & Edge Cases**

- \( 4 \leq n \leq 500 \)
- All points are distinct.
- Coordinates in \([-1000, 1000]\).
- A quadrilateral must be convex.
- Trapezoid: **at least** one pair of parallel sides (can be parallelogram).
- Don't count the same set of 4 points more than once (order doesn't matter).
- Degenerate or concave quadrilaterals are not valid.
- Must avoid double-counting (e.g., if a parallelogram is counted as a trapezoid, it still should be counted only once for each set of 4 points).

---

## 3. **Optimal Algorithm**

### **Key Observations**
1. **Pairs of Parallel Segments:**  
   Any pair of non-overlapping segments \((a, b)\) and \((c, d)\) with equal slope can be two parallel sides of a trapezoid.
2. **Convex Quadrilaterals only:**  
   Need to check if the four points form a convex quadrilateral.
3. **Efficiency:**  
   Brute-force over all \(O(n^4)\) 4-tuples is too slow.  
   Instead:  
   - Group all unordered pairs of points by their slope.
   - For each group with \(k\) pairs (\(k \geq 2\)), for each pair of pairs (with disjoint points), check if the 4 points form a convex quadrilateral.

### **Steps**
1. For each unordered pair of points \((i, j)\), compute reduced slope, and group all pairs by slope.
2. For each group:
   - For every pair of pairs \((a, b), (c, d)\) (with disjoint points):
     - Get the 4 points.
     - Check if they form a convex quadrilateral.
3. Store each 4-point set in a set (e.g., sort and insert), to avoid duplicates.
4. Return the size of the set.

### **Convex Quadrilateral Check**
Given 4 points, in all 24 orderings, at most 2 are convex.  
But if you consider all cyclic permutations and flips, you can pick any ordering and check if it is convex.

- Let's sort the points in cyclic order (convex hull in O(1) for 4 points), and check convexity using cross products (orientation check).

Or, for each permutation of 4 points, check if all interior angles < 180° (cross products with same sign).

But since we'll be considering only a potentially small number of cases per candidate, it's fine.

---

### **Complexity**

- Pairing: \(O(n^2)\) pairs.
- For each unique slope, group all pairs sharing that slope.
    - For each pair of pairs: \(O(k^2)\) per group.
- In total, bottleneck is \(O(\text{number of parallel pair pairs}) \leq O(n^4)\), but in practice much less.

## 4. **C++ Solution**

```cpp
#include <vector>
#include <map>
#include <algorithm>
#include <tuple>
#include <set>
using namespace std;

class Solution {
public:
    typedef pair<int,int> pii;
    struct Slope {
        int dy, dx;
        Slope(int a, int b) {
            // Reduce slope a/b
            int g = __gcd(a,b);
            a /= g; b /= g;
            if (b<0) { a = -a; b = -b; }
            dy = a; dx = b;
        }
        bool operator<(const Slope& s) const {
            return tie(dy,dx) < tie(s.dy,s.dx);
        }
    };
    
    bool isConvexQuad(vector<pii> &ps) {
        // Sort as per convex hull order
        // For 4 points, smallest lexicographical order is sufficient
        sort(ps.begin(), ps.end());
        // Now, generate the cyclic permutations of ps
        vector<int> perm = {0,1,2,3};
        do {
            bool good = true;
            long long signs[4];
            for (int i = 0; i < 4; ++i) {
                auto &a = ps[perm[i]];
                auto &b = ps[perm[(i+1)%4]];
                auto &c = ps[perm[(i+2)%4]];
                long long x1 = b.first-a.first, y1 = b.second-a.second;
                long long x2 = c.first-b.first, y2 = c.second-b.second;
                signs[i] = x1*y2 - x2*y1;
            }
            bool pos = true, neg = true;
            for (int i=0; i<4; ++i) {
                if (signs[i] < 0) pos = false;
                if (signs[i] > 0) neg = false;
            }
            // Convex if all cross products have same nonzero sign
            if ((pos || neg) && !(signs[0]==0 || signs[1]==0 || signs[2]==0 || signs[3]==0)) {
                return true;
            }
        } while (next_permutation(perm.begin(), perm.end()));
        return false;
    }

    int countTrapezoids(vector<vector<int>>& points) {
        int n = points.size();
        vector<pii> pts(n);
        for (int i=0; i<n; ++i) pts[i] = {points[i][0], points[i][1]};
        map<Slope, vector<pair<int,int>>> slopePairs;
        // Collect all pairs for each slope
        for (int i=0; i<n; ++i) {
            for (int j=i+1; j<n; ++j) {
                int dy = pts[j].second - pts[i].second;
                int dx = pts[j].first - pts[i].first;
                if (dx == 0 && dy == 0) continue; // skip degenerate
                Slope s(dy, dx);
                slopePairs[s].push_back({i, j});
            }
        }
        set<vector<int>> used; // set of unique sorted 4-pt indices
        for (auto& kv : slopePairs) {
            auto &v = kv.second;
            int sz = v.size();
            for (int i=0; i<sz; ++i) {
                for (int j=i+1; j<sz; ++j) {
                    int a = v[i].first, b = v[i].second;
                    int c = v[j].first, d = v[j].second;
                    // All indices must be distinct
                    set<int> s = {a, b, c, d};
                    if (s.size() != 4) continue;
                    vector<int> quad = {a, b, c, d};
                    sort(quad.begin(), quad.end());
                    if (used.count(quad)) continue;
                    // Check for convexity
                    vector<pii> p4 = {pts[a], pts[b], pts[c], pts[d]};
                    if (!isConvexQuad(p4)) continue;
                    used.insert(quad);
                }
            }
        }
        return used.size();
    }
};
```

## 5. **Example Explained**

### **Input:** `points = [[-3,2],[3,0],[2,3],[3,2],[2,-3]]`
Let points be labeled [P0,P1,P2,P3,P4].

Look for all quadruples that form a convex quadrilateral and have at least one pair of parallel sides.

One such is:  
- Points [-3,2], [2,3], [3,2], [2,-3]  
- Corresponds to indices 0,2,3,4
- The segment [-3,2]→[2,3] is parallel to [2,-3]→[3,2].

Another such set:  
- [2,3], [3,2], [3,0], [2,-3]
- Indices 2,3,1,4

Thus, output is **2**.
