Let's cover your requirements step by step:

---

## 1. **Short Summary**

Given a string `s` with lowercase letters and special characters `*`, `#`, `%`, **process** it from *left to right* following these rules:
- **Letter**: Append to the result.
- **`*`**: Remove last character from the result (if any).
- **`#`**: Duplicate the entire current result and append it.
- **`%`**: Reverse the current result.
Return the final result string.

---

## 2. **Constraints & Edge Cases**

### Constraints:
- `1 <= s.length <= 20` (small limit)
- Only valid chars: lowercase `'a'-'z'`, `*`, `#`, `%`.

### Edge Cases:
- Multiple special ops in a row (e.g. `"**##"`)
- Special characters at the start/end (e.g. `"*a"`, `"abc#*%"`)
- Empty result before `*`, `#`, `%` (e.g. `"*#%"` should yield `""`, since nothing to pop, duplicate, or reverse)
- Long chains: e.g. `"aaaa##"`: result grows fast, but n is only up to 20, so performance is not a worry.
- All letters, all symbols, mixed cases.

---

## 3. **Optimal Algorithm**

- Start with an empty string.
- Iterate character by character.
- Implement the rules as specified:
    - For letters: append.
    - For `*`: remove last (if not empty).
    - For `#`: double the string (append it to itself).
    - For `%`: reverse.
- Since the input is short (`n <= 20`), no optimization necessary; string operations are fine.

**Time Complexity:** O(n^2) in worst case for repeated duplication/reverse, but n is very small.

---

## 4. **Clean C++ Solution**

```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    string processString(string s) {
        string result;
        for (char c : s) {
            if (c >= 'a' && c <= 'z') {
                result += c;
            } else if (c == '*') {
                if (!result.empty()) result.pop_back();
            } else if (c == '#') {
                result += result;
            } else if (c == '%') {
                reverse(result.begin(), result.end());
            }
        }
        return result;
    }
};
```

---

## 5. **Explain with Example**

Let's pick **Example 1:**  
`s = "a#b%*"`  

| Step | Char | Action        | Result   |
|------|------|--------------|----------|
| 0    | a    | append       | a        |
| 1    | #    | duplicate    | aa       |
| 2    | b    | append       | aab      |
| 3    | %    | reverse      | baa      |
| 4    | *    | pop last     | ba       |

**Final result:** `"ba"`
