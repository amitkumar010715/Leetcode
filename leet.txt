Let's go through your requirements step by step:

---

## 1. **Short Summary**

Given a singly linked list, a **critical point** is a node which is either a local maximum or local minimum (i.e., its value is strictly greater or less than neighbors).  
We need to **find the minimum and maximum number of nodes between any two distinct critical points**.  
Return `[-1,-1]` if there are fewer than 2 critical points.

---

## 2. **Constraints & Edge Cases**

### **Constraints:**
- Number of nodes: `2 <= n <= 1e5` (up to 100,000 nodes)
- Node values: `1 <= Node.val <= 1e5`

### **Edge Cases:**
- The head or tail can **never** be a critical point (no previous/next node).
- Fewer than two critical points → return `[-1,-1]`.
- Multiple critical points, possibly at consecutive positions.
- Duplicate values are possible, but for critical points, we require **strictly** greater/smaller for maxima/minima.
- The position is 1-based index for clarity (but can use 0-based internally).

---

## 3. **Optimal Algorithm**

### **High-level Idea:**
- Traverse the list, and find the positions (indices) of all critical points.
- If there are fewer than 2, return `[-1, -1]`.
- For min distance: find the smallest difference between consecutive critical point positions.
- For max distance: difference between the first and the last critical point positions.

### **Pseudocode:**

1. Traverse list, track index, and if a node is critical (using previous and next), add its position to a vector.
2. If fewer than 2 critical points: return `[-1, -1]`.
3. Compute min distance between any two consecutive critical points.
4. Max distance is last - first critical point positions.

**Time Complexity:** O(N)  
**Space Complexity:** O(N) (for storing critical points, worst case)

---

## 4. **C++ Solution**

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */

class Solution {
public:
    vector<int> nodesBetweenCriticalPoints(ListNode* head) {
        vector<int> critPositions;
        int idx = 1; // 1-based, but C++ code can use 0 based
        ListNode* prev = head;
        ListNode* curr = head->next;
        while (curr && curr->next) {
            // Is curr a local minima?
            if (curr->val < prev->val && curr->val < curr->next->val) {
                critPositions.push_back(idx);
            }
            // Is curr a local maxima?
            else if (curr->val > prev->val && curr->val > curr->next->val) {
                critPositions.push_back(idx);
            }
            // Advance all pointers
            prev = curr;
            curr = curr->next;
            idx++;
        }
        
        if (critPositions.size() < 2) {
            return {-1, -1};
        }
        int minDist = INT_MAX;
        for (int i = 1; i < critPositions.size(); ++i) {
            minDist = min(minDist, critPositions[i] - critPositions[i-1]);
        }
        int maxDist = critPositions.back() - critPositions.front();
        return {minDist, maxDist};
    }
};
```

## 5. **Example Explanation**

Let's explain **Example 2**:

#### **head = [5,3,1,2,5,1,2]**

Positions (0-based for clarity):
- 0: 5
- 1: 3
- 2: 1
- 3: 2
- 4: 5
- 5: 1
- 6: 2

Walk-through:
- At pos=1 (`3`): prev=5, next=1; 3 < 5 and 3 > 1 - not a critical point.
- At pos=2 (`1`): prev=3, next=2; 1 < 3 and 1 < 2 ⇒ local minima! (add pos=2)
- At pos=3 (`2`): prev=1, next=5; 2 > 1 and 2 < 5 - not a critical point.
- At pos=4 (`5`): prev=2, next=1; 5 > 2 and 5 > 1 ⇒ local maxima! (add pos=4)
- At pos=5 (`1`): prev=5, next=2; 1 < 5 and 1 < 2 ⇒ local minima! (add pos=5)

`critPositions = [2, 4, 5]`

- minDist: min(4-2, 5-4) = min(2, 1) = 1
- maxDist: 5-2 = 3

**Output: [1, 3]**

## **In summary**:

- Traverse, record critical point positions.
- Compute distances for result.
- Solution is O(N), single pass, and clean.
