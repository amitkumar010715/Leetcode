## 1. Short Summary

Given two integer arrays, find the **maximum dot product of two non-empty subsequences (of equal length)** where you choose elements **in order** from each array (not necessarily contiguous). The subsequences can be of **any length ≥ 1**, and their elements are multiplied pairwise and summed.

---

## 2. Constraints & Edge Cases

- **Constraints:**
  - `1 <= nums1.length, nums2.length <= 500`
  - `-1000 <= nums1[i], nums2[i] <= 1000`
- **Edge Cases:**
  - Arrays may contain all negatives, all positives, or a mix.
  - Maximum/minimum values can occur.
  - Subsequence can be a single element (as shown in example 3).
  - Optimal answer can be negative (if all products are negative).
  - Must **not** return zero for all-negative cases unless it's truly valid.
  - Can't skip both elements at any step (must pick at least one within either array to advance, allowing subsequences to be built).

---

## 3. Optimal Algorithm

This is a classic **DP problem on two sequences**, much like the "Longest Common Subsequence" but you want to maximize the total sum of products.

Let's use:
- `dp[i][j]`: The **maximum dot product for any non-empty subsequences** using `nums1[i:]` and `nums2[j:]`.

At each position `(i, j)`:
- You have three choices:
  1. **Pair `nums1[i]` and `nums2[j]`**: Take their product, possibly add the best value from future indices, **must count at least this product if this is the only pair so far**.
  2. **Skip `nums1[i]`**: `dp[i+1][j]`
  3. **Skip `nums2[j]`**: `dp[i][j+1]`

Recurrence:
```
dp[i][j] = max(
  nums1[i]*nums2[j],                // Just this pair, start new subsequence
  nums1[i]*nums2[j] + dp[i+1][j+1], // Extend subsequence with this pair 
  dp[i+1][j],                       // Skip nums1[i]
  dp[i][j+1]                        // Skip nums2[j]
)
```
- **We must ensure at least one element pairs up** (by always allowing just-the-pair option).

Boundary: When any index is out of range, `dp[i][j]=INT_MIN` to avoid using further empty subsequences.

**Time Complexity:** O(N x M)  
**Space Complexity:** O(N x M), or O(min(N,M)) with optimization.

---

## 4. C++ Solution

```cpp
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int maxDotProduct(vector<int>& nums1, vector<int>& nums2) {
        const int n = nums1.size(), m = nums2.size();
        vector<vector<int>> dp(n+1, vector<int>(m+1, INT_MIN));

        for (int i = n-1; i >= 0; --i) {
            for (int j = m-1; j >= 0; --j) {
                int cur = nums1[i]*nums2[j];
                // Take only this pair
                int maxVal = cur;
                // Take this pair and further pairs
                if (i+1 < n && j+1 < m)
                    maxVal = max(maxVal, cur + dp[i+1][j+1]);
                // Skip nums1[i]
                if (i+1 < n)
                    maxVal = max(maxVal, dp[i+1][j]);
                // Skip nums2[j]
                if (j+1 < m)
                    maxVal = max(maxVal, dp[i][j+1]);
                dp[i][j] = maxVal;
            }
        }
        return dp[0][0];
    }
};
```

## 5. Example Explanation

Let's use **Example 1:**
```
nums1 = [2, 1, -2, 5]
nums2 = [3, 0, -6]
```

- Try picking subsequence `[2, -2]` from nums1 and `[3, -6]` from nums2.
  - Dot product: `2*3 + (-2)*(-6) = 6 + 12 = 18`
- Or try `[5]` and `[-6]`: `5 * -6 = -30` (worse).
- Try `[5]` and `[3]`: `5 * 3 = 15` (less than 18).
- Others are less.

**Hence, the answer is 18**, as the DP will find.

### **Conclusion**

A 2D DP where `dp[i][j] = max product considering nums1[i:] and nums2[j:]`, always allowing the "just this pair" option to guarantee non-empty selections and proper handling of negatives.
