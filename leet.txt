## 1. **Short Summary**

In **Stone Game II**, Alice and Bob take turns picking the first `X` piles of stones from a row, with `1 ≤ X ≤ 2M`, and then set `M = max(M, X)`. Alice starts first, both play optimally, the goal is to maximize Alice's stone total. Return the most stones Alice can get.

---

## 2. **Constraints & Edge Cases**

### Constraints:
- `1 ≤ piles.length ≤ 100` (small enough for DP).
- `1 ≤ piles[i] ≤ 10^4` (stone values don't affect complexity).

### Edge Cases:
- **Single pile:** Alice takes all stones.
- **All piles equal:** Should handle ties correctly.
- **Big last pile:** The algorithm must handle optimal turn ordering, not just greedy.

---

## 3. **Optimal Algorithm**

Let's use **Dynamic Programming** with memoization.

Let `dp(i, m)` = the maximum stones the current player can get with the current subarray starting at index `i` and parameter `M = m`.

At each step:
- The player can take `X` piles, where `1 ≤ X ≤ 2M` (but not past end).
- New `M` becomes `max(m, X)`.
- The player gets the sum of the piles taken; then, the opponent plays optimally on the remainder.
- The goal is to maximize the total stones the **current player** can collect.

**Transition:**
```
dp(i, m) = max(sum(i, X) + totalStones(i+X) - dp(i+X, max(m, X))) for all 1 ≤ X ≤ 2m
```
But it's simpler to imagine: since both play optimally and "win as much as possible", at each move, the player's stones = the remainingSum - opponent's maximum from the rest.

So the main recurrence is:
```
dp(i, m) = max(totalRemaining(i) - dp(i+X, max(m, X))) for X in [1, 2m]
```
We precompute `suffixSum[i] = sum(piles[i:])` for efficient access.

**Base case:** If `i` is beyond last pile, get `0`.

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <algorithm>
#include <cstring>
using namespace std;

class Solution {
public:
    int dp[101][101]; // Index, M

    int stoneGameII(vector<int>& piles) {
        int n = piles.size();
        vector<int> suffixSum(n+1, 0); // suffixSum[i] = sum of piles[i...n-1]
        for (int i = n-1; i >= 0; --i)
            suffixSum[i] = piles[i] + suffixSum[i+1];

        memset(dp, -1, sizeof(dp));
        return dfs(0, 1, suffixSum, n);
    }

    int dfs(int i, int M, vector<int>& suffixSum, int n) {
        if (i >= n) return 0;
        if (dp[i][M] != -1) return dp[i][M];

        int res = 0;
        // At most take all remaining piles.
        for (int X = 1; X <= 2*M && i+X <= n; ++X) {
            // Stones taken this round: suffixSum[i] - suffixSum[i+X]
            // The opponent will get dfs(i+X, max(M, X)), so we get:
            int taken = suffixSum[i] - suffixSum[i+X];
            int opp = dfs(i+X, max(M, X), suffixSum, n);
            res = max(res, taken + (suffixSum[i+X] - opp));
            // Or simply: res = max(res, suffixSum[i] - dfs(i+X, max(M, X),...))
            res = max(res, suffixSum[i] - opp);
        }
        return dp[i][M] = res;
    }
};
```

## 5. **Example Explanation**

### Example 1:

**Input:** `piles = [2, 7, 9, 4, 4]`

**Suffix sums:** `[26, 24, 17, 8, 4, 0]`
- At start: Alice can take X = 1 or 2 piles.

#### Option A: Alice takes 1 pile (2)

- Remaining: [7, 9, 4, 4], M=1
- Bob can take X=1 or 2:
    - Bob takes 2: takes [7,9]=16, remaining [4,4], M=2
        - Alice can take 1 or 2 piles (but only left is [4,4]):
        - Alice takes both: gets 8
        - Bob gets 0 more
        - Final: Alice 2+8=10, Bob 16

#### Option B: Alice takes 2 piles (2+7=9):

- Remaining: [9, 4, 4], M=2
- Bob now can take up to 2*2=4 piles (so all), so Bob takes all: Bob gets 17 (bad for Alice).
- Alice gets 9, Bob gets 17.

So, optimal for Alice is Option A: **10**.

| Action          | Alice's Stones | Bob's Stones |
|-----------------|:-------------:|:------------:|
| Alice:1, Bob:2  |      10       |     16       |
| Alice:2, Bob:3  |       9       |     17       |

**Return value:** `10`
