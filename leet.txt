Let's break down the problem and solution:

---

## 1. Summary

We need to find all numbers within a range \([low, high]\) whose digits are **sequential**, meaning each digit is exactly one more than the previous one (e.g., 1234, 4567). Return these numbers in sorted order.

---

## 2. Constraints & Edge Cases

- **Constraints:**
  - \( 10 \leq \text{low} \leq \text{high} \leq 10^9 \)
  - All outputs must be *sequential digit* numbers and in the given range.
- **Edge Cases:**
  - Input range does **not** overlap any sequential digit numbers.
  - \(\text{low}\) and/or \(\text{high}\) themselves are sequential digits.
  - The sequence can be of length 2 up to 9 (e.g., 12, 23456, 123456789).
  - Smallest possible \(\text{low}\) is 10, largest \(\text{high}\) is \(10^9\).

---

## 3. Optimal Algorithm

### Insights:

- There are only a few possible sequential digit numbers, since the highest one is `123456789`.
- For each possible starting digit, generate possible sequential numbers until the next digit would exceed 9. For all possible sequence lengths from 2 to 9:
  - For example, for `length = 3`: try starting from `1` ("123"), `2` ("234"), ..., `7` ("789").
- If the number falls within \([low, high]\), add it to the output.

### Steps:

1. **For** `length` from 2 to 9 (max digit length):
   - **For** starting digit `start` from 1 to (10 - length):
     - Generate the sequential number by repeatedly adding next digits.
     - If in range, add to results.

**Why is this efficient?**  
The number of sequential digits is tiny (at most 36), so we can just generate all and filter by the range.

---

## 4. Clean C++ Solution

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> sequentialDigits(int low, int high) {
        vector<int> result;
        // Sequential digits numbers can be at most 9 digits.
        for (int length = 2; length <= 9; ++length) {
            for (int start = 1; start <= 10 - length; ++start) {
                int num = 0;
                int digit = start;
                for (int i = 0; i < length; ++i) {
                    num = num * 10 + digit;
                    ++digit;
                }
                if (num >= low && num <= high) {
                    result.push_back(num);
                }
            }
        }
        return result;
    }
};
```

## 5. Example Explanation

**Example 2:**
- **Input:** `low = 1000, high = 13000`
- **Process:**
  - Generate sequential numbers of lengths 4 and 5 (since that's the digit range).
    - 4-digit: 1234, 2345, ..., 6789
    - 5-digit: 12345 (since 23456 > 13000)
- **Filter in range \([1000, 13000]\):**
  - 1234, 2345, 3456, 4567, 5678, 6789, 12345
- **Output:** `[1234,2345,3456,4567,5678,6789,12345]`
