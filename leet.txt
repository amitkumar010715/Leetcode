## 1. **Short Summary**

Given integers `n` and `k`, find the k-th **lexicographically smallest** "happy string" of length n (over {'a','b','c'}) where no two adjacent characters are equal. If there are fewer than k such strings, return an empty string.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- 1 ≤ n ≤ 10  
- 1 ≤ k ≤ 100

**Key Observations:**
- The set of possible characters is very small (`a`, `b`, `c`).
- At each position (after the first), only 2 choices (different from previous) are valid.
- The total number of happy strings of length n = 3 × 2<sup>n-1</sup>

**Edge Cases:**
- When k exceeds the total number of happy strings, you should return `""`.
- For n = 1, the happy strings are simply `"a"`, `"b"`, `"c"`.
- Lexicographical order should be strictly maintained.

---

## 3. **Optimal Algorithm**

### Approach: "Jumping" Lexicographically

**Idea**:  
Build the string character by character.  
For each position, try adding a valid character in lexicographical order, and count how many strings can be formed with that choice.  
If the k-th string is not within the current branch, skip it and update k accordingly.

**Algorithm Steps:**
1. Calculate total possible strings: `total = 3 * pow(2, n-1)`
   - If `k > total`, return `""`
2. Start from the first character; for each character position:
   - Try `'a'`, `'b'`, `'c'` (skip if the same as the previous character).
   - For each candidate character, compute how many strings can be formed fixing this character at current position.
      - Remaining positions: r
      - Possible strings from here: 2<sup>r-1</sup> per valid path
   - If k is within those, fix character and proceed.
   - Else, subtract those and try next.

**Complexity:**
- Since `n` is at most 10, O(n) work.

---

## 4. **C++ Solution**

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string getHappyString(int n, int k) {
        string result = "";
        char chars[3] = {'a','b','c'};
        int total = 3 * (1 << (n-1));

        if (k > total) return "";

        char prev = 0;
        for (int i = 0; i < n; ++i) {
            for (int ci = 0; ci < 3; ++ci) {
                if (i > 0 && chars[ci] == prev) continue;
                // At position i, with previous letter 'prev', choosing chars[ci]
                int rem = n - i - 1;
                int comb = 1 << rem; // 2^(rem)
                if (k > comb) {
                    k -= comb;
                } else {
                    result.push_back(chars[ci]);
                    prev = chars[ci];
                    break;
                }
            }
        }
        return result;
    }
};
```

## 5. **Example Explanation**

### Example: `n = 3`, `k = 9`
- **Total possible happy strings:** 3 × 2<sup>2</sup> = 12
- **Lex-order:**  
  1. aba  
  2. abc  
  3. aca  
  4. acb  
  5. bab  
  6. bac  
  7. bca  
  8. bcb  
  9. **cab**  
  10. cac  
  11. cba  
  12. cbc  

Let's step through:

#### Step-by-step:

1. First letter: try `'a'` (covers 4 strings), `'b'` (next 4), `'c'` (last 4)
   - `'a'` (strings 1–4): skip, k = 5
   - `'b'` (strings 5–8): skip, k = 9 - 8 = 1
   - `'c'` (strings 9–12): pick!

2. Now, `prev = 'c'`, remaining 2 characters, k = 1
   - Next letter can't be `'c'`, try `'a'` (covers 2 strings), `'b'` (covers 2)
   - `'a'` (strings 9–10): k = 1, pick!
   
3. Last letter, can't be `'a'`, try `'b'`, `'c'`
   - `'b'` (string 9): k = 1, pick!

Result: **cab** (the 9th happy string).
