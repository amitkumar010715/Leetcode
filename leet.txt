---

## 1. **Short Summary**

Given a string `s` of characters `'('` and `')'`, the task is to find the length of the longest contiguous substring in `s` that is a valid sequence of parentheses (i.e., well-formed).

---

## 2. **Constraints & Edge Cases**

### **Constraints**
- `0 <= s.length <= 30,000`
- `s[i]` is either `'('` or `')'`

### **Edge Cases**
- Empty string (`""`): Should return 0.
- No valid substrings: Should return 0.
- All opening or all closing parentheses: Should return 0.
- Multiple valid substrings: Return the length of the longest.
- Valid string is at the edges.

---

## 3. **Optimal Algorithm**

There are several efficient ways, but the **stack-based** and **two-pass counter** approaches are optimal (O(n) time, O(1) or O(n) space).

### **Stack Approach**
1. **Idea**: Use a stack to keep track of the indices of unmatched `'('`. Push `-1` at the beginning as a base for calculations.
2. **For each character**:
    - If `'('`, push its index.
    - If `')'`:
        - Pop from the stack (remove a matching `'('`).
        - If stack is empty afterward, push the current index as the new "base."
        - If not empty, current valid substring length is `i - stack.top()`. Update `maxLen`.
        
**Why `-1`?**  
To handle the case of a valid starting substring from the very beginning.

### **Two-pass Approach (O(1) extra space)**
- Left-to-right: Count `(` and `)`. When equal, update max length. Reset if `)` count > `(`.
- Right-to-left: Same logic but reverse direction, to catch cases like `(()`.

**I'll show the stack method since it's most intuitive for C++:**

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    int longestValidParentheses(string s) {
        stack<int> stk;
        stk.push(-1);  // Base
        int maxLen = 0;

        for (int i = 0; i < s.size(); ++i) {
            if (s[i] == '(') {
                stk.push(i);
            } else {
                stk.pop();  // Match with last '('
                if (stk.empty()) {
                    stk.push(i); // New base for future substrings
                } else {
                    maxLen = max(maxLen, i - stk.top());
                }
            }
        }
        return maxLen;
    }
};
```

---

## 5. **Example Explained**

**Input:** `")()())"`

Step by step:
- Index: 0 | `)` | stack: [-1] → pop → stack empty → push 0 (base)
- Index: 1 | `(` | stack: [0] → push 1
- Index: 2 | `)` | stack: [0,1] → pop → not empty, length = 2-0=2, maxLen=2
- Index: 3 | `(` | stack: [0] → push 3
- Index: 4 | `)` | stack:[0,3] → pop → not empty, length = 4-0=4, maxLen=4
- Index: 5 | `)` | stack:[0] → pop → stack empty → push 5

**Result:** maxLen = `4`, which corresponds to substring `()()` from index 1 to 4.
