## 1. **Short Summary**

Given an array `nums` and integer `k`, we need to find the **largest integer** in `nums` that appears in **exactly one subarray** of size `k`. If no such integer exists, return `-1`.

---

## 2. **Constraints & Edge Cases**

- `1 ≤ nums.length ≤ 50` (small size; O(N²) is OK)
- `0 ≤ nums[i] ≤ 50` (very small values, so we can use small arrays and counting)
- `1 ≤ k ≤ nums.length`
- **Edge Cases:**
  - If every integer appears in 0 or more than 1 subarray, answer is `-1`.
  - Duplicate numbers must be handled.
  - If `k == nums.length`, only one subarray (the entire array).
  - If `k == 1`, each element forms a subarray. If an integer occurs more than once, it appears in multiple subarrays.

---

## 3. **Optimal Algorithm**

Because all constraints are small, we can brute force:

1. For each subarray of size `k` (there are `n - k + 1`), count which numbers appear in that subarray.
2. For each number `x`, keep a **set of subarray IDs (indices)** where it appears.
3. After iterating, for each number that ever appeared, if its set of subarrays has length == 1, add it to a list of candidates.
4. Return the **maximum** of those candidates; if none, return `-1`.

**Implementation Notes:**  
- Since `0 <= nums[i] <= 50`, we can use an array of size 51 to track sets of subarray IDs.
- For counting sets unambiguously, we can use a 2D array (`present[num][sub_idx] = 1/0`) or use `std::set<int>` for each number.

**Time Complexity:** O(n²) (For each subarray (O(n)), scan k elements (O(k)), total O(nk) <= 50*50 = 2500)

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <set>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findLargestAlmostMissing(vector<int>& nums, int k) {
        // 0 <= nums[i] <= 50, so use array of sets
        vector< set<int> > appear_in(51); // appear_in[num] = set of subarray indices with this num
        
        int n = nums.size();
        for (int start = 0; start <= n - k; ++start) {
            // For each subarray nums[start .. start+k-1]
            set<int> already; // avoid double-counting the same number in this subarray
            for (int i = start; i < start + k; ++i) {
                int num = nums[i];
                if (!already.count(num)) {
                    appear_in[num].insert(start);
                    already.insert(num);
                }
            }
        }
        int ans = -1;
        for (int num = 0; num <= 50; ++num) {
            if (appear_in[num].size() == 1)
                ans = max(ans, num);
        }
        return ans;
    }
};
```

## 5. **Example Explanation**

Let's explain **Example 1**:  
`nums = [3,9,2,1,7], k = 3`

All subarrays of size 3 are:  
- [3, 9, 2] (`idx 0`)
- [9, 2, 1] (`idx 1`)
- [2, 1, 7] (`idx 2`)

Build map of number → set of subarrays (indices) it appears in:
- 3: {0} (in [3, 9, 2])
- 9: {0,1}
- 2: {0,1,2}
- 1: {1,2}
- 7: {2}

Now, numbers appearing in **exactly one** subarray: **3 (subarray 0), 7 (subarray 2)**
Pick the largest: **7**

---

Return **7**.
