Let's tackle the problem step by step:

---

## 1. **Short Summary**

The problem asks to compute the **highest altitude** reached by a biker, who starts at altitude **0**. Each value in the `gain` array represents the **change in altitude** to reach the next point. The goal is to simulate this journey and return the highest reached altitude.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= n <= 100`: The gain array will have at least 1 and at most 100 elements.
- `-100 <= gain[i] <= 100`: The gain at each step can be negative (descend), zero, or positive (ascend).
- The biker always starts at 0.

**Edge Cases:**
- All negative gains: Altitude will only decrease (the answer will be 0, since the start is the highest).
- All positive gains: Altitude will only increase (the answer is the cumulative sum).
- Mixed positive and negative.
- Single element in gain array (`n=1`): just compare 0 and gain[0].

---

## 3. **Optimal Algorithm**

### Intuition & Steps:

- Start with `altitude=0` and `maxAltitude=0`
- For each value in `gain`:
    - Add it to the current `altitude`
    - If `altitude > maxAltitude`, update `maxAltitude`
- After processing all gains, return `maxAltitude`.

**Time Complexity:** O(n)  
**Space Complexity:** O(1)

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int largestAltitude(vector<int>& gain) {
        int altitude = 0;
        int maxAltitude = 0;
        for (int g : gain) {
            altitude += g;
            if (altitude > maxAltitude)
                maxAltitude = altitude;
        }
        return maxAltitude;
    }
};
```

---

## 5. **Example Explanation**

### Example 1

**Input:**  
`gain = [-5, 1, 5, 0, -7]`

Let's compute the cumulative altitudes:
- Start: 0
- After -5: 0 + (-5) = **-5**
- After 1:  -5 + 1   = **-4**
- After 5:  -4 + 5   = **1**
- After 0:   1 + 0   = **1**
- After -7: 1 + (-7) = **-6**

So, the altitudes at each point are: `[0, -5, -4, 1, 1, -6]`

**The highest is 1.**  
**Output:** `1`
