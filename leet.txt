Let's address your requirements step by step:

---

## 1. **Short Summary**

You are given an array `nums`. Starting at index `0`, you want to reach the last index (`n-1`) in minimum jumps. From any index `i`, you can:
- Jump to adjacent indices (`i-1` or `i+1`, if they exist).
- If `nums[i]` is **prime**, you can "teleport" to any other index `j ≠ i` such that `nums[j]` is **divisible** by `nums[i]`.

Find the **minimum** number of jumps needed to reach the end.

---

## 2. **Constraints & Edge Cases**

- **n** can be up to 100,000; **nums[i]** up to 1,000,000 &ge; 1.
- Large constraints mean `O(n log n)` is okay, `O(n^2)` is not.
- No consecutive duplicate indices in teleportation. (Can’t teleport to self.)
- If no element is prime, it's a standard adjacency jump problem.
- Some numbers may repeat in `nums`.
- All numbers are possible: some may be low (like 1, 2, etc.), some high.

**Edge cases:**
- Only one number: already at the end, requires 0 jumps.
- All numbers are non-prime.
- Repeated numbers, e.g. `[2,2,2,2,2]` – allows teleport chains.
- Teleportation via primes where no destination is valid (e.g., `[2,3,5,7]`).

---

## 3. **Optimal Algorithm**

- **Model** the problem as a **graph**: indices are nodes.
- Edges: connect index `i` to `i-1` and `i+1`, and, if `nums[i]` is prime, connect to every index `j` with `nums[j] % nums[i] == 0` and `j != i`.
- **Find the shortest path** from `0` to `n-1` — classic **0-1 BFS**. Every move has cost 1.
- To **avoid TLE**:
    - Precompute all primes up to 1,000,000 (Sieve).
    - For each **prime**, create a **list of indices** in `nums` whose values are multiples of that prime (reverse mapping).
    - For each visited prime at `nums[i]`, **do teleportation once**, and don’t process the same prime again globally. (Otherwise repeated work.)
- **Implementation Steps**:
    1. Sieve up to `1,000,000` to check primality quickly.
    2. For each unique prime in `nums`, maintain a mapping: `prime p -> list of indices i` where `nums[i] % p == 0`.
    3. Standard BFS: enqueue `(index, jumps)`; for each pop, try adjacent moves. If at a **prime** index not processed before, process all teleportable jumps for that prime and mark the teleportations for `nums[i]` prime as used.
    4. Stop at first time you reach `n-1`.

**BFS guarantees the minimum jumps**.

---

## 4. **C++ Solution**

```cpp
#include <bits/stdc++.h>
using namespace std;

// Sieve for fast primality and for collecting primes <= 1e6
vector<char> primeSieve(int n) {
    vector<char> is_prime(n + 1, 1);
    is_prime[0] = is_prime[1] = 0;
    for (int i = 2; i * i <= n; ++i) {
        if (!is_prime[i]) continue;
        for (int j = i * i; j <= n; j += i)
            is_prime[j] = 0;
    }
    return is_prime;
}

class Solution {
public:
    int minimumJumps(vector<int>& nums) {
        int n = nums.size(), MAX_NUM = 1e6 + 1;
        auto is_prime = primeSieve(MAX_NUM);

        // Map: prime p -> all indices i where nums[i] % p == 0
        unordered_map<int, vector<int>> prime_to_indices;
        // For each unique value in nums, store all its indices for fast search.
        unordered_map<int, vector<int>> num_to_indices;
        for (int i = 0; i < n; ++i)
            num_to_indices[nums[i]].push_back(i);

        // For every unique prime p that exists as nums[i], construct the list
        for (int i = 0; i < n; ++i) {
            for (int p = 2; p * p <= nums[i]; ++p) {
                if (nums[i] % p == 0) {
                    if (is_prime[p])
                        prime_to_indices[p]; // will be filled next loop
                    int temp = nums[i]/p;
                    if (temp != p && is_prime[temp])
                        prime_to_indices[temp];
                }
            }
            if (is_prime[nums[i]])
                prime_to_indices[nums[i]];
        }
        // Now, for each candidate prime p, fill prime_to_indices
        // For speed, for each p, collect all i where nums[i]%p==0
        for (auto& pr : prime_to_indices) {
            int p = pr.first;
            for (int i = 0; i < n; ++i)
                if (nums[i] % p == 0)
                    pr.second.push_back(i);
        }

        vector<int> dist(n, -1);
        queue<int> q;
        dist[0] = 0;
        q.push(0);

        // Keep track of which primes we've already processed in teleportation
        unordered_set<int> used_prime;

        while (!q.empty()) {
            int idx = q.front(); q.pop();
            int d = dist[idx];

            if (idx == n - 1) return d;

            // Try i-1 and i+1
            for (int neighbor : {idx - 1, idx + 1}) {
                if (neighbor >= 0 && neighbor < n && dist[neighbor] == -1) {
                    dist[neighbor] = d + 1;
                    q.push(neighbor);
                }
            }

            // Teleportation
            int val = nums[idx];
            if (is_prime[val] && !used_prime.count(val)) {
                used_prime.insert(val);
                for (int j : prime_to_indices[val]) {
                    if (j != idx && dist[j] == -1) {
                        dist[j] = d + 1;
                        q.push(j);
                    }
                }
            }
        }
        return -1; // Should not happen per constraints
    }
};
```

## 5. **Example Explained**

### Example 1

**Input:** `nums = [1,2,4,6]`

- Start at index 0 (`1`), can only move to index 1.
- At index 1 (`2`): `2` is prime.
    - Adjacent moves: can go to index 0 or 2.
    - **Teleportation:** `nums[2]=4 % 2==0`, `nums[3]=6 % 2==0`.
        - Index 2 is closer, but 1 step ahead from where we would be without teleportation.
- Best jump: From index 1 **teleport to index 3** (`6 % 2==0`).
- Sequence: `0 → 1 → 3`.

Thus, **answer is 2**.
