Let's address your requirements step by step:

---

## 1. **Short Summary**

Given an array `nums`, compute arrays `leftSum` and `rightSum`, where `leftSum[i]` is the sum of all elements to the left of index `i`, and `rightSum[i]` is the sum of all elements to the right. Return an array `answer` with `answer[i] = |leftSum[i] - rightSum[i]|`.

---

## 2. **Constraints & Edge Cases**

- `1 <= nums.length <= 1000` — The array can have as little as 1 element and up to 1000.
- `1 <= nums[i] <= 10^5` — Each entry is a positive integer.
- **Edge cases:**  
    - If `nums` has length 1, both sums are zero.
    - If all elements are the same, differences may be symmetric.
    - No negative numbers, so sums grow monotonically.

---

## 3. **Optimal Algorithm**

We can compute everything efficiently in three passes (O(n) time, O(n) space):

1. Calculate `totalSum = sum(nums)`, which is equal to rightSum[0] since there are no left elements for index 0.
2. Initialize `leftSum = 0`.
3. For each index `i` from 0 to n-1:
    - Compute `answer[i] = |leftSum - (totalSum - leftSum - nums[i])|`
       - where `(totalSum - leftSum - nums[i])` is the right sum for index i,
         because `leftSum` sums nums[0..i-1], `nums[i]` is current, and the rest is right.
    - Update `leftSum += nums[i]`

**This avoids allocating extra arrays for leftSum/rightSum.**

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <cmath>
using namespace std;

class Solution {
public:
    vector<int> leftRightDifference(vector<int>& nums) {
        int totalSum = 0, n = nums.size();
        for (int num : nums) totalSum += num;
        vector<int> answer(n);
        int leftSum = 0;
        for (int i = 0; i < n; ++i) {
            int rightSum = totalSum - leftSum - nums[i];
            answer[i] = abs(leftSum - rightSum);
            leftSum += nums[i];
        }
        return answer;
    }
};
```

---

## 5. **Explain One Example**

Let’s use the first example: `nums = [10, 4, 8, 3]`

- totalSum = 10 + 4 + 8 + 3 = **25**
- Iteration:
    1. i=0: leftSum=0, rightSum=25-0-10=15 → answer[0]=|0-15|=15, leftSum+=10→leftSum=10
    2. i=1: leftSum=10, rightSum=25-10-4=11 → answer[1]=|10-11|=1, leftSum+=4→leftSum=14
    3. i=2: leftSum=14, rightSum=25-14-8=3 → answer[2]=|14-3|=11, leftSum+=8→leftSum=22
    4. i=3: leftSum=22, rightSum=25-22-3=0 → answer[3]=|22-0|=22, leftSum+=3→leftSum=25

**Result:** `[15, 1, 11, 22]`
