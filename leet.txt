Let's address each requirement step-by-step:

---

## 1. **Short Summary**

Given a list of unique points, **count the number of quadruples (sets of 4 distinct points) that form a convex quadrilateral with at least one pair of horizontal sides** (sides parallel to the x-axis, so they share the same `y` coordinate).

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
    - `4 <= points.length <= 1e5` &mdash; Must be linear or O(N log N); can't enumerate all quadruples.
    - All points are distinct.
    - `-1e8 <= x_i, y_i <= 1e8`.

- **Edge Cases:**
    - Multiple points may have the same `y` but different `x`, so many horizontal segments possible per `y`.
    - All points in a single horizontal line (no quadrilateral).
    - Only two unique `y` values: can only pair rows to make horizontal sides.
    - Expected count should be modulo `1e9 + 7`.

---

## 3. **Optimal Algorithm**

### **Key Insight**

For horizontal sides, **edges must have both endpoints with the same `y` value**.

Count the number of quadruples with at least **one pair of horizontal sides** (i.e., two points with one y-coordinate and two points with a different y-coordinate).

#### **Step-by-step Approach**

1. **Group x-coordinates by y-coordinate.**
    - For each unique y, store pts on that row.
    - For row y, if there are k points: the number of ways to choose 2 to form a horizontal line is C(k,2).

2. **For each pair of different rows y1, y2:**
    - Pick **two points from y1 (horizontal edge)**: C(k1, 2)
    - Pick two points from y2: C(k2, 2)
    - These 4 points form a quadrilateral with both top and bottom horizontal.
    - Each such pair forms `C(k1,2) * C(k2,2)` quadrilaterals.

3. **Total number: sum over all unordered (y1, y2), y1 != y2, of `C(k1,2)*C(k2,2)`**

    - Instead of iterating over all pairs:
        - Let’s pre-calculate C(k, 2) for all y.
        - If `row_pairs` is the array of all `C(k_y, 2)`, then the sum over all unordered pairs is:
          ```
          total = (sum(row_pairs) ^ 2 - sum(row_pairs^2)) / 2
          ```
          (Standard "sum of all pairs" trick.)

**Why is this correct?**  
Given two rows, we choose two points on each, and these give us a unique set of 4 points (since all points are distinct). The only requirement is that the sides formed on both rows are horizontal (i.e., parallel to x-axis). Since at least one pair of horizontal sides is required, this covers all cases (if there were more than two horizontal sides, it's still included).

**Convexity**: It's guaranteed for points with different y-values forming two segments (no three points are co-linear vertically, so quadrilaterals made this way are convex and valid).

#### **Implementation Details**

- Use `unordered_map<int, int>` to count number of points per y-coordinate.
- For each y, compute `C(cnt, 2)`.
- Use prefix sum trick above.
- Watch for zeros (when fewer than 2 points in a row).

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int countTrapezoids(vector<vector<int>>& points) {
        const int MOD = 1e9 + 7;
        unordered_map<int, int> y_count;
        for (auto& p : points) {
            y_count[p[1]]++;
        }
        vector<long long> pairs;
        long long sum_pairs = 0, sum_pairs_sq = 0;

        for (const auto& [y, cnt] : y_count) {
            if (cnt >= 2) {
                long long val = (1LL * cnt * (cnt - 1) / 2) % MOD;
                pairs.push_back(val);
            }
        }
        for (long long x : pairs) {
            sum_pairs = (sum_pairs + x) % MOD;
            sum_pairs_sq = (sum_pairs_sq + x * x % MOD) % MOD;
        }
        // Compute (sum^2 - sum_of_squares) / 2, modulo MOD.
        long long ans = ((sum_pairs * sum_pairs % MOD - sum_pairs_sq + MOD) % MOD) * ((MOD + 1) / 2) % MOD;
        return (int)ans;
    }
};
```

## 5. **Example Explained**

For  
**Input:** `points = [[1,0],[2,0],[3,0],[2,2],[3,2]]`

Unique y’s:  
- y = 0: [1,0], [2,0], [3,0] (**3 points**)
- y = 2: [2,2], [3,2] (**2 points**)

C(3,2) = 3, C(2,2) = 1

Total # of pairs:
- sum_pairs = 3 + 1 = 4
- sum_pairs_sq = 3^2 + 1^2 = 9 + 1 = 10

Total: (4^2 - 10)/2 = (16 - 10)/2 = 6/2 = 3

**So, the answer is 3.**

## **Final Notes**

- **Time Complexity:** O(N) for grouping and O(R) for final calculation (R = # unique y), both << N.
- **Space Complexity:** O(R) for storing y-groups.
