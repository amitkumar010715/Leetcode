## 1. **Short Summary**

We are to count the number of arrays of length `n` whose values are within `[l, r]`, such that:
- No two adjacent elements are equal.
- No three consecutive elements are strictly increasing or decreasing.

This is a classic **Dynamic Programming** problem where the state depends on the previous two elements (to prevent both repeats and monotonic runs).

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `3 ≤ n ≤ 2000`
  - `1 ≤ l < r ≤ 2000` (So up to 2000 values for each position)
  - The answer must be computed modulo \(10^9 + 7\).
- **Edge cases:**
  - Only 2 different possible values: arrays must alternate.
  - Large n: O(nk²) is feasible, but O(nk³) is not.
  - Every sequence must check both increasing and decreasing runs of length 3.
  - The minimum value of `n` is 3.

---

## 3. **Optimal Algorithm**

### **DP State:**
Let’s define  
`dp[pos][last][second_last]` := number of arrays of length `pos+1`, ending at `last` (current value), with `second_last` as the element before that.

- **pos**: current index (0-based).
- **last**: The value at `pos`
- **second_last**: Value at `pos-1`

#### **Base case:**
For position 1 (`pos=1`), for all valid `last` and `second_last`, set `dp[1][last][second_last] = 1` if last != second_last.

#### **Transition:**
For pos from 2 to n-1:
- For all `x = l..r`: current value (will be a[pos])
    - For all `y = l..r`: previous value (will be a[pos-1])
        - For all `z = l..r`: value before previous (a[pos-2])
            - **Valid only if**:
                - x != y (no same adjacent)
                - y != z (ensured by previous transitions)
                - (z, y, x) is **not** strictly increasing: !(z < y && y < x)
                - (z, y, x) is **not** strictly decreasing: !(z > y && y > x)
            - Then:
              ```
              dp[pos][x][y] += dp[pos-1][y][z]
              ```

#### **Optimization:**
- At each step, keep only two layers (`cur`, `prev`), reducing memory to O(k²).
- As k can be up to 2000, and n up to 2000, total DP states: O(n k²), which is feasible.

---

### **Implementation Plan**
- Initialize dp for size 2 ("arrays of length 2").
- For pos = 2..n-1, transition as above.
- Finally, sum all `dp[n-1][last][second_last]`.

---

## 4. **C++ Code**

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1'000'000'007;

int numberOfZigZag(int n, int l, int r) {
    int k = r - l + 1;
    // Compress value range to [0..k-1]
    // dp[cur][last][second_last]
    vector<vector<int>> prev(k, vector<int>(k, 0));
    // Initialize base: sequences of length 2
    for (int a = 0; a < k; ++a) {
        for (int b = 0; b < k; ++b) {
            if (a != b) {
                prev[b][a] = 1;
            }
        }
    }

    for (int pos = 2; pos < n; ++pos) {
        vector<vector<int>> cur(k, vector<int>(k, 0));
        for (int x = 0; x < k; ++x) {         // current
            for (int y = 0; y < k; ++y) {     // previous
                if (x == y) continue;
                for (int z = 0; z < k; ++z) { // second last
                    // Prevent strictly inc/dec run
                    if (z < y && y < x) continue;
                    if (z > y && y > x) continue;
                    cur[x][y] = (cur[x][y] + prev[y][z]) % MOD;
                }
            }
        }
        prev.swap(cur);
    }

    // Sum over possible last two elements
    int ans = 0;
    for (int x = 0; x < k; ++x) {
        for (int y = 0; y < k; ++y) {
            ans = (ans + prev[x][y]) % MOD;
        }
    }
    return ans;
}
```

## 5. **Example Explanation**

### Example: `n = 3, l = 1, r = 3`

So, k = 3 (possible values: 1, 2, 3):

- All arrays of length 3 using 1,2,3, such that:
    1. Adjacent elements are different.
    2. No three consecutive numbers are strictly increasing/decreasing.

Let's list possible arrays:
- [1,2,1], [1,2,3] (**[1,2,3]** is strictly increasing: not allowed), so invalid.
- [1,3,1], [1,3,2]
- [2,1,2], [2,1,3]
- [2,3,1], [2,3,2]
- [3,1,2], [3,1,3]
- [3,2,1], [3,2,3]

But let's check for strictly inc/dec runs (`a < b < c` or `a > b > c`):

Listing only **valid**:
- [1,2,1] ✅
- [1,3,1] ✅
- [1,3,2] ✅
- [2,1,2] ✅
- [2,1,3] ✅
- [2,3,1] ✅
- [2,3,2] ✅
- [3,1,2] ✅
- [3,1,3] ✅
- [3,2,3] ✅

That's 10, as required.
