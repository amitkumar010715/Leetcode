### 1. **Short Summary**

Given an array of positive integers, find the length of the **longest contiguous subarray** such that  
**product of all elements** = **gcd of all elements × lcm of all elements**.  
Return the length of this subarray.

---

### 2. **Constraints & Edge Cases**

**Constraints:**
- `2 <= nums.length <= 100` (small size, brute force possible)
- `1 <= nums[i] <= 10` (very small numbers make brute force practical)

**Edge Cases:**
- All elements are 1: All subarrays are valid (since prod=gcd=lcm=1).
- Array with no valid subarray larger than one: Output 1.
- Non-overlapping subarrays: Find **longest**, so need the maximum.

---

### 3. **Optimal Algorithm**

**Observation:**

If `g = gcd(arr)` and `l = lcm(arr)`,  
then `g * l` is the smallest possible product for this set (since the numbers are usually multiples and divisors of each other).

But for arbitrary arrays, generally **product of elements = g * l** **only if all numbers are powers of the same prime**, or have almost no prime factors in common.

But since `nums[i]` is quite small (max 10), and array is short, we can check **all subarrays**.

**Algorithm Steps:**
1. For every subarray `(i, j)`, compute:
   - product
   - gcd
   - lcm
2. If `product == gcd * lcm`, update max length.

**Performance:**  
Since `n <= 100`, O(n²) is acceptable (100 * 100 = 10,000 subarrays).  
GCD and LCM are fast for small numbers.

---

### 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

// Helper for GCD
int gcd(int a, int b) {
    while (b) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

// Helper for LCM
int lcm(int a, int b) {
    return a / gcd(a, b) * b;
}

class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int n = nums.size(), res = 1;
        for (int i = 0; i < n; ++i) {
            int prod = 1;
            int G = nums[i], L = nums[i];
            for (int j = i; j < n; ++j) {
                // Avoid overflow, but nums[i] <= 10, prod is safe for <=100 elements
                prod *= nums[j];
                G = gcd(G, nums[j]);
                L = lcm(L, nums[j]);
                if (prod == G * L)
                    res = max(res, j - i + 1);
            }
        }
        return res;
    }
};
```

---

### 5. **Example Explanation**

Let's use **Example 1**:  
**Input:** `nums = [1,2,1,2,1,1,1]`

Consider subarray `[1, 2, 1, 1, 1]` (positions 2 to 6, zero-indexed).

- Product: `1 × 2 × 1 × 1 × 1 = 2`
- GCD: `gcd(1,2,1,1,1) = 1`
- LCM: `lcm(1,2,1,1,1) = 2`
- GCD × LCM: `1 × 2 = 2`, which **matches the product**.

No longer subarray can achieve this. The answer is **5**.

---

**In summary:**  
Brute-force all subarrays, tracking product, gcd and lcm, and find the maximum length where `product == gcd * lcm`. Constraints allow this solution, and the implementation is direct with helper functions for gcd/lcm and a doubly-nested loop.
