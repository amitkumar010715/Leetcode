Let's address the problem step by step:

---

## 1. **Summary**

Given a singly linked list, delete its **middle** node and return the head of the resulting list. The middle node is located at index ⌊n / 2⌋, using **0-based indexing**.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - Number of nodes: 1 ≤ n ≤ 10⁵ (must be O(n) time, O(1) space).
  - Node value: no impact on logic.
- **Edge Cases:**
  - **1 node:** Deleting the only node → should return `nullptr`.
  - **2 nodes:** Delete the node at index 1 (second node).
  - Lists with even or odd lengths.

---

## 3. **Optimal Algorithm**

We need **O(n)** time with **O(1)** space.

### General Approach

1. **Find the index of the middle node:**  
   - `mid = n / 2` (using integer division).

2. **Traverse to the node *before* the middle node:**  
   - For the middle node at index `mid`, stop at index `mid-1`.

3. **Delete the middle node:**  
   - Bypass it: `prev->next = target->next`.

### Two-Pointer Trick

Instead of two passes (one for length, one for deletion), we can do:
- Use **slow** and **fast** pointers:
  - Advance fast by 2, slow by 1.
  - When fast reaches the end, slow is at middle.
  - To **delete** the middle, **keep track of the previous node** to slow.

### Pseudocode

```cpp
if head is null: return null
if head->next is null: return null (only one node)

prev = nullptr
slow = head
fast = head

while fast != null and fast->next != null:
    prev = slow
    slow = slow->next
    fast = fast->next->next

prev->next = slow->next
delete slow

return head
```
- Handles all edge cases in one pass.

---

## 4. **C++ Solution**

```cpp
// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    ListNode* deleteMiddle(ListNode* head) {
        if (!head || !head->next) 
            return nullptr; // One node, nothing to keep

        ListNode* slow = head;
        ListNode* fast = head;
        ListNode* prev = nullptr;

        while (fast && fast->next) {
            prev = slow;
            slow = slow->next;
            fast = fast->next->next;
        }

        // Now, slow points to the middle node
        prev->next = slow->next; // Remove slow

        // Optionally, delete slow, but not needed for LeetCode

        return head;
    }
};
```

---

## 5. **Example Walkthrough**

**Example:**  
**Input:** `[1,3,4,7,1,2,6]`  
n = 7, so mid = 3 (`7/2`)

**Step by Step:**  
Indexes:  0 1 2 3 4 5 6  
Values:   1 3 4 7 1 2 6

- After traversal, **slow** points at node with value `7` (index 3).
- **prev** points at node with value `4` (index 2).
- Skip the middle: `prev->next = slow->next` → `4` now links to `1` (index 4).
- Result: `[1,3,4,1,2,6]`
