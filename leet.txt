## **1. Short Summary**

Given a positive integer `n`, find the longest distance between any two **adjacent** `1`s in its binary representation (distance is the number of bit positions between them, counted inclusively). Return `0` if there are fewer than two `1`s.

---

## **2. Constraints & Edge Cases**

**Constraints:**
- `1 <= n <= 10^9`  
  (n fits in 32 bits, so binary representation is at most 30 bits.)

**Edge Cases:**
- `n` has only one `1` (like `n = 8` => `1000`), so no valid pair: **should return 0**.
- `n` is very small (`n = 1`), so only one bit set: **return 0**.
- `n` is of form `11...1` (like 15 => `1111`): all ones, gap is 1 everywhere, so answer is 1.

---

## **3. Optimal Algorithm**

### **Idea**

We will scan the bits of `n` **from least significant to most significant (right to left)**, keeping track of the indices (bit positions) where we see `1`. Every time we find a new `1`, we compute the distance from the previous `1` and keep the largest gap seen.

**Step-by-step:**
1. Initialize `prev` to -1 (to track previous position of a `1`), `maxGap` to 0.
2. For each bit position `i` (start at 0), if bit is `1`:
    - If `prev != -1`, distance = `i - prev`, update `maxGap` if necessary.
    - Update `prev` to `i`.
3. Move to next bit (`i++`), right shift `n`.
4. At the end, return `maxGap`.

**Time Complexity:**  
- O(log n): at most 30-32 steps.

**Space Complexity:**  
- O(1): only counters.

---

## **4. Clean C++ Solution**

```cpp
class Solution {
public:
    int binaryGap(int n) {
        int prev = -1;
        int maxGap = 0;
        int pos = 0;
        while (n > 0) {
            if (n & 1) {
                if (prev != -1) {
                    maxGap = std::max(maxGap, pos - prev);
                }
                prev = pos;
            }
            n >>= 1;
            pos++;
        }
        return maxGap;
    }
};
```

## **5. Explanation of Example**

Let’s explain **Example 1**:  
**Input:** n = 22  
**Binary:** 10110 (positions, from right (LSB): 0 1 2 3 4)

Diagram:
```
4 3 2 1 0   (bit positions)
1 0 1 1 0   (bits, 22)
```

Scan from LSB (right):
- At pos=1: found first 1.
- At pos=2: found next 1, gap = 2-1 = 1 (**maxGap = 1**).
- At pos=4: found another 1, gap = 4-2 = 2 (**maxGap = 2**).

**No more 1s**, so answer is **2**.
