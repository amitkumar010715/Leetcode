Let's solve **Mirror Distance of an Integer**.

---

## 1. **Short Summary**

Given an integer `n`, compute its *mirror distance*:  
- Reverse its digits to get `reverse(n)`
- Return `abs(n - reverse(n))`

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
    - `1 <= n <= 10^9`
    - O(1) or O(log n) solution required due to input size

- **Edge Cases:**
    - `n` is a single digit, e.g., `7`
    - `n` ends with zero, e.g., `10 → reverse(10)=1`
    - `n` is a palindrome, e.g., `121`, so distance is 0

---

## 3. **Optimal Algorithm**

- **Reverse the number:**  
  Use math, not string conversion, for efficiency.
    1. Initialize `rev=0`
    2. While `n>0`, pop last digit and append to `rev`

- **Calculate the answer:**  
  - `reverse_n = reverse(n)`
  - Return `abs(n - reverse_n)`

**Time complexity:** O(log n)  
**Space complexity:** O(1)

---

## 4. **C++ Solution**

```cpp
class Solution {
public:
    int mirrorReflection(int n) {
        int original = n;
        int rev = 0;

        while (n > 0) {
            rev = rev * 10 + (n % 10);
            n /= 10;
        }

        return abs(original - rev);
    }
};
```

(If LeetCode function signature is `int findMirrorDistance(int n);`, adjust accordingly.)

--- 

## 5. **Example Explained**

**Input:** `n = 25`

- Reverse 25:  
  25 % 10 = 5 ⟶ rev = 5  
  25/10 = 2  
  2 % 10 = 2 ⟶ rev = 5*10 + 2 = 52  
  2/10 = 0  

- Mirror distance: |25 - 52| = 27

**Output:** `27`
