Let's address your requirements in order for **Jump Game IX**.

---

## 1. **Short Summary**

Given an array `nums`, you can jump:

- **Forward** (to a higher index) if `nums[j] < nums[i]`.
- **Backward** (to a lower index) if `nums[j] > nums[i]`.

From each index `i`, find the **maximum value in `nums` reachable** by any sequence of valid jumps starting at `i`.

---

## 2. **Constraints & Edge Cases**

- **Size:** Large arrays (up to 1e5 elements), so O(n log n) solutions are needed.
- **Element Values:** Large (up to 1e9) and not unique.
- **Edge Cases:**
    - All elements are equal: Every index can only reach itself, so output is the array itself.
    - Strictly increasing/decreasing: Only jumps in one direction are possible.
    - Single element: Only that element is reachable.

---

## 3. **Optimal Algorithm**

Observations:

- **Jumps** can be chained: From `i`, you can jump to a `j`, then from `j` continue, recursively.
- **From i:** Any sequence of valid jumps. We need the maximum value that can be reached.

We need to precompute (for each index) which other indices it can jump to.

We notice:
- At each step, we can either jump forward to a strictly smaller value, or backward to a strictly greater value.

This is reminiscent of "jump game with monotonic stacks".

### **Key Insight**

- For each `i`, you can only reach indices recursively where each jump is strictly reducing (`nums[j] < nums[i]` when forward) or strictly increasing (`nums[j] > nums[i]` when backward).
- But at each step, you can only jump to one direction, but then chain further.

#### **Dynamic Programming with Monotonic Stack:**

1. **For each index, collect two possible "jumps":**
    - Forward jump: Nearest next strictly smaller (`nums[j] < nums[i]`) index (`j > i`)
    - Backward jump: Nearest previous strictly greater (`nums[j] > nums[i]`) index (`j < i`)
2. For each index, the maximum value reachable is the **maximum of:**
    - Its own value.
    - DP value from forward jump (if exists).
    - DP value from backward jump (if exists).
3. **Compute dp[i]:** the max value reachable from i.

#### **How do we compute nearest strictly smaller/greater efficiently?**

- Use monotonic stacks:
    - For *next smaller*: scan left→right, stack decreasing, pop while top ≥ current.
    - For *previous greater*: scan left→right, stack increasing, pop while top ≤ current.

But we update DP in "right" order to ensure all dependencies are computed.

#### **Order of Processing?**

If we process indices from right→left for next smaller and left→right for previous greater, we can fill in jumps. Then, process DP from right→left and left→right again.

But since there are cycles, we use a **topological order**:
- Values not depending on others (like at ends, or with no possible jumps) are base cases.

**But in fact, since every jump is either forward (to a strictly smaller) or backward (to a strictly greater), if we process the indices in the order of decreasing value, we can fill recursive dependencies.**

Let’s generalize:
- Sort all indices in order of decreasing `nums[i]`.
- For each, for both directions, DP is filled either from higher to lower (for forward/reverse jumps) — so no cycles.

**Final Steps:**
1. For each index, precompute:
   - Next forward `j` with `nums[j] < nums[i]` (`j > i`)
   - Previous backward `j` with `nums[j] > nums[i]` (`j < i`)
2. For each index, initialize `dp[i] = nums[i]`.
3. For each index in decreasing `nums[i]`:
    - For each possible jump (forward/backward), update `dp[i] = max(dp[i], dp[j])`.
4. Return `dp`.

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <stack>
#include <algorithm>

using namespace std;

class Solution {
public:
    vector<int> maxReachableValues(vector<int>& nums) {
        int n = nums.size();
        vector<int> nextSmaller(n, -1);     // right jump: next index with nums[j] < nums[i]
        vector<int> prevGreater(n, -1);     // left jump:  previous index with nums[j] > nums[i]
        
        // Monotonic stack for next smaller to right
        stack<int> stk;
        for (int i = 0; i < n; ++i) {
            while (!stk.empty() && nums[stk.top()] > nums[i]) {
                nextSmaller[stk.top()] = i;
                stk.pop();
            }
            stk.push(i);
        }
        
        // Monotonic stack for previous greater to left
        while (!stk.empty()) stk.pop();
        for (int i = n - 1; i >= 0; --i) {
            while (!stk.empty() && nums[stk.top()] < nums[i]) {
                prevGreater[stk.top()] = i;
                stk.pop();
            }
            stk.push(i);
        }

        // DP: max reachable value from each index
        vector<int> dp(n);
        for (int i = 0; i < n; ++i) dp[i] = nums[i];

        // To process in topological order, sort indices by decreasing nums[i]
        vector<int> idx(n);
        for (int i = 0; i < n; ++i) idx[i] = i;
        sort(idx.begin(), idx.end(), [&](int a, int b) {
            return nums[a] > nums[b];
        });

        for (int i : idx) {
            if (nextSmaller[i] != -1) {
                dp[i] = max(dp[i], dp[nextSmaller[i]]);
            }
            if (prevGreater[i] != -1) {
                dp[i] = max(dp[i], dp[prevGreater[i]]);
            }
        }
        return dp;
    }
};
```

## 5. **Example Explanation ([2,3,1])**

```cpp
nums = [2, 3, 1]

Indexes: 0   1   2
Values:  2   3   1
```

**Jumps:**
- i=0: next smaller? j > 0 with nums[j] < nums[0]=2 → j=2 (nums[2]=1)
- i=0: previous greater? none.

- i=1: next smaller? j>1 with nums[j]<nums[1]=3 → j=2 (nums[2]=1)
- i=1: previous greater? none.

- i=2: next smaller? none.
- i=2: previous greater? j<2 with nums[j]>nums[2]=1 → j=1 (nums[1]=3)

**Build DP (process indices in order of nums descending: 3,2,1):**

- i=1 (nums=3): 
  - nextSmaller[1]=2, prevGreater[1]=-1
  - dp[1] = max(nums[1]=3, dp[2]=1, nothing) = 3

- i=0 (nums=2): 
  - nextSmaller[0]=2, prevGreater[0]=-1
  - dp[0] = max(nums[0]=2, dp[2]=1, nothing) = 2

- i=2 (nums=1): 
  - nextSmaller[2]=-1, prevGreater[2]=1
  - dp[2] = max(nums[2]=1, dp[1]=3) = 3

**Result: [3,3,3]**


**But according to the problem statement, in your example, the expected output is [3,3,3]. The code above matches that.**

| 0     | 2     | 2 → 1        | -             | 3             |
| 1     | 3     | 2 → 1        | -             | 3             |
| 2     | 1     | -            | 1 ← 3         | 3             |

### **Summary**

- Use monotonic stacks to precompute valid jumps for each index.
- Use DP in decreasing value order to propagate maximum reachable value.
- Total time O(n log n).
