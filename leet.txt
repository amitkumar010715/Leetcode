Let's address the problem step by step:

---

## 1. **Short Summary**

Given an integer array, we replace each element with its **rank**. The rank is **1-based** (smallest value has rank 1), **equal elements share the same rank**, and the ranks are as small as possible. Our goal is to efficiently compute and return the resulting array of ranks.

---

## 2. **Constraints & Edge Cases**

- **Size**: `0 <= arr.length <= 1e5`  
  (The algorithm needs to be O(n log n) at worst.)
- **Element values**: `-1e9 <= arr[i] <= 1e9`
- **Duplicates**: Multiple elements can be the same.
- **Edge cases**:
    - **Empty array**: Should return an empty array.
    - **All elements equal**: All should have rank 1.
    - **Already sorted**: Should work efficiently.
    - **Single element**: Rank is 1.

---

## 3. **Optimal Algorithm**

### Step-by-step

1. **Copy and Sort:**  
   Copy the array, sort it, and remove duplicates to get the ordered list of unique values. Sorting takes O(n log n).

2. **Assign Ranks:**  
   Create a hash map (unordered_map) from value to its rank (starting from 1). Assign ranks in sorted order.

3. **Transform Original Array:**  
   Replace each element in the original array with its rank using the map. This is O(n).

**Time complexity:** O(n log n) (due to sorting)

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>

class Solution {
public:
    std::vector<int> arrayRankTransform(std::vector<int>& arr) {
        std::vector<int> sorted = arr;
        std::sort(sorted.begin(), sorted.end());
        // Remove duplicates
        sorted.erase(std::unique(sorted.begin(), sorted.end()), sorted.end());
        
        std::unordered_map<int, int> valueToRank;
        for (int i = 0; i < sorted.size(); ++i) {
            valueToRank[sorted[i]] = i + 1;  // ranks start from 1
        }
        
        std::vector<int> result;
        result.reserve(arr.size());
        for (int num : arr) {
            result.push_back(valueToRank[num]);
        }
        return result;
    }
};
```

---

## 5. **Example Explained**

**Example:**  
Input: `[37,12,28,9,100,56,80,5,12]`

- **Step 1:** Sort and deduplicate: `[5,9,12,28,37,56,80,100]`
- **Step 2:** Assign ranks:
    - `5` → 1
    - `9` → 2
    - `12` → 3
    - `28` → 4
    - `37` → 5
    - `56` → 6
    - `80` → 7
    - `100` → 8
- **Step 3:** Transform each element:
    - 37 → 5
    - 12 → 3
    - 28 → 4
    - 9 → 2
    - 100 → 8
    - 56 → 6
    - 80 → 7
    - 5 → 1
    - 12 → 3

**Output:** `[5,3,4,2,8,6,7,1,3]`

---

**In summary:** We sort, deduplicate, assign ranks, and map back easily in O(n log n) time, supporting large inputs and all valid integer values.
