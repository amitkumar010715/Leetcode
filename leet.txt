Let's address the problem step-by-step:

---

## 1. **Short Summary**

Given an integer array, in each move, you can increment or decrement any element by 1. You need to **make all elements equal in a minimum number of moves**.  
The **minimum moves** needed is the **sum of absolute differences to the median**.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= nums.length <= 10^5`  
- `-10^9 <= nums[i] <= 10^9`  
- The answer fits into a 32-bit integer.

**Edge Cases:**
- Array of one element: already equal, **0 moves**.
- Array with all equal elements: **0 moves**.
- Presence of negative numbers does not affect logic.
- Even or odd array size: median can be any middle value.

---

## 3. **Optimal Algorithm Explanation**

**Key Observations**:
- To minimize the sum of absolute differences from a target value, the target should be the **median** of the array.
- This classic "minimize L1 distance" problem’s optimal point is always located at the median.

**Algorithm Steps**:
1. **Sort `nums`**.
2. **Find median**:
   - Median is at index `n / 2` when `n` is odd.
   - For even `n`, either of the middle values works.
3. **Sum the absolute differences of all elements to the median.**

**Time Complexity:** `O(n log n)` (for sorting)

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int minMoves2(vector<int>& nums) {
        int n = nums.size();
        sort(nums.begin(), nums.end());
        int median = nums[n/2]; // median
        int moves = 0;
        for(int v : nums) {
            moves += abs(v - median);
        }
        return moves;
    }
};
```

---

## 5. **Example Explanation**

### Example: `nums = [1, 10, 2, 9]`

**Step 1:** Sort  
`[1, 2, 9, 10]`

**Step 2:** Median  
`n = 4`, so median is at index 2, i.e., `nums[2] = 9`; but index 2 is value 9. For even-numbered list, median can be either of the two middles. Select index 2 (9), or index 1 (2). Let's pick 9:

Sum abs differences to 9:  
- |1 - 9| = 8  
- |2 - 9| = 7  
- |9 - 9| = 0  
- |10 - 9| = 1  
**Total:** 8 + 7 + 0 + 1 = 16

This matches the expected output.

---

### **Final Summary**
- Always move every element towards the **median value**.
- The answer is the sum of the absolute differences between each element and the median.
- Handles all edge cases correctly.
