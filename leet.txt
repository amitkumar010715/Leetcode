## 1. **Short Summary**

Given a string `moves` with characters 'L', 'R', and '_', representing moves on a number line from origin (0), where '_' can be replaced by 'L' **or** 'R' at will, determine the **maximum possible distance from the origin you can reach after making all the moves**.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= moves.length <= 50`
- All characters in `moves` are 'L', 'R', or '_'.

**Edge Cases:**
- All moves are '_': Can maximize in either direction.
- No '_': Only sum 'L' and 'R'.
- Moves cancel: Equal 'L' and 'R', so only '_' contribute.
- Only one move: Answer is 1.
---

## 3. **Optimal Algorithm**

**Observation:**
- Each 'L' is forced left (-1), each 'R' is forced right (+1).
- Each '_' can be **either** 'L' **or** 'R', so to maximize distance, assign all '_' to the **same** direction as the net effect of the forced moves or to the direction that increases the total magnitude.

**Algorithm:**
1. Count number of 'L' (`countL`), 'R' (`countR`), and '_' (`count_`).
2. Compute:
    - Furthest left: assign all '_' as 'L', distance = |countL + count_| - countR|
    - Furthest right: assign all '_' as 'R', distance = |countR + count_| - countL|
3. The **maximum of these two** (since you can choose any direction).

Simplified:
- Furthest left: total = -countL - count_ + countR 
  - distance = | -countL - count_ + countR | = |countR - (countL + count_)|
- Furthest right: total = countR + count_ - countL
  - distance = |countR + count_ - countL| (but same as above, both signs).

Therefore, the answer is:
```cpp
max(abs((countR + count_) - countL), abs((countL + count_) - countR))
```
But with absolute value, this reduces to:
```cpp
abs(countR - countL) + count_
```

But taking maximum shows both options, but because, for magnitude, (adding '_' all to one side) gives you:
- Option 1 (all left): |countL + count_ - countR|
- Option 2 (all right): |countR + count_ - countL|
But both yield the same (absolute) value.

So, the final formula is:
```cpp
abs(countL - countR) + count_
```

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int furthestDistanceFromOrigin(string moves) {
        int countL = 0, countR = 0, count_ = 0;
        for (char c : moves) {
            if (c == 'L') countL++;
            else if (c == 'R') countR++;
            else count_++;
        }
        return abs(countL - countR) + count_;
    }
};
```

---

## 5. **Example Explanation**

**Example:**  
`moves = "_R__LL_"`

- countL = 2
- countR = 1
- count_ = 4

Maximum distance:
- Compute `abs(countL - countR) + count_`
- `abs(2 - 1) + 4 = 1 + 4 = 5`

**How?**  
- If we assign all '_' as 'L', movement sequence: L, R, L, L, L, L, L => Position: -5  
- If all '_' as 'R', sequence: R, R, R, R, LL => Position: 3  
- **Maximum distance = 5**
