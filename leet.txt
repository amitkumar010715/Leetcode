Let's answer each requirement step by step.

---

## **1. Short Summary**

Given 4 dates for Alice's and Bob's arrival and departure in Rome, **count how many days** (inclusive) both are present in the city at the same time. All dates are in "MM-DD" format in a non-leap year.

---

## **2. Constraints & Edge Cases**

- Each date is valid and within the same non-leap year.
- Alice and Bob's own arrival date is *earlier than or equal to* the departure date.
- The answer might be 0 if the intervals don't overlap at all.
- Dates could be the same for both Alice and Bob.
- Both intervals can be fully or partially overlapping.
- Dates are *inclusive*.

---

## **3. Optimal Algorithm**

**Key Insight:**  
For two date intervals `[a1, l1]` and `[a2, l2]`, their overlapping interval is  
`[max(a1,a2), min(l1,l2)]`.  
Days overlapped: `max(0, min(l1,l2) - max(a1,a2) + 1)`.

We need to convert MM-DD to the "day-of-year" format for easy comparison.

**Steps:**
1. Convert each date ("MM-DD") to its day-of-year integer.
2. Find the overlap as above.
3. Return the length of overlap or 0 if non-overlapping.

---

## **4. C++ Solution**

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

// helper: MM-DD to day-of-year
int toDayOfYear(const string& date) {
    // months days, 0-indexed: Jan=0
    static vector<int> daysInMonth = 
        {31,28,31,30,31,30,31,31,30,31,30,31};
    int month = stoi(date.substr(0, 2));
    int day = stoi(date.substr(3, 2));
    int doy = day;
    for(int m = 0; m < month - 1; ++m)
        doy += daysInMonth[m];
    return doy;
}

int countDaysTogether(string arriveAlice, string leaveAlice, string arriveBob, string leaveBob) {
    int a1 = toDayOfYear(arriveAlice);
    int l1 = toDayOfYear(leaveAlice);
    int a2 = toDayOfYear(arriveBob);
    int l2 = toDayOfYear(leaveBob);

    int start = max(a1, a2);
    int end = min(l1, l2);
    return max(0, end - start + 1);
}
```

---

## **5. Example Explained**

**Example 1:**  
`arriveAlice = "08-15", leaveAlice = "08-18"`  
`arriveBob   = "08-16", leaveBob   = "08-19"`

- Alice:  **Aug 15** to **Aug 18** (inclusive)
- Bob:    **Aug 16** to **Aug 19** (inclusive)

**Convert to day-of-year:**  
- Aug: It's the 8th month. By July 31st: Jan(31) + Feb(28) + Mar(31) + Apr(30) + May(31) + Jun(30) + Jul(31) = 212
- Aug 15: 212 + 15 = 227  
- Aug 16: 212 + 16 = 228  
- Aug 18: 212 + 18 = 230  
- Aug 19: 212 + 19 = 231

**Alice: 227 ~ 230**  
**Bob:   228 ~ 231**

Overlap = [max(227, 228), min(230, 231)] = [228, 230] = 3 days (**Aug 16, 17, 18**)

**Output: 3**

---

### **Summary**
- Convert "MM-DD" to day-of-year.
- Compute overlap as `[max(a1,a2), min(l1,l2)]`.
- Return `max(0, end - start + 1)`.
