## 1. **Short Summary**

Given an array `nums` and a `pivot`, we must **rearrange** `nums` so that:

- All elements **less than `pivot`** come first,
- then all elements **equal to `pivot`**,
- and finally, all elements **greater than `pivot`** at the end.

We **must maintain** the **relative order** of elements *within* each group.

---

## 2. **Constraints & Edge Cases**

- `1 <= nums.length <= 10^5` ⇒ Efficient, linear (O(n)) solution required.
- `-10^6 <= nums[i] <= 10^6` ⇒ All values reasonable for array processing.
- `pivot` is guaranteed to be in the array.
- **Edge Cases:**
  - All elements are the same as `pivot`.
  - No elements less than or greater than `pivot`.
  - Only one element.
  - Multiple occurrences of `pivot`.

---

## 3. **Optimal Algorithm**

### Approach: **Three Lists (Stable Partition)**

Since we need to partition by *three* groups (less than, equal to, greater than) and maintain relative order, an efficient way is to traverse `nums` **once** and store numbers in three separate vectors:

1. `less`: elements `< pivot`
2. `equal`: elements `== pivot`
3. `greater`: elements `> pivot`

After the traversal, **concatenate** the vectors in the order `[less, equal, greater]`. This approach is O(n) time and space, and maintains order.

**Alternative**: This is similar to a stable partition with three parts. Since constraint is only on rearrangement (not in-place), extra space is perfectly acceptable.

---

## 4. **C++ Solution**

```cpp
#include <vector>
using namespace std;

vector<int> pivotArray(vector<int>& nums, int pivot) {
    vector<int> less, equal, greater;
    for (int num : nums) {
        if (num < pivot) {
            less.push_back(num);
        } else if (num == pivot) {
            equal.push_back(num);
        } else {
            greater.push_back(num);
        }
    }
    // Concatenate results
    vector<int> result;
    result.reserve(nums.size());
    result.insert(result.end(), less.begin(), less.end());
    result.insert(result.end(), equal.begin(), equal.end());
    result.insert(result.end(), greater.begin(), greater.end());
    return result;
}
```

---

## 5. **Example Explanation**

**Example:**  
`nums = [9,12,5,10,14,3,10]`, `pivot = 10`

**Step 1:** Separate into three lists:
- `< pivot`: `[9,5,3]`  
- `== pivot`: `[10,10]`  
- `> pivot`: `[12,14]`  

**Step 2:** Concatenate: 

`[9,5,3,10,10,12,14]`

- `[9,5,3]` **(order preserved)**
- `[10,10]`
- `[12,14]` **(order preserved)**

**Thus the output is:**  
`[9,5,3,10,10,12,14]`

---

### **Conclusion**

- Traverse the array once, putting numbers in three separate vectors according to their relation with `pivot`.
- Concatenate the vectors for the final result.
- This is stable, O(n) time/space.
