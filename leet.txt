Let's address the problem step by step:

---

## 1. **Summary**
Given a binary tree, remove exactly **one edge** such that the two resulting subtrees' **sum of values** have their product maximized. Return the maximum such product modulo $10^9 + 7$.

---

## 2. **Constraints & Edge Cases**
- **2 ≤ number of nodes ≤ 50,000:** Efficient O(N) solution is required; brute force is not feasible.
- **1 ≤ Node.val ≤ 10,000:** All sums are positive integers.
- **Edge cases:**
  - Tree is skewed (like a linked list) or perfectly balanced.
  - All node values are the same.
  - Removing the edge closest to the root or to the leaves.

---

## 3. **Optimal Algorithm**

### Approach:

1. **Compute total sum of the tree.**
2. **For every edge:** (effectively, every subtree except entire tree itself), consider removing the edge *above* a subtree.
    - The product becomes `sum(subtree) * (totalSum - sum(subtree))`.
3. **Maximize this product** for all such splits.
4. Use post-order traversal to calculate each subtree sum.

### Complexity: O(N) time and O(H) space (H = tree height, recursion stack).

---

## 4. **C++ Solution**

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */

class Solution {
    using ll = long long;
    ll maxProductFound = 0;
    ll totalSum = 0;
    const int MOD = 1e9 + 7;

    // First pass: get total sum
    ll getTotal(TreeNode* root) {
        if (!root) return 0;
        return root->val + getTotal(root->left) + getTotal(root->right);
    }

    // Second pass: try every split
    ll dfs(TreeNode* node) {
        if (!node) return 0;
        ll currSum = node->val + dfs(node->left) + dfs(node->right);
        if (node != root_node) { // prevent splitting root (tree can't be empty)
            ll product = currSum * (totalSum - currSum);
            if (product > maxProductFound)
                maxProductFound = product;
        }
        return currSum;
    }

    TreeNode* root_node = nullptr;
    
public:
    int maxProduct(TreeNode* root) {
        root_node = root;
        totalSum = getTotal(root);
        dfs(root);
        return maxProductFound % MOD;
    }
};
```

---

## 5. **Example Explanation**

### Example 1:
`root = [1,2,3,4,5,6]`

Visual:
```
      1
    /   \
   2     3
  / \   /
 4   5 6
```
- **Total sum:** 1 + 2 + 3 + 4 + 5 + 6 = **21**
- Try every edge cut (every subtree):
    - Suppose we cut between node 1 and node 2: The sum of subtree rooted at 2 is 2+4+5=11. The other is 21-11=10. Product: 11*10=**110**.
    - Try other splits, but none is better.

**Final Answer:** 110

---

## **Key Takeaway**
- Use two DFS: one for total sum, another for subtree splits.
- For each (non-top) subtree sum, maximize its product with the rest.
- The answer is efficient by post-order traversal.
