Let's address each requirement thoroughly:

---

## 1. **Short Summary**

Given two strings `s` and `t`, count **how many distinct subsequences of `s` are equal to `t`**. A subsequence is obtained by deleting any elements (possibly none) from a string without changing their order.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= s.length, t.length <= 1000`
  - Both `s` and `t` contain only English letters.
- **Output should fit a 32-bit signed integer.**
- **Edge Cases:**
  - If `t` is **longer** than `s`, result is `0` (cannot form a longer string as a subsequence).
  - If `t` is an **empty string**, there is **1** way (choose nothing from `s`).
  - If `s` is empty but `t` is not, result is `0` (cannot form non-empty string from nothing).
  - If `s == t`, there is **1** way.
  - If `s` has repeated letters — count each valid matching.

---

## 3. **Optimal Algorithm (DP Explanation)**

### Approach: **Dynamic Programming**

Let:
- `s` has length **m**
- `t` has length **n**

Define:
- **dp[i][j]:** Number of distinct subsequences of the first `i` chars of `s` forming first `j` chars of `t`.

#### **Recurrence:**
- If `s[i-1] == t[j-1]`: 
  - Either match `s[i-1]` with `t[j-1]` (*use it*), or skip `s[i-1]`.
  
  `dp[i][j] = dp[i-1][j-1] + dp[i-1][j]`

- Else (if characters differ), skip `s[i-1]`:

  `dp[i][j] = dp[i-1][j]`

#### **Base Cases:**
- `dp[i][0] = 1` for all `i` (empty `t` can always be matched: by choosing nothing)
- `dp[0][j] = 0` for `j > 0` (cannot match non-empty `t` from empty `s`)

#### **Space Optimization**
Because `dp[i][*]` only references `dp[i-1][*]`, use a 1-D dp array and update from back to front:
- Let `dp[j]` represent ways to form first `j` characters of `t`.
- Start with `dp[0]=1, dp[j>0]=0`
- For each character in `s` (outer loop), iterate `j` from `n` down to `1`.

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int numDistinct(string s, string t) {
        int m = s.length(), n = t.length();
        vector<long long> dp(n + 1, 0);
        dp[0] = 1; // Empty t

        for (int i = 1; i <= m; ++i) {
            // Go backward to prevent overwriting values needed for current row
            for (int j = n; j >= 1; --j) {
                if (s[i - 1] == t[j - 1]) {
                    dp[j] += dp[j - 1];
                }
                // else case: do nothing, dp[j] stays as is (dp[j] = dp[j])
            }
        }
        return (int)dp[n];
    }
};
```

## 5. **Example Explanation**

**Example:**  
`s = "babgbag"`, `t = "bag"`

Let's walk through the DP process:

- Initialize: `dp[0]=1, dp[1-3]=0` (since t has length 3)
- For each char in `s`, update the `dp` arr:

| s char | dp after processing (`[dp[0],dp[1],dp[2],dp[3]]`) |
|--------|--------------------------------------------------|
| b      | [1,1,0,0]             | (s[0]='b', t[0]='b')   |
| a      | [1,1,1,0]             | (s[1]='a' matches t[1]='a') |
| b      | [1,2,1,0]             | (s[2]='b' matches t[0]='b') |
| g      | [1,2,1,1]             | (s[3]='g' matches t[2]='g') |
| b      | [1,3,1,1]             | (s[4]='b' matches t[0]='b') |
| a      | [1,3,4,1]             | (s[5]='a' matches t[1]='a') |
| g      | [1,3,4,5]             | (s[6]='g' matches t[2]='g') |

Final `dp[3] = 5`, which matches the expected result.  
So, there are **5 distinct subsequences of "babgbag" that form "bag"**.
