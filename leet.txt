Let's break down the problem and provide an optimal solution.

---

## 1. **Short Summary**

You are given a DAG (Directed Acyclic Graph) where some nodes are *offline*, except the start (0) and end (\( n-1 \)). Each edge has a "recovery cost". A path is *valid* if:
- All intermediate nodes are online.
- The total cost on the path does not exceed \( k \).

The **score** of a path is the *minimum* edge cost along the path.

Your task: **Return the largest possible path-score over all valid 0-to-\( n-1 \) paths** (that is, maximize the minimal edge cost), or -1 if impossible.

---

## 2. **Constraints & Edge Cases**

- \( n \) can be up to 50,000, \( m \) up to 100,000.
- Costs can be up to \( 10^9 \), \( k \) up to \( 5 \times 10^{13} \).
- Offline intermediate nodes make all paths through them invalid.
- Always a DAG (so topological ordering is possible).
- Multiple edges from node \( u \) to \( v \) are possible.

**Edge Cases:**
- All paths exceed \( k \).
- All intermediate nodes offline.
- All edges have cost 0.
- Multiple valid paths, different scores.
- No valid path at all (\(-1\) should be returned).

---

## 3. **Optimal Algorithm**

### **Step 1: Binary Search on Answer (Path Score)**

- The minimum edge cost along a path is exactly the "bottleneck" for the score.
- If we fix a candidate minimum edge cost \( x \), can we find a path from 0 to \( n-1 \) using only edges with cost \(\geq x\), with total path cost \(\leq k\) and only online nodes?
- This is a **monotonic predicate**: if we can do it for \( x \), we can do it for all smaller \( x \), but maybe not for bigger.

### **Step 2: For Given \( x \), Check Path Existence**

- Build a graph using only edges with cost \(\geq x\), and only online intermediate nodes.
- Find the **minimum path cost** from 0 to \( n-1 \) (classic shortest path / DP on DAG), skipping offline nodes (besides start/end).
- If minimum total path cost \(\leq k\), this \( x \) is feasible.

### **Step 3: Implement**

- Binary search \( x \) in [0, \( 10^9 \)].
- For each \( x \), run DP on DAG (efficient given constraints).

- **Topological sort** for dynamic programming.
- For each node, keep the minimum total cost to reach it.
- If \( n-1 \) is reachable and cost \(\leq k\), answer \( x \) is possible.

### **Complexity**

- Binary search on edge costs: \( O(\log M) \), with \( M \) = max possible edge cost (\(10^9\)), at most 30-40 steps.
- Each check is a DP over the DAG: \( O(n + m) \).
- Total: \( O((n + m) \cdot \log M) \), efficient under constraints.

## 4. **C++ Solution**

```cpp
#include <vector>
#include <queue>
#include <limits>
using namespace std;

class Solution {
public:
    long long maxPathScore(int n, vector<vector<int>>& edges, vector<bool>& online, long long k) {
        // Build adjacency list
        vector<vector<pair<int, int>>> graph(n);
        for (auto& e : edges) {
            graph[e[0]].emplace_back(e[1], e[2]);
        }

        // Find all unique edge costs for binary search or simply search in [0, 1e9]
        int low = 0, high = 1000000000;
        int answer = -1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (canReach(n, graph, online, k, mid)) {
                answer = mid;
                low = mid + 1; // Try to find larger possible minimal edge
            } else {
                high = mid - 1;
            }
        }
        return answer;
    }

    bool canReach(int n, const vector<vector<pair<int, int>>>& graph, const vector<bool>& online, long long k, int min_edge) {
        // DP: min cost to each node, direction: topological order
        // 1. Build filtered graph and in-degree
        vector<vector<pair<int, int>>> g(n);
        vector<int> indeg(n, 0);

        for (int u = 0; u < n; ++u) {
            for (auto& [v, cost] : graph[u]) {
                if (cost >= min_edge && (v == n-1 || v == 0 || online[v])) {
                    g[u].emplace_back(v, cost);
                    indeg[v]++;
                }
            }
        }

        // 2. DP initialization
        vector<long long> dp(n, /*infinite*/numeric_limits<long long>::max());
        dp[0] = 0;
        // 3. Topological sort
        queue<int> q;
        for (int i = 0; i < n; ++i) if (indeg[i] == 0) q.push(i);

        while (!q.empty()) {
            int u = q.front(); q.pop();
            // If offline and not source/target, skip!
            if (u != 0 && u != n-1 && !online[u]) continue;

            for (auto& [v, cost] : g[u]) {
                if (dp[u] + cost < dp[v]) {
                    dp[v] = dp[u] + cost;
                }
                indeg[v]--;
                if (indeg[v] == 0)
                    q.push(v);
            }
        }
        return dp[n-1] <= k;
    }
};
```

## 5. **Example Explanation**

**Example 2:**
```
edges = [[0,1,7],[1,4,5],[0,2,6],[2,3,6],[3,4,2],[2,4,6]]
online = [true,true,true,false,true]
k = 12
```
- Node 3 is offline, so ignore any path through 3.
- Paths:
    1. 0 → 1 → 4: costs 7 + 5 = 12, minimum edge = 5 → valid (score 5)
    2. 0 → 2 → 4: costs 6 + 6 = 12, minimum edge = 6 → valid (score 6)
- Maximum path score is **6**.

The algorithm works by binary searching for the largest minimal edge cost that allows a valid path to be constructed with total cost ≤ 12, using DP over the online DAG.
