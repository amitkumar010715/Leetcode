## 1. Short Summary

Given a singly linked list with even number of nodes, **pair** each node from the start (`i`) with its twin from the end (`n-1-i`). The "twin sum" is the sum of their values. Return the **maximum** such twin sum for any pair.

---

## 2. Constraints & Edge Cases

- The list length is always **even**: `[2, 10^5]`.
- All node values are in `[1, 10^5]`.
- Edge cases:
    - Minimum list: 2 nodes (trivial, just their sum).
    - All elements are the same.
    - Strictly increasing or decreasing values.
    - Large n (so must be O(n) time and O(n) or O(1) space).

---

## 3. Optimal Algorithm (O(n) time, O(1) space)

### Steps:

1. **Find the middle** of the linked list using slow and fast pointers.
2. **Reverse the second half** of the list (starting from the middle).
3. **Traverse** from start and from reversed half simultaneously, compute and track the maximum twin sum.
4. *(Optionally, restore the list structure if needed, but it's not required here.)*

**Why?**
- By reversing the second half, you can easily access both "ends" of the list at the same time, with constant space.

---

## 4. Clean C++ Solution

```cpp
// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    int pairSum(ListNode* head) {
        // 1. Find the middle of the list with slow and fast pointers.
        ListNode* slow = head, *fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        // Now slow is at the start of the second half.

        // 2. Reverse the second half.
        ListNode* prev = nullptr;
        while (slow) {
            ListNode* next = slow->next;
            slow->next = prev;
            prev = slow;
            slow = next;
        }
        // Now prev points to the head of the reversed second half.

        // 3. Walk forwards from both ends, taking sums.
        int max_sum = 0;
        ListNode* p1 = head;
        ListNode* p2 = prev;
        while (p2) { // or p1, but both have n/2 steps
            max_sum = std::max(max_sum, p1->val + p2->val);
            p1 = p1->next;
            p2 = p2->next;
        }
        return max_sum;
    }
};
```

---

## 5. Example Explanation

**Example:** `head = [4,2,2,3]`

- List: `4 → 2 → 2 → 3`
- Length: 4 (even).
- Pairs:
    - First (`4`, at index 0) pairs with last (`3`, index 3): 4+3=**7**
    - Second (`2`, at index 1) pairs with third (`2`, at index 2): 2+2=4
- Maximum twin sum: **7**

### How the Algorithm Works for this Example

- Find mid (`slow` lands on `2` at index 2).
- Reverse second half: `2 → 3` becomes `3 → 2`
- Walk:
    - p1=`4`, p2=`3`: sum=7 (max so far)
    - p1=`2`, p2=`2`: sum=4 (max=7)
- Done. Return 7.
