Let's break down the problem and solution step by step.

---

## 1. Short Summary

Given a list of student scores (`nums`) and an integer `k`, you must pick **k** students such that the **difference between the highest and lowest of their scores is minimized**. Return this minimum difference.

---

## 2. Constraints & Edge Cases

**Constraints:**
- `1 <= k <= nums.length <= 1000`
- `0 <= nums[i] <= 10^5`

**Edge Cases:**
- `k == 1`: Always returns 0 (since max and min of one number are equal).
- All `nums` are identical: The answer is 0 for any `k`.
- `nums` is already sorted/unsorted.
- Large `k` (`k == nums.length`): Difference between maximum and minimum of all.
- `nums` may contain only two unique values, or values can be very spread.

---

## 3. Optimal Algorithm

**Observation:**  
To minimize the difference between **max** and **min** in any selected `k` elements, it's optimal to pick `k` numbers that are **closest together**, i.e., in a consecutive sorted segment.

**Algorithm Steps:**
1. **Sort** the array `nums`.
2. **For each window** of size `k` (i.e., `nums[i] ... nums[i+k-1]`), calculate the difference between the maximum and minimum in that window (`nums[i+k-1] - nums[i]`).
3. **Keep track** of the minimum such difference across all possible windows.

**Time Complexity:**  
- Sorting: O(n log n)  
- Window checking: O(n)  
**Total:** O(n log n)

---

## 4. Clean C++ Solution

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minimumDifference(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int ans = INT_MAX;
        for (int i = 0; i <= nums.size() - k; ++i) {
            ans = min(ans, nums[i+k-1] - nums[i]);
        }
        return ans;
    }
};
```

---

## 5. Example Explanation

**Example:**  
Input: `nums = [9,4,1,7]`, `k = 2`

**Step 1: Sort**  
Sorted array: `[1, 4, 7, 9]`

**Step 2: Find all windows of size 2**
- Window `[1, 4]`: diff = 4-1 = **3**
- Window `[4, 7]`: diff = 7-4 = **3**
- Window `[7, 9]`: diff = 9-7 = **2**

**Step 3: Minimum Difference**  
Among (3, 3, 2), the **minimum is 2**.

**Output:**  
`2`

---

### **In Summary**
- Sort `nums`.
- The answer is the smallest difference between the max and min in any window of size `k`.
- Efficient: O(n log n).
