Let's tackle the "Find the Safest Path in a Grid" problem step by step:

---

## 1. **Short Summary**

Given an `n x n` grid with cells marked as thieves (1) or empty (0), you start at the top-left and want to reach the bottom-right. A "safeness factor" of a path is the **minimum** Manhattan distance from any cell on the path to any thief. You must find the **maximum possible safeness factor** achievable by any path from start to end.

---

## 2. **Constraints & Edge Cases**

- **Grid size**: Up to 400 × 400 ⇒ solutions slower than O(N² logN) may TLE.
- **Multiple thieves possible**: Must handle >1 start points for BFS.
- **Start & End on thieves**: If either (0,0) or (n-1, n-1) is a thief, max safeness factor is 0.
- **No thieves**: Not possible, per constraints.
- **Movement**: 4 directions only.

---

## 3. **Optimal Algorithm**

A **two-stage approach**:
1. **Preprocessing**:  
   For every cell, compute its **minimum distance to any thief** using **multi-source BFS** from all thieves. Let's call this safeness map `safe[r][c]`.

2. **Maximize Minimum Safeness Path**:  
   Now, find a path from (0,0) to (n-1,n-1) such that the **minimum** safeness (from above) along the path is **maximized**.  
   This is a classic **"Maximum of Minimum"** path, sometimes called the **Widest Path** or **Bottleneck Path**.  
   Use **binary search** over possible safeness factors (from 0 up to max in `safe`), and for each candidate safeness factor, use BFS or DFS to check if there's a path only through cells whose safeness factor ≥ candidate.

   Alternatively, use a **priority queue / max-heap** Dijkstra style, where at each step, you move to adjacent cells and keep track of the minimum safeness factor so far.

   **Optimal approach**:  
   - Preprocess `safe` via BFS from all thieves (O(N²)).
   - Use Dijkstra's Algorithm with max-heap to always try to get to a cell with **the largest minimum safeness so far**.

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maximumSafenessFactor(vector<vector<int>>& grid) {
        int n = grid.size();
        vector<vector<int>> safeness(n, vector<int>(n, -1));
        queue<pair<int,int>> q;
        // Step 1: Multi-source BFS from all thieves
        for(int r=0; r<n; ++r)
            for(int c=0; c<n; ++c)
                if(grid[r][c]==1) {
                    safeness[r][c] = 0;
                    q.emplace(r, c);
                }
        vector<pair<int,int>> dirs{{0,1},{1,0},{0,-1},{-1,0}};
        while(!q.empty()) {
            auto [r, c] = q.front(); q.pop();
            for(auto [dr, dc] : dirs) {
                int nr = r + dr, nc = c + dc;
                if(nr>=0 && nr<n && nc>=0 && nc<n && safeness[nr][nc]==-1) {
                    safeness[nr][nc] = safeness[r][c] + 1;
                    q.emplace(nr, nc);
                }
            }
        }
        // Step 2: Dijkstra's algorithm for widest path (max below min on path)
        priority_queue<tuple<int, int, int>> pq; // (safeness, r, c)
        vector<vector<int>> vis(n, vector<int>(n, -1));
        pq.emplace(safeness[0][0], 0, 0);
        vis[0][0] = safeness[0][0];
        while(!pq.empty()) {
            auto [cur_safe, r, c] = pq.top(); pq.pop();
            if(r == n-1 && c == n-1) return cur_safe;
            for(auto [dr, dc] : dirs) {
                int nr = r+dr, nc = c+dc;
                if(nr>=0 && nr<n && nc>=0 && nc<n) {
                    int next_safe = min(cur_safe, safeness[nr][nc]);
                    // If we can offer a bigger minimum along path to (nr, nc), continue
                    if(next_safe > vis[nr][nc]){
                        vis[nr][nc] = next_safe;
                        pq.emplace(next_safe, nr, nc);
                    }
                }
            }
        }
        // Should not reach here
        return 0;
    }
};
```

## 5. **Example Explanation**

**Let's explain Example 2:**
```txt
grid = [[0,0,1],
        [0,0,0],
        [0,0,0]]
```

- Thief at (0,2).
- Safeness map after BFS:
    - (0,2): 0 (thief)
    - (0,1): 1 (distance to thief)
    - (0,0): 2
    - (1,2): 1
    - (2,2): 2
    - (1,1), (1,0), (2,0), (2,1): distances 2 or 3

Now, starting from (0,0) (safeness 2), the path tries to keep the lowest safeness along the path as large as possible.  
One possible path: (0,0)→(1,0)→(2,0)→(2,1)→(2,2)  
The **minimum safeness** along this path is 2.

Thus, the answer is **2**.

---

### **Summary**
- **Two steps**: BFS for grid distances; Dijkstra for widest path.
- **Time complexity** is efficient: O(N² logN).
- Handles large grids and all edge cases efficiently.
