Let's solve the **Balanced Binary Tree** LeetCode problem step by step:

---

## 1. **Summary**

Given a binary tree, determine if it is **height-balanced**.  
A binary tree is height-balanced if for every node, the height difference of its left and right subtree is **no more than 1**.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - Number of nodes: `0` to `5000`.
  - Node values: From `-10^4` to `10^4`.
- **Edge Cases:**
  - **Empty tree** (`root == nullptr`): Should return `true` (an empty tree is balanced).
  - **Single node:** Always balanced.
  - **Small subtrees differing by more than one in height:** Should be correctly detected.

---

## 3. **Optimal Algorithm**

### Approach: **Post-order Traversal with Early Stopping**

- Use recursion to traverse the tree **bottom-up (post-order)**.
- At each node, compute:
  - The **height** of the left and right subtrees.
  - If at any node the height difference > 1, **propagate imbalance upwards**.
- Use a special value (e.g., `-1`) to signal an imbalance so we can return early.

### **Time Complexity**
- **O(N)**, where N is the number of nodes.
- Each node is visited once.

### **Space Complexity**
- O(H), H is the height of the recursion stack (worst O(N), best O(log N)).

---

## 4. **C++ Solution**

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    // Helper function returns height if balanced, -1 if not balanced
    int check(TreeNode* node) {
        if (!node) return 0; // Height = 0 for null
        int left = check(node->left);
        if (left == -1) return -1; // unbalanced left
        int right = check(node->right);
        if (right == -1) return -1; // unbalanced right

        if (abs(left - right) > 1)
            return -1; // Current node unbalanced

        return 1 + std::max(left, right);
    }

    bool isBalanced(TreeNode* root) {
        return check(root) != -1;
    }
};
```

---

## 5. **Example Explained**

### Example 1:

Input: `root = [3,9,20,null,null,15,7]`

The tree structure:
```
      3
     / \
    9  20
      /  \
     15   7
```

- Node `9`: Both children null → height = 1.
- Node `15`, node `7`: Both children null → height = 1.
- Node `20`: left/right heights = 1/1 → height = 2.
- Node `3`: left/right heights = 1/2 → height = 3.
- Height difference at every node ≤ 1, so the tree is **balanced**.

**Output:** `true`

---

**In summary:** Use a recursive post-order traversal to check heights and propagate imbalance with an early return if the difference exceeds 1. This ensures `O(N)` runtime and fast detection.
