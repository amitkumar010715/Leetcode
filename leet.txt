Let's step through your requirements one by one.

---

### 1. **Short Summary**

You are given three arrays describing a set of coupons, each with a code string, business line string, and activity status. A coupon is valid if its code is non-empty and consists only of letters, digits, or underscores, its business line is one of a given four categories, and it is active. Return all **valid codes**, sorted first by the required business line order and then lexicographically.

---

### 2. **Constraints & Edge Cases**

- **n (number of coupons):** 1 ≤ n ≤ 100 (small, so brute-force is fine)
- **code[i], businessLine[i]:** Max length 100, can be empty or have special characters
- **Code Validity:** must be non-empty, only [a-zA-Z0-9_]
- **Business Line:** must be in {"electronics", "grocery", "pharmacy", "restaurant"}
- **isActive:** Must be true
- **Edge Cases:**
    - Empty codes
    - Codes with illegal characters (like @, #, etc.)
    - Invalid businessLine values
    - Inactive coupons
    - Multiple codes in the same business line
    - All coupons invalid (return empty list)
    - Codes with different case letters (e.g. `code[i] = "a_B1"` is valid)

---

### 3. **Optimal Algorithm**
1. **Initialize**: Setup a mapping for business line sort order.
2. **Iterate once over the arrays**:
    - For each coupon:
        - Check **activity** and businessLine validity.
        - Validate code: non-empty, and all characters are from [a-zA-Z0-9_].
    - For each valid coupon, **store** its code along with its businessLine.
3. **Sort** the valid coupons:
    - By business line (according to given order), then by code lexicographically.
4. **Output**: Gather sorted codes for output.

_All steps are **O(n log n)** because sorting is on at most 100 elements._

---

### 4. **C++ Solution**

```cpp
#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>

using namespace std;

class Solution {
public:
    vector<string> validCoupons(
        vector<string>& code,
        vector<string>& businessLine,
        vector<bool>& isActive
    ) {
        // Business line order for sorting
        unordered_map<string, int> blPriority{
            {"electronics", 0},
            {"grocery", 1},
            {"pharmacy", 2},
            {"restaurant", 3}
        };

        vector<pair<int, string>> valids; // store {businessOrder, code}

        int n = code.size();
        for (int i = 0; i < n; ++i) {
            // Check activity
            if (!isActive[i])
                continue;
            // Check businessLine
            auto it = blPriority.find(businessLine[i]);
            if (it == blPriority.end())
                continue;
            // Check code: non-empty, [A-Za-z0-9_]
            string& s = code[i];
            if (s.empty())
                continue;
            bool ok = true;
            for (char c : s) {
                if (!( (c >= 'a' && c <= 'z') ||
                       (c >= 'A' && c <= 'Z') ||
                       (c >= '0' && c <= '9') ||
                       (c == '_') )) {
                    ok = false;
                    break;
                }
            }
            if (!ok)
                continue;
            // Valid
            valids.emplace_back(it->second, s);
        }

        // Sort: first by business order, then lex code
        sort(valids.begin(), valids.end(), [](const auto& a, const auto& b){
            if (a.first != b.first) return a.first < b.first;
            return a.second < b.second;
        });

        vector<string> result;
        for (auto& p : valids)
            result.push_back(p.second);
        return result;
    }
};
```

### 5. **Example Walkthrough**

#### Example 1:

**Input:**
```
code = ["SAVE20","","PHARMA5","SAVE@20"]
businessLine = ["restaurant","grocery","pharmacy","restaurant"]
isActive = [true,true,true,true]
```
**Step-by-step:**
1. `"SAVE20"`: active, in `restaurant`, code is non-empty & valid.
2. `""`: empty code → INVALID (skipped)
3. `"PHARMA5"`: active, in `pharmacy`, code is valid.
4. `"SAVE@20"`: active, in `restaurant`, but code has `@` (invalid char) → INVALID

Now gather valid (code, businessLine):

- ("SAVE20", "restaurant")
- ("PHARMA5", "pharmacy")

Sort order of businessLine: electronics < grocery < pharmacy < restaurant

- "pharmacy" comes before "restaurant"

**So output:** `[ "PHARMA5", "SAVE20" ]`
