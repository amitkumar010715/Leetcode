Let's tackle the problem step by step:

---

### 1. **Summary**

Given:
- Several packs with some apples (`apple` array).
- Several boxes with capacities (`capacity` array).

**Task:** Find the **minimum number of boxes** needed such that their combined capacity can hold all the apples (apples from the same pack can go into different boxes).

---

### 2. **Constraints & Edge Cases**

- `1 <= n, m <= 50` (small arrays)
- `1 <= apple[i], capacity[i] <= 50`
- It is *guaranteed* that it is always possible to distribute the apples into boxes.
  
**Edge Cases:**
- Number of boxes < number of packs.
- All capacities are 1, apples are all small.
- One box is much larger than all others (potentially answer is 1).

---

### 3. **Optimal Algorithm**

Let's think:

- All that matters is the *total* apples and the *total* capacity.
- To **minimize the number of boxes**, we want to pick the *largest* boxes first.

So:
1. Compute `total_apples = sum(apple)`.
2. Sort `capacity` *descending*.
3. Start picking boxes one by one from the largest, accumulating their capacity, until the sum >= `total_apples`.
4. The count of boxes used is the answer.

**Time Complexity:**  
- Sorting: O(m log m)  
- Accumulation: O(m)  
This is easily fast for constraints.

---

### 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minimumBoxes(vector<int>& apple, vector<int>& capacity) {
        int total_apples = 0;
        for (int a : apple) total_apples += a;
        
        // sort capacities descending
        sort(capacity.rbegin(), capacity.rend());
        
        int sum = 0;
        for (int i = 0; i < capacity.size(); ++i) {
            sum += capacity[i];
            if (sum >= total_apples) {
                return i + 1;
            }
        }
        // constraints guarantee it is always possible, so this line should never be reached
        return -1;
    }
};
```

---

### 5. **Example Explanation**

#### Example 1:

- `apple = [1,3,2]` ⇒ total_apples = 1 + 3 + 2 = 6
- `capacity = [4,3,1,5,2]`
- Sort descending: [5,4,3,2,1]

Now, pick largest boxes until sum ≥ 6:
- 5 (used 1 box, sum=5)
- 5 + 4 = 9 (now sum=9, boxes used = 2)

Answer: 2

**As shown in the code and approach, we select boxes with 5 and 4 capacity. Their combined 9 can accommodate all 6 apples. Using any less is not possible.**

---

**Summary:**  
Sort capacities descending, pick boxes until you have enough total capacity for all apples. Return the number of boxes picked.
