## 1. **Short Summary**

Given a list of strings `patterns` and a string `word`, count how many of the patterns appear as substrings within `word`.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= patterns.length <= 100`
  - `1 <= patterns[i].length <= 100`
  - `1 <= word.length <= 100`
  - All characters are lowercase English letters.

- **Edge Cases:**
  - **Duplicate Patterns:** The same string may appear multiple times in `patterns` and should be counted each time it matches as a substring.
  - **Whole Word Match:** If a pattern equals the entire `word`, it counts.
  - **Pattern Longer Than Word:** Impossible for such pattern to be a substring; none will match.
  - **All Patterns Match / None Match:** Both situations possible.

---

## 3. **Optimal Algorithm**

- For each `pattern` in `patterns`:
  - Use the `find` function (or equivalent) to check if `pattern` appears anywhere in `word`.
  - If found, increment a counter.
- Return the counter.

**Why This Is Optimal?**
- `patterns.size()` and `word.size()` are both small (≤ 100).
- Checking for substring using `find` runs in O(N*M) where N is length of `pattern` and M is length of `word`, but with low constraints, this is efficient.

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int numOfStrings(vector<string>& patterns, string word) {
        int count = 0;
        for (const string& pattern : patterns) {
            if (word.find(pattern) != string::npos) {
                count++;
            }
        }
        return count;
    }
};
```

---

## 5. **Example Explanation**

**Example 1:**

> patterns = ["a","abc","bc","d"], word = "abc"

- `"a"` appears in `"abc"` (at index 0).
- `"abc"` appears in `"abc"` (at index 0, the whole word).
- `"bc"` appears in `"abc"` (at index 1).
- `"d"` does **not** appear in `"abc"`.

**So the output is `3`.**
