## 1. **Short Summary**

Given an array of even length, pair up all elements such that *every element is in exactly one pair* and **the maximum pair sum is minimized**. Return this minimal possible *maximum pair sum*, after you optimally form pairs.

---

## 2. **Constraints & Edge Cases**

- **Constraints**:
    - `2 <= n <= 1e5` (`n` even)
    - `1 <= nums[i] <= 1e5`
- **Edge Cases**:
    - Minimum length (n = 2): Just two numbers, the answer is their sum.
    - All elements are the same: Any pairing gives the same sum.
    - Some or all elements are the largest allowed (1e5).
    - The array is not presorted; efficient solution shouldn't rely on starting order.

---

## 3. **Optimal Algorithm**

### **Key Insight:**
To minimize the largest pair sum, pair the *smallest* number with the *largest*, the second smallest with the second largest, etc. This way, sums are "balanced" and you avoid very large or very small sums.

### **Algorithm Steps:**
1. **Sort** the array.
2. For all `i` from `0` to `(n/2 - 1)`, pair `nums[i]` (smallest not yet used) with `nums[n-1-i]` (largest not yet used).
3. Compute each pair's sum; keep track of the **maximum** among these.
4. Return this maximum sum.

### **Complexity**
- **Time:** O(n log n) (for sorting), O(n) for the pairing loop.
- **Space:** O(1) extra space if sorting in-place.

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minPairSum(vector<int>& nums) {
        sort(nums.begin(), nums.end()); // O(n log n)
        int n = nums.size();
        int maxPair = 0;
        for (int i = 0; i < n/2; ++i) {
            int pairSum = nums[i] + nums[n-1-i];
            if (pairSum > maxPair) maxPair = pairSum;
            // or: maxPair = max(maxPair, pairSum);
        }
        return maxPair;
    }
};
```

---

## 5. **Example Explanation**

**Input:** `[3,5,2,3]`

1. Sort: `[2,3,3,5]`
2. Pairings:
    - Pair 1: `2 + 5 = 7`
    - Pair 2: `3 + 3 = 6`
3. Pair sums: `[7, 6]`
4. Maximum pair sum is `7`.

**Output:** `7`

---

**Summary:**  
Sort the array, pair the smallest with the largest, and the maximum of these pairs is minimized. This greedy strategy works because it balances high and low numbers to avoid a large sum spike. The approach is efficient and handles the upper constraint sizes well.
