## 1. **Short Summary**

Given a binary string `s` and an integer `k`, determine if **every possible binary code of length `k`** appears as a substring in `s`. There are `2^k` possible codes. If all appear, return true; else false.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
  - `1 <= s.length <= 5 * 10^5`
  - `1 <= k <= 20`
  - `s[i]` is either `'0'` or `'1'`
- **Edge Cases:**
  - If `k > s.length`, impossible for all codes to appear: return `false`.
  - If `k == 1`, need both "0" and "1" present.
  - If `k == s.length`, only one substring exists; must check if all codes fit.
  - Large values of `k` (up to 20) mean there can be up to about a million codes (`2^20 = 1048576`). 

---

## 3. **Optimal Algorithm**

Given the large limits, we need an efficient way:
- There are at most `s.length - k + 1` substrings of length `k` in `s`.
- Each code is a binary string, which we can map to an integer in `0..2^k-1`.
- Use a **bitset** or an **unordered_set<int>** to record seen codes.
- Use a rolling hash (convert substrings to integer values efficiently).

**Algorithm Steps:**
1. Edge case: if `k > s.length`, return false.
2. Use a rolling integer to encode the last `k` bits as we iterate.
3. For each position once the first window is ready:
   - Add the integer value to a set/bitset.
   - If ever all `2^k` codes are seen, return true (early stopping).
4. Return `true` if all codes seen, else `false`.

**Complexity:**  
- **Time:** O(n)  
- **Space:** O(2^k) (for the set/bitset)  

---

## 4. **C++ Solution**

```cpp
#include <string>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool hasAllCodes(string s, int k) {
        int need = 1 << k; // total codes needed
        int allOnes = need - 1;  // mask for last k bits
        unordered_set<int> seen;
        int hash = 0;
        int n = s.size();
        
        for (int i = 0; i < n; ++i) {
            // shift in the next bit
            hash = ((hash << 1) & allOnes) | (s[i] - '0');
            if (i >= k - 1) {
                // start recording from i == k - 1
                seen.insert(hash);
                if ((int)seen.size() == need) return true; // early exit
            }
        }
        return (int)seen.size() == need;
    }
};
```
