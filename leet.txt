## 1. Short Summary

Given a binary tree where each node contains a `0` or `1`, each root-to-leaf path forms a binary number. The task is to **sum** all such numbers for every root-to-leaf path.

---

## 2. Constraints & Edge Cases

**Constraints:**
- The tree has 1 to 1000 nodes (manageable for DFS).
- Node values are only `0` or `1`.
- The sum fits in a 32-bit integer (no overflow concerns).

**Edge Cases:**
- Tree with only the root node.
- All left-leaning or right-leaning trees.
- Unbalanced trees.
- All paths yield binary numbers with leading zeros.

---

## 3. Optimal Algorithm

### Approach

We'll use **DFS (depth-first search)** to traverse the tree:

- At each node, we keep a running number (`curr`), forming the binary number as we descend.
- As we traverse:  
  - At each step, perform `curr = (curr << 1) | node->val`.
- On reaching a leaf, we add the current binary number to the running total.

### Time & Space Complexity

- **Time:** O(n), since we visit each node once.
- **Space:** O(h), where `h` is height of the tree (stack space).

---

## 4. Clean C++ Solution

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int sumRootToLeaf(TreeNode* root) {
        return dfs(root, 0);
    }
    
    int dfs(TreeNode* node, int curr) {
        if (!node) return 0;
        curr = (curr << 1) | node->val;
        // If leaf, return the current sum
        if (!node->left && !node->right) {
            return curr;
        }
        // Otherwise, sum left and right subtree
        return dfs(node->left, curr) + dfs(node->right, curr);
    }
};
```

## 5. Example Explanation

Consider the tree:
```
      1
     / \
    0   1
   / \ / \
  0  1 0  1
```
Paths (Root to Leaf):
- 1→0→0 = 100 (binary) = 4
- 1→0→1 = 101 (binary) = 5
- 1→1→0 = 110 (binary) = 6
- 1→1→1 = 111 (binary) = 7

**Sum:** 4 + 5 + 6 + 7 = 22

The C++ code builds each binary number from the root to the leaf and sums up their decimal values, yielding the correct output `22` for this example.
