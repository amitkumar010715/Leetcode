Let's break down the solution step by step:

---

## 1. **Summary**

Given an array of positive integers, you may swap any two elements **only if** their values differ by at most `limit`. You can do this as many times as you want. Return the **lexicographically smallest array** possible after any number of such swaps.

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= limit <= 10^9`

**Edge Cases:**
- If `limit` is 0, **no swap** is possible unless elements are **equal**.
- If `limit` is very large (≥ `max(nums)` - `min(nums)`), you can swap **any** two elements, i.e., you can fully sort the array.
- All elements are equal: trivial.
- Entire array is already sorted: no operation needed.
- No two elements can ever be swapped: the result == original array.

---

## 3. **Optimal Algorithm**

Let's break down the operation:

- **Key Insight**: Two elements can be swapped **(directly or indirectly)** if, through a **chain of valid swaps**, their values have a sequence where consecutive numbers differ by at most `limit`.

- **Graph Model**: Each index is a node. Draw an edge between nodes `i` and `j` if `|nums[i] - nums[j]| <= limit`. But we can't build all the edges because O(N^2) is too slow.

- **Efficient Approach**:
    - We only care **which indices can reach each other** (i.e., are in the same connected component).
    - **Observation**: All numbers differing by at most `limit` can be in the same connected component. So, elements "close together" in value form components.

### Steps:

1. **Sort a list of (value, index) pairs**.
2. **Sweep** through values, and for consecutive values within `limit`, **unite** their indices (Union-Find / DSU).
3. After going through all the array, for all indices in the **same component**, **sort their elements** and assign back in order of indices to get the lex smallest arrangement for that component.

#### **Algorithm in Details**

- Build a list of pairs `(value, index)`, and sort them by value.
- Use **Union-Find**.
    - For each adjacent pair in the sorted list, if `next_value - curr_value <= limit`, union their indices.
- For each group/component, collect their indices. Sort the indices, and the values at those indices. Assign the sorted values to indices in sorted index order.

#### **Complexity**

- O(N log N) for sorting.
- Union-Find operations are nearly O(1) (amortized).
- Final collection and sorting within components is O(N log N) total.

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
#include <numeric> // For iota
#include <unordered_map>
using namespace std;

struct DSU {
    vector<int> parent;
    DSU(int n) : parent(n) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        if (x != parent[x])
            parent[x] = find(parent[x]);
        return parent[x];
    }
    void unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px != py) parent[py] = px;
    }
};

vector<int> lexicographicallySmallestArray(vector<int>& nums, int limit) {
    int n = nums.size();
    vector<pair<int, int>> arr; // (value, index)
    for (int i = 0; i < n; ++i)
        arr.push_back({nums[i], i});
    sort(arr.begin(), arr.end()); // Sort by value

    DSU dsu(n);

    // Connect consecutive in sorted array if diff <= limit
    for (int i = 1; i < n; ++i) {
        if (arr[i].first - arr[i-1].first <= limit) {
            dsu.unite(arr[i].second, arr[i-1].second);
        }
    }

    // Group indices by component
    unordered_map<int, vector<int>> groups;
    for (int i = 0; i < n; ++i) {
        groups[dsu.find(i)].push_back(i);
    }

    // Prepare answer
    vector<int> result = nums;
    for (auto& [root, indices] : groups) {
        // Collect values in this group
        vector<int> vals;
        for (int idx : indices) vals.push_back(nums[idx]);
        // Sort both indices and values
        sort(indices.begin(), indices.end());
        sort(vals.begin(), vals.end());
        // Place smallest values at smallest indices
        for (int j = 0; j < indices.size(); ++j)
            result[indices[j]] = vals[j];
    }
    return result;
}
```

## 5. **Example Explanation**

Let’s pick **Example 1**:

> `nums = [1,5,3,9,8], limit = 2`

- Pairs: (1,0), (5,1), (3,2), (9,3), (8,4)
- Sorting by value: (1,0), (3,2), (5,1), (8,4), (9,3)
- Now, step through with Union-Find:
    - 1 (idx 0) and 3 (idx 2): |1-3| = 2 ≤ 2 → connect 0, 2
    - 3 (idx 2) and 5 (idx 1): |3-5| = 2 ≤ 2 → connect 2, 1 (Now 0,2,1 are in the same set)
    - 5 (idx 1) and 8 (idx 4): |5-8| = 3 > 2 → no union
    - 8 (idx 4) and 9 (idx 3): |8-9| = 1 ≤ 2 → connect 4, 3

- Components: {0,1,2}, {3,4}
    - Group 1: indices [0,1,2], values [1,5,3]
        - Sort indices: [0,1,2], sort values: [1,3,5] ⇒ assign 1→0, 3→1, 5→2
    - Group 2: indices [3,4], values [9,8]
        - Sort indices: [3,4], values: [8,9] ⇒ assign 8→3, 9→4

- **Final array**: `[1,3,5,8,9]`
