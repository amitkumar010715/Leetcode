Let's tackle the problem step by step:

---

## 1. Short Summary

Given a row of houses with various colors (represented as an array), **find the maximum distance between two houses with different colors**. The distance is the absolute difference of their indices.

---

## 2. **Constraints & Edge Cases**

- **2 ≤ n ≤ 100**: Array is small, solutions up to O(n²) are feasible, but we can do better.
- **0 ≤ colors[i] ≤ 100**: Color codes are non-negative integers.
- **At least two houses have different colors.**
- Edge cases:
  - Array length is just 2 (e.g., `[1,2]`): Return 1.
  - All colors except two at ends are the same (e.g., `[1,1,1,2]`): The furthest different is at the ends.

---

## 3. **Optimal Algorithm**

Key idea:  
The furthest possible distance between two different-colored houses must **involve at least one of the endpoints** (`colors[0]` or `colors[n-1]`).  
So, for maximum efficiency:

1. **Check** all positions from left to right:
   - Find the *furthest* position from the **left** (`i`) where `colors[i] != colors[0]`. The distance: `abs(i - 0)`.
2. **Check** all positions from right to left:
   - Find the *furthest* position from the **right** (`i`) where `colors[i] != colors[n-1]`. The distance: `abs(i - (n-1))`.
3. The **maximum** of these two is the answer.

**Time Complexity:** O(n)

---

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxDistance(vector<int>& colors) {
        int n = colors.size();
        int dist1 = 0, dist2 = 0;

        // Furthest from left end with a different color
        for (int i = n-1; i >= 0; --i) {
            if (colors[i] != colors[0]) {
                dist1 = i - 0;
                break;
            }
        }
        // Furthest from right end with a different color
        for (int i = 0; i < n; ++i) {
            if (colors[i] != colors[n-1]) {
                dist2 = n-1 - i;
                break;
            }
        }

        return max(dist1, dist2);
    }
};
```

---

## 5. **Example Explanation**

**Example:**  
`colors = [1, 1, 1, 6, 1, 1, 1]`

- From the left end (`colors[0]=1`):
  - Scan from right: first color different from 1 is at index 3 (`6`), so distance = 3 - 0 = **3**.
- From the right end (`colors[6]=1`):
  - Scan from left: first different color is at index 3 (`6`). Distance = 6 - 3 = **3**.

So, the answer is `max(3, 3) = **3**`.

---

**In summary:**  
Always check the furthest houses from both ends with a color different from their respective end. The maximum of these two is the required distance.
