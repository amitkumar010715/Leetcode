## 1. Short Summary

Given an array `nums`, for each index `i`, compute the sum of absolute differences `|i-j|` for every other index `j` such that `nums[j]==nums[i]` and `j != i`. If there's no such other index, set the value to 0.

---

## 2. Constraints & Edge Cases

- **Constraints:**
    - `1 <= nums.length <= 10^5`
    - `0 <= nums[i] <= 10^9` (nums can be very large, not suited for direct mapping to array-size)
- **Edge Cases:**
    - All elements are distinct: output is all zeroes.
    - All elements are equal: every position is involved with every other.
    - Input length is 1: Output is `[0]`.
    - Large groups of duplicates (test efficiency).

---

## 3. Optimal Algorithm

### **Key Observations:**

- We need, *for each occurrence* of a value, the sum of absolute differences to all other indices with the same value.
- Naively, for each i, scan all j: O(N^2) — not feasible.

#### **Efficient Approach (O(N)):**

- For each unique value, collect the list of indices where it appears.
- For each group of indices:
    - For each index, compute `sum(|i-j|)` for all j in the group (excluding i).
- This can be done efficiently by:
    - Sorting the list of indices (they're naturally sorted as we scan array).
    - Using prefix sums to compute "sum of left indices" and "sum of right indices" for each index efficiently.

#### **Algorithm Steps:**

1. **Build index groups:** For each value, store the list of positions where it appears.
2. **Process each group:**
    - For each list of positions:
        - Precompute prefix sums of indices.
        - For each position `i` at index `k` in the group:
            - Elements to the left: `k` items
                - Total left sum: `positions_sum_left = prefix_sum[k-1]` (if k >= 1)
            - Elements to the right: `len - k - 1` items
                - Total right sum: `positions_sum_right = prefix_sum[n-1] - prefix_sum[k]`
            - Result:
                ```
                arr[position[k]] = (k * positions[k] - positions_sum_left) + (positions_sum_right - (len-k-1) * positions[k])
                ```
        - This avoids O(N^2) by doing each value's positions in O(M) where M is count of that value.

## 4. Clean C++ Solution

```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    vector<long long> distance(vector<int>& nums) {
        int n = nums.size();
        vector<long long> res(n, 0);
        unordered_map<int, vector<int>> val2indices;
        // 1. Record the indices for each value
        for (int i = 0; i < n; ++i)
            val2indices[nums[i]].push_back(i);
        
        // 2. Process each group
        for (const auto& kv : val2indices) {
            const vector<int>& indices = kv.second;
            int m = indices.size();
            if (m == 1) continue;
            // Prefix sums
            vector<long long> prefix(m, 0);
            prefix[0] = indices[0];
            for (int i = 1; i < m; ++i)
                prefix[i] = prefix[i-1] + indices[i];
            long long total_sum = prefix[m-1];
            
            for (int k = 0; k < m; ++k) {
                long long left = (k > 0) ? prefix[k-1] : 0;
                long long right = total_sum - prefix[k];
                int loc = indices[k];
                res[loc] = 1LL * loc * k - left + right - 1LL * loc * (m - k - 1);
            }
        }
        return res;
    }
};
```

## 5. Example Explanation

**Example:** `nums = [1, 3, 1, 1, 2]`

Positions for value `1`: `[0, 2, 3]`

- Prefix sum: `[0, 2, 5]`
- For index at position 0 (k=0, loc=0):
    - k = 0 (no left), left sum = 0
    - right = 5 - 0 = 5
    - Right count = 2 (`3 - 0 - 1`)
    - So:
      - `arr[0] = 0*0 - 0 + 5 - 0*2 = 5`
- For index at position 2 (k=1, loc=2):
    - left = 0
    - right = 5 - 2 = 3
    - arr[2] = 1*2 - 0 + 3 - 2*1 = 2 - 0 + 3 - 2 = 3
- For index at position 3 (k=2, loc=3):
    - left = 2
    - right = 5 - 5 = 0
    - arr[3] = 2*3 - 2 + 0 - 3*0 = 6 - 2 = 4

Thus, output is `[5,0,3,4,0]`

## **Conclusion**

The algorithm efficiently handles the distance sums for identical elements using prefix sums, reducing complexity from O(N²) to O(N).
