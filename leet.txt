Let's break down the problem step by step as requested:

---

## 1. **Short Summary**

Given a binary string, **count the number of substrings** with equal numbers of consecutive 0's and 1's, where all the 0's and all the 1's in a substring are grouped together. Each valid substring is considered for every occurrence.

#### Example
For s = "00110", "0011" and "01" and "10" are valid substrings (grouped runs).

---

## 2. **Constraints & Edge Cases**

- `1 <= s.length <= 1e5` — so the algorithm must be *linear* (O(n)).
- `s[i]` is '0' or '1', no other characters.
- Edge Cases:
    - Very short strings: e.g. "0", "1" — should output 0.
    - No valid substrings: e.g. "0000" or "1111" — output is 0.
    - Valid overlaps: e.g. "0101" → substrings like "01", "10", "01".

---

## 3. **Optimal Algorithm**

This is a classic **group counting** problem.

### Key Observations:
- For valid substrings, we need sequences like `00...11...` (or vice versa). Count adjacent *runs* of 0's and 1's.
- For each adjacent pair of groups (e.g. 2 zeros then 3 ones), the **number of good substrings for this border** is the min of the two group sizes (here, min(2,3) = 2).
    - For "0011" → 2 zeros, 2 ones: min(2,2) = 2 (substrings: "0011", "01").

### Algorithm Steps:

1. Initialize counters: `prev_run_len` and `cur_run_len`.
2. Loop through the string:
    - If character same as previous, increment `cur_run_len`.
    - Else (group change): add `min(prev_run_len, cur_run_len)` to answer, set `prev_run_len = cur_run_len`, reset `cur_run_len = 1`.
3. After the loop, add one final `min(prev_run_len, cur_run_len)` for last group pair.
4. **Time complexity:** O(n), one pass.

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int countBinarySubstrings(string s) {
        int prev_run_len = 0, cur_run_len = 1;
        int result = 0;
        for (int i = 1; i < s.size(); ++i) {
            if (s[i] == s[i-1]) {
                ++cur_run_len;
            } else {
                result += min(prev_run_len, cur_run_len);
                prev_run_len = cur_run_len;
                cur_run_len = 1;
            }
        }
        result += min(prev_run_len, cur_run_len); // for the last group pair
        return result;
    }
};
```

---

## 5. **Example Explanation**

**Example:** `s = "00110011"`

- Let's track *consecutive runs*:

    - "00" (2 zeros)
    - "11" (2 ones)
    - "00" (2 zeros)
    - "11" (2 ones)

- Now pair-wise, for each boundary:
    - [00][11]: min(2,2) = 2  ("0011", "01")
    - [11][00]: min(2,2) = 2  ("1100", "10")
    - [00][11]: min(2,2) = 2  ("0011", "01")

- So **total = 2 + 2 + 2 = 6**.

### Valid substrings:
- "0011", "01", "1100", "10", "0011" (again), "01" (again).

## **Takeaway**

To solve efficiently, group consecutive characters, and use the minimal run length between adjacent groups — O(n) runtime and O(1) space!
