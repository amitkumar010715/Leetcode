Let's break down the solution step by step:

---

## 1. **Short Summary**

This problem is a variant of the classic take-away game (Nim), where each move consists of removing any non-zero perfect square number of stones. Given `n` stones and optimal play, determine if Alice (the first player) is guaranteed to win.

---

## 2. **Constraints & Edge Cases**

**Constraints:**
- `1 <= n <= 10^5`
- Each move removes a positive perfect square number of stones: 1, 4, 9, 16...
- Both players play optimally.

**Edge Cases:**
- `n = 1`: Only one move possible, Alice wins.
- `n` is a perfect square: Alice can win in one move.
- `n = 2, 3`: Alice cannot win if Bob plays optimally.

---

## 3. **Optimal Algorithm**

This is a **classic DP (Dynamic Programming)** game problem where for each `n`, we want to know if the "current player" (who starts with `n` stones) can force a win.

We define `dp[i] = true` if with `i` stones, the current player can force a win, else `dp[i] = false`.

**Transition:**
- For each `i` from 1 to n:
  - Try every legal move (removing `k*k` stones where `k*k <= i`).
  - If for some `k`, `dp[i - k*k] == false` (i.e., if after this move, opponent loses), then `dp[i] = true`.

**Initialization:**
- `dp[0] = false` (If there are no stones, current player loses).
- `dp[1] = true` (Alice wins by taking the last stone).

**Complexity:**  
- Time: `O(n * sqrt(n))`
- Space: `O(n)`

---

## 4. **Clean C++ Solution**

```cpp
#include <vector>
#include <cmath>

class Solution {
public:
    bool winnerSquareGame(int n) {
        std::vector<bool> dp(n + 1, false);
        for (int i = 1; i <= n; ++i) {
            for (int k = 1; k * k <= i; ++k) {
                if (!dp[i - k * k]) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
};
```

---

## 5. **Example Explanation**

**Example: `n = 2`**

- **Alice's move:**
  - Can only remove 1 stone (since 2 - 1 = 1, 2 - 4 < 0).
  - Leaves 1 stone for Bob (game state: `n = 1`).

- **Bob's move:**
  - Can remove the last 1 stone and wins.

Therefore, **Alice loses** for `n = 2`.

|---|-------------|--------------------------|

| 2 | false       | Remove 1, Bob wins       |

| 4 | true        | Remove 4, Bob loses      |

**This DP solution ensures optimal play and is efficient for `n` up to 1e5.**
