## 1. **Summary**

Given a permutation array of integers from 1 to n, build a BST by inserting the elements in the given order. Find out how many different permutations (excluding the original itself) will *construct the exact same BST structure* as the original insertion order. Return the answer modulo \(10^9 + 7\).

---

## 2. **Constraints & Edge Cases**
- **Array size:** up to 1000. O(n²) is fine, O(n³) is too slow.
- **All numbers are distinct, and arranged as a permutation (covers values 1…n).**
- **Edge cases:** 
  - `nums.size() == 1 || 2` (trivial BSTs)
  - Already sorted ascending (left-skew) or descending (right-skew).
  - BSTs with only one child per node (degenerated BSTs).
- Answer can be 0 (when BST is a chain), 1, or any number fitting in modulo.

---

## 3. **Optimal Algorithm**

### **Key Insight**
- The shape of the BST is determined by the root (first element), its left subtree (all smaller elements), and its right subtree (all larger elements), recursively.
- To get the same BST by reordering, we must always insert all left subtree elements before right subtree elements (except the root which is always first).
- The number of ways to interleave the left and right subtrees' insertion orders:
  - `comb(size(left) + size(right), size(left))`  
  (Choose which positions among the remaining elements are taken by the left subtree.)

### **High-Level Steps**
1. For the given `nums`, recursively:
   - Partition into root, left, and right (by value).
   - Recursively compute the number of reorderings for left and right subtrees.
   - Total ways: 
     \[
     C(n-1, leftSize) \times leftWays \times rightWays
     \]
   - where \( C \) is binomial coefficient ("n-1 choose leftSize").
2. Use **memoization** to avoid recomputation for the same sub-arrays.
3. Precompute binomial coefficients up to 1000.

### **Implementation Details**
- Precompute factorials and inverse factorials for fast combinatorial computations.
- To avoid TLE, use hashing or C++ unordered_map to memoize recursion on subarrays (accepting that their values are distinct and bounded).
- Finally, subtract one from the answer, since we don't count the identity permutation.

## 4. **C++ Solution**

```cpp
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    static constexpr int MOD = 1e9 + 7;
    vector<vector<long long>> comb;  // nCr table

    // Precompute C(n, k) for n, k <= nmax using Pascal's Triangle
    void buildComb(int nmax) {
        comb = vector<vector<long long>>(nmax + 1, vector<long long>(nmax + 1, 0));
        for (int i = 0; i <= nmax; ++i) {
            comb[i][0] = comb[i][i] = 1;
            for (int j = 1; j < i; ++j) {
                comb[i][j] = (comb[i-1][j-1] + comb[i-1][j]) % MOD;
            }
        }
    }

    long long dfs(const vector<int>& nums) {
        int n = nums.size();
        if (n <= 2) return 1;  // Only one possible BST for 0, 1 or 2 nodes

        vector<int> left, right;
        for (int i = 1; i < n; ++i) {
            if (nums[i] < nums[0]) left.push_back(nums[i]);
            else right.push_back(nums[i]);
        }
        long long leftWays = dfs(left);
        long long rightWays = dfs(right);

        // Number of ways to shuffle the left and right
        long long ways = comb[n-1][left.size()];
        ways = ways * leftWays % MOD;
        ways = ways * rightWays % MOD;
        return ways;
    }

    int numOfWays(vector<int>& nums) {
        int n = nums.size();
        buildComb(n);  // Precompute combinations up to size n

        long long res = dfs(nums);
        return (res + MOD - 1) % MOD;  // Exclude the original permutation
    }
};
```

## 5. **Explanation with Example**

### **Example:** `nums = [3, 4, 5, 1, 2]`

- **BST Structure:**
  - 3 is root
    - left subtree: [1, 2] (lower than 3)
    - right subtree: [4, 5] (greater than 3)

**Recursion Tree:**
- Root: 3
  - **Left [1, 2]:**
    - Root: 1, right child: 2
    - Only 1 way to arrange (must be [1, 2]) for this structure.
  - **Right [4, 5]:**
    - Root: 4, right child: 5
    - Only 1 way to arrange (must be [4, 5]) for this structure.

We interleave the left ([1,2]) and right ([4,5]) (total 4 elements) in all possible ways while preserving their respective orders:  
This is C(4,2) = 6 ways, but original ordering counts as one, so we subtract one at the end.

Now, since both subtrees have `ways = 1`, total is `6 * 1 * 1 = 6`.  
We subtract 1 at the end (the input itself), so:
- Final answer: **5**

**Hence, `numOfWays([3, 4, 5, 1, 2]) = 5`.**
