## 1. **Short Summary**

Given two non-negative integers `low` and `high`, return the count of **odd numbers** in the closed interval `[low, high]` (i.e., both endpoints included).

---

## 2. **Constraints & Edge Cases**

- Constraints: `0 <= low <= high <= 10^9`
- The interval can be very large, so **a brute-force iteration is not feasible**.
- Edge Cases:
    - The range includes only one number (i.e., `low == high`).
    - The interval includes all even numbers or all odd numbers.
    - Both `low` and `high` can be even or odd (check endpoints).

---

## 3. **Optimal Algorithm**

**Observation:**
- Every two consecutive numbers have **one odd** and **one even**.
- The count of numbers in `[low, high]` is `(high - low + 1)`.
    - In that count, about half will be odd (rounded up if odd).
- Formula:
    - **Number of odd numbers = (high - low + 1 + (low % 2) + (high % 2)) // 2**
    - But actually, it can be simplified as:  
      **(high + 1) // 2 - (low) // 2**
    - This counts how many odds are ≤ `high`, and subtract how many odds are < `low`.

**Why does this work?**
- All odd numbers up to `x` are exactly `(x + 1) // 2`
- So, odd numbers in `[low, high]` are:  
  - Odds ≤ `high` minus odds < `low` -> `(high + 1) // 2 - (low // 2)`

---

## 4. **Clean C++ Solution**

```cpp
class Solution {
public:
    int countOdds(int low, int high) {
        return (high + 1) / 2 - (low / 2);
    }
};
```

---

## 5. **Explanation of an Example**

### Example: `low = 3`, `high = 7`

- All odd numbers in `[3,7]` are **[3, 5, 7]**.
- Calculation:
    - `(high + 1) / 2 = (7 + 1) / 2 = 8 / 2 = 4` (count of odds upto 7)
    - `(low) / 2 = 3 / 2 = 1` (count of odds upto 2)
    - **Result = 4 - 1 = 3**
- So, answer is **3** (matching with the actual numbers).

---

**Summary of Approach:**  
Just compute `(high + 1) / 2 - (low / 2)` for an O(1) and very efficient solution. No iteration is needed!
