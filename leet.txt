## 1. **Short summary**

Given an array `nums`, find the length of the **longest subsequence** whose elements' bitwise **XOR is non-zero**. Return 0 if all subsequences have zero XOR.

---

## 2. **Constraints & Edge Cases**

- **Constraints:**
    - 1 ≤ nums.length ≤ 1e5
    - 0 ≤ nums[i] ≤ 1e9

- **Edge Cases:**
    - If all elements are zero, any non-empty subsequence will have XOR zero.
    - If the whole array's XOR is non-zero, using the whole array is the answer.
    - If the whole array's XOR is zero, we want the longest possible subsequence with non-zero XOR (possibly the array minus one element).

---

## 3. **Optimal Algorithm**

### **Observation**
- **Key point:** XOR of the whole array (let's call it `totalXor`) tells us much:
    - If `totalXor != 0`, the full array is a valid, maximal subsequence: answer is `n`.
    - If `totalXor == 0`, ANY subsequence missing one element will have non-zero XOR **if and only if** that one element is NOT zero itself (because removing a non-zero element changes the XOR, and may result in non-zero).
    - But for any length > n-1, we must include the whole array, which would have XOR 0.

### **Implementation Plan**
1. Compute the XOR of all elements (`totalXor`).
2. If `totalXor != 0`, return `n` (whole array length).
3. If `totalXor == 0`, any subsequence missing **any one element** could have nonzero XOR, but that’s not necessarily true for all subsets—let’s check if it's possible.
   - Actually, by removing any one element, the XOR becomes "totalXor ^ nums[i]" which is just `nums[i]`, so:
      - If any single element is **non-zero**, then removing it, XOR of the rest is NOT zero (`nums[i]`).
      - If all elements are zero, then "totalXor" is zero and any removal will still return 0 for the rest, so answer is 0.
   - Thus, if there is at least one non-zero element, answer is `n-1`. Otherwise 0.

**Time complexity:** O(n).

---

## 4. **C++ Solution**

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int longestSubsequence(vector<int>& nums) {
        int n = nums.size();
        int totalXor = 0;
        bool hasNonZero = false;
        for (int x : nums) {
            totalXor ^= x;
            if (x != 0) hasNonZero = true;
        }
        if (totalXor != 0) 
            return n;
        // totalXor == 0
        return hasNonZero ? n - 1 : 0;
    }
};
```

---

## 5. **Example Explained**

**Example:** `nums = [1, 2, 3]`

- Compute `totalXor`:
    - 1 ^ 2 = 3
    - 3 ^ 3 = 0
- So `totalXor == 0`.
- At least one element is non-zero (all are!).
- Therefore, the maximal length is `n - 1 = 3 - 1 = 2`.

**Explanation:** Any 2-element subsequence will have XOR non-zero:  
- [1,2] → 3  
- [1,3] → 2  
- [2,3] → 1  
So answer is **2**.
