## 1. Short Summary

Given an array `nums`, we are to find the *smallest index* `i` such that the **sum of the digits** of `nums[i]` equals `i`. If no such index exists, return `-1`.

---

## 2. Constraints & Edge Cases

- **Constraints:**
  - `1 <= nums.length <= 100` &rarr; small array, so linear search is fine.
  - `0 <= nums[i] <= 1000` &rarr; values are at most 4 digits.
- **Edge Cases:**
  - All `nums[i]` have a digit sum not equal to index &rarr; Output should be `-1`.
  - More than one index matches &rarr; Return the smallest index.
  - `nums[i]` could be `0` (digit sum is `0`).
  - Array of length `1` (minimal case).
  - `nums[i]` with leading zeros isn't possible (no such representation for int).

---

## 3. Optimal Algorithm

Given small constraints, a linear search is acceptable.

**Algorithm:**
1. For each index `i`, compute digit sum of `nums[i]`.
2. If digit sum == `i`, return `i` immediately.
3. If none found, return -1.

Digit-sum can be calculated using:
```cpp
int digitSum(int x) {
    int sum = 0;
    while (x > 0) { sum += x % 10; x /= 10; }
    return sum;
}
```
But for `x == 0`, ensure it returns 0.

**Time Complexity:**  
O(n · d), where n = length of `nums`, d = number of digits (≤4), so overall O(n).

---

## 4. Clean C++ Solution

```cpp
class Solution {
public:
    int digitSum(int x) {
        int sum = 0;
        if (x == 0) return 0;    // Handle single zero case
        while (x > 0) {
            sum += x % 10;
            x /= 10;
        }
        return sum;
    }
    
    int smallestEqual(vector<int>& nums) {
        int n = nums.size();
        for (int i = 0; i < n; ++i) {
            if (digitSum(nums[i]) == i) {
                return i;
            }
        }
        return -1;
    }
};
```

---

## 5. Example Explanation

Take **Example 2**:

**Input:** `nums = [1,10,11]`

We look at each index:
- i = 0: `nums[0] = 1` → digit sum is 1 ≠ 0
- i = 1: `nums[1] = 10` → digit sum is 1 + 0 = 1 == 1 → This matches!  
- i = 2: `nums[2] = 11` → digit sum is 1 + 1 = 2 == 2 (also matches, but index is larger)

Since we want the **smallest index**, the answer is **1**.
