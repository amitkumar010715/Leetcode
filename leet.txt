## 1. **Short Summary**

Given two integers, `left` and `right`, count how many numbers in the range `[left, right]` (inclusive) have a **prime number of set bits** in their binary representation (the number of `1`'s in their binary form).

---

## 2. **Constraints & Edge Cases**

- `1 ≤ left ≤ right ≤ 10^6`
- `0 ≤ right - left ≤ 10^4`  
  (At most ~10,000 numbers to check – brute force per number is acceptable.)
- The max number (`right`) is `10^6` (about 20 bits in binary).
- **Edge cases:**
    - Minimal range: `left == right` (single number).
    - Numbers whose binary representation has very few set bits (e.g., powers of 2).
    - Largest possible range (`right - left = 10,000`).
    - `1` is not a prime, so a number with `1` set bit (i.e., powers of two) should not be counted.

---

## 3. **Optimal Algorithm**

- **Step 1:** Precompute all **prime numbers** up to 20 (since max bits for `10^6` is ~20), and store in a set (for fast lookup).
- **Step 2:** For every `n` in `[left, right]`:
    - Count the number of set bits in its binary representation (`__builtin_popcount` in C++).
    - If the set bit count is prime (from our set), increment answer.
- **Step 3:** Return the result.

- **Complexity:**  
  For each of up to 10,001 numbers, you count up to 20 bits:  
  O(N), where N = `right-left+1` (≤ 10^4).

---

## 4. **C++ Solution**

```cpp
#include <unordered_set>
using namespace std;

class Solution {
public:
    // Precompute all primes up to 20
    bool isPrime(int x) {
        static unordered_set<int> primes{2, 3, 5, 7, 11, 13, 17, 19};
        return primes.count(x) > 0;
    }
    
    int countPrimeSetBits(int left, int right) {
        int count = 0;
        for (int n = left; n <= right; ++n) {
            int bits = __builtin_popcount(n);
            if (isPrime(bits)) ++count;
        }
        return count;
    }
};
```
